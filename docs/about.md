# 关于本站

## 定位

Hackdion 的个人网站，用于分享个人知识整理、学习课程与项目实践。工程知识与注册监理工程师课程是本站知识库与课程中心栏目的一部分，不代表网站全部内容。

## 内容发布规则

- 公开内容先完成整理与 AI 核对，再通过自动构建与发布边界检查，经用户确认公开发布授权后上线；发布不再逐次等待人工验收。
- AI 核对与人工验收分开记录，不把 AI 核对写成人工验收。
- 未取得公开发布授权的素材、原始 PDF、待审核原料与内部管理资料不出现在网站与公开仓库中。
- 页面不使用假数据冒充真实内容，暂未发布的栏目如实标注。

## 技术说明

- 框架：VitePress + Vue 3，纯静态站点，无数据库、无用户系统、无后台管理。
- 部署：GitHub Pages，推送 main 分支后由 GitHub Actions 自动构建；发布前执行发布边界检查（`npm run check`），检查失败会阻断部署。
- 大陆访问提示：`github.io` 在中国大陆访问可能不稳定；正式面向国内用户时计划迁移至腾讯云 EdgeOne Makers。
