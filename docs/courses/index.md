# 课程

本站提供系统化在线课程，每门课程可按以下四种模式学习（以实际已发布素材为准）：

| 模式 | 说明 |
| --- | --- |
| 文章阅读 | 课程配套文字内容，适合快速浏览与查阅 |
| 音频 + 文本阅读 | 课程音频配合文本同步学习 |
| OpenMAIC 互动课件 | 可交互的离线课件，支持翻页与练习 |
| 完整课程视频 | 完整录播视频，沉浸式学习 |

## 课程列表

- [第3课 · 互动课件示例](./lesson3) — 《建设工程监理概论》第3课，OpenMAIC 互动课件已上线（示例课程，本地预览）。

## 如何新增课程

1. 将课程素材（课件、音频、视频等）放入 `docs/public/media/<课程目录>/` 下对应子目录。
2. 在 `docs/courses/` 下新建课程详情页（可参考 `lesson3.md` 的四种模式结构）。
3. 在本页「课程列表」中添加入口，并在 `docs/.vitepress/config.mts` 的 `/courses/` 侧边栏中登记。
4. 未就绪的素材模式请在课程页中标注「暂未发布」，不要虚构链接。
