# 课程中心

基于 OpenMAIC 制作的系统化课程。每门课程可按以下四种模式学习（以实际已发布素材为准）：

| 模式 | 说明 |
| --- | --- |
| 文章阅读 | 课程配套文字内容，适合快速浏览与查阅 |
| 音频 + 文本阅读 | 课程音频配合文本同步学习 |
| OpenMAIC 互动课件 | 可交互的离线课件，支持翻页与练习 |
| 完整课程视频 | 完整录播视频，沉浸式学习 |

## 课程列表

- [建设工程监理概论 · 第3课](./lesson3) — 内容质量已验收，公开发布授权待确认，**暂未发布**。

## 发布规则

课程上线需同时满足两个条件：**内容人工验收通过** + **公开发布授权确认**。缺任一条件时，课程页将如实标注状态，不以提示文字代替实际的素材隔离。

## 如何新增课程

1. 课程素材（课件、音频、视频等）先放入 `待审核素材/`，完成人工验收并确认公开发布授权。
2. 将已授权素材放入 `docs/public/media/<课程目录>/` 下对应子目录。
3. 在 `docs/courses/` 下新建课程详情页（参考 `lesson3.md` 的四种模式结构）。
4. 在本页「课程列表」中添加入口，并在 `docs/.vitepress/config.mts` 的 `/courses/` 侧边栏中登记。
5. 未就绪的素材模式请在课程页中标注「暂未发布」，不要虚构链接。
