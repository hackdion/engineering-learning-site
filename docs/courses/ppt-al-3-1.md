## 招标投标与合同管理：三段一条线

<p class="dk-lead">监理招标解决<strong>选谁</strong>，监理投标解决<strong>怎么被选中</strong>，监理合同解决<strong>选完以后各自干什么</strong>。</p>

- **招标**：公开招标与邀请招标两种方式，八个环节走完程序，评标分初步评审和详细评审两道关。
- **投标**：先决策投不投，再编投标文件，核心是监理大纲，最后靠六条策略提高中标率。
- **合同**：《标准监理招标文件（2017 年版）》由通用条款和专用条款组成，另附合同协议书与履约保证金格式。
- **一条主线**：招标文件写规则，投标文件作响应，合同文件定权责，三者前后咬合。

<template #notes>

先立三段式框架：招标是建设单位的动作，投标是监理单位的动作，合同是双方动作的落点。本节考点密集在评标规则（否决投标、同分排序）和合同文件优先解释顺序，这两处后面都会单独展开。提醒学生：这三段不是三门课，而是一条链条——招标文件的要求，投标文件必须响应，最后变成合同的组成部分。

</template>

</Slide>

  { t: '认真研究招标文件，深入领会意图', d: '弄清监理范围、目标、评标权重和建设单位的真实关注点，再决定怎么写' },
  { t: '内容详细、层次分明、重点突出', d: '该细的地方细，该突出的重点放在前面，让评标委员会一眼看到得分点' }
]" />

**投标文件的核心是监理大纲**，尤其是针对工程具体情况制定的监理对策和向建设单位提出的原则性建议。

<span class="dk-tag">工程概况</span><span class="dk-tag">监理依据和监理工作内容</span><span class="dk-tag">工程监理实施方案</span><span class="dk-tag">工程监理难点、重点及合理化建议</span>

<template #notes>

三原则里第一条是生死线：不响应就废标，后面写得再好也没用。监理大纲四项内容要背，注意第四项是「难点、重点及合理化建议」，这一项最能体现针对性，也是评标打分的重点。可以提醒学生，投标文件不是越厚越好，而是要点对得上评标办法的评分表。

<template #notes>

六条策略不是并列的口号，有先后：先分析因素，再读懂文件，然后选策略、配机构、提建议，最后靠答辩落地。案例题里如果问「如何提高中标率」，就按这六条答，比只写「降低报价」全面得多。特别提醒：答辩的关键是总监，不是随便派个人去讲。

## 监理合同：两条款加两个附件

<Steps title="《标准监理招标文件（2017 年版）》的组成" :steps="[
  { t: '通用合同条款', d: '共 12 条：一般约定、委托人义务、委托人管理、监理人义务、监理要求、开始监理和完成监理、监理责任与保险、合同变更、合同价格与支付、不可抗力、违约、争议解决' },
  { t: '专用合同条款', d: '对通用合同条款的细化、完善、补充、修改或另行约定，由当事人按工程特点谈判协商确定' },
  { t: '合同协议书格式', d: '订立合同时采用的规范化文件，明确当事人、监理范围、期限、报酬等基本事项' },
  { t: '履约保证金格式', d: '与合同协议书同属合同附件格式，用于担保监理人按约履行' }
]" />

> 通用条款管「共性」，专用条款管「个性」；专用条款可以改通用条款，但要把改的内容写清楚。

<template #notes>

12 条通用条款不必逐条死背，但要能说出结构：先约定一般事项和双方义务，再讲监理要求与期限，然后是责任保险、变更、价格支付、不可抗力、违约和争议解决。专用条款的定位要讲透：它不是另起一套，而是对通用的细化、补充、修改，所以解释顺序上专用优先于通用。

</template>

## 排序：合同文件的优先解释顺序

<SortSteps id="ppt-al-3-1-order" prompt="合同文件发生不一致时，按优先解释顺序从高到低排一排" :items="[
  '合同协议书',
  '中标通知书',
  '投标函及投标函附录',
  '专用合同条款',
  '通用合同条款',
  '委托人要求',
  '监理报酬清单',
  '监理大纲',
  '其他合同文件'

> 记法：**先协议、再中标、后投标函；条款专用压通用；要求、报酬、大纲依次排；其他文件垫底**。

<template #notes>

这九项顺序是本节最典型的排序考点。逻辑上很好理解：越能体现双方最终合意的越靠前——协议书是最后签的，中标通知书是承诺，投标函是报价承诺，然后才是条款和技术性文件。专用条款排在通用条款之前，因为专用是对通用的修改。监理大纲排在报酬清单之后，说明大纲主要是技术文件，不决定价格。除专用条款另有约定外才适用这个顺序，这句话不要漏。

</template>

</Slide>

  { t: '其他义务', d: '履行合同约定的其他义务' }

<Reveal label="紧急情况下口头指示，24 小时这条线怎么算？">

委托人代表或其授权人员可以当场签发**临时书面指示**，监理人应遵照执行；委托人代表应在临时书面指示发出后 **24 小时内发出书面确认函**，逾期未发，该临时书面指示**视为委托人的正式指示**。

</Reveal>

<template #notes>

委托人的指示有两个形式要求：盖单位章、委托人代表签字确认，缺一不可。24 小时这条线要讲清因果：不是指示无效，而是逾期未确认就自动转为正式指示，监理人照做有依据。委托人指示延误或错误造成费用增加、工期延误的，由委托人承担，这是后面索赔题的常见起点。

</template>

## 小结：规则写在招标文件，权责落在合同文件

<p class="dk-lead">招标定规则，投标作响应，合同定权责；三份文件里，解释顺序就是解决分歧的那把尺子。</p>

- **招标**：公开与邀请两种方式；六段程序；评标看单位、人员、大纲、设备、报价五项；初步评审一票否决，详细评审综合评估法排序。
- **投标**：决策两问加综合评价法、决策树法；文件编制三原则；核心是监理大纲四项；六条策略里答辩关键在总监。
- **合同**：通用条款 12 条加专用条款，另附协议书和履约保证金格式；优先解释顺序九项，协议书第一、大纲第八。
- **两个高频数字**：临时书面指示 24 小时内书面确认；监理规划在第一次工地会议 7 天前报委托人。
