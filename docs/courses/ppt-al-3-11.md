## 缺陷与事故：先认成因，再走程序

<p class="dk-lead">质量缺陷要<strong>查成因、按程序处理</strong>，质量事故要<strong>报告、调查、处罚、处理</strong>四步走。</p>

- **常见缺陷**：不均匀沉降、混凝土裂缝、构件变形、强度不合格、墙体裂缝、建筑渗漏六类。
- **缺陷处理**：六步程序，修补、返工、不做处理三种方法。
- **事故处理**：24 小时内报告，调查附具证据材料，调查组成员签名，依法处罚。
- **一条主线**：缺陷按程序修补，事故依法定程序追责。

<template #notes>

本节分两块：缺陷和事故。缺陷是「质量瑕疵」，按程序处理；事故是「已造成后果」，要依法报告调查。关键数字是 24 小时报告时限，关键程序是缺陷处理的六步和三种处理方法。先立这个「缺陷走程序、事故走法定」的区分。

## 缺陷与事故的边界：为什么程序不同

<Reveal label="质量缺陷和质量事故有什么区别？">

质量缺陷是工程未达到规定要求、但尚未造成较大损失的质量问题，按缺陷处理程序修补即可；质量事故是已造成人员伤亡或经济损失、需依法报告调查的事件。两者的分界在于**后果的严重程度**，处理的程序和法律后果也随之不同。

</Reveal>

<CompareCard title="缺陷处理与事故处理对照（可点击「遮住自测」）" :cols="['质量缺陷处理', '质量事故处理']" :rows="[
  { k: '性质', v: ['未达到规定要求的质量问题', '已造成后果、需依法处理的事件'] },
  { k: '程序', v: ['通知—查因—审方案—实施验收—费用—归档', '24 小时报告—调查—处罚—处理'] },
  { k: '方法', v: ['修补、返工、不做处理', '依法追责并处理结构安全和功能问题'] }
]" />

<template #notes>

缺陷和事故的分界是后果严重程度。缺陷走监理主导的六步程序，事故走法律法规主导的四步程序。考试常让判断「某情况是缺陷还是事故」，抓手就是后果：已造成人员伤亡或较大损失就是事故，否则按缺陷处理。

</template>

</Slide>

## 小结：缺陷按程序，事故按法规

<p class="dk-lead">缺陷按程序修补，事故按法规追责。</p>

- **缺陷**：六类常见缺陷各有成因，处理走六步程序，方法分修补、返工、不做处理。
- **事故**：24 小时报告，调查附证据、成员签名，依法处罚并处理结构安全和功能问题。
- **边界**：后果严重程度决定是缺陷还是事故，程序和法律后果随之不同。
