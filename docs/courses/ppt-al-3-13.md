## 建安工程费：两套口径，一张总账

<p class="dk-lead">同一笔建安工程费，可以按<strong>费用构成要素</strong>拆成七项，也可以按<strong>造价形成</strong>拆成五项，两套口径必须能对上。</p>

- **按构成要素**：人工费、材料费（含工程设备）、施工机具使用费、企业管理费、利润、规费、税金。
- **按造价形成**：分部分项工程费、措施项目费、其他项目费、规费、税金。
- **对应关系**：前五项要素费用装进前三种造价费用，规费和税金单列，两套口径首尾一致。
- **总账思路**：建安工程费只是工程费用的一部分，往上还有设备购置费、工程建设其他费、预备费、建设期利息和流动资金。

<template #notes>

这一节是投资控制的计算底座，概念多但结构清楚。开场先把两套口径立住：按要素是「钱花在什么上」，按造价形成是「钱花在哪个清单里」。学生最容易犯的错是把两套口径混着用，比如把企业管理费直接列进措施项目费，或者把规费算进分部分项工程费。后面每一页都围绕这个对应关系展开。

## 设备购置费：原价、抵岸价、运杂费

<Steps title="设备购置费的三个计算口径" :steps="[
  { t: '国产标准设备原价', d: '一般指设备制造厂的交货价，即出厂价；带有备件的原价应按带有备件的出厂价计算' },
  { t: '国产非标准设备原价', d: '有多种计算方法，包括成本计算估价法、系列设备插入估价法、分部组合估价法、定额估价法等' },
  { t: '进口设备抵岸价', d: '设备抵达买方边境、港口或车站，缴纳完各种手续费、税费后形成的价格，由到岸价（CIF）和进口从属费用构成' },
  { t: '设备运杂费', d: '设备原价（或进口设备抵岸价）中未包括的包装和包装材料器具费、运输费、装卸费、采购费及仓库保管费、供销部门手续费等' }
]" />

进口设备采用装运港船上交货价（FOB）时：

$$
\begin{aligned}
\text{进口设备抵岸价} = {} & \text{进口设备货价} + \text{国外运费} + \text{国外运输保险费} + \text{银行财务费} \\
& + \text{外贸手续费} + \text{进口关税} + \text{增值税} + \text{消费税}
\end{aligned}
$$

$$
\text{设备运杂费} = \text{设备原价(或进口设备抵岸价)} \times \text{设备运杂费费率}
$$

<template #notes>

设备购置费的关键是分清三个价：出厂价、抵岸价、运杂费后的购置费。抵岸价的八项按「货价—运费—保险费—两笔手续费—关税—增值税—消费税」的顺序记，前四项属于到岸价加费用，后四项是从属税费。常见错误是把设备运杂费也算进抵岸价，抵岸价只到边境或港口，运杂费是抵岸之后运到工地的费用。进口设备的交货方式分内陆交货、目的地交货、装运港交货三类，FOB 属于装运港交货类。

</template>

</Slide>

## 工程建设其他费：十五类，按阶段记

<Reveal label="十五类其他费各是什么？（点击展开）">

- **土地与补偿**：土地使用费和其他补偿费。
- **建设管理费**：建设单位管理费、工程监理费、设备监造费、招标投标费、设计评审费、特殊项目定额研究及测定费、其他咨询费、印花税。
- **前期工作咨询费**：专题研究、项目申请报告、项目建议书、可行性研究报告等咨询费用。
- **专项评价费**：环评、安全预评价、职业病危害评价、地震安全性评价、地质灾害评价、水土保持评价、压覆矿产评价、节能评估、社会稳定风险评估等。
- **研究试验费、勘察设计费**：含 BIM 技术应用服务费。
- **场地准备费和临时设施费**：场地平整、余留设施拆除清理，以及未列入工程费用的临时水、电、路、信、气和临时建（构）筑物费用。
- **引进技术和进口设备材料其他费、特殊设备安全监督检验费和标定费**。
- **市政公用配套设施费、联合试运转费、保险费、专利及专有技术使用费、生产准备费、其他费用**。

</Reveal>

> 计费原则一句话：**必须或应该发生时计费，不发生时不计费**。

<template #notes>

十五类不要求逐条默写，但要能按「土地—管理—前期—评价—勘察设计—场地—引进—试运转—保险—生产准备」的时间线归类。考试常考三个判断：工程监理费属于建设管理费；勘察设计费含 BIM 服务费；其他费「不发生不计费」，不是概算里列了就一定要花。保险费的免责要点是：不包括已列入施工企业管理费的施工管理用财产、车辆保险费。

</template>

## 预备费：基本预备费与涨价预备费

<Steps title="两类预备费的计算" :steps="[
  { t: '基本预备费', d: '指在项目实施中可能发生难以预料的支出，需要预先预留的费用，又称不可预见费，主要用于设计变更及施工过程中可能增加工程量的费用' },
  { t: '基本预备费计算', d: '以工程费用和工程建设其他费用之和为基数，乘以基本预备费费率' },
  { t: '涨价预备费', d: '指建设项目在建设期内由于价格等变化引起工程造价变化的预测预留费用' },
  { t: '涨价预备费计算', d: '按建设期内各年投资计划额，考虑建设期价格上涨指数，逐年计算后求和' }
]" />

$$
\text{基本预备费} = (\text{工程费用} + \text{工程建设其他费用}) \times \text{基本预备费费率}
$$

$$
P = \sum_{t=1}^{n} I_t \left[(1+f)^m (1+f)^{0.5} (1+f)^{t-1} - 1\right]
$$

> 式中：$I_t$ 为第 $t$ 年投资计划额；$f$ 为价格上涨指数；$m$ 为建设前期年限。

<template #notes>

两个预备费不要混：基本预备费管「量变」，应对设计变更和工程量增加；涨价预备费管「价变」，应对建设期价格上涨。基本预备费的基数一定要背准，是工程费用加工程建设其他费，不含建设期利息。涨价预备费的公式看起来复杂，抓住三点：按年投资额加权、建设前期按 m 年复利、当年按半年计。案例题里通常给简化条件，按题目给的指数代入即可。

</template>

</Slide>

## 建设期利息与流动资金

<Reveal label="建设期利息到底包含哪些？为什么按半年计息？">

建设期利息包括各类借款利息、债券利息、贷款评估费、国外借款手续费及承诺费、汇兑损益、债券发行费用及其他债务利息支出或融资费用。

$$
Q = \sum_{j=1}^{n} (P_{j-1} + A_j / 2) \, i
$$

式中：$Q$ 为建设期利息；$P_{j-1}$ 为建设期第 $j-1$ 年末借款累计余额；$A_j$ 为建设期第 $j$ 年借款额；$i$ 为年利率。当年借款按半年计息，是因为借款在年度内均衡发生，近似取年中时点。

</Reveal>

- **流动资金估算**：扩大指标估算法、分项详细估算法两种。
- **扩大指标估算法**：参照同类企业流动资金占营业收入、经营成本、建设投资的比例，或单位产量占用流动资金额估算。
- **分项详细估算法**：分别估算存货、现金、应收账款、应付账款等分项，再汇总得出流动资金。

<template #notes>

建设期利息的公式要会代：上年末累计余额全额计息，当年新增借款按一半计息，这是「均衡发生」假设的结果。案例题常把建设期利息漏掉，导致总投资算少。流动资金两种估算法要能说出适用场景：扩大指标法用于机会研究或初步可行性研究阶段，精度低；分项详细法用于可行性研究阶段，精度高。流动资金是总投资的一部分，但借款利息只算建设期。

</template>

</Slide>

## 小结：两套口径，一条总账

<p class="dk-lead">按要素看钱花在什么上，按造价形成看钱花在哪个清单里，两套口径必须能对上。</p>

- **两套口径**：要素七项（人材机管利规税）；造价形成五项（分部分项、措施、其他、规费、税金）。
- **四项费用**：人工费五项、材料费四项、机具使用费两类、企业管理费十七项，检验试验费在企管费。
- **三个公式**：基本预备费以工程费用加其他费为基数；涨价预备费按年投资额加权；建设期利息当年借款按半年计息。
- **两个易错**：暂列金额由发包人掌握、未发生应扣除；脚手架工程费属于措施项目费，不是分部分项工程费。
