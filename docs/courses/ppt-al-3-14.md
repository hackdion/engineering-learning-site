## 施工阶段投资控制：五步闭环

<p class="dk-lead">投资控制不是最后一个结算数字，而是<strong>计划、计量、调价、支付、纠偏</strong>五步不断循环。</p>

- **计划**：协助建设单位编制资金使用计划，把总目标值分解为分目标值和详细目标值。
- **计量**：工程量的正确计量是发包人向承包人支付合同价款的依据。
- **调价**：清单缺陷、暂列金额、暂估价、物价变化、法规变化，都要按合同约定调整。
- **支付**：预付款、安全生产措施费、进度款、施工过程结算、竣工结算依次推进。
- **纠偏**：用挣值法比较计划值与实际值，分析偏差原因并采取措施。

<template #notes>

这一节内容多，先用一条闭环把八个小节串起来。计划是起点，计量是支付的前提，调价和支付是过程控制，纠偏是反馈。案例题往往只给其中一段，但要能说清它处在闭环的哪个位置。提醒学生：投资控制的第一责任人是建设单位，监理是协助和审核，不能越位替建设单位拍板。

]" />

<Reveal label="计日工适用于哪些情形？（点击展开十种）">

1. 不能依据施工图纸、工程变更及合同约定计量规则计量的增加工程或替代工程；
2. 按发包人要求增加的短工期、零星、有限工程范围、工程数量少的工程项目；
3. 极端变化的工作条件导致的非正常操作；
4. 进行紧急工程引致其他工程损坏的修复；
5. 按发包人要求打开已隐蔽工程，但相关工程经检测证明符合合同要求；
6. 修复其他承包人完成工作后周边受影响工程的费用；
7. 因发包人暂缓（停）工程引致工程延期而必须更换的材料设备费用；
8. 合同外发包人特殊要求的清扫和清场工作；
9. 合同外发包人要求的测试运行；
10. 非承包人原因导致的修复和恢复被损坏的微小工程（大规模损坏恢复按工程变更计量计价）。

</Reveal>

<template #notes>

六类计量里，措施项目计量最容易被忽略：已标价清单的措施项目原则上不予计量调整，只有合同另有约定或工程变更规定应计量的才调整。计日工十种情形不用逐条背，抓住共同点：零星、临时、无法按图纸或清单规则计量、由发包人要求引起。返工计量的前提是「工程变更或发包人责任事件」，承包人自己原因造成的返工不能计量。

## 物价变化：两种调差方法

<Steps title="物价变化调差的两种方法" :steps="[
  { t: '价格指数调差法', d: '根据招标人提供的附录，承包人提供可调价主要材料表，采用投标函附录中的价格指数和权重表约定的数据，计算差额调整合同价格' },
  { t: '价格指数法公式', d: '以签约合同价为基数，按定值权重 A 和各可调因子权重 B 加权计算现行指数与基本指数之比，再减去 1 得到调整系数' },
  { t: '价格信息调差法', d: '根据招标人提供的附录，承包人提供可调价主要材料表，采用投标函附录中的价格数据，按差额计算调整合同价格' },
  { t: '价格信息法公式', d: '只对实际价格变化超过合同约定风险幅度的部分调整，即差额减去承包人应承担的风险幅度乘以基期价格' }
]" />

$$
\Delta P = P_0 \left[ A + \left( B_1 \times \frac{F_{t1}}{F_{01}} + B_2 \times \frac{F_{t2}}{F_{02}} + \cdots + B_n \times \frac{F_{tn}}{F_{0n}} \right) - 1 \right]
$$

$$
\Delta P = (\Delta C - C_0 \times r)Q \ \text{，其中 } |\Delta C| > |C_0 r|,\quad \Delta C = C_i - C_0
$$

<template #notes>

两种方法的选择看数据条件：有价格指数和权重表就用指数法，只有价格数据就用信息法。指数法的权重之和加上定值权重等于 1，这是校验公式对不对的简便办法。信息法的核心是承包人承担风险幅度 r，只调超过部分，未超过不调。案例题常把两种方法的适用条件互换来设错，读题时先看题目给的是指数还是价格。

</template>

</Slide>

这条规则的本质是「谁的原因谁承担不利后果」。承包人原因延期，延期期间涨价不给补、降价要扣；发包人原因延期，降价不扣、涨价要补。四类法规变化要记全：新增、修改、废止、政府解释变化，缺一不可。基准日是分界线，基准日之前的变化已经包含在合同价里。

## 挣值法：三个参数、四个指标

<Steps title="挣值法的计算体系" :steps="[
  { t: '三个基本参数', d: '已完工作预算投资 BCWP = 已完成工作量 × 预算单价；计划工作预算投资 BCWS = 计划工作量 × 预算单价；已完工作实际投资 ACWP = 已完成工作量 × 实际单价' },
  { t: '投资偏差与进度偏差', d: 'CV = BCWP - ACWP，负值表示超支、正值表示节支；SV = BCWP - BCWS，负值表示延误、正值表示提前' },
  { t: '两个绩效指数', d: 'CPI = BCWP / ACWP，小于 1 表示投资超支、大于 1 表示投资节省；SPI = BCWP / BCWS，小于 1 表示进度延误、大于 1 表示进度提前' },
  { t: '完工预测', d: 'BAC 为项目完工预算，EAC 为预测的项目完工估算，VAC = BAC - EAC；VAC 为负表示预计超支，为正表示预计节支' },
  { t: '偏差原因与纠偏', d: '偏差原因归纳为物价上涨、设计、业主、施工和客观五类；纠偏可采用组织措施、经济措施、技术措施和合同措施' }
]" />

$$
\text{CV} = \text{BCWP} - \text{ACWP}, \qquad \text{SV} = \text{BCWP} - \text{BCWS}
$$

$$
\text{CPI} = \frac{\text{BCWP}}{\text{ACWP}}, \qquad \text{SPI} = \frac{\text{BCWP}}{\text{BCWS}}, \qquad \text{VAC} = \text{BAC} - \text{EAC}
$$

<template #notes>

挣值法只要记住「两个减法、两个除法」：CV 和 SV 是减法，CPI 和 SPI 是除法，分子都是 BCWP。正负号的判断口诀是「负超支、负延误」，因为 BCWP 减 ACWP 为负说明花的比挣的多，BCWP 减 BCWS 为负说明干得比计划少。EAC 的三种估算情形也要知道：按当前趋势、重新估计剩余工作、剩余预算不变。

</template>

</Slide>

## 小结：五个动作守住投资

<p class="dk-lead">计划定目标，计量定数量，调价定单价，支付定时点，纠偏定方向。</p>

- **计划**：三种分解（构成、子项目、时间），三种形式（计划表、S 形曲线、综合表）；S 形曲线按最迟开始省利息但降低竣工保证率。
- **计量**：分部分项、措施、变更、计日工、返工、新增六类；措施项目原则上不计量调整。
- **调价**：清单缺陷 15% 门槛、暂列金额归发包人、暂估价以税前价取代、物价两法、法规变化看责任方。
- **支付与结算**：安措费 28 天 50% 不扣回、过程结算不低于 80%、履约担保与质保金不并存。
- **纠偏**：挣值法两减法两除法，偏差原因五类，纠偏措施四类。
