## 流水施工：让时间和空间都不空着

<p class="dk-lead">流水施工把工程对象拆成施工过程，组建专业工作队，让各队在<strong>不同施工段上连续作业</strong>，相邻两队最大限度搭接。</p>

- **三种组织方式**：依次施工、平行施工、流水施工。
- **三类参数**：工艺参数、空间参数、时间参数。
- **三种流水**：固定节拍、成倍节拍（一般与加快）、非节奏。
- **一条主线**：先判断节奏类型，再定流水步距，最后代工期公式。

<template #notes>

这一节是进度控制里最讲「套路」的一节，公式不多但容易代错。开场先把流水施工的定义说清：拆过程、组专业队、连续作业、最大搭接。三个关键词——连续、均衡、有节奏——是判断流水施工优点的依据。学完这一节要能做到：拿到一张流水节拍表，先判断属于哪种流水，再选对应公式。

## 三类参数：工艺、空间、时间

<Steps title="流水施工参数的三个大类" :steps="[

  { t: '施工过程', d: '根据施工组织及计划安排需要划分的工序、分项工程或分部工程，其数目用 n 表示，是流水施工的基本参数' },

  { t: '空间参数', d: '表达流水施工在空间布置上开展状态的参数，通常包括工作面和施工段' },

- **工作面**：某专业工种的工人或某种施工机械进行施工的活动空间。
- **施工段**：将施工对象在平面或空间上划分成若干个劳动量大致相等的施工段落，数目用 m 表示。
- **流水节拍**：某个专业工作队在一个施工段上的施工时间，用 t 表示。
- **流水步距**：相邻两个专业工作队在同一施工段上开始施工的时间间隔，用 K 表示。

<template #notes>

参数分三类，记号要记牢：n 是施工过程数，m 是施工段数，t 是流水节拍，K 是流水步距，T 是工期。学生最容易把流水节拍和流水步距混：节拍是「一个队在一个段上干多久」，步距是「相邻两队相继投入的时间差」。固定节拍时两者数值相等，但概念不同，简答题要写准。

</template>

## 固定节拍：四个特点

<Steps title="固定节拍流水施工的四个特点" :steps="[
  { t: '节拍全等', d: '所有施工过程在各个施工段上的流水节拍均相等，即 t 为常数' },
  { t: '步距等于节拍', d: '相邻施工过程的流水步距相等，且等于流水节拍，即 K = t' },
  { t: '队数等于过程数', d: '专业工作队数等于施工过程数，每一个施工过程成立一个专业工作队，由该队完成相应施工过程所有施工段上的任务' },
  { t: '连续作业无空闲', d: '各个专业工作队在各施工段上能够连续作业，施工段之间一般没有空闲时间' }
]" />

> 判断口诀：**节拍全等、步距等节拍、队数等过程数、段间不空闲**。

<template #notes>

四个特点是配套的：因为节拍全等，所以步距等于节拍；因为一队干一个过程，所以队数等于过程数；因为步距整齐，所以段间不空闲。这四条也是判断「某工程能不能按固定节拍组织」的依据，只要节拍不全等，就不能套固定节拍公式。

</template>

</Slide>

## 固定节拍工期：两个公式，看有没有间歇和插入

<Reveal label="有间歇、有提前插入时，工期怎么算？">

有间歇时间（工艺间歇 G、组织间歇 Z）时：

$$
T = (n-1)t + \Sigma G + \Sigma Z + m \cdot t = (m+n-1)t + \Sigma G + \Sigma Z
$$

有提前插入时间（C）时：

$$
T = (n-1)t + \Sigma G + \Sigma Z - \Sigma C + m \cdot t = (m+n-1)t + \Sigma G + \Sigma Z - \Sigma C
$$

式中：$m$ 为施工段数，$n$ 为施工过程数，$t$ 为流水节拍，$\Sigma G$ 为工艺间歇时间之和，$\Sigma Z$ 为组织间歇时间之和，$\Sigma C$ 为提前插入时间之和。

</Reveal>

- **记忆结构**：前一项 $(n-1)t$ 是各队相继投入的步距总和，后一项 $m \cdot t$ 是最后一个队走完全部施工段的时间。
- **加减方向**：间歇让工期变长，用加号；提前插入让工期变短，用减号。

<template #notes>

固定节拍工期公式不要死背，理解结构就不会错：$(n-1)t$ 是 n 个队依次投入形成的步距累计，$m \cdot t$ 是最后一个队扫完 m 个施工段的时间，合起来就是 $(m+n-1)t$。间歇是「停下来等」，所以加；提前插入是「抢在前面做」，所以减。案例题里 G、Z、C 有时只给文字描述，要先把数值归到对应的符号上。

</template>

</Slide>

## 成倍节拍：固定节拍与加快成倍的区别

<CompareCard title="两种有节奏流水的对照（可点击「遮住自测」）" :cols="['固定节拍流水施工', '加快的成倍节拍流水施工']" :rows="[
  { k: '节拍关系', v: ['所有施工过程在各施工段的流水节拍全等', '同一施工过程在各段节拍相等；不同施工过程节拍不等，但成倍数关系'] },
  { k: '流水步距', v: ['相邻施工过程步距相等，且等于流水节拍 t', '相邻专业工作队步距相等，且等于各流水节拍的最大公约数 K'] },
  { k: '工作队数', v: ['专业工作队数等于施工过程数 n', '专业工作队数 n 大于施工过程数 n，节拍大的过程按倍数增加工作队'] },
  { k: '工期公式', v: ['T = (m+n-1)t + ΣG + ΣZ - ΣC', 'T = (m+n-1)K + ΣG + ΣZ - ΣC，其中 n 为专业工作队总数'] }
]" />

> 加快的关键动作：**求最大公约数定步距，按倍数配队，再用步距和队数算工期**。

<template #notes>

这两类最容易混，区别就在「步距怎么定」和「队数怎么定」。固定节拍的步距直接等于节拍；成倍节拍要先求最大公约数 K 作步距，再算每个过程需要几个队（节拍除以 K），把队数加起来得到 n。注意公式里的 n 在成倍节拍中是专业工作队总数，不是施工过程数，这是代入时最常见的错误。

</template>

</Slide>

## 加快成倍节拍：三步算出工期

<Steps title="加快的成倍节拍流水施工计算步骤" :steps="[
  { t: '第一步：求最大公约数', d: '取各施工过程流水节拍的最大公约数 K，作为相邻专业工作队的流水步距' },
  { t: '第二步：确定各过程工作队数', d: '用各施工过程的流水节拍除以 K，得到该过程需要的专业工作队数；节拍等于 K 的过程配 1 个队，节拍为 2K 的配 2 个队，依此类推' },
  { t: '第三步：求工作队总数', d: '把各过程的工作队数相加，得到专业工作队总数 n，注意 n 大于施工过程数' },
  { t: '第四步：代入工期公式', d: 'T = (m+n-1)K + ΣG + ΣZ - ΣC，其中 m 为施工段数，n 为工作队总数，K 为步距' }
]" />

$$
T = (n'-1)K + \Sigma G + \Sigma Z - \Sigma C + m \cdot K = (m+n'-1)K + \Sigma G + \Sigma Z - \Sigma C
$$

> 注意：教材公式中的 $n'$ 是**专业工作队总数**，不是施工过程数。

<template #notes>

这四步是计算题的标准动作，顺序不能乱：先求 K，再配队，再加总队数，最后代公式。配队时可以用「节拍除以 K」快速算，比如节拍 2、4、6，K=2，则队数为 1、2、3，总队数 6。学生常犯的错是拿施工过程数直接代入公式，或者在求 K 时用了节拍之和而不是最大公约数。

</template>

</Slide>

<CompareCard title="非节奏流水的特点与计算（可点击「遮住自测」）" :cols="['四个特点', '计算要点']" :rows="[

<template #notes>

非节奏流水的特点是「三不一等」：节拍不全等、步距不尽相等、段间可能有空闲，但队数等于过程数。它之所以最常考，是因为实际工程的节拍本来就没有规律，而计算方法又最通用。记住一句话：固定节拍和成倍节拍都可以看作非节奏的特例，但考试时按题型选最简便的公式。

</template>

</Slide>

## 错位相减取大差：流水步距怎么来

<Steps title="累加数列错位相减取大差法的三个步骤" :steps="[
  { t: '第一步：累加', d: '对每一个施工过程在各施工段上的流水节拍依次累加，求得各施工过程流水节拍的累加数列' },
  { t: '第二步：错位相减', d: '将相邻施工过程流水节拍累加数列中的后者错后一位，相减后求得一个差数列' },
  { t: '第三步：取大差', d: '在差数列中取最大值，即为这两个相邻施工过程的流水步距' },
  { t: '第四步：算工期', d: '把所有相邻过程的流水步距相加得 ΣK，再加上最后一个施工过程在各段的流水节拍之和 Σtn，按公式计入间歇和插入' }
]" />

$$
T = \Sigma K + \Sigma t_n + \Sigma Z + \Sigma G - \Sigma C
$$

> 操作提醒：错位相减时**后者错后一位**，不是前者；差数列出现负数时不影响取最大值。

<template #notes>

这个方法必须动手算一遍才会。可以用一个简单例子板书：甲过程节拍 2、3、2，累加得 2、5、7；乙过程节拍 3、2、4，累加得 3、5、9；乙错后一位相减：2-0=2，5-3=2，7-5=2，0-9=-9，差数列最大值为 2，所以 K甲乙=2。第三步的「取大差」取的是差数列的最大值，不是累加数列的最大值。

</template>

</Slide>

## 排序：非节奏流水的计算顺序

## 小结：先判类型，再定步距，最后代公式

<p class="dk-lead">流水施工的计算只有一条路径：看节拍规律定类型，按类型定步距和队数，再代对应工期公式。</p>

- **三种方式**：依次、平行、流水；流水胜在连续、均衡、有节奏，资源投入不出现高峰。
- **三类参数**：工艺（施工过程、流水强度）、空间（工作面、施工段）、时间（流水节拍、流水步距、工期）。
- **三种流水**：固定节拍 K = t、队数等于过程数；加快成倍节拍 K 取最大公约数、队数大于过程数；非节奏用错位相减取大差。
- **三个公式**：结构一致，都是步距累计加最后过程扫段时间，间歇加、插入减。
