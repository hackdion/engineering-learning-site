## 网络计划：用图和数字管住逻辑与时间

<p class="dk-lead">网络计划做两件事：用<strong>箭线和节点</strong>把工作之间的先后关系画清楚，再用<strong>时间参数</strong>算出总工期、时差和关键线路。</p>

- **语法**：双代号、单代号两种网络图；工艺关系和组织关系构成逻辑关系。
- **参数**：工作持续时间、三类工期、六个时间参数、节点时间、时间间隔。
- **算法**：双代号按工作、按节点、标号法；单代号七步。
- **应用**：时标网络、工期优化、费用优化、资源优化、关键链法、搭接网络。

<template #notes>

这一节是进度控制的技术核心，也是案例题最容易失分的地方。学习路径要清：先能读懂图，再能画图，最后能算参数。特别提醒学生，网络计划不是画着好看，它的价值在于能算出「哪些工作可以拖、拖多久不影响总工期」，这就是总时差的意义。

</template>

</Slide>

## 逻辑关系：工艺、组织与前后工作

<Steps title="工作之间先后关系的七个概念" :steps="[
  { t: '工艺关系', d: '生产性工作之间由工艺过程决定的、非生产性工作之间由工作程序决定的先后顺序关系' },
  { t: '组织关系', d: '工作之间由于组织安排需要或资源调配需要而决定的先后顺序关系' },
  { t: '紧前工作', d: '相对于某工作而言，紧排在该工作之前的工作称为该工作的紧前工作' },
  { t: '紧后工作', d: '相对于某工作而言，紧排在该工作之后的工作称为该工作的紧后工作' },
  { t: '平行工作', d: '相对于某工作而言，可以与该工作同时进行的工作' },
  { t: '先行工作', d: '从起点节点开始，顺箭头方向经过一系列箭线与节点到达该工作为止的各条通路上的所有工作' },
  { t: '后续工作', d: '从该工作之后开始，顺箭头方向到终点节点的各条通路上的所有工作' }
]" />

<Reveal label="线路、关键线路和关键工作怎么定义？">

网络图中从起点节点开始，沿箭头方向顺序通过一系列箭线与节点，最后到达终点节点的通路称为**线路**。线路上所有工作的持续时间总和称为该线路的总持续时间，**总持续时间最长的线路**称为关键线路，关键线路的长度就是网络计划的总工期。

在工程网络计划中，关键线路可能不止一条；在实施过程中，关键线路还会发生转移。关键线路上的工作称为**关键工作**，关键工作的实际进度拖后，均会对总工期产生影响。

</Reveal>

<template #notes>

七个概念里，紧前紧后是「相邻」，先行后续是「所有通路」，范围不同，考试常拿来设错。工艺关系是客观的、不能随意改；组织关系是人为安排的、可以优化，这是后面调整逻辑关系的理论依据。关键线路的定义只有一句：总持续时间最长的线路，不要加上「唯一的」三个字。

</template>

</Slide>

## 时间参数：六个参数与三类工期

<Steps title="网络计划的时间参数体系" :steps="[
  { t: '工作持续时间和工期', d: '工作持续时间是一项工作从开始到完成的时间；工期分三类——计算工期按时间参数算得，要求工期是委托人提出的指令性工期，计划工期是根据要求工期和计算工期确定的实施目标工期' },
  { t: '工作的六个时间参数', d: '最早开始时间和最早完成时间；最迟完成时间和最迟开始时间；总时差和自由时差。六个参数都是时间的函数，随进度变化' },
  { t: '节点最早时间和最迟时间', d: '节点最早时间是双代号网络计划中以该节点为开始节点的各项工作的最早开始时间；节点最迟时间是以该节点为完成节点的各项工作的最迟完成时间' },
  { t: '相邻工作的时间间隔', d: '本工作的最早完成时间与其紧后工作最早开始时间之间可能存在的差值，是判断自由时差和关键线路的基础' }
]" />

> 六个参数的关系：**最早开始加持续时间得最早完成，最迟完成减持续时间得最迟开始，总时差是最迟减最早，自由时差看紧后。**

<template #notes>

六个参数建议按「两对加减、两个时差」记：最早开始、最早完成是一对，最迟开始、最迟完成是一对；总时差是本工作可以机动的时间，自由时差是不影响紧后工作最早开始的可机动时间。三类工期的关系要清楚：计算工期是算出来的，要求工期是给定的，计划工期是两者比较后确定的实施目标。

</template>

</Slide>

]" />

<template #notes>

单代号七步的顺序不能乱：最早参数顺箭线，总时差逆箭线，自由时差看间隔，最迟参数可回推。学生最容易在第五步出错，忘了「终点节点工作的自由时差等于计划工期减最早完成」，而不是取间隔最小值。第七步确定关键线路有两种方法，结果应当一致，可以用来互相校验。

</template>

</Slide>

## PERT：三点估计把不确定变成期望值

<Reveal label="乐观、最可能、悲观三个时间怎么用？">

计划评审技术（PERT）中，工作持续时间通常采用三点估计法确定，即给出工作的乐观时间 $a$、最可能时间 $m$ 和悲观时间 $b$，作为计算的依据。

工作 $i-j$ 持续时间的期望值：

$$
D_{i-j} = \frac{a_{i-j} + 4m_{i-j} + b_{i-j}}{6}
$$

离散程度（标准差）：

$$
\sigma_{i-j} = \frac{b_{i-j} - a_{i-j}}{6}
$$

</Reveal>

- **权重含义**：最可能时间权重为 4，乐观和悲观各为 1，体现「最可能值最可信」。
- **标准差含义**：$b-a$ 越大，估计越不确定；标准差越小，工期越可控。
- **应用**：当工作持续时间难以确定、只能给出区间估计时，用 PERT 把不确定性转化为期望工期。

<template #notes>

三点估计的公式要会代，权重 1-4-1 是最容易记的。标准差只与乐观和悲观之差有关，与最可能时间无关，这一点常被忽略。案例题里如果给出 a、m、b 三个值，先算期望值再进网络计算；如果只问离散程度，直接用 (b-a)/6。要提醒学生，PERT 算出的期望工期不是保证工期，实际工期仍有波动。

</template>

</Slide>

四种优化的目标不同：工期优化压时间，费用优化找总成本最低点，资源优化调分布，关键链法处理资源冲突和不确定性。工期优化的两条铁律必须背：不能把关键工作压成非关键工作；多条关键线路要压相同数值。案例题常给两条关键线路只压一条的情境，问工期能否缩短，答案是不能。

## 搭接关系与多级网络

<Reveal label="五种搭接关系分别是什么？多级网络怎么编？">

工程建设实践中，许多工作的开始并不以紧前工作完成为条件，只要紧前工作开始一段时间后即可进行本工作，这种关系称为搭接关系。搭接关系有五种：

1. 结束到开始（FTS）的搭接关系；
2. 开始到开始（STS）的搭接关系；
3. 结束到结束（FTF）的搭接关系；
4. 开始到结束（STF）的搭接关系；
5. 混合搭接关系。

多级网络计划系统由处于不同层级且相互有关联的若干网络计划组成，既可以分解为若干独立网络计划，也可以综合成一个系统。编制必须采用**自顶向下、分级编制**的方法：先编总体网络计划，再编局部网络计划，最后编细部网络计划；分级多少视工程规模、复杂程度和组织管理需要而定；分级编制应与科学编码相结合，便于计算机绘图、计算和管理。

</Reveal>

> 搭接关系解决「不等完成就能开始」，多级网络解决「大工程画不进一张图」。

<template #notes>

五种搭接关系中，FTS 最常见，STF 最少见。记忆时可以画一条时间轴：F 在前 S 在后是结束到开始，S 在前 S 在后是开始到开始，依此类推。多级网络的关键词是「自顶向下、分级编制」，这三个词在简答题里是得分点。分级数量不是固定的，可以是二级到五级，必要时还可以再分。

</template>

</Slide>

<template #notes>

这道题考两条铁律：多条关键线路要同步压缩、不能把关键工作压成非关键工作。可以带学生算一下：C 压缩 10 天后，A→C→F 变成 110 天，但 A→D→G 仍是 120 天，所以总工期还是 120 天，关键线路转移到了 A→D→G。正确的赶工方案应当同时压缩 C 和 D（或 G），各 10 天，并且检查压缩后是否出现新的关键线路。

## 小结：先画对图，再算准数，最后用起来

<p class="dk-lead">网络计划的价值在于：能算出哪些工作可以拖、拖多久，从而把工期和资源管在可控范围内。</p>

- **图**：双代号箭线代表工作、节点是连接点；单代号节点代表工作、箭线是逻辑关系；多起点加 S、多终点加 F。
- **关系**：工艺关系客观、组织关系可调；紧前紧后是相邻，先行后续是全部通路；关键线路是总持续时间最长的线路。
- **数**：六个时间参数、三类工期、节点时间、时间间隔；双代号三法，单代号七步，PERT 用 1-4-1 权重。
- **用**：时标网络按最早开始画、波形线读间隔；工期优化两条铁律；资源优化调分布不调总量；搭接关系五种。
