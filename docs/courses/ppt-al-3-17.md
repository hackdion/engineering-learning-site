## 进度调整：先比出来，再判影响，最后动手

<p class="dk-lead">进度控制不是看到拖延就赶工，而是先<strong>比较</strong>实际与计划，再判断拖延<strong>要不要紧</strong>，最后才选调整方法。</p>

- **四种比较方法**：横道图比较法、S 曲线比较法、香蕉曲线比较法、前锋线比较法。
- **三步偏差分析**：是不是关键工作、有没有超过总时差、有没有超过自由时差。
- **两种调整方法**：改变某些工作间的逻辑关系、缩短某些工作的持续时间。
- **一条原则**：先判断影响范围，再决定是否调整、调整哪里。

<template #notes>

这一节篇幅不长，但方法论很强：比较是手段，判断是核心，调整是动作。学生常犯的错是跳过判断直接赶工，结果花了钱却没缩短总工期。开场要把「总时差」和「自由时差」的分工讲清：总时差管总工期，自由时差管紧后工作。

</template>

</Slide>

<template #notes>

前锋线比较法的关键词是「时标网络计划」和「检查时刻」。它把每条工作箭线在检查时刻的实际进度点连成折线，折线左凸就是拖后，右凸就是超前。要提醒学生：前锋线读出的拖后天数只是「表面偏差」，真正的影响要看这项工作是不是关键工作、偏差有没有超过时差。

## 偏差分析：三步判断

<Steps title="进度偏差对后续工作和总工期影响的分析步骤" :steps="[
  { t: '第一步：看是不是关键工作', d: '偏差工作位于关键线路上，无论偏差多大都将对后续工作和总工期产生影响，必须采取调整措施' },
  { t: '第二步：看有没有超过总时差', d: '偏差大于该工作的总时差，必将影响其后续工作和总工期，必须调整；未超过总时差，则不影响总工期' },
  { t: '第三步：看有没有超过自由时差', d: '偏差大于自由时差，将对其后续工作产生影响，应根据后续工作的限制条件确定调整方法；未超过自由时差，则不影响后续工作' },
  { t: '第四步：综合判断影响范围', d: '把三步结论合起来，确定是只影响后续工作、只影响总工期，还是两者都影响' },
  { t: '第五步：选择调整方法', d: '影响总工期且逻辑关系允许改变时，可改变工作间逻辑关系；否则缩短某些工作的持续时间' }
]" />

<template #notes>

这三步是有顺序的：先看是不是关键工作，关键工作直接判定影响总工期，不用再比时差；非关键工作才进入总时差和自由时差的比较。学生常犯的错是把顺序颠倒，先比自由时差再比总时差，导致结论混乱。记住一句话：总时差是「不影响总工期的额度」，自由时差是「不影响紧后工作的额度」。

</template>

</Slide>

## 两种调整方法：改逻辑，还是压时间

<Steps title="进度计划调整的两种方法" :steps="[
  { t: '方法一：改变工作间的逻辑关系', d: '当进度偏差影响到总工期，且有关工作的逻辑关系允许改变时，改变关键线路和超过计划工期的非关键线路上的有关工作之间的逻辑关系，达到缩短工期的目的' },
  { t: '方法二：缩短某些工作的持续时间', d: '不改变各项工作之间的逻辑关系，采取增加资源投入、提高劳动效率等措施缩短某些工作的持续时间，使进度加快，保证按计划工期完成' },
  { t: '两种方法的选择', d: '逻辑关系允许调整时优先考虑改变逻辑关系，因为不增加资源；逻辑关系受工艺约束不能改时，只能压缩持续时间' },
  { t: '压缩对象的选择', d: '优先压缩关键线路上有压缩空间、费用增加较少的工作；有多条关键线路时要同步压缩' }
]" />

<Reveal label="为什么改变逻辑关系通常比压缩工期更经济？">

改变逻辑关系是把原本先后进行的工作改为平行或搭接进行，不增加资源投入，只改变组织安排；而缩短持续时间通常要增加人力、机械或加班，直接推高成本。但改变逻辑关系有前提：工艺关系不能违背，比如混凝土养护未达到强度就不能进入下一道工序。组织关系才是可以调整的对象。

</Reveal>

<template #notes>

两种调整方法的本质区别是「改顺序」还是「改速度」。改逻辑关系成本低，但受工艺约束；压缩持续时间成本高，但适用范围广。要强调：工艺关系是客观规律，不能为了赶工而违反；组织关系是人为安排，可以优化。这个区分是回答「能不能改变逻辑关系」的关键。

</template>

</Slide>

## 小结：比出来、判影响、再调整

<p class="dk-lead">四种比较方法是眼睛，三步偏差分析是大脑，两种调整方法是手。</p>

- **四种比较**：横道图（匀速、非匀速）、S 曲线、香蕉曲线（ES 与 LS 闭合）、前锋线（用于时标网络）。
- **三步判断**：关键工作一票否决；非关键看总时差定总工期；再看自由时差定后续工作。
- **两种调整**：改变逻辑关系（优先，受工艺约束）、缩短持续时间（增资源、提效率）。
- **一条原则**：先判断影响范围，再决定是否调整、调整哪里，不要一见拖后就赶工。
