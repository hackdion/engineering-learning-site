## 工程监理组织：模式决定委托，委托决定机构

<p class="dk-lead">承包模式是<strong>背景</strong>，监理委托方式是<strong>接口</strong>，项目监理机构是<strong>落地的组织</strong>。</p>

- **承包模式**：按承包范围分 DBB 与工程总承包；按承包关系分平行、联合体、合作体；按融资分 PPP 等模式。
- **委托方式**：平行承包下可委托一家或分标段委托多家；施工总承包和工程总承包下宜或应委托一家。
- **监理机构**：四步设立，四种组织形式，人员要满足专业结构和技术职称结构。
- **一条逻辑**：一个承包主体对应一家监理单位，合同界面越少，监理委托越集中。

<template #notes>

本节内容跨度大但逻辑清楚：先看工程是怎么发包的，再看监理怎么被委托，最后看监理机构内部怎么搭。核心判断只有一句：建设单位与几个承包主体签合同，就决定监理要面对几个合同界面。把这句话记住，后面的委托方式和机构设置都能推出来。

## 委托方式：一个承包主体，一家监理

<CompareCard title="三种承包模式下的监理委托方式（可点击「遮住自测」）" :cols="['平行承包模式', '施工总承包模式', '工程总承包模式']" :rows="[
  { k: '合同关系', v: ['建设单位分别与各承包单位签订施工合同', '建设单位与施工总承包单位只签订一份承包合同', '建设单位与工程总承包单位签订一份工程总承包合同'] },
  { k: '委托几家', v: ['可以委托一家监理单位，也可划分为多个监理标段分别委托多家', '宜委托一家工程监理单位实施监理', '针对一个承包主体，应委托一家工程监理单位实施监理'] },
  { k: '用词分量', v: ['可以——两种做法都允许', '宜——原则上集中委托', '应——必须集中委托一家'] }
]" />

<Reveal label="委托方式与承包模式匹配，能带来什么？">

有利于**优化资源配置、明确权责**；**提高管理效率、减少冲突**；**有效控制项目目标、加强风险管理**。三句话对应三组关系：资源与责任、效率与冲突、目标与风险。

</Reveal>

<template #notes>

这一页的关键是「可以、宜、应」三个词的分量：平行承包下两种做法都行；施工总承包下原则上委托一家；工程总承包下必须委托一家。考试常把「宜」改成「应」或反过来设陷阱。匹配的三点好处要能背，答「为什么要选择与承包模式相匹配的委托方式」时直接用。

</template>

</Slide>

## 八项实施原则：一张清单

<span class="dk-tag">依法监理</span><span class="dk-tag">科学规范</span><span class="dk-tag">预防为主</span><span class="dk-tag">责任到位</span><span class="dk-tag">协调沟通</span><span class="dk-tag">实事求是</span><span class="dk-tag">廉洁自律</span><span class="dk-tag">持续改进</span>

<Reveal label="八项原则怎么分组记？">

- **守底线**：依法监理、廉洁自律——按法律法规和职业道德办事。
- **讲方法**：科学规范、预防为主、实事求是——用标准说话，把工作做在前面，结论有依据。
- **抓组织**：责任到位、协调沟通、持续改进——人到位、事说清、循环改进。

</Reveal>

<template #notes>

八项原则按三组记比顺口溜好：守底线两条、讲方法三条、抓组织三条。答题时如果问「监理工作应遵循哪些原则」，按组写不容易漏。预防为主这一条和后面的巡视、旁站、平行检验是呼应的——手段是为原则服务的。

</template>

</Slide>

## 项目监理机构：怎么设、怎么撤

<Steps title="项目监理机构设立的四个步骤" :steps="[
  { t: '确定项目监理机构目标', d: '目标来自监理合同：质量、造价、进度三大目标和安全生产管理的法定职责' },
  { t: '确定监理工作内容', d: '按合同约定和工程特点，把三控两管一协调一履行分解成具体工作' },
  { t: '设计项目监理机构组织结构', d: '选择直线制、职能制、直线职能制或矩阵制，划分部门与岗位' },
  { t: '制定工作流程和信息流程', d: '把审批、验收、支付、报告等流程固化成图，保证指令和信息畅通' }
]" />

> 机构设立后，监理单位应**及时将组织形式、人员构成及总监任命书面通知建设单位**，并在**第一次工地会议上告知承包单位**。撤离现场前，应由**监理单位书面通知建设单位并办理移交手续**。

<template #notes>

四步的顺序不能颠倒：先有目标，才有工作内容；有了内容，才谈组织结构；结构定了，才谈流程。三个「告知」要区分：对建设单位是书面通知，对承包单位是在第一次工地会议告知，撤离时是书面通知建设单位并办移交。案例题常考「监理机构撤场需要谁同意、办什么手续」。

</template>

</Slide>

## 人员配备：数量够不够，结构合不合理

<Steps title="确定人员数量要考虑的四个因素" :steps="[
  { t: '工程建设强度', d: '投资额、工期、同时开工的单位工程数量越大，需要的监理人员越多' },
  { t: '建设工程复杂程度', d: '技术难度、专业交叉、地质条件和新工艺应用，直接决定专业配置的深度' },
  { t: '工程监理单位的业务水平', d: '单位的管理体系、人员素质和信息化程度高，单人可承担的监理范围更大' },
  { t: '项目监理机构的组织结构和任务职能分工', d: '同样的工作量，组织设计不同，所需人数和岗位也不同' }

**人员结构要合理**：既要有**合理的专业结构**，覆盖工程涉及的各专业；又要有**合理的技术职称结构**，高、中、初级人员搭配使用。

> 配备数量和专业还要满足监理合同对监理工作深度和目标控制的要求，能体现项目监理机构的整体素质。

<template #notes>

四个因素从「活多少、活多难、干的人多强、怎么分工」四个角度记。人员结构的两句话要背原表述：合理的专业结构和合理的技术职称结构。案例里常见的错误是「只按投资额配人」或者「全是高职称但没有对应专业」，这两种都要指出来。

</template>

<template #notes>

## 小结：界面越少，组织越集中

<p class="dk-lead">承包模式决定合同界面，合同界面决定监理委托，委托方式决定机构怎么搭、人怎么配。</p>

- **承包模式**：DBB 与工程总承包；平行、联合体、合作体；PPP 全部采取特许经营，五种方式，期限原则上不超 40 年。
- **委托方式**：平行承包「可以」一家或分标段；施工总承包「宜」一家；工程总承包「应」一家。
- **监理机构**：四步设立——定目标、定内容、设结构、定流程；四种组织形式以直线职能制最常用。
- **人员配备**：四个因素定数量，专业结构与技术职称结构定质量；四类人员靠书面任命和书面授权。
