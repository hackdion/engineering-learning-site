## 干什么、怎么干：一句话加五种手段

<p class="dk-lead">工作内容概括为<strong>三控两管一协调一履行</strong>，工作方式是<strong>审查核验、巡视、平行检验、旁站、见证</strong>。</p>

- **三控**：控制工程质量、造价、进度三大目标。
- **两管**：合同管理、信息管理。
- **一协调**：协调工程建设相关方关系。
- **一履行**：履行建设工程安全生产管理的法定职责。
- **五种方式**：审查核验、巡视、平行检验、旁站、见证，是监理落到现场的手和眼。

这一节是整章的操作核心，先记「三控两管一协调一履行」这十个字，再记五种工作方式。要提醒学生：三控不是三件事分开做，而是相互制约的一个目标系统；五种方式也不是并列选用，而是按工序风险搭配使用。后面的案例题基本都在这两个框架里出。

## 三大目标：相互制约的一个系统

<p class="dk-lead">质量、造价、进度相互关联、相互制约，建设单位希望质量好、投资省、工期短，但实践中几乎不可能同时实现。</p>

- **不能单打一**：防止盲目追求单一目标而冲击或干扰其他目标，也不可分割三大目标。
- **先论证总目标**：根据投资方及利益相关者需求，结合工程本身及所处环境特点综合论证，总目标是目标控制的基本前提。
- **再逐级分解**：按参建单位、项目组成和时间进展，分解为分目标、子目标及可执行目标。
- **形成目标体系**：自上而下层层展开、自下而上层层保证，为动态控制奠定基础。

<Reveal label="目标控制为什么必须动态进行？">

目标体系构建后，关键在于**动态控制**：在实施过程中监督检查实际情况，将实际与计划目标比较，采取有效措施纠正偏差。没有比较和纠偏，目标体系只是一张纸。

</Reveal>

<template #notes>

这段的答题价值很高：问「如何处理三大目标关系」，就答统筹兼顾、不盲目追求单一目标、不分割目标；问「目标体系怎么形成」，就答分析论证总目标、逐级分解、自上而下展开自下而上保证。动态控制的关键词是检查、比较、纠偏，三步缺一不可。

</template>

</Slide>

**组织协调方法**：<span class="dk-tag">会议协调法</span><span class="dk-tag">交谈协调法</span><span class="dk-tag">书面协调法</span>

> 协调对象分内外：内部是人际关系、组织关系、需求关系；外部是建设单位、施工单位、设计单位、政府部门及其他单位。

## 安全生产管理的监理动作

<Steps title="安全事故隐患的三级处置" :steps="[
  { t: '发现隐患', d: '签发监理通知单，要求施工单位整改' },
  { t: '情况严重', d: '签发工程暂停令，并及时报告建设单位' },
  { t: '拒不整改或不停止施工', d: '及时向有关主管部门报送监理报告' },
  { t: '紧急情况', d: '可通过电话、传真或者电子邮件向有关主管部门报告，事后应形成监理报告' }
]" />

<Reveal label="专项施工方案的监督，监理具体做什么？">

- 要求施工单位按**已批准**的专项施工方案组织施工；方案需要调整时，施工单位应**按程序重新提交**项目监理机构审查。
- **巡视检查**危险性较大的分部分项工程专项施工方案实施情况。
- 发现**未按专项施工方案实施**的，应签发**监理通知单**，要求按方案实施。

</Reveal>

<template #notes>

三级处置的顺序是法定动作，不能颠倒：先通知单，严重才暂停令，拒不整改才报主管部门。这里还有一个体系审查的内容要记住：审查施工单位的管理制度、人员资格及施工机械设备验收手续，以及专项施工方案。紧急情况下允许先电话、传真、邮件报告，但事后必须补监理报告，这个「事后补」不能省。

</template>

</Slide>

## 小结：内容成体系，方式成组合

<p class="dk-lead">三控两管一协调一履行是内容体系，五种工作方式是落地手段，两者在每道工序上会合。</p>

- **内容**：三大目标相互制约，先论证总目标再逐级分解；质量抓五要素，造价抓计量付款变更索赔，进度抓计划审查协调索赔；四类措施里组织是前提。
- **管理**：合同管理四类事项按合同、规范和证据处理；信息管理六环节；协调分内外，方法有会议、交谈、书面。
- **安全**：通知单—暂停令—报建设单位—报主管部门，紧急情况可先电话传真邮件，事后补监理报告。
- **方式**：审查核验看文件、巡查看面上、平行检验自己测、旁站守着干、见证盯取样；数智化让这五种方式发生变化，但不替代。
