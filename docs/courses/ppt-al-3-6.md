## 风险管理：四步走完一个闭环

<p class="dk-lead">风险管理是识别风险、确定和度量风险，并制定、选择和实施风险应对策略的<strong>过程</strong>。</p>

- **风险识别**：找出引起风险的主要因素、风险的性质和可能引起的后果，成果是风险清单。
- **风险分析与评价**：把发生的可能性和损失后果定量化，评出风险等级。
- **风险应对**：确定最佳应对策略组合，四类对策是回避、损失控制、转移、自留。
- **实施和监控**：跟踪检查策略执行情况，评价执行效果，识别新风险。

<template #notes>

这一节逻辑非常清楚，就是 PDCA 式的闭环：识别—分析—应对—监控。学生要记住这是一条流程而不是四个名词，案例题问「风险管理包括哪些环节」，按顺序写全四步；问「第一步是什么」，答案是风险识别，因为不认识风险就无从谈起。

</template>

</Slide>

## 风险识别：识别什么、用什么方法

<Steps title="识别工程风险的六种方法" :steps="[
  { t: '专家调查法', d: '依靠专家的经验和判断，通过问卷、访谈等方式汇集意见，适合缺乏历史数据的项目' },
  { t: '财务报表法', d: '从财务报表分析企业的资产、负债和现金流风险，多用于判断主体的财务承受能力' },
  { t: '流程图法', d: '按工程实施的流程逐环节排查，找出每个节点的风险因素' },
  { t: '初始清单法', d: '先用通用的风险清单逐项对照，再结合工程特点补充，效率高但容易漏掉特殊风险' },
  { t: '经验数据法', d: '利用同类工程的历史事故和损失数据，推断本工程的风险分布' },
  { t: '风险调查法', d: '通过现场调查、访谈和资料核查，直接获取第一手风险信息' }
]" />

**识别三项内容**：识别引起风险的主要因素、识别风险的性质、识别风险可能引起的后果。

<Reveal label="风险识别的成果是什么？">

风险识别的最主要成果是**风险清单**，它最简单的作用是**描述存在的风险并记录可能减轻风险的行为**。风险清单是进行风险分析与评价的重要基础。

</Reveal>

<template #notes>

六种方法按「问人—看账—走流程—对清单—查历史—跑现场」记。注意区分：识别方法里没有蒙特卡罗模拟法和敏感性分析法，那两个属于分析与评价方法，这是最常见的混淆点。识别成果只记一句话：风险清单，描述风险并记录减轻风险的行为。

</template>

</Slide>

## 分析与评价：五项任务

<Steps title="风险分析与评价的五项任务" :steps="[
  { t: '定概率', d: '确定单一风险因素发生的概率' },
  { t: '定范围', d: '分析单一风险因素的影响范围大小' },
  { t: '定时间', d: '分析各个风险因素的发生时间' },
  { t: '定影响', d: '分析各个风险因素的结果，探讨这些风险因素对建设工程目标的影响程度' },
  { t: '综合评估', d: '在单一因素量化分析的基础上，考虑多种风险因素的综合影响，评估风险严重程度' }
]" />

**风险度量**：按发生频繁程度把概率分为 **3～5 个等级**；等级划分反映一种主观判断，数量可根据实际情况调整。

**风险评定**：按后果严重程度分 **3～5 个等级**，与概率等级组合后形成 9 个区域，再按风险量归为 5 级。

<template #notes>

五项任务前四项都是「单一因素」，第五项才是「多因素综合」，这个层次关系要讲清。两个「3～5 级」不要记成一个：概率按频繁程度分 3～5 级，后果按严重程度分 3～5 级，都是主观判断、可调整。这是教材的原表述，考试时照写最稳妥。

</template>

</Slide>

## 风险量五级与可接受性

<CompareCard title="9 个区域归为 5 个风险量等级（示意，可点击「遮住自测」）" :cols="['后果大（H）', '后果中（M）', '后果小（L）']" :rows="[
  { k: '概率大（H）', v: ['VH（很大）', 'H（大）', 'M（中等）'] },
  { k: '概率中（M）', v: ['H（大）', 'M（中等）', 'L（小）'] },
  { k: '概率小（L）', v: ['M（中等）', 'L（小）', 'VL（很小）'] }
]" />

- **VH、H**：风险程度较高，是**不可接受的风险**，需要给予重点关注。
- **M**：**不希望有的风险**。
- **L**：**可接受的风险**。
- **VL**：**可忽略的风险**。

> 风险量等级评定之后，才能进行风险可接受性评定，进而决定管控的轻重缓急。

<template #notes>

五个等级按英文缩写记：VL 很小、L 小、M 中等、H 大、VH 很大。可接受性的四句话要背原表述：大和很大不可接受、需要重点关注；中等是不希望有的；小是可接受的；很小是可忽略的。矩阵只是帮助理解「概率×后果」，考试以文字表述为准。

</template>

</Slide>

## 分析与评价的四种方法

<Steps title="常用的风险分析与评价方法" :steps="[
  { t: '调查打分法', d: '请专家对风险因素打分，加权汇总得出综合评分，简单易行但依赖主观判断' },
  { t: '蒙特卡罗模拟法', d: '对风险变量的概率分布进行大量随机抽样模拟，得到结果的分布，适合复杂项目' },
  { t: '计划评审技术法', d: '在进度计划中考虑工序时间的随机性，评估工期风险，常与网络计划结合' },
  { t: '敏感性分析法', d: '逐个改变不确定因素，观察目标值的变化幅度，找出最敏感的因素' }
]" />

> 风险分析与评价往往采用**定性与定量相结合**的方法，两者并非相互排斥，而是**相互补充**。

<template #notes>

四种方法按「打分—模拟—评审—敏感」记。敏感性分析法最适合回答「哪个因素对造价或工期影响最大」，蒙特卡罗适合回答「结果落在某个区间的概率有多大」。定性定量相互补充这句话是教材原句，答题时可以直接引用。

</template>

</Slide>

四类对策的判断标准是「风险能不能躲、躲不掉能不能减、减不了能不能转、转不了只能留」。风险回避的三个适用条件要同时满足，缺一个就不该回避。损失控制是唯一被教材称为「主动、积极」的策略，这个定性常考。

## 损失控制：两类措施加三个计划

<Steps title="损失控制的措施与计划系统" :steps="[
  { t: '预防损失措施', d: '作用在于降低或消除（通常只能做到降低）损失发生的概率，如安全教育、方案审查、材料检验' },
  { t: '减少损失措施', d: '作用在于降低损失的严重性或遏制损失的进一步发展，使损失最小化，如应急预案、隔离措施' },
  { t: '预防计划', d: '在损失发生前，通过组织、技术、管理手段降低事故发生的可能性' },
  { t: '灾难计划', d: '针对可能造成严重后果的事件，预先安排处置方案，减少人员伤亡和财产损失' },
  { t: '应急计划', d: '事故发生后启动，明确指挥、救援、报告和恢复的具体安排' }
]" />

> 损失控制方案不是二选一，而是**预防措施与减少措施的有机结合**，再配上预防、灾难、应急三个计划。

<template #notes>

预防和减少的分界看作用点：预防作用于「发生的概率」，减少作用于「后果的严重性」。三个计划的分界看时间：预防计划在事前，灾难计划针对严重后果，应急计划在事发后启动。三者合起来才是完整的损失控制计划系统。

</template>

</Slide>

## 转移与自留：两种「不躲」的选择

<CompareCard title="风险转移与风险自留（可点击「遮住自测」）" :cols="['风险转移', '风险自留']" :rows="[

  { k: '怎么做', v: ['非保险转移通过合同约定转移责任；保险转移通过投保把损失风险转给保险人', '将风险保留在风险管理主体内部，通过内部控制措施等化解'] },

<template #notes>

两者都是「不躲」，区别在于风险留在谁的口袋里。转移的关键是合同和保险两个工具；自留的关键是「有计划」——计划性自留有预算有预案，非计划性往往是没识别出来的被动承担。案例里如果出现「未投保、也未在合同中约定」，多半就是非计划性自留。

</template>

</Slide>

## 风险监控：盯住变化，及时启动应急

<Steps title="风险监控的四项主要内容" :steps="[
  { t: '评估策略效果', d: '评估风险应对策略产生的效果，判断是否达到预期' },
  { t: '跟踪风险变化', d: '跟踪评估风险变化程度，看风险是在增大还是减小' },
  { t: '监测新风险征兆', d: '监测新的风险发生征兆，及时把新风险纳入清单' },
  { t: '提供启动依据', d: '提供启动风险应急计划的时机和依据' }
]" />

> 通常用**风险跟踪检查表格**记录结果，再制成**风险跟踪检查报告**；报告应及时准确、简明扼要，详细程度依决策者需要而定。**无论是否出现新风险，都应在报告中对风险重新估计**。

<template #notes>

四项内容里前三项是「看」，第四项是「用」——监控不是为了写报告，而是为了在合适的时机启动应急计划。最后一句最容易考：即使没有新风险，也要重新估计，因为原有风险的程度可能已经变化。

</template>

</Slide>

## 小结：先认清风险，再选择对策

<p class="dk-lead">识别给清单，评价给等级，应对给组合，监控给反馈——四步走完，风险管理才闭环。</p>

- **识别**：看因素、性质、后果；六种方法里没有蒙特卡罗和敏感性分析；成果是风险清单。
- **评价**：五项任务从单因素到多因素综合；概率和后果各分 3～5 级，风险量分 VL、L、M、H、VH 五级；大和很大不可接受。
- **对策**：回避看三个条件；损失控制分预防与减少，配预防、灾难、应急三个计划；转移分非保险与保险；自留分计划性与非计划性。
- **监控**：评估效果、跟踪变化、监测征兆、提供启动应急的依据；无论有无新风险都要重新估计。
