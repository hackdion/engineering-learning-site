## 第四节：投资案例的五组公式

<p class="dk-lead">投资控制案例看着是算数，其实考的是<strong>口径</strong>：谁作基数、按什么比例、哪一段该调价，口径错了整道题都错。</p>

- **方案比选**：财务净现值看整体效果，净现值率看单位投资盈利能力，变化幅度看抗风险能力。
- **资金成本**：优先股、普通股（CAPM）、加权平均（税后）三组公式。
- **计量支付**：预付款、保留金、最低付款限额、工程量变化调价四个关口。
- **偏差分析**：挣值法三参数四指标，投资偏差与进度偏差两条公式。
- **综合单价**：人材机→管理费→利润→规费→税金的取费顺序。

## 资金成本：三组公式一次记牢

<Steps title="融资方案资金成本计算（案例 4-2）" :steps="[
  { t: '优先股资金成本', d: 'Kp = Dp / (P - F)，其中 Dp 为每年优先股股利，P 为发行价格，F 为发行费用。本题 = (4000×12%)/(4000-4000×2%) = 12.24%' },
  { t: '普通股资金成本（CAPM）', d: 'Ks = Rf + β(Rm - Rf)，Rf 无风险收益率、Rm 市场组合预期收益率、β 投资风险系数。本题 = 4% + 1.2×(11%-4%) = 12.4%' },
  { t: '加权平均资金成本（税后）', d: '各类资金成本按其占筹资总额的比重加权；银行借款利息可抵税，要乘 (1-所得税税率)。本题 = [16000×12.4% + 4000×12.24% + 20000×7%×(1-15%)]/40000 = 9.16%' },
  { t: '企业价值（分段法）', d: '前若干年逐年折现，第 5 年起按固定增长率 g 永续增长：P = ΣRi(1+r)^-i + [Rn(1+g)/(r-g)](1+r)^-n = 24493.94 万元' },
  { t: '资产证券化风险提示', d: '须有资产支撑且未来收入流可预期；资产出售给 SPV 实现破产隔离；还要建立该资产与 SPV 资产之间的风险隔离机制' }
]" />

<template #notes>

三组公式的基数要分清：优先股用「股利/(发行价-发行费)」；普通股用 CAPM 四要素；加权平均时借款利息必须乘(1-所得税税率)，这是最常漏的一步。分段法企业价值的公式较长，抓住两段结构——前期逐年折现、后期按固定增长率折现到同一时点。资产证券化的三句话是案例问答题的直接答案，要能原句写出。

</template>

## 建设期利息、折旧与偿债备付率

<Reveal label="建设期利息为什么当年借款按半年计？偿债备付率怎么算？（点击展开）">

**建设期利息**（案例 4-3，贷款年利率 6%，建设期 2 年、每年均衡投入 1000 万元）：
- 第 1 年利息 = 1000×6%÷2 = 30 万元；
- 第 2 年利息 = (1000+30+1000÷2)×6% = 91.80 万元；
- 合计 121.80 万元。
当年借款按半年计息，是因为借款在年度内均衡发生，近似取年中时点。

**固定资产与折旧**：固定资产 = 3600+121.80 = 3721.80 万元；年折旧 = 3721.80×(1-5%)/10 = 353.57 万元。

**等额本息**：A = P·i(1+i)ⁿ/[(1+i)ⁿ-1] = 1767.19×6%×(1+6%)⁴/[(1+6%)⁴-1] = 510.00 万元。

**偿债备付率**：(息税折摊前利润 - 所得税)/应还本息 = (602.84-35.81)/510.00 = 1.11 > 1，满足还款要求。

</Reveal>

<template #notes>

建设期利息的公式要会代：上年末累计余额全额计息，当年新增借款按一半计息，这是「均衡发生」假设的结果。案例题常把建设期利息漏掉，导致总投资、固定资产、折旧全算少。偿债备付率大于 1 才说明满足还款要求，这个判断要会写。等额本息是「已知 P 求 A」，别用反了。

</template>

</Slide>

## 因素分析法：投资差额怎么构成

<Steps title="连环替代法分析投资变化（案例 4-13）" :steps="[
  { t: '基准：计划投资', d: '10000 m³ × 500 元/m³ × 1.04（索赔因素）= 520 万元' },
  { t: '第一次替代：工程量变化', d: '15000 × 500 × 1.04 = 780 万元；影响 = 780 - 520 = +260 万元' },
  { t: '第二次替代：单价变化', d: '15000 × 600 × 1.04 = 936 万元；影响 = 936 - 780 = +156 万元' },
  { t: '第三次替代：索赔因素变化', d: '15000 × 600 × 1.03 = 927 万元；影响 = 927 - 936 = -9 万元' },
  { t: '汇总差额', d: '实际投资 - 计划投资 = 927 - 520 = 407 万元；构成 = 260 + 156 - 9 = 407 万元，两者必须相等' }
]" />

<template #notes>

因素分析法的规则是「逐项替代、替代后不回头」：每次只把一个因素换成实际值，其余保持上一步状态，相邻两次结果之差就是该因素的影响额。三大因素（工程量、单价、索赔比例）的顺序按题目给定，不能随意调换，否则各因素影响额会变。最后要用「各因素影响额之和 = 总差额」自检，案例 4-13 的 407 万元就是校验和。

</template>

</Slide>

## 工程量变化怎么调价

<Reveal label="15% 与 2%+20% 两套调价规则，分别用在哪？（点击展开）">

**一般清单计价（案例 4-8）**：实际工程量超过原估算工程量 15% 以上时，超出部分综合单价乘调整系数 0.9。
- 案例 4-8：工程量变动率 200/400=50%>15%，其中 400×15%=60 m³ 执行原价 417.6 元/m³，其余 140 m³ 按 417.6×0.9=375.84 元/m³。

**FIDIC 合同（案例 4-9）**：只有当「变更款额超过合同总价 2%」**且**「实际工程量超过或少于暂估工程量 20% 以上」时，才调整费率或价格。
- 案例 4-9：款额变化 3.04%>2%，工程量变化 24.94%>20%，故应调整；20% 以内部分按原价 764 元/m³，超过部分按新价 735 元/m³。

**清单规则（案例 4-7）**：分部分项工程量清单由招标人统一提供，投标人不得擅自修正、补列；有疑义只能在投标准备阶段提出。措施项目清单投标人可按项目特点和企业实际调整。

</Reveal>

<template #notes>

两套调价规则要分清适用场景：国内清单计价常用 15%（也有题目给 10%），FIDIC 合同是「2%+20%」双条件，必须同时满足。案例 4-9 的 2% 和 20% 是两个独立门槛，缺一不可。清单规则那三句也是案例题常问的「投标人这样做是否允许」，答案要分清单类型说。

</template>

## 小结：口径对了，计算才对

<p class="dk-lead">投资控制案例的真功夫不是算得快，而是每一笔都知道「以谁为基数、按什么比例、在哪一段调整」。</p>

- **方案比选**：净现值看整体、净现值率看单位投资、变化幅度看抗风险；投资额不同时以净现值为准。
- **资金成本**：优先股 Dp/(P-F)；普通股 CAPM；加权平均时借款利息乘 (1-所得税率)。
- **计量支付**：预付款起扣点 T=P-M/N；保留金 5% 按 10% 扣；低于最低限额本月不签发。
- **偏差分析**：挣值法三参数四指标；投资偏差减实际、进度偏差减拟完，均从已完计划出发。
- **取费顺序**：人材机→管理费→利润→规费→税金；工程量超 15% 或 FIDIC 双条件时调价。
