## 建立有四个阶段，运行也分阶段推进

<p class="dk-lead">质量、环境、职业健康安全管理体系的建立，可分为准备、初始（状态）评审、管理体系策划和文件化信息建立四个阶段；建立之后进入试运行，再通过保持和持续改进让体系长期有效。</p>

- **建立**：准备 → 初始（状态）评审 → 管理体系策划 → 文件化信息建立。
- **运行**：管理体系试运行 → 保持和持续改进。
- 建立阶段解决“体系怎么搭起来”，运行阶段解决“体系怎么真正转起来”。

## 准备阶段：领导决策、成立班子、制定计划

- **领导决策，统一认识**：领导层的认识与投入是管理体系建立与实施的关键；最高管理者要统一各管理层的思想认识，确定管理方针和管理目标。
- **成立班子，明确任务**：成立**领导班子**和**工作班子**。领导班子由最高管理者作为负责人，可确定授权管理者，任务是总体规划、制定方针目标、按职能部门进行职能分解；工作班子由相关职能部门领导共同牵头、各职能部门选派代表参加，承担具体工作。
- **制定计划，培训人员**：工作计划要有明确目标、时间表、主要负责人、参与人员、职责分工和协作关系。
- **三类培训**：管理层培训重在统一思想、争取支持配合；内审员培训重在具备初始评审、编写体系文件和审核的能力；全体员工培训重在了解体系并主动参与。

<template #notes>

准备阶段有三项工作。 第一是领导决策、统一认识，领导层的认识与投入是体系建立与实施的关键，最高管理者要统一各管理层的思想并确定方针目标。 第二是成立班子、明确任务，领导班子由最高管理者负责，工作班子由相关职能部门领导共同牵头、选派代表参加。 第三是制定计划、培训人员，计划要明确目标、时间表、负责人和职责分工。 培训分管理层、内审员和全体员工三类，内审员要具备初始评审、编写体系文件和审核的能力。

## 初始评审：先摸清现状，再谈建体系

**目的**：了解组织管理现状，评价其与管理体系标准要求的符合性，为组织建立管理体系搜集信息并提供依据，是建立组织管理体系的基础工作。

**六个步骤**：

1. **准备工作**：界定初始（状态）评审范围，明确工作小组成员分工和职责，制定评审计划。
2. **现状调查**：收集组织过去和现在有关管理工作状况资料与信息。
3. **重要影响因素评价**：识别和评价组织活动、产品或服务过程中的重要影响因素。
4. **法律法规要求和其他要求适用性评价**：明确适用的法律法规及其他要求，并评价组织行为与这些要求的符合性。
5. **现有管理工作有效性评价**：分析评价现有管理工作的可行性、有效性，找出体系要素在构成、运行、协调、监督中的缺陷。
6. **形成初始（状态）评审报告**：作为建立管理体系的基础。

<template #notes>

初始评审的目的是摸清组织管理现状，评价它和管理体系标准要求的符合性，为建立体系搜集信息、提供依据。 评审分六步：先做准备工作，界定范围、明确分工、制定计划；再做现状调查，收集过去和现在的管理资料。 第三步评价重要影响因素，第四步评价法律法规和其他要求的适用性，第五步评价现有管理工作的有效性并找出缺陷。 最后形成初始状态评审报告，这份报告是建立管理体系的基础。

</template>

## 管理体系策划：四件事定框架

1. **制定方针、目标**：方针是最高管理者正式发布的总的质量、环境、职业健康安全宗旨和方向；目标是组织在这些方面所追求的目的。
2. **确定管理体系覆盖范围**：界定体系的边界和应用范围，应包含覆盖的产品、服务或区域，主要过程，地点范围，相关方要求。
3. **设计组织机构和职责**：调整组织机构设置、编制**职能分配矩阵表**，确定各部门职能分配及相互关系，落实职责权限，将组织结构形成文件。
4. **准备必要的资源**：所需资源取决于组织所处的环境、管理体系覆盖范围、组织活动性质和相关风险，应确保人力、物力和财力资源充足。

<template #notes>

管理体系策划要做四件事。 第一是制定方针和目标，方针是最高管理者正式发布的宗旨和方向，目标是组织追求的目的。 第二是确定管理体系覆盖范围，把产品服务或区域、主要过程、地点范围和相关方要求界定清楚。 第三是设计组织机构和职责，调整机构设置、编制职能分配矩阵表、落实职责权限并形成文件。 第四是准备必要的资源，资源多少取决于组织环境、覆盖范围、活动性质和相关风险，要保证人财物充足。

</template>

</Slide>

## 方针与目标：方向管目的，目标撑方向

- **方针**：由最高管理者正式发布，是组织总的质量、环境、职业健康安全**宗旨和方向**，为组织确定未来发展的蓝图，也为目标的建立和评审提供框架。
- **目标**：是组织在质量、环境、职业健康安全方面所追求的**目的**，为组织运作提供具体要求，应以方针为框架具体展开。
- **两者关系**：方针必须通过目标的执行和实现才能得到落实；目标要在组织当前管理水平的基础上，按照自身对更高要求的合理期望来确定，并适时修订和提高，与持续改进的承诺相一致。
- **覆盖范围四项**：覆盖的产品、服务或区域；主要过程；地点范围；相关方要求。

<template #notes>

方针和目标是一对关系。 方针由最高管理者正式发布，是组织总的宗旨和方向，为未来发展确定蓝图，也为目标提供框架。 目标是组织在质量、环境、职业健康安全方面追求的目的，以方针为框架具体展开。 方针要通过目标的执行和实现才能落实，目标要按组织当前管理水平和合理期望确定，并适时修订提高。 确定覆盖范围时要写清产品服务或区域、主要过程、地点范围和相关方要求。

</template>

</Slide>

## 文件化信息：三个层次，从纲领到记录

- **第一层次：管理手册**。对管理体系提出具体要求的**纲领性文件**，通常包括修订记录表、目录、发布令、组织概况及发展宗旨、管理要求、术语和定义、文件编号及修订状态标识、组织结构图、职能分配表、方针总目标和指标、管理者代表任命书、实现管理标准条款的要求。
- **第二层次：程序文件**。指导如何实施某项活动或某个过程的**指导性文件**，通常包括做什么、谁来做、怎么做、用什么资源、应做哪些记录。
- **第三层次：操作性文件和记录**。操作性文件包括操作规范、作业指导书、工艺参数控制要求、注意事项等；记录通常是表格形式，用于记载实际运行状况。

<template #notes>

管理体系文件分三个层次。 第一层次是管理手册，属于纲领性文件，写清组织概况、方针目标、组织结构、职能分配和管理标准条款的要求。 第二层次是程序文件，用来指导某项活动或过程怎么实施，回答做什么、谁来做、怎么做、用什么资源、应做哪些记录。 第三层次是操作性文件和记录，操作性文件包括操作规范、作业指导书和注意事项，记录一般是表格，用来记载实际运行状况。

</template>

</Slide>

## 运行：先试运行，再保持和改进

- **试运行**：完成建立工作后，把体系付之于实践，检验管理体系的**适宜性、符合性、充分性和有效性**，针对问题采取纠正措施，进一步完善体系文件。
- **试运行三项工作**：宣贯管理体系文件；建立试运行记录；采取纠正措施。
- **保持和持续改进**：包括内部审核和管理评审、持续改进、管理体系认证。
- 试运行是“检验”，保持和改进是“长期维护”，两者共同保证体系不是纸面文件。

<template #notes>

体系建立完成后先进入试运行。 试运行是把体系付之于实践，检验它的适宜性、符合性、充分性和有效性，针对发现的问题采取纠正措施，进一步完善体系文件。 试运行有三项工作：宣贯体系文件、建立试运行记录、采取纠正措施。 试运行之后进入保持和持续改进阶段，包括内部审核和管理评审、持续改进以及管理体系认证。 试运行是检验，保持和改进是长期维护，两者合起来才能保证体系不是纸面文件。

</template>

</Slide>

## 试运行：宣贯、记录、纠正

- **宣贯管理体系文件**：文件经最高管理者批准后正式发布，发布意味着体系进入试运行阶段；发布后应进行全面的宣贯培训。
- **建立试运行记录**：所有与体系活动有关的人员按要求做好信息的收集、分析、传递、反馈、处理和归档；记录要**完整、规范**；内部审核发现问题时，应在内审整改时修改，**不可对原始记录重新整理、更改**。
- **采取纠正措施**：针对试运行中发现的不符合项及风险问题，开展纠正措施、预防措施活动。
- **纠正措施流程**：确认不合格的重要程度及风险 → 分析产生不合格原因 → 评价不再发生不合格的措施 → 实施纠正措施并提供证据 → 记录实施结果 → 主管领导评审有效性。

<template #notes>

试运行要抓三件事。 第一是宣贯体系文件，文件经最高管理者批准发布后，体系就进入试运行，发布后要全面宣贯培训。 第二是建立试运行记录，信息收集、分析、传递、反馈、处理和归档都要完整规范，内部审核发现问题应在整改时修改，不能对原始记录重新整理或更改。 第三是采取纠正措施，先确认不合格的重要程度和风险，再分析原因、评价措施、实施并取证、记录结果，最后由主管领导评审措施的有效性。

</template>

</Slide>

## 宣贯分层：高层、中层、普通员工各有侧重

- **高层管理人员**：着重培训管理体系的**原理、原则、功能及控制方法**。
- **中层管理人员**：主要培训其**部门体系要素的工作内容**。
- **普通员工**：侧重培训程序性、操作性文件和记录中涉及**各自岗位的程序、规定、作业标准**。
- 分层的目的是让不同岗位的人都知道自己在体系里做什么、依据什么做、做到什么程度。

<template #notes>

宣贯培训要按对象分层。 高层管理人员重点学体系的原理、原则、功能及控制方法，理解体系为什么这样设计。 中层管理人员重点学本部门体系要素的工作内容，知道自己部门要落实哪些要求。 普通员工重点学程序性、操作性文件和记录中涉及本岗位的程序、规定和作业标准。 分层的目的，是让不同岗位的人都清楚自己在体系里做什么、依据什么做、做到什么程度。

</template>

</Slide>

## 纠正措施与预防措施：一个治已发生，一个防未发生

- **纠正措施**：为使管理体系运行中的不合格得到控制，**消除产生不合格的原因**。各级管理层及项目监理机构应确认不合格的重要程度及风险，判断是否需要采取纠正措施；分析原因；评价不再发生不合格的措施；实施并取证；记录结果；主管领导评审有效性。
- **预防措施**：充分利用体系运行及监理服务过程控制数据及以往历史经验，**消除潜在不合格的原因**。确定措施并得到审批；实施措施；记录实施过程；评价实施效果；提供效果证据。
- **区别**：纠正措施针对已经出现的不合格，预防措施针对尚未发生但可能发生的不合格。

<template #notes>

纠正措施和预防措施容易混。 纠正措施针对已经出现的不合格，目标是消除产生不合格的原因，流程是确认风险、分析原因、评价措施、实施取证、记录结果、评审有效性。 预防措施针对潜在不合格，利用体系运行数据、监理服务过程控制数据和历史经验，消除潜在原因，流程是确定并审批、实施、记录、评价效果、提供证据。 一句话区分：纠正措施治已发生，预防措施防未发生。

</template>

</Slide>

## 持续改进与认证：让体系长期有效

**持续改进**的两个来源：一是体系运行一段时间后发现不完善的地方，通过改进使之完善；二是国家、行业出台新的工程管理要求和标准后，改进原有体系以适应新要求。要做两件事：严格监测体系运行情况；对不符合及时采取有效的纠正和预防措施。

**管理体系认证**：由第三方认证机构依据特定管理体系标准，对企业或组织的管理体系进行审核、评定，并证明其符合标准要求。过程包括提出认证申请、认证机构进行文件审查、现场审核，审核通过后颁发认证证书。

认证的作用：

- **内部管理**：优化管理流程，提高工作效率，促使企业持续改进。
- **市场竞争**：提升企业信誉，体现企业实力，吸引更多客户。
- **风险控制**：帮助企业识别、评估和应对各类风险。
- **稳定合作**：促进企业与利益相关方的良好合作。

## 小结：建立四步，运行三段

- **建立**：准备（领导决策、成立班子、制定计划培训人员）→ 初始评审（六步并形成报告）→ 策划（方针目标、覆盖范围、机构职责、资源）→ 文件化信息（手册、程序文件、操作性文件和记录）。
- **运行**：试运行（宣贯、记录、纠正措施）→ 内部审核和管理评审 → 持续改进 → 管理体系认证。
- **两个关键主体**：内部审核由管理者代表组织，管理评审由最高管理者组织；例行内部审核和管理评审一般每年一次。
- **两条措施**：纠正措施消除已发生不合格的原因，预防措施消除潜在不合格的原因。
