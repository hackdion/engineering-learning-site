## 投标决策四原则：量力而行，集中优势

1. 充分衡量自身**人员和技术实力**能否满足工程要求，根据自身实力、经验和外部资源确定是否参与竞标。
2. 充分考虑**国家政策、建设单位信誉、招标条件、资金落实情况**等，保证中标后项目能顺利实施。
3. 一般情况下，与其将有限人力资源分散到几个小工程投标中，**不如集中优势力量参与一个较大工程监理投标**。
4. 对于**竞争激烈、风险特别大或把握不大**的工程项目，应**主动放弃投标**。

<Reveal label="为什么要“集中优势力量”投一个较大工程？">

因为目前工程监理单位普遍存在**注册监理工程师稀缺、监理人员数量不足**的情况。投标决策要从工程特点与企业自身需求之间选择最佳结合点，实现最优盈利目标。

</Reveal>

## 决策树法：期望值算出来，收益取最大

- **适用**：风险型决策。不考虑竞争对手，仅根据自身实力决定某些工程是否投标及如何报价时，适合采用。
- **结构**：决策点（**方框**）→ 方案枝 → 自然状态点（**圆圈**）→ 概率分枝 → 终点（**“△”**，右侧标损益值）。需要第二阶段决策的，用决策点“□”代替终点“△”。
- **计算**：一般**从终点逆向**逐步计算，每个自然状态点的损益期望值 **E = Σ（P × B）**，P 为概率分枝的概率，B 为损益值。
- **选择**：考虑收益值，取**最大**期望值；考虑损失值，取**最小**期望值；再结合决策者的才智与经验作最后判断。

<template #notes>

决策树记三件事：方框是决策点，圆圈是自然状态点，三角是终点；算的时候从右往左倒着算；比收益取最大，比损失取最小。

</template>

</Slide>

## 决策树示例：投 A 还是投 B？

资源有限，只能在 A、B 两项工程中选一项投标，或都不投。投**高价标**中标机会 **30%**，投**低价标**中标机会 **50%**；投标未果损失 **5 万元**（投标准备费）。

  { k: 'B 高价', v: ['250', '71.5'] },
  { k: 'B 低价', v: ['230', '112.5'] }

<Reveal label="B 低价方案的 112.5 万元是怎么算出来的？">

先算中标后的自然状态点：0.3 × 600 + 0.6 × 100 + 0.1 × （−100）= **230**。再算方案点：0.5 × 230 + 0.5 × （−5）= **112.5**。结论：投 A 宜投高价标，投 B 应投低价标，**选定 B 工程投低价标更为有利**。

## 投标策划与投标文件编制原则

**投标策划**

1. **明确投标目标，决定资源投入**：投标目标决定了企业层面对投标过程的资源支持力度。
2. **成立投标小组并确定任务分工**：由有类似工程监理投标经验的项目负责人全面负责，任务和职责界面清晰、人尽其职。

**投标文件编制原则**（编制投标文件是工程监理单位投标的**首要任务**）

1. **响应招标文件，保证不被废标**。
2. **认真研究招标文件，深入领会招标文件意图**，通过标前答疑会解决发现的问题，防止“失之毫厘，差之千里”。
3. **内容详细、层次分明、重点突出**，针对评分办法的重点得分内容有意识地说明和标设。

<template #notes>

策划就两件事：定目标、组小组。编制原则三条，第一条最要紧：先响应、不废标，再谈精益求精。第三条是技巧，评分重点要让评委一眼看到。

</template>

</Slide>

> 工程监理投标文件的**核心**是反映监理服务水平高低的**监理大纲**。

<Reveal label="“监理评标的重点”和“整个投标文件的精髓”分别指哪一部分？">

**工程监理实施方案是监理评标的重点**，建设单位特别关注资源投入：机构设置和人员配备（尤其是总监理工程师），以及检测、办公、交通和通信等设备配置。**工程监理难点、重点及合理化建议是整个投标文件的精髓**，既要全面涵盖“三控两管一协调”和安全生产管理职责，又要有针对性，并说明建议带来的效益。

</Reveal>

## 编制注意事项、开标答辩与投标后评估

**编制投标文件注意 6 点**：对招标文件作出实质性响应；机构设置合理，突出人员素质，**尤其是总监理工程师人选**；有类似工程监理经验；监理大纲体现技术、管理能力；报价符合招标文件要求和成本—利润测算；既要响应要求，又要巧妙回避苛刻要求，**避免盲目扩大监理工作范围**。

- **参加开标**：应按时参加开标，避免废标。
- **答辩**：拟定答辩的基本范围和纲领，细化到人和具体内容，组织演练、相互提问；了解竞争对手；各组织成员配齐后，**总监理工程师担当答辩的组织者**。
- **投标后评估**：对投标全过程的分析和总结，**无论投标成功与否都不可缺少**；评价决策是否正确、重难点和建议是否有针对性、人员和机构是否合理、报价预测是否准确等，任何细节都不能放过。

<template #notes>

注意事项最后一条很实用：为了中标盲目扩大监理范围，会给履约留隐患。投标后评估记一句话：成也好、败也好，都要做。

</template>

</Slide>

## 分析影响投标的四类正常因素

**非正常因素**（假招标、权力标、陪标、低价抢标、保护性招标等）均属违法行为，应予以禁止。**正常因素**分四类：

1. **建设单位（买方）**：对照综合评分标准逐一自我测评，特别分析**报价的分值比重**；分析授权和监理费用支付条件、资金落实和筹措、管理人员素质；施工单位已选定的，关注建设单位与施工单位的关系。
2. **投标人（卖方）自身**：按经营状况选择投标类型；量力而行，尽可能积极参与投标；可采用**联合体投标**扬长补短。
3. **竞争对手**：数量和实力、以往竞争结果、投标积极性、决策者情况。
4. **环境和条件**：**施工单位**（最直接、至关重要的环境条件）、工程难易、自然条件、设计单位水平、社会文化环境、工程条件和环境风险。

<template #notes>

四类因素按“买方、卖方、对手、环境”记。买方那条要盯住评分细则里报价占多少分；环境那条要记住施工单位是最直接、最要紧的环境条件。

</template>

## 生存型、竞争型、盈利型

<CompareCard :cols="['生存型', '竞争型', '盈利型']" :rows="[

  { k: '投标态度', v: ['即使不盈利甚至赔本也要投标', '即使低盈利也可投标', '即使难度大、困难多也可参与竞争，获取丰厚利润和社会经济效益'] }
]" />

<Reveal label="任务不饱满时，为什么要尽可能积极参与投标？">

教材给了四点理由：第一，参加投标项目多，中标机会就多；第二，在公众面前出现的机会多，起到广告宣传作用；第三，积累经验、掌握市场行情、收集信息、了解竞争对手惯用策略；第四，建设单位邀请时不参加（或不响应），可能破坏信誉度，失去开拓市场的机会。

</Reveal>

> 分析竞争对手时同样适用：对手面临生存危机，势必采用**“生存型”**策略；对手作为联合体投标，势必采用**“盈利型”**策略。

<template #notes>

三种投标类型按企业处境分：活不下去了是生存型，赔本也投；想打开新市场是竞争型，低利也投；日子好过是盈利型，难也敢投、要赚足。这套判断也可以反过来用在竞争对手身上。

## 机构设置、合理化建议与总监答辩

- **项目监理机构**：满足招标文件要求，必要时附专家名单；人员名单写明姓名、性别、年龄、专业、职称、拟派职务、资格，并以**横道图**明确每人进场及退场时间；总监理工程师应具备**同类工程监理经验**和良好的组织协调能力，复杂工程可考虑配备总监理工程师代表。
- **合理化建议**：招标人借此了解投标人的专业技术能力、管理水平以及对工程的熟悉和关注程度。
- **答辩的关键是总监理工程师的答辩**：携带答辩提纲和主要参考资料，带上笔和笔记本记录问题；切忌未弄清题意就匆忙作答。

<Reveal label="回答专家提问，教材提了哪“三要”？">

一要**抓住要害，简明扼要**；二要**力求客观、全面、辩证，留有余地**；三要**条理清晰，层次分明**。对概念不太理解的，可以请提问专家解释，或说出自己的理解并确认后再作回答。

</Reveal>

<template #notes>

机构设置要具体到每个人的进退场时间，用横道图表示。答辩是总监的主场，记住“三要”：抓要害、留余地、有条理。没听懂可以先确认，别抢答。

## 小结：会算、会选、会讲

<p class="dk-lead">决策 → 策划 → 编制投标文件 → 开标及答辩 → 投标后评估</p>

- 决策：**是否投、怎么投**；集中优势打大工程，没把握的**主动放弃**。
- 定量：综合评价法**权重之和为 1**、五级打分；决策树**逆向计算**，收益取**最大**期望值。
- 编制：首要任务；核心是**监理大纲**；实施方案是**评标重点**，难点重点及合理化建议是**精髓**。
- 策略：分析因素是**前提**，理解招标文件是**基础**，机构设置是**保证**；生存型、竞争型、盈利型按处境选。
- 计费：费率、建筑面积、人工时、服务内容，**由双方在合同中约定**。
