## 承包模式怎么分，监理就怎么委托

<p class="dk-lead">工程监理委托方式与工程承包模式<strong>密切相关</strong>：承包模式不同，委托方式也会不同。</p>

## DBB：按阶段线性推进，我国应用最广泛

<p class="dk-lead">建设单位委托勘察设计单位完成设计，再通过招标选择施工单位，施工单位按图施工。</p>

- **核心特点**是按工程建设阶段**线性推进**；适用于大多数设计要求明确、施工中设计变更不多的工程。也是**我国应用最广泛**的项目交付方式。
- **合同关系**：建设单位处于**核心地位**。勘察设计合同是项目启动的关键；施工合同是推进工程实体建造的直接依据。
- 勘察设计单位与施工单位之间**无直接合同关系**，但存在紧密的协作关系。
- 经建设单位同意，勘察设计单位、施工单位可将部分任务**分包**给有相应资质的单位；分包单位向总包单位负责，总包单位对分包单位履行管理和监督职责。

<template #notes>

DBB 就是“先设计、再招标、后施工”，一棒接一棒。合同上建设单位是中心，分别和设计、施工签合同；设计和施工之间没有合同，但要配合。

</template>

</Slide>

<Slide>

## EPC/DB：一家对设计、采购、施工负总责

<p class="dk-lead">承包单位对工程设计、采购、施工（<strong>EPC</strong>）或者设计、施工（<strong>DB</strong>）等实行总承包，并对工程质量、安全、工期和造价等<strong>全面负责</strong>。</p>

- 建设单位与工程总承包单位签订**工程总承包合同**。
- 设计任务分包的，总承包单位与设计分包单位就设计分包任务承担**连带责任**；施工任务分包的，与施工分包单位就施工分包任务承担**连带责任**。
- 总承包单位还与材料设备供应商签订采购合同，与金融机构、保险公司签订借款、保险等合同。

<Reveal label="国际上的“工程总承包管理模式”有什么不同？">

业主将设计与施工任务发包给专门从事设计与施工组织管理的**工程管理公司**。该公司**既没有设计力量，也没有施工队伍**，而是将设计和施工任务全部分包出去，自己专心致力于工程项目管理工作。

</Reveal>

<template #notes>

EPC 和 DB 的区别就在于采购：EPC 把采购也包进来，DB 只包设计和施工。不管哪种，总承包单位都要对质量、安全、工期、造价全面负责，分包出去的部分要和分包单位一起承担连带责任。

</template>

</Slide>

</template>

## 专业分包 vs 劳务分包

我国有大量企业不具备工程总承包或施工总承包资质和能力，主要作为分包单位承接专业分包或劳务分包任务。

  { k: '责任范围', v: ['质量、安全、工期等全面负责', '仅对劳务作业质量负责'] },
  { k: '合同对象', v: ['工程总承包或施工总承包单位', '工程总承包单位、施工总承包单位或专业分包单位'] }
]" />

> 劳务分包单位可以提供施工作业工具及简单设备，但**不负责工程技术、材料设备采购**等。

<template #notes>

专业分包包的是“一块专业工程”，技术也归它，责任全面；劳务分包只出人干活，只对劳务作业质量负责。注意合同对象：劳务分包还可以从专业分包单位那里接活。

## 平行承包：分开发包，监理来协调

<p class="dk-lead">建设单位将工程分解为若干可以独立发包的设计或施工标段，分别发包给不同承包单位。</p>

- **适用**：工程规模大、技术模块间界面清晰、建设单位或其委托的工程监理单位**管理协调能力强**的项目。
- **合同关系**：各承包单位之间**没有直接的合同关系**；需要彼此沟通的事项，**均需通过工程监理单位进行协调**。
- **优点**：有利于择优选择承包单位；有利于控制工程质量；有利于缩短建设工期。
- **不足**：组织管理和协调工作量大；工程造价控制难度大；不利于发挥技术水平高、综合管理能力强的承包商综合优势。

<Reveal label="为什么说承包单位之间的“相互制约”有利于质量？">

例如路基填筑与路面铺设分别由两个承包单位承包时，路基标高达不到设计要求的，路面铺设单位**不会同意**在此路基上铺设路面，否则要消耗大量路面材料去弥补高程。这种承包单位之间的制约机制**比自控更有约束力**。

</Reveal>

<template #notes>

平行承包的关键句：承包单位之间没有合同，沟通全靠监理协调。所以它要求监理的协调能力强。优点三条、不足三条，对称着记。

</template>

</Slide>

## 项目融资 + 工程承包：PPP

- 我国大力推行的项目融资方式是**政府和社会资本合作（PPP）**。依据国办函〔2023〕115号，PPP 应**全部采取特许经营模式**实施。
- **特许经营期限原则上不超过 40 年**；投资规模大、回报周期长的可以根据实际情况适当延长，法律法规另有规定的除外。
- PPP 应限定于**有经营性收益的项目**，如交通、物流、市政、生态环境治理、具有发电功能的水利、社会项目和新型基础设施等。

## 监理委托方式：跟着承包模式走

选择与承包模式相匹配的委托方式，有利于**优化资源配置，明确权责**；**提高管理效率，减少冲突**；**有效控制项目目标，加强风险管理**。

  { k: '施工总承包模式', v: ['建设单位与施工总承包单位只签订一份承包合同，宜委托一家工程监理单位'] },
  { k: '工程总承包模式', v: ['针对一个承包主体，应委托一家工程监理单位；往往还需为建设单位提供工程建设全过程咨询服务'] }
]" />

<template #notes>

委托方式跟承包方式一一对应：平行承包可以一家也可以多家；施工总承包“宜”委托一家；工程总承包“应”委托一家。注意“宜”和“应”的区别。

## “总监理单位”，以及两种总承包下的委托

- **“总监理单位”**：建设单位先委托一家总监理单位，再与其共同选择几家工程监理单位分别承担不同施工合同段；或在已选定的几家中确定一家。总监理单位负责**总体策划和协调控制**，管理其他各工程监理单位，可**减轻建设单位的管理压力**。
- **施工总承包模式下宜委托一家**：有利于明确界定责任边界、避免扯皮；有利于施工合同管理和协调控制，施工总承包单位只与一家监理单位对接；有利于对质量、进度和造价统筹规划与控制。
- **工程总承包模式下应委托一家**：监理单位往往还要提供全过程咨询服务，需具备**全过程工程咨询服务能力**；面对合同管理难度大、设计施工过程**“他控机制”薄弱**等问题，做好综合策划、组织协调、目标管控及接口管理。

<template #notes>

总监理单位相当于“监理的监理”，替建设单位管其他几家监理。工程总承包下的监理更难，因为设计和施工都在总包手里，外部监督弱，所以要求监理有全过程咨询的能力。

</template>

</Slide>

## 小结：先认承包模式，再选委托方式

<p class="dk-lead">承包模式不同，监理委托方式也不同；工程监理主要定位在施工阶段。</p>

- **DBB**：线性推进、我国最广泛；问题是周期长、变更贵、协调难。
- **EPC/DB**：一家负总责、固定总价；问题是前期工作量大、报价高、道德风险高。
- **专业分包**全面负责，**劳务分包**只对劳务作业质量负责。
- **平行承包**靠监理协调；**联合体**共同签约、连带责任；**合作体**先签意向协议、风险在建设单位。
- **PPP** 全部采取特许经营，期限原则上不超过 **40 年**。
- 委托方式：平行承包**一家或多家**（多家可设“总监理单位”）；施工总承包**宜**委托一家；工程总承包**应**委托一家。
