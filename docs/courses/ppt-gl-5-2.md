## 监理怎么干：按程序走，按原则办

- 严格按程序开展工作，不但能有效监督和保障工程质量和进度、合理控制造价、履行安全生产管理职责，还可**规范建设单位、施工单位的质量安全行为**。
- 遵循一定的原则实施监理，以达到**实现工程建设目标、提升投资效益和落实社会责任**等目的。
- **实施程序**：从签订工程监理合同后开始，直至完成合同规定的全部监理工作为止的一系列工作步骤和流程。

<template #notes>

这一节两件事：程序和原则。程序是从签合同到交总结的六个环节，原则是八条做事的准则。程序管“先做什么后做什么”，原则管“怎么做才对”。

## 组建项目监理机构

- 投标、承接任务时，可选派符合总监理工程师任职资格的人员主持或参与；签订合同时，该主持人即可作为总监理工程师在合同中明确。
- 中标后，**工程监理单位法定代表人**应根据合同及《建设工程监理规范》，**书面任命总监理工程师**，并组建项目监理机构。
- 监理人员包括**总监理工程师、专业监理工程师和监理员**，专业配套、数量满足需要，**必要时可设总监理工程师代表**。
- 总监理工程师是项目的总负责人：**对内向工程监理单位负责，对外向建设单位负责**；确定机构人员及岗位职责，并根据需要及时调整。

<template #notes>

组建机构记三点：总监由法定代表人书面任命；机构里是总监、专监、监理员三类人，总监代表是“必要时”才设；总监对内对监理单位负责，对外对建设单位负责。

## 规范化开展工程监理工作

按照合同约定、法律法规、工程建设标准、监理规划及监理实施细则开展工作，规范化主要体现在两方面：

1. **过程控制规范化**：通过清晰的控制流程、明确的操作标准和有效的监督机制，在质量、造价、进度控制及安全生产管理等方面做到**工作目标明确、职责分工严密、工作程序合规、工作手段有效**。
2. **工作记录与报告规范化**：工作记录与报告是监理工作的**核心成果**，应实现**“责任可界定、风险可防控、过程可追溯”**；总监理工程师应定期检查工作成果。

<Reveal label="过程控制规范化的本质，教材用一句话怎么说？">

**“用规则替代经验，用系统替代个人”**，在标准化框架下高效协作，同时为创新留出空间。

</Reveal>

<template #notes>

规范化两条：过程控制和记录报告。过程控制的本质那句话要背：用规则替代经验，用系统替代个人。记录报告要做到三个“可”：责任可界定、风险可防控、过程可追溯。

</template>

</Slide>

- 工作完成后，及时整理、归档保存监理规划、监理实施细则、监理日志、监理月报、工程质量评估报告等，并向建设单位提交**合同约定**的文件资料。
- 合同未作明确约定的，应移交：**工程监理管理文件**；**工程质量、造价、进度控制及安全生产管理文件**；**工程监理验收文件资料**等。

## 监理工作总结：六部分，一条主线

<span class="dk-tag">项目概况</span><span class="dk-tag">监理工作执行情况</span><span class="dk-tag">监理工作成效</span><span class="dk-tag">问题与挑战</span><span class="dk-tag">改进建议与经验总结</span><span class="dk-tag">结语与展望</span>

- **执行情况**按质量控制、造价控制、进度控制、安全生产与文明施工管理分别写，另含合同管理、信息管理、组织协调等方面的数据分析与情况总结。
- **成效**：质量验收结论、避免的重大质量事故隐患、工期实现情况、投资节约或预算控制效果、安全隐患排查处置及文明施工评价等。
- **结语与展望**：整体自评、建设单位反馈或行业主管部门评价、同类工程改进方向和能力提升目标。

> 主线：**“工作执行 → 成果呈现 → 问题反思 → 改进方向”**，**数据化**呈现工程监理价值。

<template #notes>

总结六部分不用逐字背，抓主线：做了什么、做成了什么、遇到什么问题、以后怎么改。关键词是“数据化”，用次数、金额、天数说话。

</template>

</Slide>

## 预防为主：把重点放在“预控”上

工程项目具有一次性、单件性等特点，存在很多风险，监理要有预见性，**防患于未然**。

<Steps title="预控贯穿全过程" :steps="[
  { t: '编制监理规划及实施细则时', d: '分析和预测可能发生的问题，制定相应对策和预控措施' },
  { t: '施工前', d: '审查施工组织设计、专项方案及材料质量证明文件，确保技术可行、措施到位' },
  { t: '施工过程中', d: '通过旁站、巡视和平行检验，加强对关键工序、关键部位的质量监控' },
  { t: '对可能出现的风险', d: '如深基坑坍塌、高支模失稳等，要求施工单位制定应急预案，并定期检查落实情况' }
]" />

<template #notes>

预防为主不是一句口号，教材给了四个落点：编文件时预测问题，施工前审方案，施工中旁站巡视平行检验，对大风险要求编应急预案并且定期检查。

<p class="dk-lead">组建机构 → 规划细则 → 规范化开展 → 竣工预验收 → 移交资料 → 监理总结</p>

- 总监由**法定代表人书面任命**；对内向监理单位负责，对外向建设单位负责。
- 规划是**指导性**文件、**监理单位技术负责人**批准，报送后经**建设单位确认**方可实施；细则是**操作性**文件、**专监编写、总监批准**。
- 过程控制规范化：**用规则替代经验，用系统替代个人**；记录报告做到三个“可”。
- 预验收由**项目监理机构**组织，通过后出**工程质量评估报告**；竣工验收由**建设单位**组织。
- 八项原则：依法依规、科学规范、**预防为主**、**责任到位**、协调沟通、实事求是、廉洁自律、持续改进。
- 总监理工程师负责制：责任、权力、利益三个主体，**核心是责任**。
