## 工程风险管理：识别不确定性，再持续应对

<p class="dk-lead">工程风险管理贯穿项目决策和实施，围绕可能的损失不确定性，识别风险、分析评价、制定并实施应对策略，持续监控其效果。</p>

- 工程监理单位既要加强自身履职风险管理，也可以为委托方提供风险管理服务。
- 从风险识别到应对监控，形成持续循环的管理过程。

<template #notes>

工程风险管理既是工程监理单位自己的工作，也是可以提供给委托方的服务。它不是只列出风险，而是要识别、分析评价、选择并落实应对办法。实施中还要跟踪风险变化，检查应对有没有效果。

## 工程风险：关注损失的不确定性

- 工程风险发生在工程项目**决策和实施过程中**，体现为实际结果与预期目标的差异及其发生概率。
- 差异包括损失的不确定性和收益的不确定性；本节所说的工程风险侧重**损失的不确定性**。
- 风险识别要找出引起风险的主要因素、风险性质，以及风险可能造成的后果。

<Reveal label="风险识别只要列出可能发生的事件吗？">

不够。还要识别引起风险的主要因素和风险的性质，并分析它可能带来的后果。

</Reveal>

<template #notes>

教材把工程风险放在项目决策和实施过程中讨论，重点是实际结果偏离预期目标的可能性。本节关注损失的不确定性，而不是收益的不确定性。识别时不能只写事件名称，还要找出风险因素、判断风险性质，并考虑可能的后果。

## 初始清单：先系统列风险，再结合工程修正

**技术风险**：设计、施工、其他、自然与环境。  
**非技术风险**：政治法律、经济、组织协调、合同、人员、材料设备。

- 初始清单可参照保险公司或风险管理机构公布的潜在损失一览表，再结合工程情况具体化；也可按单项工程、单位工程，并从时间维、目标维和因素维分解。
- **初始清单不是识别的最终结论**；还要用同类工程经验数据或针对性调查补充、修正。
- 两个工程不会有完全一致的风险；调查既用于确认已有风险，也可能发现此前遗漏的重要风险。

<template #notes>

初始清单把工程风险先分成技术和非技术两大类，方便系统查找。技术风险涵盖设计、施工、其他及自然与环境，非技术风险包括政治法律、经济、组织协调、合同、人员和材料设备。清单可以从潜在损失资料出发，也可以把大型复杂工程逐层分解，再从不同维度识别风险。它只是起点，不是最终结论；要结合本工程特点，用经验数据和调查继续补充、修正。

</template>

</Slide>

## 风险清单：把风险、后果和措施放在一起

- 风险识别最主要的成果是**风险清单**，它是风险分析与评价的重要基础。
- 风险清单至少记录：**风险因素、可能造成的后果、可能采取的措施**；还可填写工程名称、编号、日期、审核和批准信息。
- 清单用于描述存在的风险并记录可能减轻风险的行为，不能代替后续分析与评价。

## 风险分析与评价：从单项风险看到综合影响

- 分析发生概率、影响范围、可能损失大小，以及多种风险因素对建设工程目标的总体影响。
- 任务包括判断单一风险发生概率、影响范围和发生时间，分析结果对项目目标的影响，并综合评估风险严重程度。
- 风险度量可写为 **R = F(O, P)**：O 是风险事件的所有后果集，P 是对应于所有风险结果的概率值集。

<Reveal label="怎样用概率和损失结果度量风险？">

连续型概率分布在实践中常用均匀分布、三角分布及正态分布。

离散型损失值可计算数学期望和方差：

$$E(X)=\sum x_iP(x_i)\qquad(9-2)$$

$$D(X)=\sum [x_i-E(X)]^2P(x_i)\qquad(9-3)$$

连续型损失值用概率密度函数 $f(x)$ 计算：

$$E(X)=\int_{-\infty}^{+\infty}xf(x)\mathrm{d}x\qquad(9-4)$$

$$D(X)=\int_{-\infty}^{+\infty}[x-E(X)]^2f(x)\mathrm{d}x\qquad(9-5)$$

</Reveal>

<template #notes>

分析评价不只看某一个风险会不会发生，还要看影响范围、发生时间和损失大小，并考虑多种风险的综合影响。教材用 R 表示风险事件对建设工程目标的影响，依据是后果集合和对应概率集合。损失值可以是离散型或连续型随机变量，连续型概率分布常用均匀、三角和正态分布。两种情形都可用期望值和方差来量化。

</template>

</Slide>

## 风险等级：把概率和后果放进同一张图

- 风险事件概率和事故后果严重程度通常各划分为**三个至五个等级**。
- 概率与后果各分为大（H）、中（M）、小（L），交叉形成九个区域；风险量再归为 **VL（很小）、L（小）、M（中等）、H（大）、VH（很大）**。

- **大、很大**：不可接受，重点关注；**中等**：希望有的风险；**小**：可接受；**很小**：可忽略。

## 风险回避与损失控制：看风险，也看措施代价

损失控制是**主动、积极**的风险应对策略。

<CompareCard title="两类主动应对" :cols="['风险回避', '损失控制']" :rows="[
  { k: '适用情形', v: ['风险发生概率很大且可能损失很大；或损失概率不大但后果灾难性、无法弥补', '通过预防降低或消除损失发生概率，通过减少损失降低严重性或遏制发展'] },
  { k: '具体安排', v: ['放弃项目、原有计划或改变目标', '损失控制计划由预防计划、灾难计划和应急计划组成'] },
  { k: '制定时考虑', v: ['避免可能产生的损失', '综合考虑控制效果，以及费用和时间代价'] }
]" />

- 灾难计划要明确人员安全撤离、伤亡人员救援处理、控制事故发展与损害，以及受影响区域恢复正常。
- 应急计划准备替代方案，并规定不同工作部门的相应职责。

<template #notes>

当风险发生可能性和损失都很大，或者后果具有灾难性且无法弥补时，可以考虑回避。损失控制是主动、积极的策略，同时包括预防和减少损失；确定措施时要比较效果与费用、时间代价。完整的损失控制计划包括预防、灾难和应急计划。灾难计划明确撤离、救援、控制事故和恢复安排，应急计划则准备替代方案并规定部门职责。

</template>

## 风险转移：合同与保险各有边界

<CompareCard title="两种风险转移方式" :cols="['非保险转移（合同转移）', '保险转移']" :rows="[

- 非保险转移可用于转移物价上涨、法规政策变化、设计变更等引起的投资增加；保险不能覆盖所有工程风险。
- 例：合同可约定建设单位不承担场地条件责任，或采用固定总价合同将涨价风险转移给施工单位。

<template #notes>

风险转移分为非保险转移和保险转移。非保险转移常见做法包括合同分配、工程分包和第三方担保，例如固定总价合同可以转移涨价风险；使用时要防止合同理解不一致，也要衡量转移代价。采用保险时要考虑安排方式、类别、保险人、保险范围、免赔额和保险费，免赔数额或比例由投保人确定。并非所有风险都可保或适宜投保，因此保险要和其他策略配合。

## 风险自留与监控：主动承担，也持续检查

  { k: '含义', v: ['将工程风险保留在管理主体内部，通过内部控制等化解', '跟踪已识别风险、识别新风险，保证风险计划执行并评估策略有效性'] },

  { k: '注意事项', v: ['计划性自留应与其他策略结合；重大和较大风险应已有保险或损失控制计划', '记录跟踪结果并形成报告；无论是否出现新风险，都要重新估计风险'] }

- 非计划性风险自留可能源于缺乏风险意识、风险识别或分析评价失误，以及风险决策或实施延误。
- 跟踪检查报告应**及时、准确、简明扼要**，详细程度按决策者需要确定。

<template #notes>

非计划性自留是被动的，可能源于缺乏风险意识、风险识别或分析评价失误，以及决策或实施延误；计划性自留则是经过识别评价后有意识的选择。计划性自留要和其他策略结合，对重大和较大的风险应已投保或实施损失控制。风险监控要检查应对效果、风险变化和新风险征兆，并判断是否启动应急计划。跟踪检查结果应形成及时、准确、简明的报告，而且每次都要重新估计风险。

</template>

</Slide>

## 小结：识别、分析、应对、实施、监控

<p class="dk-lead">风险管理围绕损失不确定性展开：识别风险 → 分析评价 → 选择应对 → 落实措施 → 监控效果。</p>

- 风险识别以**风险清单**为主要成果；评价时结合概率、后果及多种风险的综合影响。
- 应对策略有**回避、损失控制、转移、自留**，按风险情况选择和组合。
- 风险监控要跟踪变化、发现新风险、评估效果，并及时报告。
