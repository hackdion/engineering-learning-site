## 合同管理的一条时间轴：采购、订立、履行

<p class="dk-lead">建设工程合同管理覆盖<strong>招标采购、合同订立、合同履行</strong>多个阶段，每个阶段都有明确的任务和适用方法。</p>

<Steps title="三个阶段的主要任务" :steps="[
  { t: '招标采购管理', d: '总体策划、按标准文本编制招标文件和合同条件、细化合同界面、合理选择计价方式' },
  { t: '合同订立管理', d: '组织合同评审、争取订立前的磋商与谈判' },
  { t: '合同履行管理', d: '制度与计划、交底、跟踪诊断纠偏、变更、信息化、价款支付、索赔争议、评价总结、合作共赢、绿色低碳' }
]" />

> 合同不仅规定各方责任、权利和义务，还约定工作内容、工作流程和工作要求，同时划定各方的**风险分担**。

## 招标采购策划：先定标段，再定界面

<div class="dk-cols">

<div>

### 总体策划做什么

- 明确项目目标，回答**做什么、何时做、如何做**。
- 用目标分解、**工作分解结构**（WBS）制定总体采购计划和采购清单。
- 进行**采购标段划分**，考虑工程如何分标、物资如何分批采购。
- 以投资计划中的重要控制日期（如**开工日、竣工日**）为关键节点，用横道图、网络图统筹衔接。
- 确定采购方式（直接采购、询价比选、公开招标、邀请招标）以及自行组织还是委托代理机构。

</div>

<div>

### 合同界面管什么

- 五类界面：**工作范围、风险、组织、费用、进度**。
- 建设单位（或其委托的监理单位）、承包单位应有专门的**合同界面协调人**。
- 典型界面：土建合同与安装合同之间、安装合同与设备供应合同之间的责任界面和接口对接。
- 方法：文字说明、清单列举、图纸标注，做到**不遗漏、不重复**，各方均有合同依据。

</div>

</div>

<Reveal label="合同界面管理只划清责任就够了吗？">

不够。还应做到不同界面之间**信息开放透明、传递顺畅高效**，各方能根据项目实施进展相互检查、及时通报、确认更新，并通过合同界面管理**超前协调**项目各方工作。

</Reveal>

<template #notes>

总体策划的关键词是分解和排序：把项目拆成采购包，再按开工、竣工这些控制日期排出先后。合同界面管理的关键词是边界：五类界面要划清，而且不能只写在纸上，信息还要能流动。实践中扯皮最多的就是土建与安装、安装与设备供应之间的接口。

</template>

</Slide>

> 施工期限**一年左右**的项目可考虑固定总价合同；建设周期**一年半以上**的工程项目，宜采用可调总价合同。

## 合同评审：签之前先查五件事

<Steps title="合同评审的五项内容" :steps="[
  { t: '合法性、合规性评审', d: '不违反法律、行政法规、地方性法规的强制性规定，不违反国家标准、行业标准、地方标准的强制性条文' },
  { t: '合理性、可行性评审', d: '权利义务公平合理，不存在对合同条款的重大误解，不存在合同履行障碍' },
  { t: '合同严密性、完整性评审', d: '合同条件、技术标准、技术资料、外部环境条件、自身履约能力等满足履行要求' },
  { t: '与产品或过程有关要求的评审', d: '没有缺项漏项，没有文字歧义、数据不全、条款冲突，合同组成文件之间没有矛盾；招标项目还应符合招标文件和投标文件的实质性要求' },
  { t: '合同风险评估', d: '履行过程中可能出现的经营风险、法律风险处于可以接受的水平' }
]" />

> 评审由工程管理、经济、技术和法律方面的专业人员共同完成；发现的问题应**以书面形式提出**，并予以澄清或调整。

<template #notes>

五项评审按顺序记：合法、合理、严密、内容、风险。合法性解决「能不能签」，合理性解决「签了能不能干」，严密性解决「条款够不够」，内容评审解决「文件之间打不打架」，风险评估解决「最坏情况能不能承受」。评审发现问题必须书面提出，口头说说等于没提。

## 磋商谈判：把风险前移到签约阶段

**三个目标**

<span class="dk-tag">补正与完善：修正招标投标文件和合同文本中的错误、遗漏、不一致或矛盾</span><span class="dk-tag">争取公平条件：修改不符合行业惯例、显失公平、权利义务不对等或风险分配不合理的条款</span><span class="dk-tag">实现互利双赢：既满足项目目标，又保障当事方合法权益</span>

<Reveal label="磋商谈判有哪些方法与要点？">

1. 组建由精通合同、熟悉业务、善于沟通协调的人员组成的**谈判小组**，负责人应具备全面合同知识和谈判技巧。
2. 系统梳理谈判议题，**按优先级排序**，明确核心问题与次要问题。
3. 设定**谈判底线**，对关键条款制定可接受的底线与期望达成的目标。
4. **分析对方意图**，预测对方可能提出的问题与真实关切，制定有针对性的应对策略。
5. **倾听为先**，理解意图，营造合作氛围；保持诚信，基于事实和数据发言，不隐瞒关键信息，也不作无法兑现的承诺。

</Reveal>

<template #notes>

磋商谈判不是压价，而是把模糊的表达变清晰、把不公平的条款拉回来。三个目标里，补正与完善最基础，争取公平条件最考验能力，互利双赢是最终落点。方法五条，核心是准备：小组、议题、底线、对方意图，最后才是现场沟通。

</template>

</Slide>

## 履行前的准备：制度、计划、交底

<div class="dk-cols">

<div>

### 合同管理制度

- 合同目标管理制度
- 合同评审会签制度
- 合同交底制度
- 合同报告制度
- 合同文件资料归档保管制度
- 合同管理评估和绩效考核制度

### 合同实施计划

1. 合同实施总体安排
2. 合同分解与管理策划
3. 合同实施保证体系的建立

</div>

<div>

### 合同交底的五项内容

1. 合同的主要内容
2. 合同订立过程中的特殊问题及合同待定问题
3. 合同实施计划及责任分配
4. 合同实施的主要风险
5. 其他应进行交底的合同事项

> 交底可用书面、电子数据、视听资料和口头形式；**书面交底应签署确认书**。

</div>

</div>

<template #notes>

履行前的准备分三层：制度管人、计划管事、交底管信息。六项制度里，交底制度和报告制度最容易被忽略，但恰恰是执行层面最常用的。实施计划三项，注意保证体系要与其他管理体系协调一致。交底五项内容里，「合同待定问题」和「主要风险」是重点，不能只念合同条文。

</template>

## 履行中：跟踪、诊断、纠偏与变更

<div class="dk-cols">

<div>

### PDCA 循环下的四项工作

1. 全面收集、分类处理合同实施信息，与实施计划对比，**查找偏差**。
2. 对偏差进行定性、定量分析，包括**原因分析、责任分析、趋势预测**，并通报情况。
3. 根据偏差结果制定**纠偏措施或方案**，与其他相关方沟通协调。
4. 采用**闭环管理**持续跟踪，直至落实完成。

</div>

<div>

### 合同变更的四个条件

1. 变更内容符合合同约定或法律法规规定；超过原设计标准或批准规模的，应按规定办理**变更审批**。
2. 变更或变更异议的提出，符合合同约定或法律法规规定的**程序和期限**。
3. 变更经当事方或其授权人员**签字或盖章**后实施。
4. 变更对合同价格及工期有影响时，**相应调整合同价格和工期**。

</div>

</div>

> 收到对方信函、文书、会议纪要等文件后，应**及时回复并存档**；商谈结果可用补充协议、会议纪要、备忘录固定下来并跟踪落实。

<template #notes>

跟踪诊断纠偏是一个闭环：找偏差、查原因、定措施、跟到底。合同变更四个条件可以概括成：内容合法、程序合规、签字盖章、价期调整。现场最容易出问题的是变更没有书面签字，或者只签了技术变更却没同步调整价格和工期。

</template>

</Slide>

## 价款支付与索赔：两条高压线

**价款支付要点**

- 以合同为依据，保证计量计价规则明确、严密。
- 遵守支付周期与程序：付款申请提交时间、审核批准时限、款项支付期限。
- 所有支付行为**有据可查**：支付证书、付款凭证等。
- 《保障中小企业款项支付条例》：机关、事业单位从中小企业采购货物、工程、服务，应当自交付之日起 **30 日**内支付；合同另有约定的，付款期限最长不得超过 **60 日**。

<Reveal label="索赔应当符合哪些条件？">

1. 依据合同约定提出；合同没有约定或约定不明时，按法律法规规定提出。
2. 全面、完整地收集和整理索赔资料。
3. 索赔意向通知及索赔报告按约定或法定的**程序和期限**提出。
4. 索赔报告说明索赔理由，提出**索赔金额及工期**。

索赔证据包括当事人陈述、书证、物证、视听资料、电子数据、证人证言、鉴定意见、勘验笔录；**经查证属实的证据**才能作为认定事实的依据。

</Reveal>

<template #notes>

支付和索赔是合同履行中最容易起冲突的两块。支付记 30 日和 60 日两个数字，以及「有据可查」四个字。索赔记四个条件：有依据、有资料、有程序期限、有金额和工期。证据八种里，电子数据现在越来越重要，但无论哪种，都要经查证属实。

</template>

</Slide>

## 情景推演：这份合同该不该签？

## 小结：三个阶段，十个动作

- **采购**：总体策划定标段与节点，标准文本保条款质量，界面管理划清边界，计价方式分配风险。
- **订立**：五项评审把住合法、合理、严密、内容、风险；磋商谈判把风险前移。
- **履行**：制度与计划打底，交底传达到位，PDCA 跟踪纠偏，变更四条件，支付 30/60 日，索赔四条件，最后复盘总结。
- **理念**：合作共赢三句话，绿色低碳全过程。
