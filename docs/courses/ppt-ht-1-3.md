## 委托代理的四个特征

<Steps title="委托代理为什么是「意定代理」" :steps="[
  { t: '基于委托授权产生', d: '需要在代理人与被代理人之间存在基础法律关系，如委托合同、合伙合同、工作隶属关系；但只有被代理人授权后，委托代理关系才真正建立' },
  { t: '以实施民事法律行为为职能', d: '代理活动能产生民事法律后果，在被代理人与第三人之间发生、变更或终止民事法律关系' },
  { t: '以被代理人名义从事民事法律行为', d: '代理人以自己的名义进行民事活动，不属于代理，法律后果由行为人自己承担' },
  { t: '在代理权限范围内独立表示自己的意志', d: '不得擅自变更或扩大代理权限；代理人有别于证人、居间人，后者只能起媒介作用' },
  { t: '法律后果由被代理人承担', d: '既包括对合法代理行为承担民事责任，也包括对不当代理行为承担民事责任' }
]" />

> 授权行为是**单方**法律行为，仅凭被代理人一方意思表示即可生效；被代理人有权随时撤销授权，代理人也有权随时辞去委托，但辞去委托给被代理人和善意第三人造成损失的，应负赔偿责任。

<template #notes>

委托代理的四个特征，第五步讲的是后果归属，可以和前四步一起记：有授权、办法律行为、用被代理人名义、权限内独立表示、后果归被代理人。施工现场的项目经理、总监理工程师、招标代理机构，都是典型的委托代理，授权来自单位法定代表人。

## 无权代理：三种情形与三条救济

**三种情形**

<span class="dk-tag">没有代理权而为的代理行为</span><span class="dk-tag">超越代理权限而为的代理行为</span><span class="dk-tag">代理权终止后的代理行为</span>

<Reveal label="无权代理发生后，被代理人和相对人各有什么权利？">

- 被代理人可以按对自己有利或不利的原则，行使**追认权**或**拒绝权**；追认后，无权代理转化为合法代理。
- 相对人可以**催告**被代理人自收到通知之日起**一个月内**予以追认；被代理人未作表示的，**视为拒绝追认**。
- 行为被追认前，**善意相对人**有撤销的权利；撤销应当以通知的方式作出。
- 行为人没有代理权、超越代理权或代理权终止后仍实施代理行为，未经被代理人追认的，**对被代理人不发生效力**。

</Reveal>

<template #notes>

无权代理三种情形记「没有、超越、终止后」。救济记三个权利：被代理人的追认权和拒绝权，相对人的催告权和撤销权。一个月和「未表示视为拒绝」是两个精确考点。注意撤销权只属于善意相对人，且必须在追认前行使。

</template>

</Slide>

## 民事责任：两大体系与十一种承担方式

<p class="dk-lead">民事责任是民事主体因实施民事违法行为，依法或依约承担的对其不利的民事法律后果。</p>

**两大体系**：**合同责任**（违约责任、缔约过失责任）与**侵权责任**。

**十一种承担方式**

<span class="dk-tag">停止侵害</span><span class="dk-tag">排除妨碍</span><span class="dk-tag">消除危险</span><span class="dk-tag">返还财产</span><span class="dk-tag">恢复原状</span><span class="dk-tag">修理、重作、更换</span><span class="dk-tag">继续履行</span><span class="dk-tag">赔偿损失</span><span class="dk-tag">支付违约金</span><span class="dk-tag">消除影响、恢复名誉</span><span class="dk-tag">赔礼道歉</span>

> 承担民事责任的方式，可以**单独适用**，也可以**合并适用**。

<template #notes>

民事责任先分两大体系：合同责任和侵权责任。合同责任里再分违约责任和缔约过失责任，这是后面两页的内容。十一种承担方式不用死背顺序，按「制止、恢复、补偿、精神」四类去记。单独适用或合并适用这句话，是判断题的常客。

<Reveal label="缔约过失责任与违约责任有什么区别？">

缔约过失责任发生于**合同不成立或者合同无效**的缔约过程，构成条件必须同时具备：合同尚未成立；缔约当事人有过错；对缔约一方有损害后果；过错行为与损失有因果关系。典型情形包括假借订立合同恶意磋商、故意隐瞒与订立合同有关的重要事实或提供虚假情况、其他违背诚信原则的行为。当事人知悉的商业秘密，无论合同是否成立都不得泄露或不正当使用。

## 小结：三要素、四特征、两责任

- **合同关系**：主体、客体、内容三要素；法律事实分行为与事件。
- **委托代理**：四个特征；无权代理三种情形，追认期一个月；终止五种原因。
- **民事责任**：合同责任与侵权责任，十一种承担方式、五个原则；违约责任与缔约过失责任的分界在合同是否成立。
- **刑事责任**：主刑五种、附加刑三种；工程领域重点看质量安全、生产安全、串标三类罪名。
