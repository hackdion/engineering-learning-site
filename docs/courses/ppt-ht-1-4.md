## 担保五方式：人保、物保、钱保

<p class="dk-lead">担保是当事人根据法律规定或者双方约定，为促使债务人履行债务、实现债权人权利的法律制度；分<strong>人的担保</strong>和<strong>物的担保</strong>。</p>

<Steps title="《民法典》规定的五种担保方式" :steps="[

  { t: '抵押', d: '物的担保：债务人或第三人以不转移占有的方式提供财产担保' },

  { t: '留置', d: '法定担保：债权人留置已合法占有的债务人动产并优先受偿' },
  { t: '定金', d: '金钱担保：一方先行支付一定数额货币，以定金罚则约束双方' }
]" />

> 担保活动应当遵循**平等、自愿、公平、诚实信用**的原则；设立担保物权，应当依法订立担保合同。

## 保证期间与保证责任：六个关键规则

<Reveal label="保证期间没有约定或者约定不明确，保证人承担保证责任的期间是多久？">

保证期间是确定保证人承担保证责任的期间，**不发生中止、中断和延长**。

- 债权人与保证人可以约定保证期间，但约定的保证期间早于主债务履行期限或者与主债务履行期限同时届满的，**视为没有约定**。
- 没有约定或者约定不明确的，保证期间为主债务履行期限届满之日起 **六个月**。
- 债权人与债务人对主债务履行期限没有约定或者约定不明确的，保证期间自债权人请求债务人履行债务的**宽限期届满之日**起计算。
- 债权人和债务人变更主债权债务合同的履行期限，未经保证人书面同意的，**保证期间不受影响**。

</Reveal>

**保证责任的其他规则**

- 未经保证人书面同意变更主合同：减轻债务的，保证人仍对变更后的债务担责；加重债务的，对加重部分不担责。
- 同一债务有两个以上保证人：按约定份额担责；没有约定份额的，债权人可以请求任何一个保证人在其保证范围内承担。
- 债权人转让债权未通知保证人的，该转让对保证人不发生效力；未经书面同意允许债务人转移债务的，保证人对未经同意转移的债务不再担责。
- 保证人承担保证责任后，有权在其承担范围内向债务人**追偿**。

<template #notes>

保证期间记三句话：不中止不中断不延长；没有约定是六个月；约定早于或同时届满视为没有约定。保证责任记一个总原则：保证人只对自己书面同意的事情负责。变更主合同、转移债务，只要没经过保证人书面同意，加重部分或转移部分就不担责。

</template>

</Slide>

## 抵押：不转移占有，哪些财产能押

<CompareCard title="抵押财产范围（可打开「遮住自测」）" :cols="['可以抵押', '不得抵押']" :rows="[

  { k: '动产', v: ['生产设备、原材料、半成品、产品；交通运输工具；正在建造的船舶、航空器', '所有权、使用权不明或者有争议的财产；依法被查封、扣押、监管的财产'] },
  { k: '其他', v: ['法律、行政法规未禁止抵押的其他财产；抵押人可以将上述财产一并抵押', '学校、幼儿园、医疗机构等为公益目的成立的非营利法人的教育设施、医疗卫生设施和其他公益设施'] },
  { k: '房地一体', v: ['以建筑物抵押的，占用范围内建设用地使用权一并抵押；以建设用地使用权抵押的，地上建筑物一并抵押；未一并抵押的视为一并抵押', '乡镇、村企业的建设用地使用权不得单独抵押'] }
]" />

<Reveal label="抵押什么时候设立？抵押财产还能转让吗？">

- 以建筑物和其他土地附着物、建设用地使用权、荒地等土地承包经营权、正在建造的建筑物抵押的，应当办理抵押登记，**抵押权自登记时设立**。
- 以动产抵押的，**抵押权自抵押合同生效时设立**；但不得对抗正常经营活动中已经支付合理价款并取得抵押财产的买受人。
- 抵押期间抵押人可以转让抵押财产，当事人另有约定的除外；**抵押权不受影响**，但应及时通知抵押权人。
- 抵押权人证明转让可能损害抵押权的，可以请求将转让价款**提前清偿债务或者提存**；价款超过债权数额的部分归抵押人，不足部分由债务人清偿。

</Reveal>

<template #notes>

抵押的核心是「不转移占有」，所以抵押物必须是轻易不会灭失、权属清晰的财产。可抵押和不得抵押对照记：土地所有权永远不能押，公益设施不能押，权属有争议或被查封的不能押。登记规则分两类：不动产登记设立，动产合同生效设立。

</template>

</Slide>

## 质押：转移占有，动产与权利两条路

<CompareCard title="质押的分类与设立时点" :cols="['动产质押', '权利质押']" :rows="[

  { k: '设立时点', v: ['质权自出质人交付质押财产时设立', '有权利凭证的，自权利凭证交付质权人时设立；没有权利凭证的，自办理出质登记时设立'] },
  { k: '登记设立情形', v: ['动产质押以交付为设立要件', '基金份额、股权；注册商标专用权、专利权、著作权等知识产权中的财产权；应收账款，均自办理出质登记时设立'] },
  { k: '共同点', v: ['质权是约定的担保物权，以转移占有为特征；应书面订立质押合同', '出质人与质权人可以协议设立最高额质权'] }
]" />

> 质权人负有妥善保管质押财产的义务；因保管不善致使质押财产毁损、灭失的，应当承担赔偿责任。未经出质人同意擅自使用、处分质押财产造成损害的，也应赔偿。

<template #notes>

质押和抵押最容易混：抵押不转移占有，质押转移占有。质押再分动产和权利：动产交付即设立；权利看有没有凭证，有凭证交付设立，没凭证登记设立。基金份额、股权、知识产权、应收账款这四类，一律登记设立，这是常考细节。

</template>

## 留置：法定担保，只限四类合同

<Reveal label="哪些合同可以留置？留置权人必须给债务人多长时间履行？">

- 只有法律规定的合同种类才能适用留置：**承揽合同、运输合同、保管合同、行纪合同**。
- 例如：定作人未支付报酬或材料费，承揽人对完成的工作成果享有留置权；托运人或收货人不支付运费、保管费等，承运人对相应运输货物享有留置权。
- 留置权人与债务人应当约定留置财产后的债务履行期限；没有约定或约定不明确的，留置权人应当给债务人 **六十日以上**履行债务的期限，但鲜活易腐等不易保管的动产除外。
- 同一动产上已经设立抵押权或者质权，该动产又被留置的，**留置权人优先受偿**。

</Reveal>

**留置的三个要点**

- 留置权人负有妥善保管义务，因保管不善致毁损灭失的应赔偿；有权收取留置财产的孳息。
- 留置财产为可分物的，留置财产的价值应当**相当于债务的金额**。
- 债务人可以请求留置权人在履行期限届满后行使留置权；不行使的，债务人可以请求人民法院拍卖、变卖。

<template #notes>

留置是法定担保，不需要当事人约定，所以适用范围必须严格：承揽、运输、保管、行纪四类。六十日是底线，鲜活易腐除外。优先顺序也很重要：同一动产上抵押、质押、留置并存时，留置权人优先受偿，因为留置权人实际控制着财产。

</template>

</Slide>

## 投标保证金：2%、5 日与基本账户

<Reveal label="投标保证金的金额、有效期和退还是怎么规定的？">

- 投标保证金**不得超过招标项目估算价的 2%**。
- 投标保证金有效期应当与**投标有效期一致**，自提交投标文件的**截止之日起算**。
- 依法必须招标项目的境内投标单位，以现金或者支票形式提交的投标保证金应当从其**基本账户**转出。
- 投标人撤回已提交的投标文件，应在投标截止时间前书面通知招标人；招标人已收取投标保证金的，应自收到书面撤回通知之日起 **5 日内**退还。
- 招标人最迟应当在**书面合同签订后 5 日内**向中标人和未中标的投标人退还投标保证金及银行同期存款利息。

</Reveal>

> 投标人未能在开标前按招标文件要求以有效形式提交投标保证金的，其投标文件将被**视为无效，予以否决**。

<template #notes>

投标保证金记三个数字：2%、5 日、5 日。第一个 5 日是撤回投标后返还，第二个 5 日是签合同后返还，都要带银行同期存款利息。还有一个细节：境内投标单位以现金或支票提交的，必须从基本账户转出，这是为了防止串标和资金来源不明。

</template>

</Slide>

## 小结：一张担保地图

- **五种方式**：保证（人保）、抵押（不转移占有）、质押（转移占有）、留置（法定）、定金（金钱罚则）。
- **保证**：机关法人和公益非营利法人不得为保证人；没有约定按一般保证；保证期间默认六个月。
- **物保**：不动产登记设立，动产抵押合同生效设立，动产质权交付设立，权利质权看凭证或登记。
- **工程担保**：投标 2%、履约 10%、质量保证金 3%；支付担保保障承包人收款。
