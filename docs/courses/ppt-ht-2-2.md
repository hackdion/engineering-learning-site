## 勘察设计合同文本：三个部分构成

<p class="dk-lead">九部委勘察 / 设计合同文本由<strong>通用合同条款、专用合同条款</strong>和<strong>合同附件格式</strong>组成。</p>

- **通用合同条款**：适用于各类勘察 / 设计项目的基础性条款。
- **专用合同条款**：可对通用条款**补充、细化**，但除通用条款明确允许外，补充细化内容**不得与通用条款相抵触**，否则抵触内容无效。
- **合同附件格式**：包括合同协议书和履约保证金格式。

## 发包人应向勘察人提供的文件资料

发包人应及时向勘察人提供下列文件资料，并对其**准确性、可靠性负责**：

1. 本工程的批准文件，以及用地（附红线范围）、施工、勘察许可等批件；
2. 工程勘察任务委托书、技术要求和工作范围的地形图、建筑总平面布置图；
3. 勘察工作范围已有的技术资料及工程所需的坐标与标高资料；
4. 勘察工作范围地下已有埋藏物的资料及具体位置分布图；
5. 其他必要相关资料。

<Reveal label="发包人不能提供上述资料怎么办？">

一项或多项由勘察人收集时，订立合同时应予以明确，**发包人需向勘察人支付相应费用**。向设计人提供的文件资料按专用合同条款约定，包括基础资料、勘察报告、设计任务书等。

</Reveal>

<template #notes>

发包人提供资料的要点：一是「对准确性、可靠性负责」，二是若由勘察人代为收集，发包人要支付费用。地下埋藏物资料（电力电信电缆、管道、人防设施等）常考。

## 责任主体：项目负责人终身责任制

- 勘察 / 设计人应勤勉、谨慎、公正地履行合同项下的责任和义务。
- **勘察 / 设计责任为勘察 / 设计单位项目负责人终身责任制**。
- 项目负责人应保证勘察 / 设计文件符合法律法规和工程建设强制性标准要求，对因勘察 / 设计导致的工程质量事故或质量问题承担责任。
- 项目负责人应在**办理工程质量监督手续前**签署工程质量终身责任承诺书，连同法定代表人出具的授权书，报工程质量监督机构备案。

<template #notes>

「项目负责人终身责任制」是本节重点，监理教材里反复出现。记住两个动作：签署终身责任承诺书要在办理质量监督手续前；还要连同法定代表人授权书一起报质监机构备案。

## 责任保险：28 天内提交

除专用合同条款另有约定外，勘察 / 设计人应具有发包人认可的**工程勘察 / 设计责任险**：

- 于**合同签订后 28 天内**向发包人提交保险单副本或其他有效证明；
- 在合同履行期间保持**足额、有效**；
- 保险范围包括勘察 / 设计人疏忽或过失造成的工程质量事故损失，以及事故引发的第三者人身伤亡、财产损失或费用赔偿。

<Reveal label="发生保险事故后怎么处理？">

勘察 / 设计人应按保险人要求报告并负责办理理赔业务；**保险金不足以补偿损失的，由勘察 / 设计人自行补偿**。

</Reveal>

<template #notes>

责任保险记一个数字：合同签订后 28 天内提交保险单副本。理赔兜底：保险金不够赔的部分，勘察 / 设计人自己补。

</template>

</Slide>

## 合同价格与发包人签证制度

- 勘察 / 设计合同价款确定方式、调整方式和风险范围划分，在**专用合同条款**中约定。
- 勘察 / 设计费用实行**发包人签证制度**：完成项目后通知发包人验收，通过验收后由发包人代表对项目、数量、质量和实施时间签字确认，作为计算费用依据之一。
- 勘察合同价通常包括：收集资料、踏勘、制订纲要、测绘勘探取样试验、编制勘察文件、施工配合、青苗园林绿化补偿、占地补偿、扰民民扰、占道施工、安全防护文明施工环境保护、农民工工伤保险等全部费用和增值税税金。

<Reveal label="哪些费用不含在合同价格里？">

发包人要求勘察 / 设计人进行**外出考察、试验检测、专项咨询或专家评审**时，相应费用不含在合同价格之中，由**发包人另行支付**。

</Reveal>

<template #notes>

合同价格的核心机制是「发包人签证制度」——验收后发包人代表签字确认，作为算钱依据。外出考察、试验检测、专项咨询、专家评审这四类费用不含在合同价里，要另行支付。

</template>

</Slide>

<Reveal label="发生违约后怎么救济？">

## 小结：合同订立三条线

- **文本结构**：通用条款 + 专用条款 + 附件；解释顺序**协议 → 通知 → 投标函 → 专用 → 通用 → 发包人要求 → 费用清单 → 纲要方案 → 其他**。
- **主体与责任**：项目负责人**终身责任制**；责任保险**28 天**内提交；联合体牵头人组织履约。
- **价款与支付**：发包人**签证制度**；定金 / 预付款、中期支付、费用结算都是**28 天**；考察 / 检测 / 咨询 / 评审费用另行支付。
- **违约**：勘察 / 设计人 5 类、发包人 4 类，救济都是「通知 → 纠正 → 解除」。
