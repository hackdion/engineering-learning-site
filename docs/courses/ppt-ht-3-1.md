## 招标管理：一条程序、两道审查、两种评标

<p class="dk-lead">施工招标是合同管理的第一道关口：先把<strong>规则</strong>定下来，再把<strong>人</strong>筛出来，最后把<strong>价</strong>评出来。</p>

- **一条程序**：招标准备 → 资格审查 → 发售文件与踏勘 → 开标评标 → 合同签订；失败还有重新招标与不再招标。
- **两道审查**：资格预审与资格后审，二者**不同时使用**，审查时间不同、审查内容一致。
- **两种评标**：经评审的最低投标价法与综合评估法，由招标人按项目特点选择。
- 全过程受《招标投标法》及其实施条例约束，标准文本则是把规则落到纸面上的载体。

## 招标文件里到底装了什么

**施工招标文件九项内容**

<span class="dk-tag">招标公告或投标邀请书</span><span class="dk-tag">投标人须知</span><span class="dk-tag">评标办法</span><span class="dk-tag">合同条款及格式</span><span class="dk-tag">工程量清单</span><span class="dk-tag">图纸</span><span class="dk-tag">技术标准和要求</span><span class="dk-tag">投标文件格式</span><span class="dk-tag">前附表规定的其他材料</span>

招标人对招标文件的**澄清、修改**，也构成招标文件的组成部分。

**投标人须知 = 前附表 + 正文 + 附表格式**，正文十部分：总则、招标文件、投标文件、投标、开标、评标、合同授予、重新招标和不再招标、纪律和监督、需要补充的其他内容。

<Reveal label="标底就是概算价，也就是将来的合同价吗？">

不是。标底是招标人组织专门人员为准备招标的工程计算出的一个**合理的基本价格**，它**不等于工程的概（预）算，也不等于合同价格**。标底属招标人的**绝密资料**，开标前不能向任何无关人员泄露。

</Reveal>

<template #notes>

九项内容里，前八项是“有实体”的文件，第九项是兜底。投标人须知的前附表很关键，它把正文里的具体要求、时间安排、投标书编制要求都具体化到本工程。

</template>

</Slide>

## 预审还是后审：时间不同，内容相同

<CompareCard title="资格预审与资格后审对照（可点击「遮住自测」）" :cols="['资格预审', '资格后审']" :rows="[
  { k: '适用方式', v: ['公开招标的项目', '邀请招标的项目'] },
  { k: '审查时间', v: ['投标前，对获取资格预审文件并递交申请文件的申请人组织审查', '开标后，由评标委员会对投标人资格进行审查'] },
  { k: '审查内容', v: ['审查内容一致，均按资格预审文件或招标文件规定的标准和方法进行', '审查内容一致，只是移到开标后进行'] },
  { k: '适用项目', v: ['单件性特点明显、技术难度较大、投标文件编制费用较高或潜在投标人数量较多', '潜在投标人数量不多的通用性、标准化项目'] }
]" />

**两种审查办法**

- **合格制**：凡符合初步审查标准和详细审查标准的申请人**均通过**，取得投标人资格；比较公平公正，但人数多会增加招标成本。如无特殊情况，**鼓励采用合格制**。
- **有限数量制**：通过初步审查和详细审查后**量化打分**，按得分由高到低确定，通过人数不超过须知说明的数量。

<Reveal label="通过详细审查的申请人不足 3 个，怎么办？">

招标人应分析具体原因，根据实际情况**重新组织资格预审**，或**不再组织资格预审而直接招标**。注意：资格预审与资格后审**不同时使用**。

</Reveal>

<template #notes>

预审和后审不是“内容不同”，而是“时间不同”，这是选择题的经典陷阱。合格制和有限数量制的本质区别也只有一句话：要不要量化打分、要不要限人数。

</template>

## 现场踏勘与投标预备会：都在投标截止 15 日前

**现场踏勘**：招标人组织投标人对项目实施现场的经济、地理、地质、气候等客观条件和环境进行现场调查。

- 投标人**承担自己踏勘现场发生的费用**。
- 除招标人原因外，投标人**自行负责**踏勘现场中发生的人员伤亡和财产损失。
- 招标人介绍的场地和周边情况**供参考**，不对投标人据此作出的判断和决策负责。

**投标预备会**：澄清招标文件疑问、解答投标人对招标文件和勘察现场提出的问题；会后书面澄清内容**构成招标文件的组成部分**。

<Reveal label="踏勘后要改招标文件，最晚什么时候通知？">

踏勘现场后涉及对招标文件澄清修改的，招标人应当在投标文件提交截止时间**至少 15 日前**以书面形式通知所有招标文件收受人。因此组织踏勘的时间一般应在**投标截止时间 15 日前及投标预备会召开前**；投标预备会一般也应在**投标截止时间 15 日以前**进行。

</Reveal>

<template #notes>

踏勘这一页记三句话：费用自担、风险自担、介绍仅供参考。再加一个 15 日：踏勘和预备会都要留在投标截止前 15 日以前，给投标人留出修改投标文件的时间。

</template>

</Slide>

## 评标委员会：5 人以上单数，专家不少于 2/3

- 成员名单一般于**开标前确定**，在中标结果确定前应当**保密**。
- 由招标人或其委托的招标代理机构熟悉相关业务的代表，以及技术、经济等方面的专家组成。
- 成员人数为 **5 人以上单数**，其中技术、经济等方面的专家**不得少于成员总数的 2/3**。
- 专家一般从依法组建的专家库**随机抽取**；技术复杂、专业性强或有国家特殊要求，随机抽取难以保证胜任的，可由招标人**直接确定**。
- 评标专家应从事相关专业领域工作**满 8 年**并具有**高级职称或同等专业水平**。

<Reveal label="哪些人应当回避？">

四类：① 投标人或投标人主要负责人的近亲属；② 项目主管部门或行政监督部门的人员；③ 与投标人有经济利益关系，可能影响公正评审的；④ 曾因在招标、评标等活动中从事违法行为而受过行政处罚或刑事处罚的。

</Reveal>

<template #notes>

评标委员会的三个数字：5 人以上单数、专家不少于 2/3、专家从业满 8 年。回避的四类人里，“项目主管部门或行政监督部门的人员”最容易被忽略，监督的人不能下场当评委。

</template>

</Slide>

## 最低评标价法：把各种因素折成钱再比

适用于具有**通用技术、性能标准**，或者招标人对其技术、性能标准**没有特殊要求**的招标项目。

**评审思路**：以投标报价为基数，按详细评审标准规定的量化因素和量化标准进行**价格折算**，按经评审的投标价由低到高推荐中标候选人；投标报价低于其成本的除外。

**教材例题（污水处理厂，工期 30 个月）**

<Steps title="三家投标人的评标价计算" :steps="[

  { t: '投标人 B', d: '报价 4900 万元；污水成本高 1 个百分点，调增 4900×1×2% = 98 万元；工期 29 个月，提前 1 个月调减 50 万元；评标价 4948 万元，排序 2' },
  { t: '投标人 C', d: '报价 5000 万元；污水成本低 2 个百分点，调减 5000×2×1% = 100 万元；工期 28 个月，提前 2 个月调减 100 万元；评标价 4800 万元，排序 1' },
  { t: '结论', d: '投标人 C 经评审的投标价最低，评标委员会推荐其为中标候选人（投标报价本身最高，但折算后最低）' }
]" />

<template #notes>

这道例题的关键不是算数，而是理解“经评审的投标价”不等于“投标报价”。A 报价最低，但污水成本偏差加价最多；C 报价最高，却因为成本低、工期短，折算后反而最低。这就是最低评标价法的题眼。

</template>

<Reveal label="中标人拖着不签合同，或者不交履约担保，会怎样？">

- 不按招标文件要求提交履约担保的，**视为放弃中标**，投标保证金**不予退还**；给招标人造成的损失超过投标保证金数额的，还应赔偿超过部分。
- 中标人无正当理由拒签合同的，招标人**取消其中标资格**，投标保证金**不予退还**，损失超过保证金数额的同样要赔偿。
- 反过来，招标人无正当理由拒签的，应向中标人**退还投标保证金**；造成损失的，还应赔偿损失。

## 小结：招标管理的四句话

<p class="dk-lead">文本是尺子，程序是轨道，审查是筛子，评标是秤。</p>

- **文本**：标准文本四卷八章；简明文本八章，工期不超过 **12 个月**的小型项目。
- **程序**：招标准备 → 资格审查 → 发售文件与踏勘 → 开标评标 → 合同签订；**投标人少于 3 个**应重新招标。
- **审查**：预审在投标前、后审在开标后，**内容一致、不同时使用**；合格制与有限数量制，鼓励**合格制**。
- **评标**：最低评标价法**折算成钱**比高低，综合评估法**打分**排先后；两种办法都不得推荐**低于成本**的投标。
