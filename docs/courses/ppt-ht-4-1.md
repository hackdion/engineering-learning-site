## 总承包招标：一个主体，一套文本，一条程序

<p class="dk-lead">设计施工总承包把<strong>设计与施工</strong>交给同一个承包人，招标要解决的是「一次选对责任主体」。</p>

- **一个主体**：设计与施工由同一承包人承担，发包人只面对一份合同、一个责任接口。
- **一套文本**：《标准设计施工总承包招标文件》三卷七章，适用于设计施工一体化总承包招标。
- **一条程序**：与施工招标基本相同，差异集中在招标文件、价格清单、资格审查、评标办法和发包人要求五处。
- **一个前提**：招标文件应包含招标项目的**所有实质性要求和条件**，它是投标人编制投标文件和报价的依据。

这一节先立骨架：一个主体、一套文本、一条程序。总承包招标和施工招标的程序大体一样，所以学习重点不是重背流程，而是找出「不一样的那几处」。后面每一页都对应一条差异，听完要能自己列出来。

## 标准文本：三卷七章怎么排

<Steps title="《标准设计施工总承包招标文件》的卷章结构" :steps="[
  { t: '第一卷：第一章至第四章', d: '招标公告（投标邀请书）、投标人须知、评标办法、合同条款及格式' },
  { t: '第二卷：第五章、第六章', d: '第五章发包人要求、第六章发包人提供的资料' },
  { t: '第三卷：第七章', d: '投标文件格式' },
  { t: '使用规则', d: '用相同序号标示章、节、条、款、项、目供选择使用；空格由招标人按项目特点具体化，确实无需填写的用「/」标示，最终选择其一形成一份完整的招标文件' }
]" />

> 一句话记住：**四章 + 两章 + 一章**，第一卷装的是前四章，第二卷装的是「发包人要求」和「发包人提供的资料」，第三卷只有投标文件格式。

<template #notes>

三卷七章的对应关系是选择题高频点。记法：第一卷四章是「程序性文件」，第二卷两章是「发包人给的东西」，第三卷一章是「投标人交的格式」。还有一个细节：空格不是留白，确实没有内容要填「/」，这是标准文本的填写规则。

</template>

</Slide>

## 招标文件里装了什么

**施工总承包招标文件的八项内容**

<span class="dk-tag">招标公告或投标邀请书</span><span class="dk-tag">投标人须知</span><span class="dk-tag">评标办法</span><span class="dk-tag">合同条款及格式</span><span class="dk-tag">发包人要求</span><span class="dk-tag">发包人提供的资料</span><span class="dk-tag">投标文件格式</span><span class="dk-tag">投标人须知前附表规定的其他材料</span>

招标人对招标文件的**澄清、修改**，也构成招标文件的组成部分。

**投标人须知 = 前附表 + 正文 + 附表格式**

正文九项：总则、招标文件、投标文件、投标、开标、评标、合同授予、纪律和监督、需要补充的其他内容。附表格式包括开标记录表、问题澄清通知书、中标通知书、中标结果通知书等。

<template #notes>

八项内容里，第四项「合同条款及格式」之后是「发包人要求」和「发包人提供的资料」，这两项是总承包招标特有的，施工招标里没有。投标人须知正文是九项，比标准施工招标文件少一项，注意不要按十项去背。

</template>

</Slide>

## 设计方面多出来的三条要求

<Steps title="投标人须知在设计方面的特别要求" :steps="[
  { t: '质量标准', d: '投标人须知中要提出设计要求的质量标准，而不只是施工质量标准' },
  { t: '投标人资格要求', d: '项目经理应当具备工程设计类或者工程施工类注册执业资格；设计负责人应当具备工程设计类注册执业资格' },
  { t: '设计成果补偿', d: '招标人对符合招标文件规定的未中标人的设计成果进行补偿的，按投标人须知前附表规定给予补偿，并有权免费使用未中标人设计成果' }
]" />

<Reveal label="为什么项目经理可以是施工类资格，设计负责人却必须是设计类资格？">

因为总承包的**设计质量**必须由具备设计执业资格的人把关，设计负责人不能由只有施工背景的人担任；而项目经理负责的是整个项目的组织实施，具备工程设计类**或者**工程施工类注册执业资格都可以胜任。

</Reveal>

<template #notes>

这三条是总承包招标文件区别于施工招标文件的核心。特别记「设计负责人只能是设计类资格」——这是唯一不能通融的一条。设计成果补偿要注意逻辑：先按前附表补偿，补偿之后发包人才有权免费使用，不是不给钱就能用。

</template>

</Slide>

## 评标办法：设计部分怎么评

<Steps title="评标办法前附表在设计方面增加的三项内容" :steps="[
  { t: '设计负责人资格评审', d: '设计负责人的资格评审标准需符合投标人须知相应规定，即具备工程设计类注册执业资格' },
  { t: '资信业绩评分', d: '资信业绩评分标准新增设计负责人业绩，把设计团队的过往项目纳入打分' },
  { t: '增加设计部分评审', d: '在原有评审内容之外单独增加设计部分的评审，对设计方案或设计工作进行评价' }
]" />

> 总承包与施工的评标办法**都包括**综合评估法和经评审的最低投标价法，差别不在办法种类，而在评标因素里多了「设计」。

<template #notes>

评标这一页只记一句话：办法不变，因素加设计。设计负责人资格、设计负责人业绩、设计部分评审，三处都指向同一件事——总承包评标必须能评价设计能力。

## 小结：总承包招标的四句话

<p class="dk-lead">一份合同定责任，一套文本定规则，一处要求定成败。</p>

- **模式**：单一合同责任、固定工期固定费用、缩短建设周期、减少设计变更；代价是设计不一定最优、监督被减弱。
- **文本**：三卷七章——第一卷第一至四章，第二卷第五、六章，第三卷第七章；适用于设计施工一体化总承包招标。
- **文件**：招标文件八项，多了**发包人要求**和**发包人提供的资料**；价格清单八项，多了**勘察设计费**。
- **评审**：资格审查增加设计类业绩，评标办法增加设计负责人资格、设计负责人业绩和设计部分评审；设计负责人必须是**设计类**注册执业资格。
