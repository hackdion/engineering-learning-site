## 合同订立：把招标成果固化成一叠文件

<p class="dk-lead">总承包合同订立要解决四件事：<strong>哪些文件算合同</strong>、<strong>发包人要求写什么</strong>、<strong>三方各干什么</strong>、<strong>哪些条款必须二选一</strong>。</p>

- **九项文件**：从合同协议书到其他合同文件，序号就是矛盾时的优先解释顺序。
- **一份核心文件**：发包人要求是承包人设计和施工的基础，应说明 **11 个方面**。
- **三方责任**：发包人管条件与支付，承包人管设计与实施，监理人管指示与监督。
- **十个待明确**：通用条款给出两种可选做法的地方，都要在专用条款里选定一种。

<template #notes>

这一节信息量大，但结构很清楚：先认文件，再认要求，再认人，最后认那些「二选一」的条款。听的时候把「必须约定、不约定就出争议」的地方标出来，这些正是案例题和选择题的落脚点。

<Steps title="承包人责任义务的三个层次" :steps="[

  { t: '联合体承包', d: '发包人和监理人仅与联合体牵头人或联合体授权的代表联系，由其负责组织和协调各成员全面履行合同' },
  { t: '联合体的稳定性', d: '联合体协议经发包人确认后作为合同附件；履行过程中未经发包人同意，承包人不得擅自改变联合体组成和修改联合体协议' }
]" />

<Reveal label="联合体内部怎么分工，发包人管不管？">

发包人**不直接管**联合体内部事务，只认牵头人或授权代表。但联合体的组成和内部分工是评标中很重要的评审内容，并且已经通过联合体协议固定为合同附件，所以履行阶段不能擅自变动——要变，必须先经发包人同意。

</Reveal>

<template #notes>

联合体这一页记两句话：对外只认一个接口（牵头人或授权代表），对内不能擅自变动（组成和协议都要经发包人同意）。这两句话背后是同一个逻辑：发包人当初是按这个联合体评标的，换了人等于换了投标主体。

</template>

## 监理人：指示怎么发，文件怎么批

<Reveal label="总监理工程师超过 2 天不能履职，项目怎么办？">

应**委派代表代行其职责**，并通知承包人。另外，总监理工程师更换时应**提前 14 天**通知承包人；发包人应在发出开始工作通知**前**将总监理工程师的任命通知承包人。

</Reveal>

**两个容易被忽略的规则**

- **指示的效力**：监理人受发包人委托享有合同约定权力，其发出的任何指示**视为已得到发包人批准**；指示应盖监理人授权的项目管理机构章，并由总监理工程师或其授权人员签字。
- **文件的批准**：监理人未在专用条款约定期限内对承包人文件提出否定意见，**视为已获批准**，承包人可继续后续工作；但批准或视为批准，**均不影响**监理人以后否定该项工作的权力。

> 承包人对总监理工程师授权的监理人员发出的指示有疑问，可在指示发出后 **48 小时**内向总监理工程师提出书面异议，总监理工程师应在 **48 小时**内确认、更改或撤销。

<template #notes>

监理人这一页抓三个数字和两个「视为」：更换提前 14 天、不能履职超过 2 天要派代表、异议双向 48 小时；未按期否定视为批准、指示视为已获发包人批准。特别提醒「视为批准不等于最终认可」，监理人以后仍然可以否定。

</template>

</Slide>

## 发包人要求出错：两种补偿条款

<CompareCard title="无条件补偿与有条件补偿（可点击「遮住自测」）" :cols="['无条件补偿条款', '有条件补偿条款']" :rows="[
  { k: '复核未发现错误', v: ['实施中因该错误增加费用和（或）工期延误，发包人承担并支付合理利润', '承包人自行承担由此增加的费用和（或）工期延误'] },
  { k: '复核发现并通知', v: ['发包人承担增加的费用和（或）工期延误，并支付合理利润', '发包人坚持不做修改的，对确实存在错误造成的损失，补偿增加的费用和（或）顺延工期'] },
  { k: '适用方式', v: ['对承包人更有利，发包人风险更大', '对发包人更有利，承包人复核责任更重'] }
]" />

<Reveal label="哪些资料出错，无论承包人发现与否都由发包人承担？">

五类：① 发包人要求中引用的**原始数据和资料**；② 对工程或其任何部分的功能要求；③ 对工程的工艺安排或要求；④ **试验和检验标准**；⑤ 除合同另有约定外，**承包人无法核实**的数据和资料。这几类由发包人承担增加费用和（或）延误工期，并支付合理利润。

</Reveal>

<template #notes>

两种条款的差别只在「承包人复核未发现错误」这一种情形：无条件条款下仍由发包人担，有条件条款下由承包人自担。但五类资料是共同例外，不管哪种条款、不管发没发现，都归发包人。所以订立合同时必须明确采用哪一种，不能空着。

</template>

</Slide>

## 小结：合同订立的四句话

<p class="dk-lead">文件定顺序，要求定标准，责任定边界，条款定选择。</p>

- **文件**：九项合同文件，序号即优先解释顺序；合同协议书排第一，专用条款排在通用条款之前。
- **要求**：发包人要求 11 个方面，是承包人设计和施工的基础；承包人建议书是对它的响应，价格清单总和为**签约合同价**。
- **责任**：发包人管场地、手续、支付；承包人管设计与实施，联合体只留一个接口；分包五条红线，主体和关键性工作不得分包。
- **选择**：材料设备、施工设备、区段工程、暂列金额、不可预见物质条件、竣工后试验六处二选一；履约担保保到接收证书，有竣工后试验的保到试验通过。
