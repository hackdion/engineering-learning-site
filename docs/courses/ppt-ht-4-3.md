## 履行管理：五条主线，一串时限

<p class="dk-lead">总承包模式下承包人承担更多职责，履行管理就围绕<strong>进度、设计变更、价款支付、竣工缺陷、违约索赔</strong>五条主线展开。</p>

- **进度**：计划报批、开始工作通知、工期顺延，三个动作各有期限。
- **设计与变更**：设计要满足规范与合同，审查有 21 天；变更只能由监理人按程序发出指示。
- **价款**：支付分解表、月度申请、14 天审核、28 天支付。
- **竣工与缺陷**：竣工试验三阶段、竣工验收五项条件、缺陷责任期最长 2 年。
- **违约与索赔**：双方各有解除情形，索赔是一条 28 天接 28 天的链条。

## 设计审查：21 天与 7 天

<Steps title="设计文件的审查流程" :steps="[
  { t: '发包人组织审查', d: '承包人的设计文件提交监理人后，发包人组织设计审查，按发包人要求文件约定的范围和内容审查是否满足合同要求' },
  { t: '审查期限不超过 21 天', d: '自监理人收到设计文件之日起，审查期限不超过 21 天；承包人的设计与合同约定有偏离的，应在提交设计文件的通知中说明' },
  { t: '修改后重新起算', d: '承包人需要修改已提交的设计文件，应立即通知监理人，提交修改后的文件后审查期重新起算；审查认为不符合约定的，书面说明具体内容，承包人修改后重新报送，审查期限重新起算' },
  { t: '视为同意', d: '合同约定的审查期限届满，发包人没有作出审查结论也没有提出异议，视为承包人的设计文件已获发包人同意' },
  { t: '报送政府有关部门', d: '设计文件需政府有关部门审查或批准的，发包人应在审查同意后 7 天内报送，承包人协助' }
]" />

> 政府审查意见如果只需完善设计，承包人按意见修改；如果意见需要修改**发包人要求**（如某些要求与法律法规相抵触），发包人应重新提出发包人要求，由此增加的工作量和拖延的时间**按变更对待**。

<template #notes>

两个数字：发包人审查不超过 21 天，审查同意后 7 天内报政府。两个「重新起算」：承包人主动修改要重算，审查不通过修改后也要重算。还有一个「视为同意」：期满不表态就是同意，但注意这只针对发包人审查，不等于政府审批也自动通过。

## 变更：谁有权发指示，程序怎么走

<Steps title="变更权与监理人指示变更的程序" :steps="[
  { t: '变更权归属', d: '履行合同过程中，经发包人同意，监理人可按约定程序向承包人作出有关发包人要求改变的变更指示，承包人应遵照执行' },
  { t: '变更的时间要求', d: '变更应在合同相应内容实施前提出，否则发包人应承担由此给承包人造成的损失；没有监理人的变更指示，承包人不得擅自变更' },
  { t: '发出变更意向书', d: '监理人向承包人发出变更意向书，说明变更具体内容和发包人对变更的时间要求，附必要资料，并要求承包人提交实施方案' },
  { t: '承包人同意', d: '承包人提交包括拟实施变更工作的设计、计划、措施和竣工时间等内容的实施方案，发包人同意后由监理人发出变更指示' },
  { t: '承包人不同意', d: '承包人认为难以实施时，应立即通知监理人说明原因并附详细依据；监理人与承包人和发包人协商后，确定撤销、改变或不改变原变更意向书' }
]" />

<template #notes>

变更这一页的核心是「三条通道、一个前提」：变更指示只能由监理人经发包人同意后发出，承包人不能擅自变更；变更必须在实施前提出。承包人不同意时不是硬扛，而是立即书面说明理由，由三方协商处理。

</template>

## 付款时限链：7—7—14—28

## 竣工试验：提前 21 天申请，14 天定时间

<Steps title="竣工试验的程序" :steps="[
  { t: '承包人申请竣工试验', d: '提前 21 天将申请竣工试验的通知送达监理人，并按专用条款约定份数提交竣工记录、暂行操作和维修手册' },
  { t: '监理人确定时间', d: '监理人应在 14 天内确定竣工试验的具体时间' },
  { t: '第一阶段', d: '承包人进行适当的检查和功能性试验，保证每一项工程设备都满足合同要求，并能安全地进入下一阶段试验' },
  { t: '第二阶段', d: '承包人进行试验，保证工程或区段工程满足合同要求，在所有可利用的操作条件下安全运行' },
  { t: '第三阶段', d: '工程能安全运行时，承包人通知监理人进行其他竣工试验，包括各种性能测试，以证明工程符合发包人要求中列明的性能保证指标' }
]" />

> 某项竣工试验未能通过，承包人应按监理人指示**限期改正**并承担合同约定的相应责任；试验通过后，承包人按合同约定进行工程及工程设备试运行。

<template #notes>

竣工试验的三阶段是递进的：先保证单台设备能安全进入下一阶段，再保证整个工程能安全运行，最后才验证性能指标。顺序不能颠倒，因为前一步不过，后一步的数据没有意义。两个时间：申请提前 21 天，监理人 14 天内定时间。

</template>

## 竣工后试验：两种主体，都提前 21 天

<CompareCard title="竣工后试验由谁做（可点击「遮住自测」）" :cols="['发包人负责', '承包人负责']" :rows="[

  { k: '通知义务', v: ['发包人应将竣工后试验的日期提前 21 天通知承包人', '发包人应提前 21 天将竣工后试验的日期通知承包人'] },
  { k: '承包人未到场', v: ['承包人未能在该日期出席，发包人可自行进行试验，承包人应对检验数据予以认可', '承包人在发包人在场情况下进行试验；因承包人原因未通过，按约定赔偿或提出修复建议并在合理期限内改正'] }

> 竣工后试验发生在**缺陷责任期内、工程稳定运行一段时间后**，目的是检验承包人的设计、设备选型和运行情况等技术指标是否满足合同约定；试验所需的电力、设备、燃料、仪器、劳力、材料由**发包人**提供。

竣工后试验和竣工试验不是一回事：竣工试验在移交前做，竣工后试验在缺陷责任期内、运行稳定后做。两种主体的通知期限都是提前 21 天，区别在于谁动手做、谁在场。试验条件由发包人提供，这一点两种主体都一样。

> 承包人未在前述 **28 天**内发出索赔意向通知书的，**工期不予顺延，且无权获得追加付款**；发包人索赔同样应在知道或应当知道索赔事件发生后 **28 天**内发出索赔通知，逾期丧失扣减付款和（或）延长缺陷责任期的权利。

### 标准总承包合同：三项补偿判定

《标准设计施工总承包招标文件（2012 年版）》第 3.4.5 款：由于监理人未能按合同约定发出指示、指示延误或指示错误而导致承包人费用增加和（或）工期延误的，发包人应承担由此增加的费用和（或）工期延误，并向承包人支付合理利润。

第 6.2.6 款：发包人提供的材料和工程设备的规格、数量或质量不符合合同要求，或由于发包人原因发生交货日期延误及交货地点变更等情况的，发包人应承担由此增加的费用和（或）工期延误，并向承包人支付合理利润。

第 11.4 款：由于出现专用合同条款规定的异常恶劣气候的条件导致工期延误的，承包人有权要求发包人延长工期和（或）增加费用。

第 13.4.3 款：经检验证明工程质量符合合同要求的，由发包人承担由此增加的费用和（或）工期延误，并支付承包人合理利润。

## 小结：履行管理的一条时间轴

<p class="dk-lead">进度定节奏，设计定质量，变更定价格，竣工定交付，索赔定损失。</p>

- **进度**：计划逾期不批**视为批准**；开始工作通知提前 **7 天**，发包人原因 **90 天**未发通知承包人可调价或解约。
- **设计**：审查不超过 **21 天**，期满不表态视为同意；报政府 **7 天**；变更指示只能在实施前由监理人发出。
- **价款**：支付分解两个 **7 天**，审核 **14 天**，支付 **28 天**；价格清单数量只是估算。
- **竣工与缺陷**：竣工试验三阶段，申请提前 **21 天**、监理人 **14 天**定时间；实际竣工日期以提交申请报告之日为准；缺陷责任期最长 **2 年**。
- **违约与索赔**：整改或暂停 **28 天**可解除，撤离与转让 **14 天**；索赔意向、正式通知、最终通知各 **28 天**，监理人 **42 天**不答复视为认可。
