## 材料设备招标：把「货物」和「服务」分开想

<p class="dk-lead">材料设备招标是建设工程<strong>最普遍使用</strong>的一种采购类型：采购主体提出货物类型、质量、数量、交货期等具体要求，约请供货商报价，择优签订供货合同。</p>

- **采购主体**：可以是建设单位，也可以是承包商（承包人）。
- **采购对象**：建筑材料（钢材、水泥、混凝土、门窗、电线电缆等）与设备（电梯、配电、消防、暖通、给排水、楼宇自动化等）。
- **采购模式**：发包人自行采购、承包人包工包料采购、大宗材料由发包人采购（当地小量材料由承包人采购）；永久工程大型设备一般由发包人采购，EPC 模式下可由总承包商采购。
- 既有设备又有安装服务的项目，可**设备与安装分开招标**，也可**合并招标**；合并招标按设备/安装所占费用比例确定招标类型。

## 批次与标包：到货要「恰好」，竞争要「够多」

<p class="dk-lead">采购批次要保证到货及时、节省资金，标包划分要吸引多家投标人竞争。</p>

- **批次安排**：综合考虑工程实际需要的时间、市场供应情况、价格变动趋势、建设资金到位与周转计划；同类材料设备可**一次招标分期交货**，不同材料设备可**分阶段采购**。
- **延误交货** → 停工待料，影响工期；**提前交货** → 占用场地、增加仓储保管费用和风险。
- **标包原则**：避免划分过大（中小厂商无法满足），也避免划分过小（缺乏对大厂吸引力）；投标的基本单位是**标包**，每次招标可只发一个标包或分几个标包同时招标。

<Reveal label="投标人能否只对一个标包中的某几项投标？">

不能。投标人可以投一个或其中的几个标包，但**不能仅对一个标包中的某几项进行投标**。

</Reveal>

<template #notes>

标包这一页记住两个「不能」：批次不能早也不能晚，早了占场地、晚了停工待料；标包不能太大也不能太小。最后一条最常考：投标的基本单位是标包，可以整包投，但不能拆开只投一个包里的几项。

</template>

</Slide>

## 材料招标方式、资格要求与招标文件

- **招标方式**：公开招标或邀请招标均可；招标程序与勘察设计、施工招标基本相同，但**评标评审要素和量化比较方法**不同。
- **招标公告应列明**：招标条件、项目概况与招标范围、投标人资格要求、招标文件获取方式、投标文件递交时间地点及方式、招标人联系方式等。其中「招标条件」应写明材料名称，「项目概况与招标范围」应写明建设地点、规模、工期、标段划分及材料名称、数量、技术规格、交货地点、交货期。

<Reveal label="资格要求与供货要求各要注意什么？">

对投标人的资格要求（5 项）：①独立订立合同能力；②专业技术、设备设施、人员组织、业绩经验等方面具备相应资格和能力；③完善的质量保证体系；④业绩良好，有相同或相近材料的供货业绩及运行经验；⑤良好的银行信用和商业信誉。供货要求中标的物名称要用正式、标准名称的全称，数量单位避免「车、包、捆」等歧义单位。

</Reveal>

这一页把「怎么招、谁能投、文件装什么」三件事串起来。资格要求是通用五条，抓「独立订约、专业技术、质保体系、业绩、信用」。招标文件 7 项把施工招标的「工程量清单、图纸」换成了「供货要求」——供货要求是材料招标特有的一块，名称要用全称、计量单位别用「车、包、捆」。

## 投标文件与投标保证金

<p class="dk-lead">材料采购投标文件共 11 项，核心是对招标文件作出实质性响应。</p>

<Steps title="投标文件的主要组成部分" :steps="[
  { t: '投标函及投标函附录', d: '法定代表人身份证明或授权委托书、联合体协议书' },
  { t: '商务和技术偏差表', d: '全部偏差须列明，写清章节及条款号' },
  { t: '投标保证金 + 分项报价表', d: '投标报价为各分项报价金额之和' },
  { t: '资格审查资料 + 投标材料质量标准', d: '技术支持资料、相关服务计划' },
  { t: '其他资料', d: '投标人须知前附表规定的其他资料' }
]" />

<Reveal label="投标保证金有什么上限规定？">

投标保证金一般**不得超过项目估算价的 2%**，但**最高不得超过 80 万元人民币**；保证金有效期应当与投标有效期一致。境内投标单位以现金或支票形式提交的，应从其基本账户转出。

</Reveal>

<template #notes>

投标文件 11 项里，最常考的是「商务和技术偏差表」——所有偏差必须列明并写清章节条款号，除列明外视为响应全部要求，偏差超范围或超最高项数会被否决。投标保证金两个数字必背：不超过估算价 2%、最高 80 万，且有效期与投标有效期一致。

</template>

<Steps title="初步评审的三项内容" :steps="[
  { t: '形式评审', d: '投标人名称、投标函签字盖章、投标文件格式、联合体协议书等是否符合规定' },
  { t: '资格评审', d: '营业执照和组织机构代码证、资质要求、财务要求、业绩要求、信誉要求' },

<Reveal label="投标报价出现算术错误，按什么原则修正（4 条）？">

①大写金额与小写金额不一致的，**以大写金额为准**；②总价金额与单价金额不一致的，**以单价金额为准**（单价金额小数点有明显错误的除外）；③投标报价与分项报价的合价不一致的，以各分项合价累计数为准修正投标报价；④分项报价中存在缺漏项的，视为缺漏项价格已包含在其他分项报价之中。

</Reveal>

初步评审还是「形式、资格、响应性」老三样。算术修正四条是本节必背，优先级记成口诀「大写优先、单价优先、分项累计、缺漏视为已含」。投标人拒不澄清确认的，评标委员会应当否决其投标。

<Reveal label="设备招标的「伴随服务」包括哪些？">

根据《机电产品国际招标标准招标文件（试行）》，伴随服务一般包括：①实施或监督所供货物的现场组装和试运行；②提供组装维修所需工具；③提供详细的操作和维护手册；④在商定期限内实施运行、监督、维护或修理（不免除卖方合同保证期内义务）；⑤在卖方厂家和/或项目现场对买方人员进行培训。

</Reveal>

<template #notes>

设备供货要求比材料多了「技术性能指标、检验考核、技术服务、质保期服务」，这是设备与材料招标最本质的区别。9 个概念里重点记「验收」和「质量保证期」的定义，以及「伴随服务」五条（组装试运行、工具、手册、维护、培训），这些词会在合同履行里反复出现。

## 小结：一条「货物到设备」的主线

- **两大类型**：货物买卖（通用批量，看价格）与加工承揽（复杂非标，看性价比）。
- **报价方式**：境内 EXW / 仓库交货 / 施工现场交货；境外 FOB / FCA / CIF / CIP，均按 Incoterms 解释。
- **招标文件**：7 项内容 + 供货要求；投标保证金不超过估算价 **2%**、最高 **80 万**。
- **评标**：综合评估法（打分）与最低评标价法（折钱）；算术错误按「大写、单价、分项累计、缺漏已含」修正。
- **设备招标**：9 个概念 + 伴随服务；同一品牌同一型号**只能一个代理商**；评标用综合评估法或寿命周期成本法。
