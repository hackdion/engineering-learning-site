## 金皮书：把「运营」也装进合同

<p class="dk-lead">FIDIC《设计施工和运营(DBO)合同条件》把项目设计、施工和建成后的长期运营服务整合为一个合同，交由同一个承包商承担。</p>

- **DBO 模式**：承包商负责公共设施或基础设施的设计、建造、运营和维修保养，满足工程使用期间公共部门的运营要求。
- **谁出钱**：公共部门负责项目融资；承包商在建设期获得进度付款，在运营期获得运营费用。
- **运营期假设**：合同基于新建项目编写，考虑大多数情况假设运营期为 **20 年**；运营期较短时，FIDIC 另有修改指南。
- **结构**：与银皮书类似，合同当事方是业主和承包商，双方分别任命业主代表和承包商代表。

<template #notes>

金皮书的关键词是「一体化」和「长期」。它不只管建，还管建完以后怎么运行二十年。所以读这一节要一直带着一个问题：运营期的风险、付款、缺陷、资产更换，和纯建设合同有什么不同。

</template>

## 运营服务：从试运行证书开始，先建审计机制

<p class="dk-lead">运营服务应在设计-施工工作全部完成后开始；除业主要求另有规定，自试运行证书注明的日期开始。</p>

- 试运行证书中包含高于合同内容的要求时，承包商应遵守，由此增加的费用由**业主**承担。
- 承包商希望修改已获批准的文件，应通知业主代表并提交修改文件及说明；业主代表审核并**书面批准**后才能实施。
- 任何批准、同意或审核，**不解除**承包商的任何义务或责任。

<Reveal label="独立合规审计由谁任命、费用从哪里出？">

业主和承包商应在运营服务开始**不少于 182 天前**共同任命审计机构，任命条款列在业主要求中。审计机构独立、公正地审计和监督双方遵守运营管理要求；双方不能协商一致时，可交由<strong>争端裁决委员会（DAB）</strong>任命。审计机构自运营服务开始日期起履行职责，**聘用费用从暂定金额里支付**。

</Reveal>

<template #notes>

运营期的第一道机制不是罚款，而是审计：提前 182 天把人定下来，费用走暂定金额，保证独立性。还要记住「批准不免责」——业主代表批了文件，承包商该担的责任一样不少。这是贯穿 FIDIC 系列的一条原则。

</template>

</Slide>

## 运营期的延误、中断与产量

<CompareCard title="运营服务期三类延误中断的责任" :cols="['承包商原因', '业主原因', '业主指示暂停']" :rows="[
  { k: '赔偿与处理', v: ['赔偿业主任何损失（包括收入、利润和管理费）；协商金额，总额不超过合同数据规定额度；可从后续应付款中抵扣', '赔偿承包商任何损失（包括收入和利润）；协商金额，除业主因便利终止外不超过合同数据额度；列入当月付款支付', '业主代表可随时指示暂停，承包商保护好工程、生产设备；非承包商原因持续 84 天以上，可要求继续运营，28 天内未获许可可发终止通知；恢复前联合检查并记录'] },
  { k: '补偿范围', v: ['承包商自担', '业主赔偿损失', '非承包商原因造成的暂停，承包商有权获得成本和利润补偿'] }
]" />

**未达到合同产量**：双方联合确定原因。业主原因，承包商按指示采取措施，可就损失获得成本和利润补偿；承包商原因，协商后采取措施恢复产量，并支付合同数据规定的履约赔偿费。问题持续 **84 天**以上未解决，业主可选择让承包商继续运营但补偿业主费用；产量未达最小产量时，业主可提前 **56 天**通知终止合同，随后自行或雇人运营。

<template #notes>

这一页数字多，抓两组：暂停是 84 天 + 28 天，产量不达标是 84 天 + 56 天。还要注意「任何延误、干扰或暂停都不延长运营服务期」——运营期是固定的，耽误的时间不补。产量问题的第一步永远是双方联合查原因，先定责再谈措施。

</template>

</Slide>

## 缺陷与修补：一年扫尾，修完才发证书

- **设计-施工期**：整个工程、承包商文件和每个区段均应符合合同要求；承包商应在试运行证书注明日期后**一年内**完成全部扫尾工作并修补所有缺陷；设计-施工最终付款在业主代表认为符合要求后确定。
- **运营服务期**：承包商负责修补运营服务期间发生的任何缺陷；修补所有缺陷且扫尾工作全部完成后，业主代表才能颁发**合同完成证书**。

<Reveal label="哪些缺陷的修补费用由业主承担？">

两类情形：该缺陷由**业主人员或其代理人**的行为造成；该缺陷由**特殊风险**所涵盖的某一事件导致。此外，承包商修补缺陷时应通知业主代表，并**有权按变更处理**。承包商自身原因造成的缺陷，由其自担风险和费用修补。

</Reveal>

<template #notes>

缺陷责任在 DBO 里被拉得很长：建设期有一年扫尾，运营期还要持续修补，直到合同完成证书签发。判断费用归属只看原因：业主人员行为、特殊风险由业主担，其余承包商自担。修补前记得通知业主代表，否则可能丧失按变更计价的机会。

</template>

</Slide>

## 小结：金皮书多出来的那段「运营」

<p class="dk-lead">同一套 FIDIC 骨架，多一个运营期，就多出一整套时间、资金和风险安排。</p>

- **模式**：设计—施工—运营一体化，公共部门融资，假设运营期 **20 年**，总价合同。
- **建设**：开工后 **28 天**开始设计-施工；试运行证书 **28 天**内颁发，标志建设段完成。
- **运营**：审计提前 **182 天**任命、费用走暂定金额；暂停 **84 天 + 28 天**，产量不达标 **84 天 + 56 天**。
- **钱与险**：资产更换资金四类不包、剩余正常完成平分、提前终止归业主；专用条件 **A 优先于 B**。
