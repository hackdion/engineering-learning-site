## 总进度目标：先论证实现的可能性

<p class="dk-lead">工程总进度目标在<strong>决策阶段项目定义时确定</strong>，是业主方项目管理的任务之一。进行总进度目标控制前，首先要<strong>分析和论证目标实现的可能性</strong>。</p>

- 若总进度目标**不可能实现**，项目管理方应提出调整总进度目标的建议，提请项目决策者审议。
- 工程实施阶段的总进度，包括以下各项工作进度：

<div class="dk-cols">

<div>

### 实施阶段总进度（6 项）
1. 设计前准备阶段的工作进度
2. 设计工作进度
3. 招标工作进度
4. 施工前准备工作进度
5. 工程施工和设备安装进度
6. 项目动用前的准备工作进度

</div>

<div>

### 论证为什么不是“简单排计划”
- 总进度目标论证时往往**还没有详细设计资料**，也缺乏发包组织、施工组织与实施条件的资料。
- 因此它**不是单纯的总进度规划编制**，还涉及实施条件分析与实施策划问题。

</div>

</div>

<template #notes>

总进度目标不是拍脑袋定的，它是在项目决策阶段定义时就定下来的。开始控制之前，第一步是论证这个目标到底能不能实现，不能实现就要提请决策者审议调整。论证的时候资料往往还不全，所以它不是简单画个进度表，而是要分析实施条件、做实施策划。

</template>

</Slide>

## 调查研究收集资料：五项内容

<p class="dk-lead">八步里的第一步“调查研究和收集资料”，具体包括五项工作：</p>

- **了解和收集**项目决策阶段有关项目进度目标确定的情况和资料。
- **收集**与进度有关的该项目组织、管理、经济和技术资料。
- **收集**类似项目的进度资料。
- **了解和调查**该项目的总体部署。
- **了解和调查**该项目实施的主客观条件。

<Reveal label="这五项的共性是“先了解、再收集、最后调查条件”">

五项内容都围绕“把论证所需的输入资料备齐”：先掌握决策阶段已定的目标，再补组织和类似项目资料，最后落到总体部署和实施的主客观条件上。

</Reveal>

<template #notes>

第一步虽然只有五个字，展开是五项内容。抓住一个主线：先了解已经定下来的进度目标，再收集组织和类似项目资料，最后调查总体部署和实施的主客观条件。做题时看到“类似项目进度资料”“总体部署”这些关键词，都要归到调查研究这一步。

</template>

</Slide>

## 项目结构分析：三级工作任务目录

<p class="dk-lead">大型工程的结构分析，是根据编制总进度纲要的需要，把整个工程<strong>逐层分解</strong>并确立工作目录。</p>

<CompareCard title="三级工作任务目录" :cols="['划分内容']" :rows="[
  { k: '一级工作任务目录', v: ['将整个工程划分成若干个子系统'] },
  { k: '二级工作任务目录', v: ['将每一个子系统分解为若干个子项目'] },
  { k: '三级工作任务目录', v: ['将每一个子项目分解为若干个工作项'] }
]" />

<Reveal label="容易混淆：结构分析 vs 计划系统的结构分析">

结构分析分解的是“工作任务目录”（子系统→子项目→工作项）；而进度计划系统结构分析分解的是“进度计划”本身（计划子系统→子项目进度计划→工作项进度计划）。二者对象不同，别搞混。

</Reveal>

<template #notes>

结构分析这一步，关键记住三级目录的递进关系：一级子系统、二级子项目、三级工作项。这里有一个易错点，结构分析和后面的计划系统结构分析是两个概念，前者分解的是工作任务目录，后者分解的是进度计划本身。考试常把两者混在一起出干扰项。

</template>

</Slide>

## 计划系统分层与工作编码三因素

<div class="dk-cols">

<div>

### 计划系统的多层结构
- **第一层**：将整个工程划分成若干个进度计划子系统。
- **第二层**：将每个进度计划子系统分解为若干个子项目进度计划。
- **第三层**：将每个子项目进度计划分解为若干个工作项。
- 整个项目划分多少计划层，根据项目的规模和特点而定。

</div>

<div>

### 工作编码应考虑的因素
1. 对不同**计划层**的标识。
2. 对不同**计划对象**的标识（如不同子项目）。
3. 对不同**工作**的标识（如设计工作、招标工作和施工工作等）。

</div>

</div>

<template #notes>

计划系统分成多少层，不是固定的，要根据项目规模和特点来定，一般展开就是子系统、子项目、工作项这三层。工作编码则要考虑三个标识，计划层、计划对象和工作本身。这两块都是记关键词就能拿分的点，重点抓住“层次由规模和特点决定”和“三标识”。

</template>

</Slide>

## 小结：影响因素与目标论证一张表

- **八大因素**：业主、勘察设计、施工技术、自然环境、社会环境、组织管理、材料设备、资金，其中**人为因素是最大干扰因素**。
- **控制目标**：先论证总进度目标实现的可能性，核心是编制**总进度纲要**（五项内容）。
- **论证八步**：调查收集资料 → 结构分析 → 计划系统结构分析 → 工作编码 → 编各层计划 → 协调编总进度计划 → 调整 → 报告决策者。
