## 设计单位计划系统：三个层次

<p class="dk-lead">设计单位计划系统包括<strong>设计总进度计划、阶段性设计进度计划和设计作业进度计划</strong>三个层次。</p>

<div class="dk-cols">

<div>

### 设计总进度计划
- 安排自设计准备开始至施工图设计完成的总设计时间内，各阶段工作的开始和完成时间。
- 确保设计进度控制总目标实现。

</div>

<div>

### 阶段性设计进度计划
- 包括设计准备、初步设计（技术设计）、施工图设计三阶段工作进度计划。
- 编制时必须考虑设计总进度计划对各阶段的时间要求。

</div>

<div>

### 设计作业进度计划
- 依据施工图设计工作进度计划、单位工程设计工日定额及投入的设计人员数编制。
- 作为设计人员承担设计任务的依据，控制各专业设计进度。

</div>

</div>

<template #notes>

设计单位计划分三个层次，总进度计划管全局时间，阶段性计划管设计准备、初步设计、施工图设计三阶段，作业进度计划落到具体设计人员。三个层次是从粗到细的关系。这里常考的细节是，设计作业进度计划要依据施工图设计工作进度计划、工日定额和设计人数来编。

</template>

</Slide>

## 施工单位计划系统：四个层次

<p class="dk-lead">施工单位进度计划包括<strong>施工准备、施工总进度、单位工程施工进度及分部分项工程进度</strong>四类计划。</p>

<CompareCard title="四类计划各自解决什么问题" :cols="['核心作用']" :rows="[
  { k: '施工准备工作计划', v: ['为施工创造技术和物资条件，统筹施工力量和现场'] },
  { k: '施工总进度计划', v: ['确定各单位工程及全工地性工程的施工期限与开竣工日期，进而确定资源需要量'] },
  { k: '单位工程施工进度计划', v: ['对单位工程各施工过程做时间和空间安排，是资源需要量计划和施工准备的依据'] },
  { k: '分部分项工程进度计划', v: ['针对工程量大或技术复杂的分部分项工程做时间安排，保证单位工程进度'] }
]" />

<Reveal label="为什么要层层细化到分部分项？">

因为像大型基础土方、复杂基础加固、大体积混凝土、大型桩基、大面积预制构件吊装这类工程，量大或技术复杂，必须单独编制详细进度计划，才能保证单位工程施工进度计划的顺利实施。

</Reveal>

<template #notes>

施工单位的四类计划是这节里数量最多的，从施工准备、总进度、单位工程，一路细化到分部分项。总进度计划定全工地各单位工程的开竣工日期，单位工程计划安排各施工过程，分部分项计划专治那些量大、技术复杂的工程。理解这条从粗到细的链条，就不容易记混。

</template>

</Slide>

## 横道图：形象直观，但有四大不足

<p class="dk-lead">横道图也称<strong>甘特图</strong>，由美国人甘特在 20 世纪初提出，优点是形象、直观、易编制易理解。</p>

- **横道图的四大缺点：**
1. 不能明确反映各项工作之间**错综复杂的相互关系**，工作提前或拖延时不便于分析对其他工作及总工期的影响程度。
2. 不能明确反映影响工期的**关键工作和关键线路**，无法抓住主要矛盾。
3. 不能反映工作所具有的**机动时间**，看不到计划的潜力。
4. 不能反映**工程费用与工期之间的关系**，不便于缩短工期、降低成本。

<Reveal label="横道图也不是完全没用">

当工程规模大、工艺关系复杂时，横道图很难充分暴露矛盾，调整起来也繁琐费时。但它的直观性是网络计划比不了的，实际中常与时标网络计划互补使用。

</Reveal>

<template #notes>

横道图大家都熟，但要记住它的四个短板，因为这是它和网络计划对比的核心。四个短板分别是，看不出相互关系、看不出关键线路、看不出机动时间、看不出费用与工期的关系。考试爱考“横道图不能反映什么”，把这四条背下来就能拿分。

</template>

</Slide>

## 网络计划：种类与四大特点

<p class="dk-lead">网络计划分<strong>肯定型</strong>和<strong>非肯定型</strong>两类；与横道计划相比，网络计划有四大特点，正好弥补横道图的四个短板。</p>

<div class="dk-cols">

<div>

### 网络计划的种类
- **非肯定型**：计划评审技术（PERT）、图示评审技术（GERT）、风险评审技术（VERT）、决策关键线路法（DN）。
- **肯定型派生的**：时标网络计划（时间直观）、搭接网络计划（图形简单）、有时限的网络计划、多级网络计划（适用于大中型工程），以及流水网络计划、多目标网络计划等。

</div>

<div>

### 网络计划的四大特点
- 明确表达各项工作之间的**逻辑关系**。
- 通过时间参数计算找出**关键线路和关键工作**。
- 明确各项工作的**机动时间**（时差）。
- 可用**电子计算机**计算、优化和调整。

</div>

</div>

<Reveal label="网络计划也有不足">

网络计划不像横道图那么直观明了，但这可以通过绘制时标网络计划得到弥补。

</Reveal>

<template #notes>

把网络计划的种类和特点放在一起记。种类先分肯定型和非肯定型，非肯定型记 PERT、GERT、VERT、DN 四个缩写，肯定型又派生出时标、搭接、有时限、多级四种。特点就是四个能，能表达逻辑、能找关键、能算时差、能用计算机优化，正好补上横道图的四个不能。网络计划也有不直观的不足，用时标网络计划弥补。

</template>

</Slide>

## 小结：计划体系与表示方法一张表

- **四大计划系统**：建设单位（3 项）、监理单位（总计划＋分解）、设计单位（3 层次）、施工单位（4 层次）。
- **总进度计划**：文字部分＋表格四张（一览表、总进度计划表、投资计划年度分配表、进度平衡表）。
- **表示方法**：横道图直观但“四个不能”，网络计划“四个能”，两者互补。
- **编制程序**：四阶段十步骤。
