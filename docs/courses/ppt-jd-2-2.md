## 有节奏流水施工：先分三种形式

<p class="dk-lead">有节奏流水施工是指每个施工过程在各施工段上的流水节拍都<strong>各自相等</strong>的流水施工，分<strong>等节奏</strong>和<strong>异节奏</strong>两类。</p>

- **等节奏流水施工**：各施工过程的流水节拍都相等，也称固定节拍或全等节拍流水施工。
- **异节奏流水施工**：各施工过程流水节拍各自相等、不同施工过程之间不尽相等，分等步距（加快的成倍节拍）和异步距（一般的成倍节拍）两种方式。

<Reveal label="为什么要研究成倍节拍？">

实际工程中不同施工过程复杂程度不同，很难让所有施工过程节拍都相等。只要保持同一施工过程各段节拍相等，让某些过程节拍成为其他过程的倍数，就形成成倍节拍流水施工；为缩短工期，可采用加快的成倍节拍方式。

</Reveal>

## 固定节拍工期（一）：有间歇时间

<p class="dk-lead">间歇时间指相邻两个施工过程之间因工艺或组织安排需要而增加的等待时间，分<strong>工艺间歇 $G$</strong>和<strong>组织间歇 $Z$</strong>。</p>

$$T=(n-1)t+\sum G+\sum Z+m\cdot t=(m+n-1)t+\sum G+\sum Z \tag{2-4}$$

<Steps title="有间歇固定节拍工期示例（图 2-5）" :steps="[
  { t: '已知条件', d: 'n=4、m=4、流水节拍 t=2，流水步距 K=t=2，工艺间歇 GⅡ,Ⅲ=1，其余间歇为 0。' },
  { t: '代入公式', d: 'T=(m+n−1)t+ΣG+ΣZ=(4+4−1)×2+1+0。' },
  { t: '计算结果', d: 'T=7×2+1=15（天）。' }
]" />

<template #notes>

固定节拍有间歇的工期公式 2-4，就是在 (m+n-1)t 的基础上加上工艺间歇 G 和组织间歇 Z。示例里 n 和 m 都是 4，节拍 2，中间有一处工艺间歇 1，算出来 15 天。注意公式里间歇是加项，先算 (m+n-1)t 再往上加，别漏了某一段间歇。

</template>

</Slide>

<Slide>

## 固定节拍工期（二）：有提前插入时间

<p class="dk-lead">提前插入时间 $C$ 是相邻两个专业工作队<strong>在同一施工段上共同作业的时间</strong>。在工作面允许、资源有保证时提前插入，可缩短工期。</p>

$$T=(n-1)t+\sum G+\sum Z-\sum C+m\cdot t=(m+n-1)t+\sum G+\sum Z-\sum C \tag{2-5}$$

<Reveal label="有提前插入示例（图 2-6）怎么算？">

n=4、m=3、t=3，提前插入 $C_{\mathrm{I,II}}=C_{\mathrm{II,III}}=1$、$C_{\mathrm{III,IV}}=2$，无工艺和组织间歇。则 $T=(3+4-1)\times 3+0+0-(1+1+2)=18-4=14$（天）。

</Reveal>

<template #notes>

有提前插入的公式 2-5，和公式 2-4 的唯一区别就是多减一个提前插入时间 C。提前插入就是相邻两个队在同一段上同时作业，能缩短工期。示例里 n=4、m=3、t=3，提前插入总共 4，算出来 14 天。记一个要点，间歇是加、提前插入是减，别把符号搞反。

</template>

</Slide>

## 加快的成倍节拍：四条特点

<p class="dk-lead">加快的成倍节拍流水施工，是让某些施工过程按节拍倍数<strong>增加专业工作队</strong>，从而缩短工期。</p>

  { k: '步距等于最大公约数', v: ['相邻专业工作队流水步距相等，等于流水节拍的最大公约数 K'] },
  { k: '队数大于过程数', v: ['节拍大的施工过程按倍数增加专业工作队数目'] },
  { k: '连续无空闲', v: ['各专业工作队在施工段上能连续作业，施工段之间没有空闲时间'] }
]" />

<template #notes>

加快的成倍节拍四条特点，最核心的是第二条，流水步距等于流水节拍的最大公约数。这是它和固定节拍最大的区别，固定节拍步距等于节拍本身，加快成倍步距等于最大公约数。第三条队数大于过程数，也是辨识点。抓住“最大公约数”和“队数多”这两个特征。

</template>

## 加快的成倍节拍：三步计算

<Steps title="加快的成倍节拍流水施工三步计算" :steps="[
  { t: '① 求流水步距 K', d: 'K = 各施工过程流水节拍的最大公约数。' },
  { t: '② 求各过程专业工作队数 bj 与总工作队数 n′', d: 'bj = tj / K；总工作队数 n′ = Σbj。' },
  { t: '③ 求总工期 T', d: 'T = (m + n′ − 1)K + ΣG + ΣZ − ΣC。' }
]" />

<Reveal label="三步的口诀">

先约分求步距，再除步距求队数，最后套公式求工期。即“先 K、再 b、后 T”。

</Reveal>

<template #notes>

加快成倍节拍的计算就三步。第一步，K 等于各节拍的最大公约数；第二步，每个过程的队数 bj 等于它的节拍除以 K，再求和得到总队数 n 撇；第三步，套公式 T 等于 (m+n'-1)K 加间歇减提前插入。口诀是“先 K、再 b、后 T”，按这个顺序算不会乱。

</template>

</Slide>

<Slide>

## 加快的成倍节拍：工期公式

<p class="dk-lead">加快的成倍节拍流水施工工期公式（2-6）：</p>

$$
\begin{aligned}
T&=(n'-1)K+\sum G+\sum Z-\sum C+m\cdot K\\
&=(m+n'-1)K+\sum G+\sum Z-\sum C
\end{aligned}
\tag{2-6}
$$

- $n'$——专业工作队数目，其余符号同前。
- 与固定节拍公式（2-4）形式一致，只是把“施工过程数 $n$”换成“专业工作队数 $n'$”。

<Reveal label="教材示例（图 2-7）怎么套？">

n=3、n′=6、m=6、K=1，无间歇无提前插入。$T=(6+6-1)\times 1=11$（天）。

</Reveal>

<template #notes>

加快成倍的工期公式 2-6，结构和固定节拍公式一模一样，只是把 n 换成 n 撇，也就是专业工作队总数。示例里 n=3 但 n 撇=6，m=6、K=1，算出来 11 天。这里要特别注意，公式里用的是专业工作队数 n 撇，不是施工过程数 n，这是最容易踩的坑。

</template>

</Slide>

## 小结：有节奏流水施工一张表

- **固定节拍**：步距=节拍，队数=过程数，$T=(m+n-1)t+\sum G+\sum Z-\sum C$。
- **一般成倍**：异步距，每过程一个队。
- **加快成倍**：$K=$ 最大公约数，$b_j=t_j/K$，$n'=\sum b_j$，$T=(m+n'-1)K+\sum G+\sum Z-\sum C$。
