## 双代号网络图：八大绘图红线（上）

<p class="dk-lead">绘图规则是<strong>监理案例与客观题的高频改错题</strong>，必须逐条看死。</p>

1. **必须按已定逻辑关系绘制**：不能多出多余逻辑联系（必要时用虚箭线切断）。
2. **严禁出现循环回路**：顺箭头方向不能又回到原出发点。
3. **箭线自左向右**：不应出现指向左方的水平箭线或偏向左方的斜向箭线。
4. **严禁双向箭头与无箭头连线**：方向必须唯一明确。

<template #notes>

前四条主要管“方向和逻辑”：不能画圈圈（循环回路），不能倒着指（向左），不能画成双向箭头或没箭头的线段。

</template>

</Slide>

## 双代号网络图：八大绘图红线（下）

5. **严禁出现没有箭头节点或没有箭尾节点的箭线**（不能有断头线）。
6. **严禁在箭线上引入或引出箭线**：母线法除外（多条箭线同时从同一节点引出或汇入，可用水平母线简化）。
7. **尽量避免箭线交叉**：不可避免时，采用**过桥法**或**指向法**处理。
8. **只有一个起点节点和一个终点节点**（多目标网络计划除外）。

<Reveal label="看到「节点编号不连续」算绘图错误吗？">

**不算！** 节点编号可以间断，只要满足**不重复**、且每条箭线的**箭尾编号小于箭头编号**（$i < j$）即可；但考试改错时，漏编、重号或 $i > j$ 属于错误。

</Reveal>

<template #notes>

后四条是案例改错最爱藏坑的地方：多个起点节点、多个终点节点、箭线直接搭在另一条箭线中间（非母线法）、以及交叉箭线没做过桥或指向处理。

</template>

## 虚箭线的巧妙用法：切断多余联系

- 当工作 C 的紧前工作是 A 和 B，而工作 D 的紧前工作**只有 B** 时：
  - 若直接把 A、B 都连到同一个节点再引出 C 和 D，会导致 **A 也成了 D 的紧前工作**（错误！）。
  - **正确画法**：B 结束后分两路——一路直接做 D，另一路通过**虚箭线**汇入 A 的终点节点，再引出 C。
- **口诀**：**合久必分用虚线，单向传递不串门**。

<template #notes>

这是表 3-1 到图 3-4 最经典的虚箭线用法：B 要给 C 和 D 当紧前，A 只给 C 当紧前，所以 B 的结束节点必须通过一条虚箭线单向指给 A 的结束节点。

## 小结：绘图纠错五字诀

- **查起终**：只能 1 个起点、1 个终点（单代号多开/多收加虚拟 S/F）。
- **查方向**：自左向右，绝不循环、不双向、不断头。
- **查重号**：一箭一工作，同起同终加虚线。
- **查逻辑**：多余联系用虚箭线单向切断。
