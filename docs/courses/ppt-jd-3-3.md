## 时间参数计算：先分清三种工期

<p class="dk-lead">网络计划时间参数的计算应在各项工作的<strong>持续时间</strong>（双代号 <i>D</i><sub>i-j</sub>、单代号 <i>D</i><sub>i</sub>）确定之后进行。</p>

<CompareCard title="三种工期的符号与关系（可点击「遮住自测」）" :cols="['符号', '含义与确定原则']" :rows="[
  { k: '计算工期', v: ['Tc', '根据网络计划时间参数计算而得到的工期'] },
  { k: '要求工期', v: ['Tr', '任务委托人所提出的指令性工期'] },
  { k: '计划工期', v: ['Tp', '作为实施目标的工期：有 Tr 时 Tp ≤ Tr；未规定 Tr 时令 Tp = Tc'] }
]" />

<template #notes>

学习网络计划计算之前，先把三种工期分清楚。计算工期 Tc 是算出来的，要求工期 Tr 是合同或者业主给定的目标。如果没有规定要求工期，我们就直接令计划工期 Tp 等于计算工期 Tc。

## 工作的六个时间参数与时间基准

<p class="dk-lead">为了简化计算，网络计划中的开始和完成时间都以<strong>时间单位的终了时刻</strong>为标准。</p>

- **“第 3 天开始”**：指第 3 天终了（下班）时刻开始，实际上是**第 4 天上班时刻**才开始。
- **“第 5 天完成”**：指第 5 天终了（下班）时刻完成。

<div class="dk-cols">

<div>

### 最早与最迟（4 个时刻）
- $ES_{i-j}$：最早开始时间
- $EF_{i-j} = ES_{i-j} + D_{i-j}$：最早完成时间
- $LF_{i-j}$：最迟完成时间
- $LS_{i-j} = LF_{i-j} - D_{i-j}$：最迟开始时间

</div>

<div>

### 机动时间（2 个时差）
- $TF_{i-j}$：**总时差**，不影响**总工期**的前提下可利用的机动时间
- $FF_{i-j}$：**自由时差**，不影响**紧后工作最早开始**的前提下可利用的机动时间
- 同一工作中，**$FF \le TF$**；当 $TF=0$ 时，$FF$ 必然为 $0$

</div>

</div>

<template #notes>

六个时间参数可以分成两组记：前四个是时刻，后两个是机动时间。特别要注意时间基准的规定，教材里说第 3 天开始，实际上是指第 3 天下班时刻。总时差管总工期，自由时差管紧后工作，所以自由时差永远不会超过总时差。

</template>

</Slide>

## 按工作计算法（一）：顺箭线正算最早、定工期

<Steps title="正算 ES / EF 与确定 Tc、Tp（口诀：顺箭线相加取大）" :steps="[
  { t: '1. 起点工作最早开始时间', d: '与起点节点相连的工作，如未规定最早开始时间，其 ES = 0。' },
  { t: '2. 后续工作 ES（相加取大）', d: 'ES_{i-j} = max{ 各紧前工作的 EF }；EF_{i-j} = ES_{i-j} + D_{i-j}。' },
  { t: '3. 确定计算工期 Tc', d: 'Tc = max{ 各以终点节点为完成节点的工作的 EF }。' },
  { t: '4. 确定计划工期 Tp', d: '未规定要求工期时 Tp = Tc；有要求工期 Tr 时应满足 Tp ≤ Tr。' }
]" />

<Reveal label="为什么正算时多个紧前工作要取最大值（max）？">

因为本工作必须等**所有紧前工作全部完成后**才能开始。只有最晚结束的那个紧前工作完成之后，本工作具备全部前置条件的最早时刻才算真正到来。

</Reveal>

<template #notes>

正算最早时间就记住四个字：相加取大。为什么取大？因为木桶效应，前面几项工作必须全部完工，后面这项工作才能开工，所以只能等最慢的那一个完成。算到终点节点，所有结束工作里最大的那个最早完成时间，就是计算工期 Tc。

</template>

</Slide>

<Slide>

## 按工作计算法（二）：逆箭线倒算最迟

<Steps title="倒算 LF / LS（口诀：逆箭线相减取小）" :steps="[
  { t: '1. 终点工作最迟完成时间', d: '以终点节点为完成节点的工作，其 LF = 计划工期 Tp。' },
  { t: '2. 计算本工作最迟开始时间', d: 'LS_{i-j} = LF_{i-j} − D_{i-j}。' },
  { t: '3. 前续工作 LF（相减取小）', d: 'LF_{i-j} = min{ 各紧后工作的 LS }。' }
]" />

<Reveal label="为什么倒算最迟完成时间时要取最小值（min）？">

本工作必须在**所有紧后工作最迟开始之前**完成，只要延误了其中最紧迫（$LS$ 最小）的那一项紧后工作，整个总工期就会被拖延。因此必须迁就最紧的那个 $LS$。

</Reveal>

<template #notes>

逆算最迟时间口诀也是四个字：相减取小。起点从终点往回推，先让终点工作的最迟完成时间等于计划工期 Tp，然后减去持续时间得到最迟开始时间 LS。遇到多个紧后工作时，必须满足最早要开工的那个紧后工作，所以取最小值。

</template>

</Slide>

## 按工作计算法（三）：总时差 TF 与自由时差 FF

<div class="dk-cols">

<div>

### 总时差 $TF_{i-j}$
$$TF_{i-j} = LS_{i-j} - ES_{i-j} = LF_{i-j} - EF_{i-j}$$
- 本工作可以利用、且**不影响总工期**的机动时间。
- 需要注意：如果某工作利用了总时差，**可能会减小后续工作的总时差**。

</div>

<div>

### 自由时差 $FF_{i-j}$
$$FF_{i-j} = \min\{ES_{j-k}\} - EF_{i-j}$$
- 对于以终点节点为完成节点的工作：
  $$FF_{i-n} = T_{\mathrm{p}} - EF_{i-n}$$
- 本工作可以利用、且**不影响任何紧后工作最早开始**的机动时间。

</div>

</div>

<template #notes>

总时差和自由时差是每年必考的核心公式。总时差是同工作自己的最迟减最早；自由时差是紧后工作最早开始时间的最小值减去本工作的最早完成时间。对于直接连到终点的工作，因为没有紧后工作，就用计划工期 Tp 减去它的最早完成时间。

</template>

</Slide>

<Slide>

## 关键工作与关键线路的判定规则

- **关键工作**：网络计划中**总时差最小**的工作是关键工作（特别注意：当 $T_{\mathrm{p}} = T_{\mathrm{c}}$ 时，关键工作的总时差为 $0$；若 $T_{\mathrm{p}} > T_{\mathrm{c}}$，则关键工作总时差等于 $T_{\mathrm{p}} - T_{\mathrm{c}} > 0$）。
- **关键线路**：自始至终**全部由关键工作组成**的线路，或者线路上**总的工作持续时间最长**的线路。
- 一个网络计划中至少有一条关键线路，也可能同时存在**多条**关键线路；关键线路在双代号网络图中通常用**粗箭线或双箭线**表示。

<Reveal label="常见误区：凡是总时差为零的工作才是关键工作，对吗？">

**不严谨！** 只有当计划工期等于计算工期（$T_{\mathrm{p}} = T_{\mathrm{c}}$）时，关键工作的总时差才为零。教材严谨定义是：**总时差最小的工作是关键工作**。若题目规定了大于计算工期的计划工期（如 $T_{\mathrm{c}}=15, T_{\mathrm{p}}=17$），则关键工作总时差为 $2$ 而非 $0$。

</Reveal>

<template #notes>

很多考生容易背错一句话，以为关键工作总时差一定等于零。其实只有 Tp 等于 Tc 的时候才等于零；教材里的标准说法是总时差最小的工作才是关键工作。关键线路可能不止一条，而且在执行过程中，非关键工作拖延太多也可能变成新的关键线路。

</template>

</Slide>

<Slide>

## 按节点计算法：关键节点的特性（高频陷阱）

在按节点计算法中，节点最早时间 $ET_i$ 和最迟时间 $LT_i$ 相等的节点（或 $ET_i = LT_i$ 当 $T_{\mathrm{p}}=T_{\mathrm{c}}$ 时，严格说差值最小）称为**关键节点**。

<CompareCard title="关键节点与关键工作的关系（可点击「遮住自测」）" :cols="['命题', '真假与理由']" :rows="[
  { k: '关键工作两端的节点', v: ['必为关键节点', '因为关键工作机动时间最小，其起止节点必然受关键线路约束'] },
  { k: '两个关键节点之间的工作', v: ['不一定是关键工作', '必须同时满足 ET_i + D_{i-j} = ET_j（或 LT_j − ET_i = D_{i-j}）才是关键工作'] },
  { k: '以关键节点为完成节点的工作', v: ['自由时差 = 总时差（当 Tp=Tc）', '因为完成节点处 ET_j = LT_j，故 FF = ET_j − EF = LT_j − EF = TF'] }
]" />

<template #notes>

按节点计算法有两条极其爱考的文字判断题。第一条：关键工作两端的节点一定是关键节点，但两个关键节点连起来的工作不一定是关键工作，必须算一下节点时间差是否刚好等于工作持续时间。第二条：当 Tp 等于 Tc 时，凡是以关键节点为完成节点的工作，它的总时差和自由时差相等。

</template>

</Slide>

## 单代号网络计划时间参数计算

单代号网络计划与双代号算理相同，但引入了**相邻两项工作之间的时间间隔 $LAG_{i,j}$**：

<Steps title="单代号网络计划五步算法" :steps="[
  { t: '1. 算 ES 与 EF（顺箭线取大）', d: 'ES_1 = 0；ES_j = max{ EF_i }；EF_i = ES_i + D_i；Tc = max{ EF }。' },
  { t: '2. 算时间间隔 LAG_{i,j}', d: 'LAG_{i,j} = ES_j − EF_i（紧后工作最早开始减本工作最早完成）。' },
  { t: '3. 算自由时差 FF_i', d: '有紧后工作时：FF_i = min{ LAG_{i,j} }；终点工作：FF_n = Tp − EF_n。' },
  { t: '4. 算总时差 TF_i（逆箭线推导）', d: '终点工作 TF_n = Tp − EF_n；其他工作 TF_i = min{ TF_j + LAG_{i,j} }。' },
  { t: '5. 确定关键线路', d: '从起点到终点，全部由关键工作组成，且相邻工作时间间隔 LAG_{i,j} 均为零的通路！' }
]" />

<template #notes>

单代号网络计划因为没有虚箭线表示的虚工作（除虚拟起终点外），多了一个时间间隔 LAG 的概念。记住 LAG 等于紧后工作 ES 减去本工作 EF。而自由时差就是本工作所有紧后工作里最小的那个 LAG；关键线路就是从头到尾 LAG 全部为零的那条通路。

</template>

</Slide>

## 计划评审技术（PERT）：持续时间不确定时怎么算

在计划评审技术（PERT）中，工作持续时间不是确定的常数，而是随机变量，需估计三个时间值：

- **乐观时间 $a$**：顺利情况下所需的最短时间。
- **最可能时间 $m$**：正常情况下最可能的时间。
- **悲观时间 $b$**：不利情况下所需的最长时间。

<div class="dk-cols">

<div>

### 期望值（均值）
$$D = \frac{a + 4m + b}{6}$$

</div>

<div>

### 标准差与方差
$$\sigma = \frac{b - a}{6}, \quad \sigma^2 = \left(\frac{b - a}{6}\right)^2$$

</div>

</div>

<template #notes>

如果考试考到不确定型网络计划 PERT，只需要记住这两个简单公式：期望持续时间等于乐观加 4 倍最可能加悲观再除以 6；标准差等于悲观减去乐观除以 6。

## 小结：网络计划时间参数计算一张表

- **正算最早**（顺箭线相加取大）：$ES = \max\{EF_{\text{紧前}}\}$，定出计算工期 $T_{\mathrm{c}}$ 与计划工期 $T_{\mathrm{p}}$。
- **倒算最迟**（逆箭线相减取小）：$LF = \min\{LS_{\text{紧后}}\}$。
- **两个时差**：$TF = LS - ES$（管总工期），$FF = \min\{ES_{\text{紧后}}\} - EF$（管紧后工作）。
- **单代号**：算时间间隔 $LAG_{i,j} = ES_j - EF_i$，关键线路要求全线 $LAG=0$。
