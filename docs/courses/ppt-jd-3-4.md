## 什么是双代号时标网络计划？

<p class="dk-lead">双代号时标网络计划是以<strong>时间坐标</strong>为尺度编制的网络计划，兼具网络计划与横道图的优点。</p>

- **实箭线**：表示实工作，其**水平投影长度**代表工作的持续时间。
- **虚箭线**：表示虚工作，因持续时间为 0，**必须垂直绘制**（若存在时间间隔则以波形线补齐水平投影）。
- **波形线**：表示工作与其紧后工作之间的**时间间隔**（对直接指向终点节点或一般工作时用于判定自由时差）。

## 总时差（TF）与自由时差（FF）判定难点

- **自由时差（FF）**：
  - 当工作直接指向紧后实工作时，**FF = 该工作箭线上的波形线水平投影长度**。
  - 当工作后面接的是虚工作时，FF 等于其与各紧后工作之间**时间间隔的最小值**（即经过虚箭线到达各紧后工作起点的波形线长度最小值）。
- **总时差（TF）逆推口诀**：
  $$TF_i = \min_j \{ LAG_{i,j} + TF_j \}$$
  - **通俗理解**：从本工作出发，沿着所有能走到终点的通路走一遍，把沿途遇到的**波形线长度加起来**，取**最小的那个总和**，就是本工作的总时差！

<Reveal label="以终点节点为完成节点的工作，FF 和 TF 怎么看？">

以终点节点为完成节点的工作，其**自由时差等于总时差**，且均等于**计划工期（或终点时刻）减去该工作的最早完成时间**（即其箭线末端所连的波形线长度）。

</Reveal>

<template #notes>

“沿途波形线之和取最小”这个土办法非常管用，算 TF 又快又不容易漏！记得虚工作上如果本身画了水平波形线，那也是时间间隔，也要算进通路里。

</template>

## 小结：时标网络计划口诀

- **一眼找关键**：从头到尾无波形。
- **自由时差 FF**：看自己（或经过虚线）的最小波形线。
- **总时差 TF**：沿路波形线之和取最小（逆推公式 $TF_i = \min \{LAG_{i,j} + TF_j\}$）。

## 进度计划表：把时标图转成工作日/日历表

- **工作日进度计划表**：纵列列出工作名称、持续时间与工作日，直接对应**工作日坐标体系**，方便班组按天领任务。
- **日历进度计划表**：把**节假日、周末**考虑进去后直接映射到具体年月日，方便业主和监理月报核对节点日期。
