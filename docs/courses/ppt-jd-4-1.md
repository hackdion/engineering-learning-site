## 跟踪检查：三方面工作

<p class="dk-lead">跟踪检查是计划执行信息的主要来源，是进度分析和调整的依据，也是进度控制的关键步骤。监理工程师应认真做好以下三方面工作。</p>

<CompareCard title="进度计划执行中跟踪检查的三项工作" :cols="['工作方式']" :rows="[
  { k: '定期收集进度报表资料', v: ['进度报表是反映实际进度的主要方式之一，执行单位按制度规定的时间和内容定期填写，监理工程师据此掌握实际进展'] },
  { k: '现场实地检查工程进展情况', v: ['派监理人员常驻现场随时检查，取得第一手资料，使数据更加及时、准确'] },
  { k: '定期召开现场会议', v: ['与执行单位有关人员面对面交谈，了解实际进度状况，同时协调有关方面的进度关系'] }
]" />

<Reveal label="收集的数据有哪些基本要求？">

收集的数据应当全面、真实、可靠。不完整或不正确的进度数据，将导致判断不准确或决策失误。

</Reveal>

<template #notes>

跟踪检查虽然听起来简单，展开是三件事：收报表、跑现场、开会议。报表是主渠道，现场检查拿第一手资料，会议既能了解情况又能协调关系。这里有个常考点，就是数据的要求，全面、真实、可靠，数据不完整或不正确，后面判断就全错了。记住这句就行。

</template>

</Slide>

## 检查时间间隔：由什么决定？

<p class="dk-lead">进度控制的效果与收集数据资料的时间间隔有关。多长时间检查一次，是监理工程师应当确定的问题。</p>

- 检查时间间隔与**工程项目的类型、规模、监理对象及有关条件**等多方面因素相关。
- 可视工程的具体情况，**每月、每旬或每周**进行一次检查。
- 特殊情况下，甚至需要**每日**进行一次进度检查。

<Reveal label="为什么不能检查得太稀疏？">

如果不经常地、定期地收集实际进度数据，就难以有效地控制实际进度，等发现偏差时可能已经失去纠偏的最佳时机。

</Reveal>

<template #notes>

检查间隔不是固定的，取决于项目类型、规模、监理对象等条件，一般每月、每旬或每周一次，特殊情况下甚至每天一次。关键是“经常、定期”，检查太稀疏就控制不住进度。这是一个容易出选择题的小点，把决定因素和三个时间档记住。

</template>

</Slide>

<Slide>

## 数据加工处理：让数据可比

<p class="dk-lead">收集来的实际进度数据不能直接拿去比较，必须先加工处理，<strong>形成与计划进度具有可比性的数据</strong>。</p>

- 对检查时段实际完成工作量的进度数据进行**整理、统计和分析**。
- 确定**本期累计完成的工作量**。
- 确定**本期已完成的工作量占计划总工作量的百分比**。

<Reveal label="为什么强调“可比性”？">

计划数据通常以累计量或百分比表示，只有把实际数据也换算成同一口径，才能进行有意义的对比，从而得出超前、滞后或一致的结论。

</Reveal>

<template #notes>

这一页讲的是加工处理，目的就是把零散的实际数据整理成和计划同口径、可比的数据。具体就是算两个东西：本期累计完成量，和本期完成量占计划总量的百分比。只有口径一致，比较才有意义，这也是后面各种比较方法（横道图、S 曲线等）的前提。

</template>

</Slide>

<Slide>

## 对比分析：得出一个结论

<p class="dk-lead">将实际进度数据与计划进度数据比较，确定工程项目实际执行状况与计划目标之间的差距。</p>

- 为了直观反映实际进度偏差，通常采用**表格或图形**进行对比分析。
- 比较的结论只有三种：实际进度比计划进度**超前**、**滞后**或**一致**。

<Reveal label="这一步在整个监测系统里的位置？">

对比分析是监测系统六步中的关键一步，它直接决定“是否出现偏差”这个判断，进而决定要不要进入调整系统。

</Reveal>

<template #notes>

对比分析的目标很单纯，就是得出超前、滞后还是一致的结论。为了让结果直观，常用表格或图形。这一步的结果是后面调整系统的入口，所以判断要准确。到这里，监测系统的六步就走完了，接下来进入调整系统。

</template>

</Slide>

<template #notes>

调整系统一共五步，顺序要记牢：先找原因，再分析影响，然后确定限制条件，接着采取措施，最后实施新计划并继续监测。第三步“确定限制条件”特别要强调，这些限制条件往往和合同条件有关，要认真分析后才能确定。调整不是随意改，而是受约束条件下的纠偏。

</template>

## 小结：两系统一张图

- **监测系统（六步）**：计划实施 → 建采集系统 → 收集数据 → 数据处理 → 实际与计划比较 → 判断是否出现偏差。
- **跟踪检查三方面**：收报表、跑现场、开会议；数据要全面、真实、可靠。
- **调整系统（五步）**：分析原因 → 分析影响 → 确定限制条件 → 采取措施 → 实施新计划并继续监测。
