## 谁编制、谁审核：先分清责任边界

<CompareCard title="施工总进度计划与单位工程进度计划" :cols="['监理工程师的工作', '承包单位责任']" :rows="[
  { k: '有总承包单位', v: ['审核总承包单位提交的施工总进度计划', '总承包单位负责编制和实施'] },
  { k: '大型项目分期分批发包且无总承包单位', v: ['需要编制施工总进度计划', '各承包单位仍对自身施工计划负责'] },
  { k: '若干承包单位平行承包', v: ['有必要编制施工总进度计划', '各单位计划需要相互协调'] },
  { k: '单位工程施工进度计划', v: ['只负责审核，不需要编制', '编制和实施均由承包单位负责'] }
]" />

<Reveal label="监理工程师编制施工总进度计划时，要确定什么？">

确定分期分批的项目组成，各批工程项目的开工、竣工顺序及时间安排，以及全场性准备工程特别是首批准备工程的内容与进度安排。

</Reveal>

<template #notes>

责任边界是高频考点。通常监理审核总承包单位的总进度计划，但大型项目分期分批发包且没有总承包单位，或者多个单位平行承包时，监理需要编制施工总进度计划。单位工程施工进度计划则始终只审核、不编制。无论怎样，编制和实施施工进度计划都是承包单位的责任。

</template>

</Slide>

## 审查确认不等于替承包单位负责

<Reveal label="监理审查或批准，会解除承包单位责任吗？">

不会。编制和实施施工进度计划是承包单位的责任。监理审查的主要目的是防止计划不当，并帮助承包单位实现合同进度目标，审查或批准不解除承包单位任何责任和义务。

</Reveal>

<CompareCard title="发现问题与计划确认后的处理" :cols="['正确做法', '不能误解为']" :rows="[
  { k: '审查发现问题', v: ['及时提出书面修改意见，协助修改；重大问题及时向业主汇报', '强制干预进度安排或支配劳动力、设备、材料'] },
  { k: '计划经监理确认', v: ['视为合同文件的一部分，作为处理延期或索赔的重要依据', '承包单位可以把计划不当责任转给监理'] }
]" />

<template #notes>

监理要提出建设性意见，但不能强制干预承包单位的进度安排，更不能直接支配施工所需的人、机和材料。发现问题要发书面修改意见，重大问题及时报告业主。计划一经确认，应视为合同文件的一部分，会成为以后处理延期和索赔的重要依据，但确认仍不解除承包单位责任。

</template>

</Slide>

## 例 6-1：20 组支架，计划工期怎么算？

<p class="dk-lead">每组支架由基础、柱和托梁组成，柱混凝土浇筑后需养护 <strong>20 天</strong>；合同工期 <strong>190 天</strong>。相邻两组支架开工时间差为 <strong>8 天</strong>。</p>

<Steps title="复算教材案例" :steps="[
  { t: '相邻组开工差', d: '两个柱基础持续时间相加：4+4=8 天' },
  { t: '每组施工时间', d: '4+4+3+20+5=36 天' },
  { t: '20 组总工期', d: '(20−1)×8+36=188 天' },
  { t: '作出审查判断', d: '逻辑关系合理、符合工艺和流水组织要求，且 188 天小于合同工期 190 天，应批准' }
]" />

<Reveal label="关键工作在哪里？">

所有支架的基础工程，以及第 20 组支架的柱 2、养护和托梁。不能只凭总工期不超合同工期就下结论，还要同时检查逻辑关系、施工工艺和施工组织。

</Reveal>

<template #notes>

这个案例先用流水组织算总工期。相邻组开工差八天，每组三十六天，第一组开始以后，其余十九组各错开八天，所以总工期是十九乘八再加三十六，等于一百八十八天。合同一百九十天，计划没有超期，而且逻辑和工艺合理，因此应批准。关键工作也要按教材结论识别。

</template>

</Slide>

## 小结：流程完整，边界清楚

- **工作跨度**：从施工进度计划审核开始，到保修期结束且无争议为止。
- **操作文件**：控制工作细则八项内容，是监理规划中进度控制内容的深化和补充。
- **审查责任**：六项审核内容；书面提出修改意见，不强制支配施工资源，不解除承包单位责任。
- **实施闭环**：综合平衡、及时开工、现场核查、协调纠偏、支付与延期管理、竣工移交。
- **案例结论**：20 组支架总工期 188 天，逻辑与工艺合理且不超过 190 天合同工期，应予批准。

## 自测（一）：工作细则与计划责任

<Quiz id="jd62-q6" q="监理工程师监督施工进度计划实施时，应（ ）。" :options="['只检查承包单位报表，不必现场核实', '进行现场实地检查，核实已完项目时间和工程量', '发现偏差后不分析原因', '禁止召开现场协调会']" :answer="1" explain="监理既要检查报表和分析资料，也要现场检查，核实已完项目时间和工程量，并分析偏差、研究纠偏。" cite="/textbook/schedule/chapter-06/section-02" />

<template #notes>

第三组抓及时开工和真实进度。开工令的日期直接关联合同竣工日期，拖延可能带来索赔。监督不能只靠报表，还要现场核实工程量与完成时间，发现偏差后继续分析影响和原因，必要时调整后期计划并组织协调。
