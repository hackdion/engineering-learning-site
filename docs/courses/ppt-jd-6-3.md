]" />

<Reveal label="工艺关系与组织关系有什么区别？">

工艺关系由施工技术规律和已确定的施工方案决定，违背后可能无法施工或造成质量、安全事故和返工。组织关系由劳动力、机械、材料和构配件等资源的组织安排形成，是人为关系，可通过调整取得不同经济效果。

</Reveal>

<template #notes>

工作项目划分粗细取决于计划需要，控制性粗到分部，实施性细到分项或更具体。列项要防漏防重，辅助服务项目按教材原则不必列入。施工顺序同时受工艺关系和组织关系制约，前者来自技术规律，后者来自资源组织。实际项目不能拘泥于固定顺序，要结合特点和施工方案研究。

## 工程量、劳动量与机械台班：三组公式

<p class="dk-lead">合并工作项目先求综合时间定额，再根据工程量和定额计算劳动量或机械台班数。</p>

$$
H=\frac{Q_1H_1+Q_2H_2+\cdots+Q_nH_n}{Q_1+Q_2+\cdots+Q_n}\tag{6-1}
$$

<CompareCard title="劳动量与机械台班数的两种算法" :cols="['公式', '适用条件']" :rows="[
  { k: '按时间定额', v: ['P=Q·H（式 6-2）', 'Q 为工程量，H 为时间定额'] },
  { k: '按产量定额', v: ['P=Q/S（式 6-3）', 'S 为人工产量定额或机械台班产量定额'] }
]" />

- 工程量计算单位应与现行定额手册计量单位一致。
- 要结合施工方法、安全技术要求，并按施工段分层分段计算。
- 水暖电卫等专业工程通常不计算其劳动量和机械台班数，只安排与土建配合的进度。

<template #notes>

公式先分清符号。综合时间定额是各分项工程量乘各自时间定额求和，再除以总工程量。劳动量或台班数可以用工程量乘时间定额，也可以用工程量除以产量定额。计算前单位要与定额一致，并结合施工方法、安全要求和施工段划分。专业水暖电卫按教材通常只安排配合进度。

</template>

</Slide>

## 持续时间与资源配置：正算、倒排都要会

<CompareCard title="式 6-4 与式 6-5" :cols="['公式', '用途']" :rows="[

  { k: '已知持续时间倒排资源', v: ['R=P/(D·B)', '组织流水施工时先定 D，再求每班人数或机械台数'] }

<template #notes>

持续时间的正算公式是 D 等于 P 除以 R 乘 B，倒排资源则变成 R 等于 P 除以 D 乘 B。这个例子二百四十工日、十天、每天两班，所以每班十二人。安排人数还要满足最小工作面和最小劳动组合：最小工作面限定上限，最小劳动组合限定下限，不能只算出数就直接采用。

</template>

## 小结：先编得合理，再审得完整

- **总进度计划**：计算工程量 → 定期限 → 定开竣工及搭接 → 初步计划 → 正式计划。
- **单位工程计划**：九步程序，项目粗细随用途，顺序兼顾工艺关系与组织关系。
- **计算链**：工程量和定额 → 劳动量或台班数 → 持续时间或资源配置。
- **检查调整**：顺序与总工期先解决可行性，工种与资源后解决优化。
- **监理审查**：五项内容，书面修改、重新审查，总监签认并报建设单位批准后实施。
