## 对比法发现偏差：先纠偏，慎调整

<Reveal label="施工进度检查的主要方法是什么？">

对比法。用第四章的方法，将整理后的实际进度数据与计划进度数据比较，发现是否出现偏差以及偏差大小。

</Reveal>

<Steps title="检查后的处理顺序" :steps="[

]" />

<template #notes>

检查的主要方法是对比法，不是看到现场慢了就立刻改计划。偏差较小时先分析原因、排除障碍，继续执行原计划；经过努力确实不能实现，再考虑必要调整。原计划不适应实际时，新计划成为新的控制依据，但调整要慎重，尽量减少变更计划性的调整。

</template>

## 两类调整方法：改持续时间，或改逻辑关系

<CompareCard title="缩短工期的两条路径" :cols="['是否改持续时间', '是否改先后顺序', '典型做法']" :rows="[
  { k: '缩短某些工作持续时间', v: ['缩短关键线路上工作的持续时间', '不改变工作之间的先后顺序关系', '组织、技术、经济及其他配套措施'] },
  { k: '改变某些工作间逻辑关系', v: ['不改变工作的持续时间', '改变开始和完成时间及工作衔接', '大型工程常用平行作业，单位工程常用搭接作业'] },
  { k: '两种方法组合', v: ['可同时使用', '按实际需要重新组合', '工期拖延太多或单一方法调整幅度受限时采用'] }
]" />

<Reveal label="改变逻辑关系会增加什么压力？">

无论采用搭接作业还是平行作业，工程项目在单位时间内的资源需求量都会增加。大型工程单位工程多、相互制约较小，平行作业调整空间较大；单位工程受工艺关系限制，通常采用搭接作业。

</Reveal>

<template #notes>

两类调整方法要抓本质。缩短持续时间不改先后顺序，但必须压缩关键线路上的工作；改变逻辑关系不改每项工作的持续时间，只改开始完成时间。大型工程容易采用平行作业，单位工程通常用搭接。两种方法也可以组合，但平行搭接都会提高单位时间资源需求。

</template>

</Slide>

无论采取哪种措施，一般都会增加费用。应利用费用优化原理，选择费用增加量最小的关键工作作为压缩对象。

## 小结：动态检查，慎重调整

- **实施监督**：承包单位执行计划并接受监督检查，监理定期向业主报告进展。
- **动态检查**：报表、现场跟踪和现场会议三种方式，用对比法识别偏差。
- **处理顺序**：小偏差先排障并继续原计划，确实无法实现再慎重调整。
- **调整路径**：缩短关键工作持续时间，或改变逻辑关系；必要时组合使用。
- **措施选择**：组织、技术、经济、配套分清机制，压缩对象按费用优化选择。
