## 都是拖期，责任后果完全不同

<CompareCard title="工程延期 vs 工程延误" :cols="['原因性质', '承包单位后果', '业主权利或责任']" :rows="[
  { k: '工程延期', v: ['承包单位自身以外原因', '有权要求延长工期，并可要求赔偿额外损失', '按合同承担相应费用和批准延期后的责任'] },
  { k: '工程延误', v: ['承包单位自身原因', '一切损失由承包单位承担', '业主有权对承包单位施行误期违约罚款'] }
]" />

<Reveal label="为什么监理是否批准工程延期很重要？">

它直接改变双方责任与费用后果。批准为工程延期，承包单位可不承担相应误期损失赔偿，并可要求弥补额外损失；认定为工程延误，则损失由承包单位承担，还可能面临误期违约罚款。

</Reveal>

<template #notes>

这一节先把两个概念分清。工程延期来自承包单位自身以外的原因，工程延误来自承包单位自身。名字相近，但工期和费用后果完全不同。监理审批是否构成延期，会影响误期赔偿和额外费用，所以必须按合同、工期影响和实际情况公正判断。

</template>

## 工程延期审批：意向通知与详情报告

<SortSteps id="ppt-jd-6-5-approval" prompt="按一般工程延期事件排列申报与审批步骤" :items="[

  '承包单位在合同有效期内提交详细申述报告，说明延期理由及依据',

<Reveal label="为什么要先提交意向通知？">

让监理工程师尽早了解事件，及时作出减少延期损失的决定。详细申述报告随后在合同有效期内，或监理工程师可能同意的合理期限内提交。

</Reveal>

<template #notes>

一般程序先发生事件，承包单位在合同有效期内提交书面意向通知，再提交详细申述报告，监理调查核实并确定延期时间，最后协商审批。意向通知和详情报告不能混为一谈，前者让监理尽早知道并减损，后者提供延期理由和依据。临时或最终批准前，都应与业主和承包单位协商。

</template>

  { t: '事件结束后交最终报告', d: '承包单位在合同规定期限内提交最终详情报告' },
  { t: '复查并最终确定', d: '监理复查全部内容，确定该事件所需延期时间' }

<Reveal label="复杂但非持续性事件能否先作临时决定？">

可以。对于一时难以作出结论的延期事件，即使不属于持续性事件，也可先作临时延期决定，再作最后决定；复杂事件还可以成立专门小组处理。

</Reveal>

<template #notes>

持续性事件不能等全部结束才处理，应先交阶段性报告，监理核实后作临时决定，事件结束再交最终报告并复查。临时延期时间不宜太长，一般不超过最终批准时间。复杂但非持续的事件也可以先临时后最终，必要时成立专门小组，这样既有处理时间，也避免因不及时造成损失。

</template>

</Slide>

## 三项审批原则：合同、工期、实际缺一不可

<CompareCard title="工程延期审批的三道关口" :cols="['判断要点', '不能批准或需注意的情形']" :rows="[
  { k: '合同条件（根本原则）', v: ['延期原因确实属于承包单位自身以外，并符合合同条件', '属于承包单位自身原因，不能批准为工程延期'] },
  { k: '影响工期', v: ['延长时间超过相应总时差并影响工期时才可批准', '非关键线路事件未超过总时差，即使符合合同条件也不批准延期'] },
  { k: '实际情况', v: ['承包单位详细记载并报告，监理现场考察分析并记录', '没有可靠事实依据，不能合理确定延期时间'] }
]" />

<Reveal label="关键线路固定不变吗？">

不是。关键线路会随工程进展和情况变化而转移。监理应以承包单位提交、经监理审核并不断调整后的施工进度计划为依据，判断是否批准延期。

</Reveal>

<template #notes>

三项原则要同时满足。合同条件是根本，先看原因是不是承包单位以外；影响工期看延长时间是否超过总时差，不是发生在关键线路以外就一律不批，也不是非关键事件就自动能批；实际情况要求双方记录和现场核实。关键线路会变化，所以判断要依据审核后不断调整的计划。

</template>

</Slide>

## 工程延期控制：尽量让事件少发生

<Steps title="监理工程师的三项预防与处理工作" :steps="[

  { t: '提醒业主履行合同职责', d: '提前做好施工场地、设计图纸提供，并及时支付工程进度款' },
  { t: '妥善处理工程延期事件', d: '按合同处理，既减少延期时间和损失，又在详细调查基础上合理批准延期' }
]" />

<Reveal label="业主在施工过程中还应注意什么？">

尽量减少干预、多协调，避免因业主的干扰和阻碍导致延期事件发生。

</Reveal>

<template #notes>

延期控制不只是事件发生后算时间，更重要的是提前预防。开工令之前看征地拆迁、图纸和付款准备，施工过程中提醒业主提供场地图纸并及时付款，事件发生以后按合同妥善处理。业主还应减少不必要干预、多协调，避免自身行为造成延期。

</template>

## 工程延误处理：三种手段，轻重不同

]" />

<template #notes>

工程延误处理有三种手段。拒签付款凭证是施工过程中的制约，误期损失赔偿是未按合同工期完成后的处罚，取消承包资格最严厉，一般不轻易采用。取消前业主必须事先通知，并要求承包单位在规定期限内做好辩护准备，这个程序细节常被考成判断题。

</template>

## 小结：原因定性质，时差定影响

- **责任划分**：工程延期来自承包单位以外原因，工程延误来自承包单位自身原因。
- **申报审批**：有效期内意向通知和详情报告，监理调查核实；持续事件先临时、后最终。
- **三项原则**：合同条件、影响工期、实际情况同时满足。
- **案例计算**：工作 K 停工 3.5 个月，扣除 3 个月总时差，只批准 0.5 个月。
- **延误处理**：拒签付款凭证、误期损失赔偿、取消承包资格，适用阶段和严厉程度不同。
