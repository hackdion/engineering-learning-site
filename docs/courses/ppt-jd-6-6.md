## 储备与供应计划：数量平衡要算清

<CompareCard title="两类计划的作用与依据" :cols="['主要依据', '核心作用']" :rows="[
  { k: '物资储备计划', v: ['需求计划、储备定额、储备方式、供应方式和场地条件', '确定合理储备，保证施工材料连续供应'] },
  { k: '物资供应计划', v: ['需求计划、储备计划和货源资料', '反映需要与供应平衡，挖潜利库，组织指导供应'] }
]" />

<p class="dk-lead"><strong>供应计划数量平衡 = 期内需用量 − 期初库存量 + 期末储备量</strong>。正值说明本期不足需补充，负值说明本期多余可供外调。</p>

<Reveal label="现场储备是否越多越好？">

不是。储备量主要由供应方式和现场条件决定，一般应保持 35 天用量。单层工业厂房预制构件采用随运随吊方案时，可不现场储备，用多少供多少。

</Reveal>

<template #notes>

储备计划解决连续供应，供应计划解决供需平衡。数量上先考虑期内需用量，减期初库存，再加期末储备。结果为正说明不足，负值说明多余。教材给出一般保持三十五天用量，但供应方式和现场条件不同可以调整，随运随吊就不需要现场储备。

</template>

</Slide>

<Steps title="物资供应进度监测与调整的闭环" :steps="[

  { t: '实施、检查与监督', d: '收集实际供货数据，掌握供应过程真实情况' },
  { t: '实际与计划比较', d: '识别是否出现供货拖延；没有拖延则继续实施和监测' },
  { t: '分析原因与施工影响', d: '出现拖延时分析原因，并分析对施工进度计划的影响' },
  { t: '协调调整并采取控制措施', d: '按需调整施工进度计划、物资供应计划和其他有关计划，再回到实施监测' }
]" />

<Reveal label="哪些干扰会打破原供应计划？">

施工进度提前或拖延、设计变更、价格变化、市场供应部门突然供货中断以及其他意外情况，都可能使实际供应与计划不符。

</Reveal>

<template #notes>

物资供应计划不是审批完就结束，执行中要不断比较实际和计划。没有拖延继续监测，有拖延就分析原因和对施工的影响，再决定调整施工计划、供应计划还是其他计划，并采取措施回到闭环。工程变更、供应意外中断和施工进度变化都是典型干扰。

</template>

</Slide>

## 小结：目标明确，计划成套，动态调整

- **控制目标**：适时、适地、按质、按量、成套齐备，服务投资、进度和质量。
- **计划体系**：需求、供应、储备、申请订货、采购加工、国外进口六类计划。
- **需求计算**：一次性需求三步；计划期需求可用计算法或卡段法。
- **供需平衡**：期内需用量减期初库存、加期末储备，正值补充、负值外调。
- **动态控制**：检查实际供应、分析施工影响、调整相关计划并采取措施。
- **监理职责**：协助决策、组织招标、编审计划、监督订货与实施、协调各方。
