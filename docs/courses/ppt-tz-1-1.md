## 一张图看懂「工程项目总投资」的组成骨架

<p class="dk-lead">生产性工程项目与非生产性工程项目，总投资构成有明确边界——</p>

- **生产性工程项目总投资** = **建设投资** + **建设期利息** + **流动资金**（3 部分）
- **非生产性工程项目总投资** = **建设投资** + **建设期利息**（2 部分，不含流动资金）
- **核心对应关系**：建设投资 + 建设期利息 = **固定资产投资**；流动资金 = **流动资产投资**
- **红线提醒**：政府有关部门对工程项目管理监督所发生并由其部门财政支出的费用，**不得列入**工程项目总投资。

<Reveal label="速记口诀：怎么区分「基本预备费」和「涨价预备费」？">

- **基本预备费**应对“量”和“意外”（设计变更、不可抗力等）→ 归**静态投资**；
- **涨价预备费**与**建设期利息**应对“价”和“时间资金成本”→ 归**动态投资**；
- 记住：**工程费用 = 建筑安装工程费 + 设备及工器具购置费**。

</Reveal>

静态投资和动态投资的划分是第一章的高频单选和多选题。大家只要记住一个诀窍：涨价预备费和建设期利息属于动态投资，其他四项——建安费、设备购置费、工程建设其他费、基本预备费——全归静态投资。另外要留意流动资金在可研阶段和初设阶段口径不同。

## 工程项目投资的分层次汇总（5 级分解）

<div class="dk-cols">

<div>

### 由大到小的 5 个层次
1. **工程项目**（按一个总体设计建设）
2. **单项工程**（有独立设计文件，竣工后能**独立发挥生产能力或工程效益**）
3. **单位工程**（能**独立施工**，但不能独立发挥效益）
4. **分部工程**（按专业、部位分解）
5. **分项工程**（按施工方法、构造及规格分解，计价最基本单元）

</div>

<div>

### 汇总顺序（自下而上）
- 先计算**分部分项工程**投资；
- 汇总成**单位工程**投资；
- 再汇总成**单项工程**投资；
- 最终汇总形成**工程项目总投资**。
- 常见实例：一所学校是工程项目，其中一栋教学楼是**单项工程**，该教学楼的土建工程或给排水工程是**单位工程**。

</div>

</div>

<template #notes>

这 5 个层次在案例和选择题里经常出现。判断单项工程和单位工程只有一条金标准：能不能“独立发挥生产能力或工程效益”。能独立发挥效益的是单项工程，只能独立施工但单独用不了的是单位工程。

</template>

</Slide>

<CompareCard title="各建设阶段对项目投资的影响程度（图 1-3）" :cols="['建设阶段', '影响投资可能性 & 核心地位']" :rows="[
  { k: '初步设计阶段', v: ['75% ～ 95%', '影响投资可能性最大；技术设计结束前约占建设周期 1/4'] },
  { k: '技术设计阶段', v: ['35% ～ 75%', '进一步细化技术方案，仍有较大节支潜力'] },
  { k: '施工图设计阶段', v: ['5% ～ 35%', '图纸基本落定，影响幅度明显收窄'] },
  { k: '施工阶段', v: ['约 5% ～ 25%（余地小）', '资金消耗最多，但通过施工节约投资的余地相对有限'] }

- **核心结论**：项目投资控制的重点在于施工以前的**投资决策和设计阶段**；而在项目做出投资决策后，控制项目投资的关键就在于**设计**。
- **全寿命费用视角**：设计费一般只占工程全寿命费用的 **1% 以下**，但正是这少于 1% 的费用却基本决定了几乎全部随后的费用。

这组数字是投资控制第一章绝对的必考点！初步设计阶段影响投资 75% 到 95%，技术设计 35% 到 75%，施工图设计 5% 到 35%。记住两句话：全过程重点在决策和设计阶段；做出投资决策后，控制关键就在于设计。

## 什么是「工程全寿命费用」？

<div class="dk-cols">

<div>

### 工程全寿命费用的 3 大构成
1. **建设投资**（一次性建设成本）
2. **交付使用后的经常性开支费用**
   - 经营费用
   - 日常维护修理费用
   - 使用期内大修理和局部更新费用
3. **项目使用期满后的报废拆除费用**等

</div>

<div>

### 为什么不能只盯着「建设投资」？
- 如果设计阶段一味压缩一次性建设投资，可能导致建筑能耗高、设备故障多、大修频繁，**全寿命费用反而大幅上升**；
- 反过来，设计阶段多花不到 1% 的设计费进行优化，往往能在几十年运营期里省下巨额运维成本。

</div>

</div>

<template #notes>

教材在这里顺便点出了工程全寿命费用的概念，它和后面第二章价值工程里的“寿命周期成本”是一脉相承的。考试多选题常问全寿命费用包含哪些内容，除了建设投资和经常性开支，别漏了使用期满后的报废拆除费用。

</template>

## 一页总结：本节必须拿稳的 4 个核心数字与结论

1. **总投资两分法**：生产性 = 建设投资 + 建设期利息 + **流动资金**；非生产性无流动资金。
2. **静态 4 项 vs 动态 2 项**：涨价预备费 + 建设期利息 = 动态投资；基本预备费归静态投资。
3. **三段影响比例**：初步设计 **75%～95%**、技术设计 **35%～75%**、施工图设计 **5%～35%**；设计费 &lt; 全寿命费用 **1%**。
4. **动态控制周期**：每**两周或一个月**循环一次，计划值与实际值比较需提前统一数据体系。
