## 第二部分工程建设其他费：15 类速览

- **土地类**：土地使用费和其他补偿费（出让金、征地补偿、拆迁安置等）。
- **管理与咨询类**：建设管理费（含**建设单位管理费、工程监理费、设备监造费、招标投标费、印花税**等）、前期工作咨询费、专项评价费（环评/安评/稳评等）、研究试验费、勘察设计费（含 **BIM 技术应用服务费**）。
- **场地与导入类**：场地准备费和临时设施费、引进技术和进口设备材料其他费、特殊设备安全监督检验费。
- **配套与投产类**：市政公用配套设施费、**联合试运转费**、工程保险费、**生产准备费**、专利及专有技术使用费、其他费用（如**全过程工程咨询服务费、工程总承包管理费、房产测绘费**等）。

<template #notes>

工程建设其他费名目多，考试常考归属：记住工程监理费、招标投标费属于“建设管理费”；BIM 服务费属于“勘察设计费”；全过程咨询和 EPC 管理费属于“其他费用”。

</template>

## 工程总承包（EPC）费用构成

- **构成公式**：**工程总承包费用 = 工程费用 + 工程总承包其他费**。
- **工程费用**：建筑工程费 + 安装工程费 + 设备购置费（与总投资第一部分相同）。
- **工程总承包其他费**（从总投资工程建设其他费中选取适用部分）：
  - 勘察费、设计费、**工程总承包管理费**、研究试验费、临时用地及占道使用补偿费、场地准备及临时设施费、检验检测及试运转费、系统集成费、工程保险费、其他专项费（专利、引进设备、测绘、苗木迁移等）。

<Reveal label="报建报批代办服务费怎么算？">

如果发包人将工程项目的报建报批以及与建设、供电、规划、消防、水务、城管等部门相关的技术与审批服务工作列入发包范围，则相应的**代办服务费也应纳入工程总承包其他费**。

</Reveal>

<template #notes>

工程总承包（EPC）把勘察、设计、施工、采购打包在一起，所以“工程总承包其他费”里不仅有勘察设计费、研究试验费，还有专门的“工程总承包管理费”和系统集成费。

</template>

## 小结：总投资构成一张表

- **总投资** = 建设投资 + 建设期利息 + 铺底流动资金（非生产性无流动资金）。
- **建设投资** = 工程费用 + 工程建设其他费 + 预备费（基本+涨价）。
- **静动边界**：基本预备费属静态；涨价预备费 + 建设期利息属动态。
