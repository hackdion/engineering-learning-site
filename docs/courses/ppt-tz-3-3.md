## 设备购置费总公式与国产设备原价

<p class="dk-lead"><strong>设备购置费 = 设备原价（或进口设备抵岸价） + 设备运杂费</strong></p>

- **国产标准设备原价**：一般指设备制造厂的交货价（出厂价）；若有带备件和不带备件两种出厂价，一般按**带有备件的出厂价**计算。
- **国产非标准设备原价**：无定型标准、按一次订货图纸制造，常用**成本计算估价法**、系列设备插入估价法、分部组合估价法、定额估价法。

## 进口设备抵岸价：八项构成与计算链

<Steps title="进口设备抵岸价计算八项顺推（FOB 起点）" :steps="[
  { t: '1. 进口设备货价', d: 'FOB × 人民币外汇牌价' },
  { t: '2. 国外运费', d: 'FOB × 运费费率（或 运量 × 单位运价）' },
  { t: '3. 国外运输保险费', d: '[(FOB + 国外运费) / (1 - 保险费率)] × 保险费率（价内税式除 1-r！）' },
  { t: '4. 银行财务费', d: 'FOB × 人民币外汇牌价 × 银行财务费率（一般 0.4%～0.5%）' },
  { t: '5. 外贸手续费', d: 'CIF × 人民币外汇牌价 × 外贸手续费率（一般取 1.5%）' },
  { t: '6. 进口关税', d: 'CIF × 人民币外汇牌价 × 进口关税税率' },
  { t: '7. 消费税（应税消费品）', d: '[(CIF × 牌价 + 关税) / (1 - 消费税率)] × 消费税率' },
  { t: '8. 进口环节增值税', d: '(CIF × 牌价 + 进口关税 + 消费税) × 增值税税率' }
]" />

<template #notes>

这八个公式的基数千万不能背混：只有「银行财务费」和「国外运费」是用 FOB 乘费率！外贸手续费和进口关税是用 CIF 乘费率！国外运输保险费和消费税分母都有 (1 - 税/费率)！

</template>

## 设备运杂费构成与计算

- **设备运杂费 = 设备原价 × 设备运杂费率**。
- **包含四部分**：
  1. 国产标准设备由设备制造厂交货地点起至工地仓库（或施工组织设计指定的需要安装设备的堆放地点）止所发生的**运费和装卸费**；
  2. 进口设备由我国**到岸港口或边境车站起**至工地仓库止所发生的运费和装卸费；
  3. 在设备出厂价格中没有包含的设备**包装和包装材料器具费**；
  4. **供销部门的手续费**和建设单位（或工程承包公司）的**采购与仓库保管费**。

<Reveal label="设备运杂费中“海运/国际运费”算在内吗？">

**不算！** 国外运费已经算在进口设备到岸价（CIF）和抵岸价里了；设备运杂费只算**从我国到岸港口或边境车站起**运到工地仓库的国内段运费、装卸、包装与采保费。

</Reveal>

<template #notes>

记住设备运杂费的分界点：国产设备从制造厂交货点算起，进口设备从我国到岸港口或边境车站算起，终点都是工地仓库或指定堆放点。

## 小结：设备购置费计算记忆线

- **总式**：设备购置费 = 设备原价（或抵岸价） + 设备运杂费。
- **FOB → CIF**：加国外运费，再按 $\frac{\text{FOB}+\text{运费}}{1-r}\times r$ 加国外运输保险费。
- **CIF → 抵岸价**：FOB 算银行财务费；CIF 算外贸手续费与关税；$(CIF+\text{关税}+\text{消费税})$ 算增值税。
