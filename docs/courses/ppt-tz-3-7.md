## 建设期利息计算核心假定

<p class="dk-lead">建设期利息是指项目借款在建设期内发生并计入固定资产的利息。假定借款均在<strong>每年的年中支用</strong>：<strong>借款当年按半年计息，其余各年份按全年计息</strong>。</p>

- **计算公式（式 3-56）**：
  $$Q = \sum_{j=1}^{n} \left( P_{j-1} + \frac{A_j}{2} \right) i$$
- **参数含义**：
  - $P_{j-1}$：第 $(j-1)$ 年末**贷款累计金额与利息累计金额之和**（即**复利计息**，上年的利息也要算本金生息！）；
  - $A_j$：第 $j$ 年新增贷款金额（除以 2 代表年中支用）；
  - $i$：贷款年利率（注意若题目给“按季/按月计息的名义利率”，需先折算为**年有效利率** $i_{\text{eff}} = (1 + r/m)^m - 1$）。

## 流动资金与铺底流动资金

- **流动资金**：为进行正常生产运营，用于购买原材料、燃料，支付工资及其他经营费用等所需的周转资金。
- **可研阶段 vs 初步设计及以后阶段**：
  - 在**可行性研究阶段**可根据需要计为**全部流动资金**；
  - 在**初步设计及以后阶段**可根据需要计为**铺底流动资金**。
- **铺底流动资金比例**：经营性工程项目列入工程项目总投资的铺底流动资金，**一般按全部流动资金的 30% 计算**。

## 小结：建设期利息与流动资金

- **建设期利息**：$Q = \sum (P_{j-1} + A_j / 2) i$（当年新借按半年，往年本息按全年复利）。
- **铺底流动资金**：一般按全部流动资金的 **30%** 计入建设项目总投资。
- **分项详细估算法**：流动资金 = (应收 + 预付 + 存货 + 库存现金) − (应付 + 预收)。
