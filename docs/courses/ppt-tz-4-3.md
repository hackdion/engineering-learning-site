## 资金成本是什么？（构成两部分）

<p class="dk-lead">资金成本是企业为<strong>筹集和使用资金</strong>而付出的代价，由两部分构成——</p>

<div class="dk-cols">

<div>

### 1. 资金筹集成本（筹资费）
- 在资金**筹集过程中**支付的各项费用：股票/债券的**印刷费、发行手续费、律师费、资信评估费、公证费、担保费、广告费**等。
- 一般属于**一次性费用**，筹资次数越多，资金筹集成本越高。

</div>

<div>

### 2. 资金使用成本（资金占用费）
- 因**占用资金**而支付的费用：支付给股东的**股息红利**、向债权人支付的**贷款利息**等。
- 一般与所筹资金多少、使用时间长短有关，具有**经常性、定期性**特征，是资金成本的**主要内容**。

</div>

</div>

<Reveal label="一句话区分：一次性 vs 经常性">

- **筹集成本**：筹措时**一次性**支付，之后不再发生，可作为筹资金额的一项扣除；
- **使用成本**：使用过程中**多次、定期**发生。

</Reveal>

<template #notes>

资金成本拆成两部分记：筹集成本就是"筹资费"，比如发行股票债券的印刷费、手续费、律师费、评估费，都是一次性付掉；使用成本就是"资金占用费"，比如股息红利、贷款利息，是经常性、定期发生的，也是资金成本的主要内容。考试常考哪部分是一次性、哪部分是主要内容，一句话——筹资费一次性、占用费经常性。

</template>

</Slide>

## 资金成本的三个特点与会计处理

<div class="dk-cols">

<div>

### 三个特点
1. 资金成本是**资金使用者向资金所有者和中介机构支付的筹资费和占用费之和**（源于所有权与使用权分离）。
2. 资金成本以**利息、股利**等作为表现形式，其时间价值表现为筹资费和利息。
3. 按性质和用途，会计处理分为**不计入产品成本**和**计入产品成本**两种情形。

</div>

<div>

### 会计处理两条路
- **不计入产品成本**（通常情况）：
  - 债权人的利息费用 → 作为**财务费用**在利润表体现，影响当期损益；
  - 分配给股东的股息 → 作为**利润分配**处理。
- **计入产品成本**（特定情况）：
  - 涉及**借款费用资本化**，如直接用于固定资产、投资性房地产、存货等符合条件的资产的购建或生产。

</div>

</div>

<template #notes>

资金成本特点有三个，重点抓会计处理那条：通常资金成本不计入产品成本，债权人利息进财务费用、股东股息作利润分配；只有在借款费用资本化这种特定情况下，才计入相关资产成本。这对应后面例 4-1 里"利息可以税前扣除"的伏笔，因为债务利息走财务费用、影响损益，所以能抵税。

</template>

## 资金成本率的两个公式（4-5 / 4-6）

<p class="dk-lead">资金成本通常以<strong>相对数（资金成本率）</strong>表示——用每年用资费用与筹得资金净额（筹资金额与筹资费用之差）之比来定义。</p>

$$
K = \frac{D}{P - F}\tag{4-5}
$$

或

$$
K = \frac{D}{P(1 - f)}\tag{4-6}
$$

- $K$ — 资金成本率（一般也可称为资金成本）；$P$ — 筹资资金总额；$D$ — 资金占用费；$F$ — 筹资费；$f$ — 筹资费费率（筹资费占筹资资金总额的比率）。

<Reveal label="两个公式是什么关系？何时用哪个？">

- 公式 4-5 用**绝对数** $F$（筹资费）；公式 4-6 用**费率** $f$。当题目给出筹资费费率时，优先用公式 4-6：$K = D/[P(1-f)]$。分子 $D$ 永远只放**资金占用费**。

</Reveal>

<template #notes>

资金成本率的公式是这节计算的起点。记住相对数表示法：分母是"筹得的资金净额"，即筹资金额减掉筹资费，所以是 P-F 或者 P(1-f)。五个字母的含义要记清：K 资金成本率、P 筹资总额、D 资金占用费、F 筹资费、f 筹资费费率。特别提醒，分子 D 只放资金占用费，千万别把筹资费也放进去。

</template>

</Slide>

## 个别资金成本的 5 类（债务 vs 权益）

<div class="dk-cols">

<div>

### 债务资金成本（2 类）
- **长期借款资金成本**
- **长期债券资金成本**
- 债务资金成本可采用公式 4-6 计算。

</div>

<div>

### 权益资金成本 / 自有资金成本（3 类）
- **优先股资金成本**
- **普通股资金成本**
- **留存收益成本**

</div>

</div>

> **一句话归类**：个别资金成本 = 前两类（长期借款、长期债券）是**债务资金成本**，后三类（优先股、普通股、留存收益）是**权益资金成本或自有资金成本**。

<Reveal label="为什么债务资金成本算的是「税后」成本？">

- 债务利息可以在企业所得税前扣除，因此例 4-1 中分子要乘 $(1 - \text{所得税税率})$，得到的是**税后资金成本**；而股息不能税前扣除，权益资金成本不享受这一优惠。

</Reveal>

<template #notes>

个别资金成本一共五类，先按"债务两、权益三"分清楚：债务是长期借款和长期债券，权益是优先股、普通股、留存收益。这里埋一个关键区别——债务利息可以在税前扣除，所以债务资金成本是税后成本，计算时分子要乘（1 减所得税税率）；而股息不能税前扣除，权益资金成本没这个优惠。这个区别直接决定例 4-1 怎么算。

</template>

</Slide>

## 例题精算：例 4-1 长期借款资金成本

<p class="dk-lead">某企业从银行取得 5 年长期借款 1000 万元，担保费费率 0.5%，利率 6%，每年结息一次、到期一次还本，企业所得税税率 25%。</p>

<Steps title="三步算出该笔借款年资金成本率" :steps="[
  { t: '1. 确定分子 D（税后占用费）', d: 'D = 1000 × 6% × (1 − 25%)，利息可在税前扣除，故乘税后系数。' },
  { t: '2. 确定分母 P(1−f)（筹资净额）', d: 'P(1 − f) = 1000 × (1 − 0.5%)，扣掉担保费费率后才是实际到手的资金净额。' },
  { t: '3. 套公式 4-6', d: 'K = 1000×6%×(1−25%) / [1000×(1−0.5%)] = 4.52%。' }
]" />

$$
K = \frac{1000 \times 6\% \times (1 - 25\%)}{1000 \times (1 - 0.5\%)} = 4.52\%
$$

<template #notes>

例 4-1 是本节必考的算例。三步走：分子是资金占用费，也就是 1000 万乘以 6% 的利息，再因为利息可以税前扣除，乘（1 减 25%）；分母是筹资净额，1000 万扣掉 0.5% 的担保费；两者一除，得到 4.52%。这个 4.52% 就是这笔长期借款的年资金成本率，比名义利率 6% 低，正是因为利息抵税。

</template>

</Slide>

## 综合资金成本：公式 4-7 与例 4-2

<p class="dk-lead">综合资金成本是对各种个别资金成本<strong>加权平均</strong>而得。</p>

$$
K_{\mathrm{w}} = \Sigma (K_{j} W_{j})\tag{4-7}
$$

式中 $K_{\mathrm{w}}$ 为综合资金成本率，$K_{j}$ 为第 $j$ 种个别资金成本，$W_{j}$ 为第 $j$ 种个别资金占全部资金的比重。

<Steps title="例 4-2：算加权平均" :steps="[
  { t: '1. 列出资本结构', d: '长期资本总额 10000 万元：长期借款 3000 万元、长期债券 4000 万元、普通股 3000 万元。' },
  { t: '2. 确定各资金成本', d: '长期借款 5%、长期债券 6%、普通股 10%。' },
  { t: '3. 按比重加权求和', d: 'Kw = (3000/10000)×5% + (4000/10000)×6% + (3000/10000)×10% = 6.9%。' }
]" />

<Reveal label="综合资金成本 6.9% 落在哪个区间？">

- 加权平均必然落在**最低 5% 与最高 10% 之间**，这里是 6.9%。比重最大的 4000 万债券（6%）把结果拉向中间偏下。

</Reveal>

<template #notes>

综合资金成本就是加权平均，公式 4-7 记 Kw 等于西格玛 Kj 乘 Wj，Wj 是各资金占全部资金的比重。例 4-2 三步走：3000 万借款按 5%、4000 万债券按 6%、3000 万普通股按 10%，分别乘各自比重再相加，得到 6.9%。这个结果一定落在最低和最高的个别成本之间，可以用来快速验算。

</template>

</Slide>

## 一页总结：4.3 资金成本必背 4 个关键点

1. **构成**：资金**筹集成本（一次性）** + 资金**使用成本（经常性、主要内容）**。
2. **三种作用**：个别资金成本（选筹资方式）、综合资金成本（定资本结构）、边际资金成本（追加筹资决策）。
3. **核心公式**：$K = D/(P-F) = D/[P(1-f)]$（分子只放占用费 $D$）；综合 $K_{\mathrm{w}} = \Sigma(K_j W_j)$。
4. **两道例题**：例 4-1 长期借款税后成本 **4.52%**；例 4-2 综合资金成本 **6.9%**。

## 小结：资金成本计算一张图

- **构成**：筹资成本（一次性） + 使用成本（经常性、主要内容）。
- **作用**：个别（选方式）、综合（定结构）、边际（追加筹资）。
- **公式**：$K = D/(P-F) = D/[P(1-f)]$；综合 $K_{\mathrm{w}} = \Sigma(K_j W_j)$。
- **算例**：例 4-1 长期借款 **4.52%**（税后）；例 4-2 综合 **6.9%**。
