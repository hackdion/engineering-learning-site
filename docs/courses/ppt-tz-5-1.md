## 可研报告在投资决策程序中的位置

<p class="dk-lead">可行性研究是工程项目前期工作的重要内容，是投资决策的<strong>主要依据</strong>。它同时是筹措资金、申请贷款、编制初步设计文件的重要依据，并为环境、安全、节能等专项审批提供基础资料。不同投资主体、不同资金性质，走的是不同的决策通道。</p>

    { k: '内容深度', v: ['内容和深度可依据项目具体情况适当增加或简化', '结合行业、地区、国际组织或企业的有关规定或规范适当调整'] },
    { k: '共同定位', v: ['对编写内容和深度的一般要求', '对编写内容和深度的一般要求'] }
  ]"
/>

<Reveal label="两本大纲为什么要分“通用”和“参考”？">

- 政府投资项目用的是**财政资金**，要统一口径、便于审批和监管，所以叫“**通用**大纲”，原则上必须按它写；
- 企业投资项目由**企业自主决策、自担风险**，行业差异大，所以叫“**参考**大纲”，允许结合行业规范调整；
- 两者都是一般要求，行业管理部门还可以据此再制定**具体行业或领域**的编写大纲。

</Reveal>

<template #notes>

这一页的关键词是“通用”和“参考”两个词的差别。通用对应政府投资项目，原则上按大纲编写；参考对应企业投资项目，可以参照并调整。两者都不是强制到一字不改，都允许根据项目情况增减内容，但政府项目的调整空间更小。

</template>

</Slide>

## 三大目标与七个维度：可研的论证骨架

<DeckViewSwitch
  title="点击查看三大目标分别由哪些维度支撑"

    { key: 'plan', label: '项目方案可行性', badge: '5 个维度', summary: '从要素保障性、工程可行性、运营有效性、财务合理性、影响可持续性五个维度论证。', points: ['要素保障性：土地、资源、环境等要素能否落实', '工程可行性：技术方案、设备方案、工程方案是否可行', '运营有效性：运营模式、组织、安全、绩效是否有效', '财务合理性：投融资与财务方案是否合理', '影响可持续性：经济、社会、生态、资源能源、碳排放影响'] },
    { key: 'risk', label: '项目风险可控性', badge: '1 个维度', summary: '从各类风险管控方案维度进行研究论证。', points: ['识别与评价全生命周期风险', '提出风险管控方案与应急预案', '判断采取措施后风险是否处于可控状态'] }
  ]"
/>

<Reveal label="记忆口诀：一可靠、五可行、一可控">

- **需求可靠性** → 建设必要性（1 个维度）
- **要素保障性、工程可行性、运营有效性、财务合理性、影响可持续性** → 方案可行性（5 个维度）
- **风险可控性** → 风险管控方案（1 个维度）

</Reveal>

<template #notes>

“三大目标、七个维度”是本章的总纲，后面几节都在展开其中某个维度。记住分配关系：必要性只对应需求可靠性一个维度；方案可行性对应五个维度；风险可控性对应风险管控方案。这个 1+5+1 的结构，答多选题时特别好用。

</template>

</Slide>

## 财务可持续性：累计盈余资金不能为负

<p class="dk-lead">财务可持续性分析的核心，是看项目有没有足够的净现金流量维持正常运营。</p>

<CompareCard
  title="两条判断规则（一字之差，结论不同）"
  :cols="['判断对象', '规则']"
  :rows="[
    { k: '各年净现金流量', v: ['容许个别年份出现负值', '整个运营期内，个别年份净现金流量为负是允许的'] },
    { k: '累计盈余资金', v: ['任何一年都不得出现负值', '累计盈余资金不出现负值，是项目财务上可持续的必要条件'] }
  ]"
/>

<Reveal label="累计盈余资金出现负值，怎么办？">

- **经营性项目**：研究提出**短期借款**方案，分析借款的时间、数额及可靠性，再判断财务可持续性；
- **没有营业收入的非经营性项目**：进行**资金平衡分析**，确定政府资金需求量和其他资金缺口，提出弥补措施；
- **有营业收入但不足以补偿经营成本的准经营性项目**：估算运营期各年需政府补贴的数额，分析财政补贴的可行性。

</Reveal>

<template #notes>

这里最容易混淆：个别年份净现金流量可以为负，但累计盈余资金任何一年都不能为负。原因很简单，累计为负意味着账上没钱了，运营就断链。三种补救路径按项目性质分：经营性靠短期借款，非经营性靠财政资金平衡，准经营性靠政府补贴。

</template>

</Slide>

## 影响效果分析与风险管控方案

<div class="dk-cols">

<div>

### 影响效果分析（五个方面）

- **经济影响**分析；
- **社会影响**分析；
- **生态环境影响**分析；
- **资源和能源利用效果**分析；
- **碳排放**影响分析（碳达峰碳中和）。

作用：从多个维度判断项目外部影响的**可接受性**，识别正面效果、负面代价和可持续性。

</div>

<div>

### 风险管控方案（三项）

- **风险识别与评价**：覆盖需求、建设、运营、融资、财务、经济、社会、环境、网络与数据安全等全生命周期风险；
- **风险管控方案**：提出防范和化解措施；重大项目要做社会稳定风险分析，防范“邻避”问题；
- **风险应急预案**：机构设置、应急处置机制、培训与演练要求。

</div>

</div>

<template #notes>

影响效果分析记五个方面：经济、社会、生态、资源能源、碳排放。它是从“项目对外部做了什么”角度看，为风险可控性研究提供基础。风险管控三项是递进的：先识别评价，再拿方案，最后兜底做预案。重大项目的社会稳定风险和邻避问题，是这一页的高频考点。

</template>

<Reveal label="评估结论从哪三个角度论证？">

- **合规性**：是否符合法律法规、规划政策、产业政策和准入条件；
- **合理性**：需求、规模、方案、财务、影响是否合理；
- **可行性**：要素保障、工程技术、运营组织是否具备落地条件。

评估要围绕“**三大目标、七个维度**”，给出明确的**结论性评估意见**，明确判断项目是否可行，并提出下一步需协调解决的主要问题。

</Reveal>

## 一页总结：5.1 必背四个要点

1. **三条通道**：政府直接投资与资本金注入走**审批制**；补助贴息只批**资金申请报告**；企业核准制交**项目申请报告**。
2. **一套骨架**：**三大目标**（必要性、方案可行性、风险可控性）+ **七个维度**（需求可靠、要素保障、工程可行、运营有效、财务合理、影响可持续、风险可控）。
3. **十项内容**：概述 → 背景必要性 → 需求产出 → 选址要素 → 建设方案 → 运营方案 → 投融资财务 → 影响效果 → 风险管控 → 结论附件。
4. **两条底线**：累计盈余资金**任何一年不得为负**；评估必须给出**可行与否的明确结论**。
