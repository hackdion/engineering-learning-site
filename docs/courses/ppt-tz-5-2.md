## 生产能力指数法：公式、指数取值与适用边界

<p class="dk-lead">生产能力指数法反映的是投资额与生产能力之间的<strong>非线性关系</strong>。</p>

$$
C_{2} = C_{1}\left(\frac{Q_{2}}{Q_{1}}\right)^{x} \cdot f \tag{5-1}
$$

- $C_1$：已建类似项目投资额；$C_2$：拟建项目投资额；
- $Q_1$：已建类似项目生产能力（或规模）；$Q_2$：拟建项目生产能力（或规模）；
- $f$：不同时期、不同地点的定额、单价、费用等差异的**综合调整系数**；
- $x$：生产能力指数，$0<x<1$。

<CompareCard
  title="生产能力指数 x 的取值规则（比值 = Q2 / Q1）"
  :cols="['生产能力比值', '扩大方式', 'x 取值']"
  :rows="[
    { k: '不大于 2', v: ['不论何种方式', '近似取 1'] },
    { k: '2～50', v: ['靠增大设备规格扩大', '取 0.6～0.7'] },
    { k: '2～50', v: ['靠增加相同规格设备数量扩大', '取 0.8～0.9'] }
  ]"
/>

<template #notes>

公式里有两个容易漏的点：一是括号里的比值是拟建除以已建，不能倒过来；二是最后要乘综合调整系数 f。因为 0<x<1，单位投资额随规模增大而减小，这就是规模效应。x 的取值按比值和扩大方式分三档，比值不超过 2 时直接近似取 1。

</template>

</Slide>

## 例 5-1 实操：70 万 t 乙烯项目估算

<Steps
  title="按公式（5-1）逐步计算"
  :steps="[
    { t: '列出已知条件', d: 'C1 = 60 亿元，Q1 = 30 万 t，Q2 = 70 万 t，x = 0.6，f = 1.2' },
    { t: '计算生产能力比值', d: 'Q2 / Q1 = 70 / 30 ≈ 2.333，落在 2～50 区间，与题给 x = 0.6 相符' },
    { t: '对比值取 x 次方', d: '(70 / 30)^0.6 ≈ 1.663，体现规模扩大带来的单位投资下降' },
    { t: '乘以已建投资额和调整系数', d: '60 × 1.663 × 1.2 ≈ 119.71 亿元' },
    { t: '给出估算结论', d: '拟建 70 万 t 乙烯项目投资额约为 119.71 亿元' }
  ]"
/>

<Reveal label="自查：如果把比值倒过来算，会得到什么？">

- 会得到 $60 \times (30/70)^{0.6} \times 1.2 \approx 71.9$ 亿元，明显偏小；
- 规模扩大而投资反而下降，逻辑上说不通；
- 所以牢记：**拟建在分子、已建在分母**。

</Reveal>

<template #notes>

这道例题几乎年年以计算题形式出现。三步不能少：比值、指数、调整系数。算完要用常识校验，70 万 t 的项目投资应大于 30 万 t 的 60 亿元，如果算出来更小，一定是比值写反了。

</template>

</Slide>

## 系数估算法与比例估算法：基数不同，思路相反

<CompareCard
  title="两种“按比例放大”的方法对照"
  :cols="['对比项', '系数估算法（设备系数法）', '比例估算法']"
  :rows="[
    { k: '计算基数', v: ['拟建项目设备购置费 E', '已建项目主要设备购置费占建设投资的比例 K'] },
    { k: '计算方向', v: ['由设备费向外扩展：设备费 ×（1 + 各项系数）+ 其他费用', '由设备费向内反算：主要设备费之和 ÷ K'] },
    { k: '核心公式', v: ['C = E(1 + f1P1 + f2P2 + f3P3 + …) + I', 'C = (1/K) × Σ(Qi × Pi)'] },
    { k: '适用条件', v: ['设计深度不足，主体工程费或设备购置费比重大，系数资料完备', '设计深度不足，主要设备购置费占建设投资比重大，系数资料完备'] }
  ]"
/>

- 系数估算法中：$P_1、P_2、P_3$ 是已建项目中建安费、其他费与设备购置费的**比值**，$f_1、f_2、f_3$ 是时间地点差异的**调整系数**，$I$ 是拟建项目其他有关费用；
- 比例估算法中：$Q_i$ 是第 $i$ 种主要设备数量，$P_i$ 是第 $i$ 种主要设备**到厂价格**，$n$ 是主要设备种类数。

<template #notes>

两种方法都叫“按比例”，但方向相反。系数估算法是已知设备费，往上加建安费和其他费；比例估算法是已知设备费，除以设备费占建设投资的比重，反推总投资。记公式时抓住基数：一个是 E，一个是 K。

</template>

</Slide>

## 指标估算法：可行性研究阶段的主力方法

<p class="dk-lead">可行性研究阶段对投资估算精度要求较高，原则上应采用<strong>指标估算法</strong>。</p>

- **对象**：以拟建项目的单位工程或单项工程为对象；
- **依据**：各类工程或费用的投资估算指标、概算指标；
- **路径**：各单位工程、单项工程投资 → 汇总各单项工程 → 估算工程建设其他费用、预备费、建设期利息 → 得出建设投资；
- **对主体工程的要求**：对投资有重大影响的主体工程，应先估算出**分部分项工程量**，再参考相关**综合定额（概算指标）或概算定额**编制主要单项工程的投资估算。

<Reveal label="为什么可研阶段不能再用生产能力指数法做主方法？">

- 生产能力指数法只需要生产能力和投资额，**精度不足以支撑投融资决策**；
- 可研阶段的估算要作为初步设计概算的控制目标，必须落到单项工程、单位工程；
- 所以原则上用指标估算法，指数法、系数法、比例法主要留在项目建议书阶段。

</Reveal>

<template #notes>

这一页的关键判断是“阶段—方法”的匹配。可研阶段原则上指标估算法，项目建议书阶段四种方法都可以。指标估算法的逻辑是从小到大汇总：单位工程、单项工程、其他费用、预备费、建设期利息，最后得到建设投资。

</template>

</Slide>

## 流动资金：分年估算与 30% 铺底

<p class="dk-lead">流动资金随项目投产或运营发生，随生产运营负荷改变而增减，因此应<strong>分年估算</strong>。</p>

<CompareCard
  title="流动资金估算的两种方法与适用阶段"
  :cols="['方法', '适用情形']"
  :rows="[
    { k: '分项详细估算法', v: ['可行性研究阶段一般应采用', '精度较高，按流动资产和流动负债分项测算'] },
    { k: '扩大指标估算法', v: ['项目建议书阶段可采用', '流动资金需要量较小的项目或非制造业项目也可采用'] }
  ]"
/>

<Reveal label="铺底流动资金怎么算？哪些项目不列？">

- 生产经营性项目对铺底流动资金有要求的，一般可按项目建成后所需**全部流动资金的 30%** 计算；
- **非生产经营性建设项目不列铺底流动资金**；
- 铺底流动资金属于项目总投资的一部分，但不等于全部流动资金。

</Reveal>

<template #notes>

流动资金有两个高频数字：30% 的铺底比例，以及“非生产经营性项目不列铺底流动资金”。方法选择上，可研阶段用分项详细估算法，项目建议书阶段可用扩大指标法，小项目和非制造业项目可以放宽。

</template>

</Slide>

## 一页总结：5.2 必背四个要点

1. **两阶段两精度**：项目建议书阶段可粗，可研阶段原则上用**指标估算法**；估算控制概算，超 **10%** 可要求重报可研。
2. **四方法**：生产能力指数法、系数估算法、比例估算法、指标估算法，按资料条件选择。
3. **两公式**：$C_2 = C_1 (Q_2/Q_1)^x \cdot f$；设备系数法 $C = E(1+f_1P_1+f_2P_2+\dots)+I$。
4. **两口径**：设备运杂费计入**设备购置费**；铺底流动资金按全部流动资金的 **30%**，非生产经营性项目不列。
