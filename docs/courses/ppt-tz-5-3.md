## 财务分析：站在项目微观角度算账

<p class="dk-lead">财务分析又称项目财务评价，是在国家现行财税制度和价格体系下，从<strong>项目微观角度</strong>估算财务效益和费用、编制报表、计算指标，评价项目的财务可行性。</p>

  ]"
/>

<Reveal label="为什么非经营性项目不重点分析盈利能力？">

- 非经营性项目（如公益性设施）不以营利为目标，本来就没有稳定的营业收入；
- 硬算盈利能力没有决策意义，关键是**运营期资金能不能接续**；
- 所以只重点分析**财务生存能力**，必要时做资金平衡分析。

</Reveal>

开篇先分清对象：经营性项目看三项能力，非经营性项目只看财务生存能力。财务分析的前提是“国家现行财税制度和价格体系”和“项目微观角度”，这两句话在判断题里常被改成“全社会角度”或“影子价格”来设错，那是经济分析的特征。

## 净现值：公式、准则与三个缺点

$$
NPV = \sum_{t=0}^{n}(CI-CO)_{t}(1+i_{\mathrm{c}})^{-t} \tag{5-4}
$$

$$
FNPV = \sum_{t=1}^{n}(CI-CO)_{t}(1+i_{\mathrm{c}})^{-t} \tag{5-5}
$$

- $i_c$：设定的折现率（基准收益率）；$(CI-CO)_t$：第 t 年净现金流量；n：计算期。
- 公式（5-5）把计算期第 1 年末作为投资起点，与公式（5-4）的结果相差一个系数 $(1+i_c)$，但**不影响可行性判断**。

<CompareCard
  title="NPV 的评价准则与优缺点"
  :cols="['项目', '内容']"
  :rows="[
  { k: '评价准则', v: ['NPV ≥ 0；考虑接受该投资项目'] },
  { k: '拒绝条件', v: ['NPV < 0；考虑拒绝该投资项目'] },
  { k: '优点', v: ['考虑了资金时间价值；全面考虑整个计算期的经济状况；以价值形式表示超额收益，经济意义明确、便于多方案比选；评价准则直观'] },
  { k: '缺点', v: ['必须事先确定较符合经济现实的基准折现率，确定困难；互斥方案寿命不等时，必须构造相同分析期限；不能反映单位投资的使用效率'] }
]"
/>

<template #notes>

净现值是本章的地基。三条结论要记牢：NPV 大于等于零可接受；NPV 等于零表示刚好达到基准收益率；两个公式只差一个系数，不影响判断。缺点三条中，“不能反映单位投资效率”正是净现值率存在的理由。

</template>

</Slide>

<Reveal label="如果改用公式（5-4），结果会变成多少？">

- 公式（5-4）从第 0 年开始折现，相当于把 1477.79 再乘以 $(1+5\%)$；
- 结果约为 **1551.68 万元**，数值变大但符号不变；

</Reveal>

## 内部收益率：定义、准则与试算内插

<p class="dk-lead">内部收益率是使计算期内各年净现金流量现值之和等于零的折现率，体现项目对贷款利率的<strong>最大承受能力</strong>。</p>

$$
\sum_{t=0}^{n}(CI-CO)_{t}(1+IRR)^{-t}=0 \tag{5-6}
$$

<Steps
  title="例 5-3：试算法加内插法求 FIRR"
  :steps="[
    { t: '取 r1 = 3% 试算', d: 'FNPV(3%) = 132.07 万元 > 0，说明折现率取小了，需增大' },
    { t: '取 r2 = 4% 试算', d: 'FNPV(4%) = 55.57 万元 > 0，仍需加大折现率' },
    { t: '取 r3 = 5% 试算', d: 'FNPV(5%) = −15.34 万元 < 0，至此得到一正一负两个折现率' },
    { t: '确认区间精度', d: 'i1 = 4%，i2 = 5%，|i2 − i1| = 1% ≤ 2%，满足内插精度要求' },
    { t: '内插求近似值', d: 'FIRR = 4% + 55.57/(55.57 + 15.34) × (5% − 4%) = 4.78%' }
  ]"
/>

<Reveal label="IRR 与 NPV 的评价结论为什么一致？">

- 对常规型项目，净现值函数 NPV(i) 随折现率**单调递减**，与横轴只有一个交点，即 IRR；
- IRR ≥ $i_c$ 时，NPV($i_c$) ≥ 0；IRR < $i_c$ 时，NPV($i_c$) < 0；
- 所以两种指标对同一常规型项目**结论一致**；非常规型项目 IRR 可能不唯一甚至不存在。

</Reveal>

<template #notes>

内部收益率三步走：试算找到一正一负，确认两个折现率之差不超过 2%，再用内插公式。内插公式的分母是两段绝对值之和，不要写成相减。IRR 的优点之一是不需要事先设定折现率，缺点是非常规项目可能多解。

</template>

</Slide>

## 净年值与净现值率：两个“比值型”补充指标

<CompareCard
  title="NAV 与 NPVR 对照"
  :cols="['指标', '计算与含义', '评价准则与用途']"
  :rows="[
    { k: '净年值 NAV', v: ['NAV = NPV × (A/P, ic, n)', '与 NPV 只差一个资金回收系数', 'NAV ≥ 0 可接受；寿命期不等的互斥方案选 NAV 最大者'] },
    { k: '净现值率 NPVR', v: ['NPVR = NPV / Ip', 'Ip 为全部投资现值之和，建设期超 1 年先折现再求和', 'NPVR ≥ 0 可接受；资金约束下比选投资额不同的方案'] }
  ]"
/>

<Reveal label="寿命期不等的互斥方案，为什么优先用 NAV？">

- 寿命期不同，直接比较 NPV 等于用不同长度的“尺子”量项目，不可比；
- 净年值把每个方案都摊成**每年等额**，口径统一；
- 所以寿命期不等时选 NAV 最大的方案；若坚持用 NPV，必须先构造相同的分析期限。

</Reveal>

<template #notes>

净年值和净现值率都是净现值的“变形”。NAV 乘的是资金回收系数（A/P），NPVR 除的是全部投资现值 Ip。用途要分清：寿命期不等用 NAV，资金有约束、投资额不同用 NPVR。两者正负号都与 NPV 一致。

</template>

</Slide>

## 投资回收期：静态与动态只差一个“折现”

<p class="dk-lead">投资回收期是反映项目投资回收能力的<strong>时间性指标</strong>，从项目建设起始年算起，也可以从投产年算起但须注明。</p>

$$
P_{t}=\text{累计净现金流量开始出现正值的年份数}-1+\frac{\text{上年累计净现金流量的绝对值}}{\text{当年净现金流量}} \tag{5-12}
$$

<Steps
  title="例 5-4：由累计净现金流量求静态投资回收期"
  :steps="[
    { t: '看累计净现金流量序列', d: '−600、−1500、−1200、−700、−200、300、800、1300（万元）' },
    { t: '找到首次转正的年份', d: '第 5 年累计净现金流量为 300，首次出现正值' },
    { t: '取上年累计值的绝对值', d: '第 4 年累计为 −200，绝对值为 200' },
    { t: '除以当年净现金流量', d: '当年净现金流量为 500，200 / 500 = 0.4' },
    { t: '代入公式', d: 'Pt = (5 − 1) + 0.4 = 4.4 年' }
  ]"
/>

<CompareCard
  title="静态 vs 动态投资回收期"
  :cols="['对比项', '静态投资回收期 Pt', '动态投资回收期 Pt′']"
  :rows="[
    { k: '是否折现', v: ['不折现，累计净现金流量等于零', '折现，累计折现净现金流量等于零'] },
    { k: '判别标准', v: ['与基准投资回收期 Pc 比较，Pt ≤ Pc 可接受', '与计算期 n 比较，Pt′ ≤ n 可接受'] },
    { k: '长度关系', v: ['较短', '较长；静态可接受的项目，动态未必可接受'] }
  ]"
/>

<template #notes>

回收期公式有两个陷阱：一是“减 1”，二是分子用上年累计值的绝对值。动态回收期只是把每年的净现金流量先折现，再用同样的公式。判别标准不同：静态比基准回收期 Pc，动态比计算期 n。回收期的共同缺点是没有考虑回收之后的情况。

</template>

</Slide>

## 投资收益率：ROI 与 ROE 的分子分母

<CompareCard
  title="两个投资收益率的对应关系"
  :cols="['指标', '公式', '分子与分母的含义']"
  :rows="[
    { k: '总投资收益率 ROI', v: ['ROI = EBIT / TI × 100%', '分子是息税前利润，分母是项目总投资（含权益资金和债务资金）'] },
    { k: '资本金净利润率 ROE', v: ['ROE = NP / EC × 100%', '分子是净利润，分母是项目资本金'] }
  ]"
/>

- **息税前利润 EBIT** 的两种算法：
  - EBIT = 利润总额 + 计入总成本费用的利息费用；
  - EBIT = 净利润 + 所得税 + 计入总成本费用的利息费用；
  - 或 EBIT = 营业收入 − 税金及附加 − 经营成本 − 折旧和摊销。
- **例 5-5 结果**：年平均 EBIT = 595.38 万元，ROI = 595.38 / 4400 = **13.53%**；年平均净利润 = 404.06 万元，ROE = 404.06 / 1840 = **21.96%**。
- 判别：高于**同行业收益率参考值**，表明盈利能力满足要求。

<template #notes>

ROI 和 ROE 的核心是口径对应：总投资对应息税前利润（因为总投资里有债务资金，债权人也要分息），资本金对应净利润（股东拿的是税后利润）。例 5-5 的两个结果要记住量级，ROE 高于 ROI 是因为财务杠杆放大了股东回报。

</template>

</Slide>

## 债务清偿能力：三个指标、三条底线

<CompareCard
  title="ICR、DSCR、LOAR 对照"
  :cols="['指标', '公式与口径', '判别']"
  :rows="[
    { k: '利息备付率 ICR', v: ['ICR = EBIT / PI × 100%', 'PI 为当年应付利息，即计入总成本费用的利息费用', '分年计算；正常运营企业起码大于 1，否则付息保障不足'] },
    { k: '偿债备付率 DSCR', v: ['DSCR = (EBITAD − TAX) / PD', 'EBITAD 为息税前利润加折旧和摊销，PD 为当期应还本付息金额', '分年计算；正常情况下应大于 1，小于 1 需短期借款偿付'] },
    { k: '资产负债率 LOAR', v: ['LOAR = TL / TA × 100%', 'TL 为负债总额，TA 为资产总额', '越低偿债能力越强；适度水平表明经营安全稳健、筹资能力强'] }
  ]"
/>

<Reveal label="哪些项目要特别注意 DSCR 的口径？">

- 有**维持运营投资**的，应将其从可用于还本付息的资金中**扣除**；
- **融资租赁费用**视同借款偿还，计入还本付息金额；
- 运营期内的**短期借款本息**也应纳入计算；
- 当期应还本付息金额主要包括还本金额和计入总成本费用的利息费用。

</Reveal>

<template #notes>

三个偿债指标都只用于财务分析。ICR 看息，DSCR 看本息，LOAR 看整体负债水平。DSCR 分子里的 EBITAD 要减所得税，分母 PD 包括本金和利息；有维持运营投资要扣，融资租赁和短期借款本息要加，这两加一减最容易出错。

</template>

</Slide>

## 互斥方案比选：直接比 NPV，或做增量分析

<p class="dk-lead">只有财务上可行的方案才能参加比选。实践中最常遇到的是<strong>寿命期相同的互斥方案</strong>比选。</p>

<Reveal label="例 5-6：A、B、C 三个方案，结论为什么都是 B？">

- 净现值法：NPVA = 47.92，NPVB = 74.49，NPVC = 67.73 万元，取最大者 **B**；
- 增量净现值法：ΔNPV(B−A) = 26.57 > 0，B 优于 A；ΔNPV(C−B) = −6.77 < 0，B 优于 C；
- 增量内部收益率法：ΔIRR(B−A) = 7.99% > 5%，ΔIRR(C−B) = 4.27% < 5%，仍选 **B**。
- 三种方法结论一致，说明增量分析的判别方向没有搞反。

</Reveal>

<template #notes>

增量分析最容易错在“谁减谁”和“留哪个”。规则是：大投资减小投资，指标达标就留大的，不达标就留小的。例 5-6 中 C 的 NPV 比 B 小，但 C 的投资更大，所以要做 C 减 B 的增量分析，结果增量为负，说明多投的钱不值，保留 B。

## 一页总结：5.3 必背五个要点

1. **两类对象**：经营性项目看盈利、偿债、生存三项能力；非经营性项目只看**财务生存能力**。
2. **一个公式**：经营成本 = 总成本费用 − **折旧 − 摊销 − 利息**。
3. **五个盈利指标**：NPV、IRR、NAV、NPVR、投资回收期，再加 ROI 与 ROE；判别都围绕**基准收益率或基准回收期**。
4. **三个偿债指标**：ICR、DSCR、LOAR，**只用于财务分析**，正常底线均与 1 或行业水平比较。
5. **一种比选**：寿命期相同的互斥方案，可直接比 NPV，也可做**增量投资**分析；大减小，达标留大的。
