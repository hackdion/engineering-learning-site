/>

<Reveal label="两者是什么关系？">

- **多数项目**：经济分析在财务分析基础上进行，财务分析数据是经济分析的重要依据；
- **大型项目**：经济分析反而是财务分析的前提，项目的**经济合理性决定大型项目的最终可行性**；
- 两者基本原理相同，差别在角度、内容、口径和参数。

</Reveal>

<template #notes>

五个不同要能一口气说出来：角度、内容、效益费用组成、价格体系、主要参数。价格体系那句最绕：财务分析中现金流量用实价（不考虑通胀），偿债和生存分析用时价（考虑通胀）；经济分析统一用影子价格且不考虑通胀。

</template>

</Slide>

## 三个专用参数：影子价格、影子汇率、社会折现率

<div class="dk-cols">

<div>

### 影子价格

- 经济分析**专用**的计算价格；
- 从全社会角度衡量商品或生产要素投入产出的费用与效益；
- 反映资源**稀缺程度和真实经济价值**。

### 影子汇率

- 单位外汇的**经济价值**；
- 代表外汇的影子价格；
- 替代财务分析中的官方汇率。

</div>

<div>

### 社会折现率

- 项目经济效益要求的**最低经济收益率**；
- 代表社会投资要求的最低收益率水平；
- 双重身份：衡量 EIRR 的**基准值**，计算 ENPV 的**折现率**；
- 是分析经济可行性和方案比选的**主要判据**。

</div>

</div>

<Reveal label="为什么经济分析不考虑通货膨胀？">

- 经济分析用的是**实际价值原则**，要反映资源真实价值；
- 通货膨胀只是货币购买力的普遍变化，不改变资源之间的相对稀缺关系；
- 但**相对价格变动**可以考虑，因为它反映不同资源比价的变化。

</Reveal>

<template #notes>

三个参数各管一段：影子价格管货物和服务，影子汇率管外汇，社会折现率管时间价值。社会折现率的双重身份是高频考点，既是 EIRR 的基准，又是 ENPV 的折现率。实际价值原则只剔除通货膨胀，不剔除相对价格变动。

</template>

</Slide>

## 效益与费用识别：直接、间接与转移支付

<CompareCard
  title="经济分析的效益费用口径"
  :cols="['类别', '含义与举例']"
  :rows="[
  { k: '直接效益', v: ['由项目产出物直接生成，并在项目范围内计算；例如项目产出的产品、服务带来的效益'] },
  { k: '直接费用', v: ['由于项目使用投入物而产生，并在项目范围内计算；例如项目消耗的材料、人工、土地等资源'] },
  { k: '间接效益（外部效果）', v: ['在直接效益中没有得到反映的效益；例如人力资源增值、技术扩散、环境改善、产业延伸'] },
  { k: '间接费用（外部效果）', v: ['在直接费用中没有得到反映的费用；例如项目对生态环境的不利影响'] }
]"
/>

<Reveal label="哪些财务收支属于“转移支付”，不能计为经济效益或费用？">

- 项目（企业）向政府缴纳的**所得税、增值税、消费税**等税费；
- 项目向**国内银行及国内其他金融机构**支付的贷款利息和获取的存款利息；
- **政府给予项目的补贴**。

原因：从全社会看，这些收支只是经济系统内部的财富转移，**没有造成经济资源的实际增加或减少**。

</Reveal>

<template #notes>

识别效益费用有三个层次：直接、间接、转移支付。直接和间接都要算，转移支付要剔除。判断转移支付的标准只有一条：全社会角度看有没有真正消耗或增加资源。税、国内利息、补贴都是左手倒右手，所以剔除；但如果是向国外银行付息，就是资源流出，不能简单剔除。

</template>

</Slide>

## 效益费用计算的四项原则

<CompareCard
  title="四条原则对应四类计算对象"
  :cols="['原则', '适用对象与做法']"
  :rows="[
  { k: '支付意愿原则', v: ['项目产出的正面效益；分析社会成员为项目产出愿意支付的价值，通常用消费者支付意愿测定影子价格'] },
  { k: '受偿意愿原则', v: ['项目产出的负面影响；分析社会成员接受这种不利影响所要求补偿的价值'] },
  { k: '机会成本原则', v: ['项目投入的经济价值；机会成本是某种资源的最佳可行替代用途所能获得的最大净效益'] },
  { k: '实际价值原则', v: ['所有效益和费用；采用反映资源真实价值的实际价格，不考虑通货膨胀，但可考虑相对价格变动'] }
]"
/>

<template #notes>

四条原则按“产出正面、产出负面、投入、总体”对应：正面产出用支付意愿，负面影响用受偿意愿，投入用机会成本，总体用实际价值。机会成本的定义要完整：最佳可行替代用途所能获得的最大净效益，三个限定词都不能少。

</template>

</Slide>

## 影子价格怎么定：按定价机制分三类

<CompareCard
  title="不同货物与服务的影子价格确定方法"
  :cols="['货物或服务类型', '确定方法']"
  :rows="[
  { k: '市场定价', v: ['一般按市场价格加上或减去相应物流费用计算；即采用投入产出的进出厂价格；我国大部分货物与服务已由市场定价，能基本反映支付意愿和机会成本'] },
  { k: '政府调控价格（方法一）', v: ['成本分解法：对成本进行分解，用影子价格调整换算得到分解成本；分解成本包括物料、人工、土地和资本投入的机会成本'] },
  { k: '政府调控价格（方法二）', v: ['消费者支付意愿法：按消费者为获得该货物或服务愿意付出的价格确定'] },
  { k: '政府调控价格（方法三）', v: ['机会成本法：按该货物或服务用于其他替代方案时，所有替代方案可能产生收益中的最大值确定'] },
  { k: '特殊投入与产出', v: ['特殊投入：劳动力、土地、自然资源；特殊产出：人力资本、生命价值、时间节约、环境价值'] }
]"
/>

- 政府调控价格的形式：政府定价、指导价、最高限价、最低限价；典型如**电价、铁路运价、水价**。这类价格不能真实反映价值，所以不能简单直接采用。

<template #notes>

市场定价的货物最省事，市场价加减物流费用即可；政府调控价格的货物才需要三种特殊方法。三种方法记关键词：成本分解看资源耗费，支付意愿看消费者愿付多少，机会成本看替代方案的最大收益。特殊产出如生命价值、时间节约，缺乏货币依据时可用非货币方法量化。

</template>

</Slide>

## 费用效益分析：三大指标与判别准则

<CompareCard
  title="经济费用效益分析指标"
  :cols="['指标', '公式', '判别准则']"
  :rows="[
    { k: '经济净现值 ENPV', v: ['ENPV = Σ(B − C)t (1 + is)^−t，t 从 1 到 n', '按社会折现率折现到建设期初', 'ENPV ≥ 0，从资源配置角度可接受'] },
    { k: '经济内部收益率 EIRR', v: ['Σ(B − C)t (1 + EIRR)^−t = 0', '使经济净效益流量现值之和等于零的折现率', 'EIRR ≥ is，经济效率达到可接受水平'] },
    { k: '经济效益费用比 RBC', v: ['计算期内经济效益流量现值 ÷ 经济费用流量现值', '辅助评价指标', 'RBC ≥ 1，资源配置效率可接受'] }
  ]"
/>

- 式中 $(B-C)_t$ 为第 t 年经济净效益流量，B 为经济效益流量，C 为经济费用流量；$i_s$ 为社会折现率。
- **与财务指标对照**：ENPV 对应 FNPV，EIRR 对应 FIRR，计算原理完全相同，区别在**基础数据（影子价格）和折现率（社会折现率）**。

<template #notes>

三个指标的判别线分别是 0、社会折现率、1。ENPV 和 EIRR 与财务版的公式长得一样，但分子换成经济净效益流量，折现率换社会折现率。RBC 是辅助指标，只在资源约束或多方案比选时补充使用。

</template>

</Slide>

## 费用效果分析：效果不能货币化时怎么办

<p class="dk-lead">对于经济效果难以货币化、不能货币化，或者不以货币化效果为主要目标的项目，应采用<strong>费用效果分析</strong>。</p>

<CompareCard
  title="费用（C）与效果（E）的口径"
  :cols="['要素', '口径与要求']"
  :rows="[
  { k: '费用 C', v: ['为实现预定目标付出的财务代价或经济代价，含从投资开始到项目终结的全部费用；采用货币计量，按现值或年值计算；备选方案计算期不一致时按费用年值计算'] },
  { k: '效果 E', v: ['项目所起的作用、效应或效能，反映项目目标的实现程度；一个项目可选用一个或几个效果指标；多目标时需科学确定各子目标权重'] },
  { k: '基本指标', v: ['效果费用比 RE/C 为基本指标；也可采用费用效果比 RC/E'] }
]"
/>

<Reveal label="三种项目该选哪种分析方法？">

- 效益和费用**都能货币计量** → **费用效益分析**（算 ENPV、EIRR、RBC）；
- 效益**难以或不能货币化** → **费用效果分析**（算 RE/C 或 RC/E）；
- 效益和费用**都难以货币量化** → 进行**定性经济费用效益分析**。

</Reveal>

<template #notes>

方法选择看“能不能用钱衡量”。能，就做费用效益分析；效果不能货币化，就做费用效果分析；两者都不行，只能定性分析。费用效果分析里，费用必须是货币，效果可以是床位、水量、通勤时间等实物或效用指标。

</template>

</Slide>

## 一页总结：5.4 必背四个要点

1. **一个视角**：从**全社会**角度评价项目对经济的净贡献，用**影子价格**和**社会折现率**。
2. **五个不同**：角度、内容、效益费用组成、价格体系、主要参数。
3. **三条剔除线**：税费、国内利息、政府补贴属于**转移支付**，不计效益费用。
4. **两类方法**：能货币化用**费用效益分析**（ENPV ≥ 0、EIRR ≥ is、RBC ≥ 1）；效果难货币化用**费用效果分析**（RE/C，配最小费用、最大效果、增量分析）。
