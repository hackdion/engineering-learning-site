## 两套工具，各管一段

<p class="dk-lead">财务分析和经济分析所用的数据大多来自预测和估算，具有不确定性。为分析不确定因素的影响、估计项目风险，需要做不确定性分析和风险分析。</p>

<Reveal label="为什么盈亏平衡分析不能用于经济分析？">

- 盈亏平衡分析算的是**收入与成本**的平衡，用的是财务价格和财务成本；
- 经济分析用的是影子价格、社会折现率，没有“企业盈亏”这个概念；
- 所以盈亏平衡分析只用于财务分析，敏感性分析两种分析都能用。

</Reveal>

这一页先划清边界：盈亏平衡分析只管财务，敏感性分析两边都能用。这是选择题的常客。理解上也简单，盈亏平衡看的是企业收支持平，属于微观财务概念；敏感性分析只看指标对因素的敏感程度，不涉及立场，所以两种分析都能用。

## 盈亏平衡：固定成本、变动成本与四个假设

<p class="dk-lead">线性盈亏平衡分析先把达产年总成本费用划分为<strong>固定成本</strong>和<strong>变动成本</strong>。</p>

<div class="dk-cols">

<div>

### 两类成本

- **固定成本**：在一定产销量范围内，不受产销量变动影响而保持固定不变的成本费用；
- **变动成本**：在一定产销量范围内，随产销量变化而成正比变化的成本费用。

</div>

<div>

### 盈亏平衡点

- 项目达产年**盈利和亏损的转折点**；
- 其他因素不变时，盈亏平衡点**越低**，适应市场变化能力**越强**，抗风险能力**越强**。

</div>

</div>

<CompareCard
  title="线性盈亏平衡分析的四个假设"
  :cols="['假设', '内容']"
  :rows="[
    { k: '产销平衡', v: ['年产量等于年销量'] },
    { k: '单位变动成本不变', v: ['产销量变化时单位变动成本保持不变，总成本是产销量的线性函数'] },
    { k: '产品售价不变', v: ['产销量变化时产品售价保持不变，销售收入是销售量的线性函数'] },
    { k: '产品结构不变', v: ['生产多种产品时，不同产品之间的销售比例保持不变'] }
  ]"
/>

<template #notes>

四个假设可以概括为“量价结构都不变”：产销平衡、单位变动成本不变、售价不变、多产品结构不变。正因为这四个假设，收入线和成本线才是直线，才能用一个简单公式求交点。假设不成立时，线性分析结论只能作参考。

</template>

</Slide>

## 例 5-7：用产销量表示盈亏平衡点

<p class="dk-lead">盈亏平衡时利润为零，销售收入等于总成本，即 $P Q^{*} = C_F + C_V Q^{*}$。</p>

$$
BEP(Q) = Q^{*} = \frac{C_{F}}{P - C_{V}} \tag{5-24}
$$

$$
BEP(Q) = \frac{C_{F}}{P - C_{V} - T} \tag{5-25}
$$

<Steps
  title="某项目设计年产量 5 万 t，售价 2000 元/t，年固定成本 2400 万元，单位变动成本 1100 元/t，销售税金及附加 100 元/t"
  :steps="[
    { t: '统一计量单位', d: '年固定成本 2400 万元，单价 2000 元/t = 0.2 万元/t，单位变动成本 0.11 万元/t，税金及附加 0.01 万元/t' },
    { t: '计算单位边际贡献', d: 'P − Cv − T = 2000 − 1100 − 100 = 800 元/t' },
    { t: '代入公式（5-25）', d: 'BEP(Q) = 2400 万元 ÷ 800 元/t = 3 万 t' },
    { t: '解释结果', d: '产销量由 5 万 t 降至 3 万 t 仍可保本，说明销量下降时有一定抗风险能力' }
  ]"
/>

<Reveal label="公式（5-24）与（5-25）差在哪里？">

- 公式（5-24）不考虑销售税金及附加，分母是 $P - C_V$；
- 公式（5-25）考虑销售税金及附加，分母再减 $T$；
- 这里 $T$ 指**单位产品销售税金及附加（不含增值税）**，教材为简化计算未考虑增值税；
- 分母变小，算出的 BEP(Q) 会变大，说明考虑税金后保本要求更高。

</Reveal>

<template #notes>

计算时单位统一是最容易翻车的地方：固定成本是万元，单价是元每吨，要么都换成万元，要么都换成元。分母是单位边际贡献，考虑税金时要再减 T。结论要会解读：BEP 是 3 万 t，意味着产能利用率降到 60% 才亏损，安全边际是 40%。

</template>

</Slide>

## 生产能力利用率口径与盈亏平衡分析的优缺点

$$
BEP(\%) = \frac{Q^{*}}{Q_{0}} = \frac{C_{F}}{Q_{0}(P - C_{V} - T)} \times 100\% \tag{5-26}
$$

- $Q_0$ 为项目设计生产能力；例 5-7 中 $BEP(\%) = 3/5 = 60\%$；
- 含义：项目不发生亏损时**最低必须达到的设计生产能力百分比**；
- 结论：产销量只要达到设计能力的 60% 即可保本，生产条件意外变化时有一定抗风险能力。

<CompareCard
  title="盈亏平衡分析的长处与短板"
  :cols="['类别', '具体内容']"
  :rows="[
    { k: '优点', v: ['易于理解，便于投资者进行方案比较', '计算简便，结论直观'] },
    { k: '缺点一', v: ['仅涉及运营期不确定性分析', '不是全寿命分析方法'] },
    { k: '缺点二', v: ['未考虑不确定因素发生变化的可能性', '只给出保本点，不说明变化概率'] },
    { k: '缺点三', v: ['需要产销平衡和线性关系假设', '不太符合实际'] }
  ]"
/>

<template #notes>

BEP(%) 就是 BEP(Q) 除以设计产能，两个口径要能互换。例 5-7 的 60% 要记住。优缺点三条：优点是易懂、便于比较；缺点是不全寿命、不考虑变化可能性、线性假设不符合实际。这三条也是它只能作为辅助分析的原因。

</template>

</Slide>

## 敏感性分析：五步找到“最敏感的那一个”

<Steps
  title="单因素敏感性分析的标准步骤"
  :steps="[
    { t: '确定分析对象', d: '确定需要分析的评价指标，如净现值、内部收益率、静态投资回收期等' },
    { t: '选取不确定因素', d: '如项目投资、经营成本、产品价格、建设年限、折现率、期末资产残值等' },
    { t: '测算因素波动影响', d: '假设其他因素不变，设定 ±5%、±10%、±15%、±20% 等变动幅度，逐个计算评价指标数值' },
    { t: '绘制敏感性分析图', d: '每条斜线的斜率反映评价指标对该因素的敏感程度，斜率绝对值越大，敏感度越高' },
    { t: '计算敏感度系数和临界点', d: '据此确定敏感性因素，采取措施限制其变动范围' }
  ]"
/>

<Reveal label="单因素分析里“单”字体现在哪？">

- 每次只让**一个**因素变动，其余因素固定不变；
- 这样才能把这个因素的影响从其他因素中剥离出来；
- 多因素敏感性分析则考虑多个因素同时变化，计算量大，通常只在特别需要时做。

</Reveal>

<template #notes>

五步顺序不能乱：先定指标，再选因素，然后逐个测算，画图看斜率，最后算系数和临界点。注意第三步的前提是“其他因素固定不变”，这是单因素分析的核心。敏感性分析图里，斜率越陡，说明指标对该因素越敏感。

</template>

</Slide>

## 敏感度系数与临界点：两个判据

<CompareCard
  title="敏感度系数 vs 临界点"
  :cols="['判据', '定义与计算', '如何判断']"
  :rows="[
    { k: '敏感度系数 SAF', v: ['SAF = (ΔA/A) ÷ (ΔY/Y)', '评价指标变化率与不确定因素变化率之比，又称灵敏度', '数值越大，说明该因素敏感程度越高'] },
    { k: '临界点', v: ['项目允许不确定因素向不利方向变化的极限值', '例如价格下降到某值时 NPV 刚好为零或 IRR 刚好等于 ic', '变化越过临界点，项目由可行变为不可行'] }
  ]"
/>

- 临界点一般采用不确定因素**相对于基本方案的变化率**或其对应的**具体数值**表示；
- 敏感度系数回答“影响有多大”，临界点回答“还能变多少”，两者配合才能确定敏感性因素和风险控制边界。

<template #notes>

这两个概念经常被混。敏感度系数是比值，没有单位，看的是弹性；临界点是极限值，带百分数或具体数值，看的是安全边界。考试常给一张表让判断敏感排序，用敏感度系数绝对值排序即可，但结论表述要写清正负方向。

</template>

</Slide>

<CompareCard
  title="单因素敏感性分析结果（基准 FNPV = 686.94 万元）"

    { k: '年经营成本', v: ['−33.72', '3.19%', '成本每升 1%，FNPV 降 33.72%；升幅超 3.19% 即由正转负', '次敏感'] },
    { k: '固定资产投资', v: ['−7.71', '12.97%', '投资每升 1%，FNPV 降 7.71%；升幅超 12.97% 即由正转负', '最不敏感'] }
  ]"
/>

<Reveal label="排序结论怎么写才规范？">

- 敏感性由强到弱：**产品价格 > 年经营成本 > 固定资产投资**；
- 不能只写“价格最敏感”，还要给出敏感度系数和临界点，说明影响程度和允许变动范围；
- 控制风险的重点顺序也随之确定：先保价格，再控成本，最后管投资。

</Reveal>

<template #notes>

这道例题的结论要背下来：价格 42.72、成本 −33.72、投资 −7.71，临界点分别是 −2.45%、3.19%、12.97%。正负号表示方向，价格上升对 FNPV 是正效应，所以系数为正；成本和投资上升是负效应，系数为负。排序看绝对值。

</template>

## 情景推演：四种风险对策怎么选

- **回避**：中断风险源，仅适用于可能造成巨大损失、或防范代价过高得不偿失的情形；
- **分担**：与项目其他参加人合资或合作，共担风险、共享收益；
- **转移**：保险转移（投保）与非保险转移（总承包、分包、协议）；
- **自留**：损失较小可自行承担，或投资人甘愿冒一定风险。

## 一页总结：5.5 必背四个要点

1. **分工**：盈亏平衡分析**只用于财务分析**；敏感性分析**财务、经济分析都适用**。
2. **两个公式**：$BEP(Q) = C_F/(P-C_V-T)$；$BEP(\%) = Q^*/Q_0$。盈亏平衡点越低，抗风险能力越强。
3. **两个判据**：**敏感度系数**看影响大小，**临界点**看还能变多少；例 5-8 排序为价格 > 经营成本 > 固定资产投资。
4. **四类对策**：**回避**（巨大损失或防范代价过高）、**分担**（合资合作）、**转移**（保险与非保险）、**自留**（损失较小或甘愿冒险）。
