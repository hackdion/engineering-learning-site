## 设计概算审查的内容与方式

- **审查编制依据**：合法性、时效性、适用范围。
- **审查构成内容**：
  1. 审查工程量（是否按初步设计图纸及概算定额计算）；
  2. 审查定额、指标及取费标准；
  3. 审查材料价格及设备原价/运杂费；
  4. 审查工程建设其他费、预备费等是否漏项或重复。
- **常用审查方法**：**对比分析法**、**查询核实法**、**联合会审法**。

<Reveal label="注意区分：设计概算审查方法 vs 施工图预算审查方法">

- **设计概算审查方法**：对比分析法、查询核实法、联合会审法；
- **施工图预算审查方法**：全面审查法、标准预算审查法、分组计算审查法、对比审查法、“筛选”审查法（下一节详讲）。

</Reveal>

## 小结：设计概算编制与审查

- **三级概算**：单位工程概算 → 单项工程综合概算 → 建设项目总概算。
- **建筑概算三法**：深度够用**概算定额法**；不够有指标用**概算指标法**；没指标有类似用**类似工程预算法**。
- **安装概算三法**：预算单价法 → 扩大单价法 → 概算指标法。
- **审查三法**：对比分析法、查询核实法、联合会审法。
