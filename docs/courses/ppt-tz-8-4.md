## 工程变更从哪里来？

<p class="dk-lead">工程变更、工程量变化、承包人索赔，都可能使项目投资超出原预算，项目监理机构必须严格予以控制。</p>

- **勘察设计不细**：施工中发现招标文件没有考虑或估算不准确的工程量，不得不改变施工项目或增减工程量；
- **不可预见事件**：自然或社会原因引起的停工或工期拖延等。

## 工程变更单（表 8-5）怎么看？

- 工程变更单由**提出方填写**，写明变更原因、变更内容，并附必要附件（变更依据、详细内容、图纸、对造价工期的影响分析及对功能安全影响的分析报告）。
- 涉及工程设计文件修改的，由**发包人转交原设计单位**修改工程设计文件。
- 变更单**一式四份**：发包人、项目监理机构、设计单位、承包人各一份。

<Reveal label="示例 1：材料代换类变更单要点">

- 隆翔商务大厦项目因 HRB335Φ12 钢筋不能及时供货，提出将 19、20 层楼板钢筋改用 HRB400Φ12 代换、间距相应调整；
- 该材料代换**不涉及费用及工期变更**，工程数量增减、费用增减、工期变化均为「无」；
- 由施工项目经理部、设计单位、项目监理机构、发包人四方盖章确认。

</Reveal>

<template #notes>

工程变更单是实操用表，考试主要考填写要点：提出方填、一式四份、涉及设计修改由发包人转交原设计单位。示例 1 是纯材料代换、不涉及费用工期变更，这类变更只走手续不动价款，和后面价款调整区分开。

<CompareCard title="工程量变化 15% 以内与超过 15% 的调整对比" :cols="['变化幅度', '综合单价确定规则']" :rows="[

  { k: '超过 15%（不含）', v: ['增加清单项目或工程量 → 考虑采购优惠合理下调单价；减少清单项目或工程量 → 考虑失去优惠合理上调单价；总价合同有适用单价 → 按上述调整；不适用 → 重新确定综合单价；工期实质性变化 → 按公式 8-10 调整措施项目价格'] }

## 措施项目调整（公式 8-10）

工程变更或发包人责任事件引致合同工期实质性延长或缩短的，发承包双方可按下式计算合同工期影响的措施项目调增（减）价格：

$$
\text{措施项目调整价格}=\text{按规定计算的延长或缩短工期}\times\frac{\text{所有受影响措施项目《措施项目费用分析表》所报中期运行费用总额}}{\text{合同工期}}\tag{8-10}
$$

<Reveal label="为完成工程变更而新增的额外措施项目，费用怎么算？">

- 增加的（现场没有的）**施工机具**：按实际型号、台数、耗用台班计量，按合同清单计日工相关机具单价计价；
- 增加的（现场没有的）**临时设施**：按实际类型、数量、使用时间计量，按双方协商的合理市场价计价；
- 不利一方提出调整措施项目费，应**事先**把方案提交另一方审核；逾期未提出视为放弃调整权利。

</Reveal>

<template #notes>

公式 8-10 的结构是「工期变化 × 受影响措施项目的中期运行费用总额 ÷ 合同工期」，本质是把措施费按工期摊薄。新增的机具和临时设施另按计日工或协商价计价。还要记住「逾期未提出视为放弃」这条程序性规定。

</template>

</Slide>

## 教材例题精练（例 8-7）

某综合单价合同，原合同中有 A、B 两项土方工程，工程量均为 1.6 万 m³，土方合同单价为 60 元/m³。总监理工程师以设计变更通知发布新增土方工程 C，性质与施工难度与 A、B 相同，工程量为 3.2 万 m³，协商确定的变更单价为 55 元/m³。

<Steps title="四步算新增土方变更费用" :steps="[
  { t: '1. 清单计划土方', d: '1.6 + 1.6 = 3.2 万 m³。' },
  { t: '2. 新增土方工程量', d: '3.2 万 m³。' },
  { t: '3. 按原单价计的新增工程量', d: '3.2 × 15% = 0.48 万 m³。' },
  { t: '4. 新增土方工程款', d: '0.48 × 60 + (3.2 − 0.48) × 55 = 28.8 + 149.6 = 178.4 万元。' }
]" />

<template #notes>

例 8-7 是本节招牌计算，跟 8.3 的例 8-1 一个套路：15% 以内按原单价 60 元，超出部分按协商单价 55 元。0.48 万 m³ 按 60 元、剩下 2.72 万按 55 元，合计 178.4 万元。15% 分界是这两个例题共同的题眼。

</template>

</Slide>

## 例 8-8、8-9：特殊变更怎么定单价？

<Reveal label="例 8-8：钻孔桩静载试验由 1.0m 改 1.2m，如何定费用？">

- 静载破坏试验费用由**试验费 + 桩本身费用**两部分构成；
- 试验方法及设备未因桩径改变而变化，**试验费没有增减**；
- 费用增减主要是桩径变化引起的桩身费用变化，1.2m 钻孔桩单价可在清单中查到；
- 变更费用 = **1.0m 静载破坏试验费 + 1.2m 钻孔桩清单价格**。

</Reveal>

<Reveal label="例 8-9：路堤增设排水管涵，为何不直接套清单价？">

- 承包人主张：变更提出较晚，土方已完成，二次开挖用石灰土处理过的路堤难度大，与天然表土不同；
- 总监认可：采用**条件相近的管涵价格**作基本单价，但「土方开挖」一项在原报价基础上按系数**适当提高**；
- 提高的费用叠加在基本单价上，构成新增工程价格。

</Reveal>

<template #notes>

例 8-8 的关键是「费用拆分」：试验费不变、只调桩身费，用 1.2m 桩清单价替换。例 8-9 是「类似单价 + 差异调整」的典型：基本单价套相近管涵价，但二次开挖的土方项按系数调高。两个例子示范了「类似单价换算」和「成本加利润协商」的灵活运用。

</template>

</Slide>

## 一页总结：8.4 工程变更价款确定必背要点

1. **四种情形**：承包人变更源于图纸缺陷、更经济方便、四新技术、为索赔。
2. **六项工作**：审查评估 → 设计修改会签 → 协调确定 → 议价 → 暂定价 → 监督实施。
3. **三种单价**：相同特征**用合同单价**、类似特征**换算**、都无则**成本加利润协商**。
4. **15% 优惠**：量增价降、量减价升；措施项目按公式 8-10 摊薄；例 8-7 变更费 **178.4 万元**。
