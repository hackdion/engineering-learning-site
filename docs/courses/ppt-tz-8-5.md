## 索赔的定义与监理八项工作

<p class="dk-lead">索赔是指当事人一方因<strong>非己方的原因</strong>而遭受经济损失或工期延误，按法律法规或合同约定，应由对方承担补偿义务，而向对方提出的补偿要求。索赔应有<strong>正当理由和有效证据</strong>。</p>

## 批准费用索赔的三项条件

<Reveal label="项目监理机构批准承包人费用索赔，必须同时满足哪三项条件？">

1. 承包单位在承包合同**约定的期限内**提出费用索赔；
2. 索赔事件**因非承包单位原因**造成，且符合承包合同约定；
3. 索赔事件造成承包单位**直接经济损失**。

</Reveal>

- 三项条件**缺一不可**，尤其注意是「直接经济损失」，间接损失不在此列。
- 承包单位提出的费用索赔与工程延期申请相关联的，项目监理机构可对费用索赔和工程延期提出**综合处理意见**。

<template #notes>

批准索赔的三个条件必须同时满足：约定期限内提出、非承包人原因且符合合同、造成直接经济损失。三个条件都爱考，「直接经济损失」的「直接」二字尤其容易被忽略。费用索赔与工期延期关联时可以综合处理。

</template>

</Slide>

## 不利自然条件与人为障碍

<CompareCard title="两类不可预见障碍的索赔要点" :cols="['类型', '核心规则']" :rows="[
  { k: '不利自然条件', v: ['实际自然条件比招标文件描述更困难恶劣，有经验承包人无法预测；例：铺设管道挖深 7.5m 坑时遇严重地下渗水，装抽水系统开动 35d；监理人若认为无法合理预见，经协商可给予延长工期和费用补偿（不含利润）'] },
  { k: '人为障碍', v: ['遇地下构筑物或文物（地下电缆、管道、装置），图纸上未说明的；承包人应立即通知监理人并共同讨论处理方案；费用增加（如机械挖土改人工挖土）可索赔，闲置机器费是主要部分'] }
]" />

<Reveal label="争议焦点：地质资料到底谁负责解释？">

- 合同常写明承包人投标前已考察现场并负责对资料的解释；
- 但另一条款又规定：遇到有经验承包人无法预见的外界障碍，应给予工期和费用补偿；
- 两条并存的合同文件，往往是发包人、承包人、监理人各执一端的**争议缘由**。

</Reveal>

<template #notes>

不利自然条件与人为障碍的共性是「有经验承包人无法合理预见」。地质条件变化争议最大，因为合同里既有「承包人负责解释资料」又有「无法预见应补偿」两条并存的条款。人为障碍索赔数额通常不大，但闲置机器的费用是主要部分。这两类都不含利润。

</template>

</Slide>

## 工期延误索赔：关键线路三规则

<CompareCard title="工期延误索赔的三条判断规则" :cols="['延误事件位置', '索赔工期']" :rows="[
  { k: '关键线路上的工作', v: ['延误的时间即为索赔的工期'] },
  { k: '非关键工作但超总时差', v: ['当该工作因延误超出总时差而成为关键线路上的工作时，延误时间与总时差的差值为索赔工期'] },
  { k: '仍为非关键工作', v: ['不发生工期索赔'] }
]" />

- 索赔工期所对应的工作应是**关键线路上的工作**，或索赔事件引起**关键线路改变的工作**。
- 监理人对工期延误索赔费用应**对每一索赔事件独立评估**，不应包括前期延误对后期工程造成延误的费用索赔。

<template #notes>

工期延误索赔的三规则是本节计算和判断题的高频点：关键工作延误多久赔多久；非关键工作要超出总时差才赔，赔的是「延误时间减总时差」的差值；没超总时差就不赔工期。还要记住独立评估、不含前期延误对后期的影响。

</template>

</Slide>

## 发包人责任索赔：是否含利润？

<CompareCard title="发包人责任事件：可索赔利润 vs 不索赔利润" :cols="['类别', '具体事件']" :rows="[
  { k: '可索赔利润（费用+工期+利润）', v: ['发包人将某项工作改由其他承包人完成；延迟提供施工图纸或施工场地；甲供材料质量不合格、延迟提供、改变交货地点；测量放线错误、工程返工；暂停施工、竣工前提前占用工程、缺陷责任期修复'] },
  { k: '不索赔利润（只赔直接费用）', v: ['对材料工程（含已覆盖隐蔽工程）重新检测且结果合格；额外增加的检查、检验、试验；工程试运行失败；其他情况的直接损失'] }
]" />

<template #notes>

发包人责任索赔的关键分界是「是否含利润」。发包人自身违约类（延迟图纸、甲供材不合格、测量放线错误、暂停施工等）可索赔利润；而重新检测合格、额外检查试验、试运行失败这类「配合性、程序性」事件只赔直接费用不赔利润。这条是本节最经典的多选陷阱。

</template>

</Slide>

## 不可抗力损失承担原则 + 例 8-10

<CompareCard title="不可抗力事件损失承担原则" :cols="['损失项目', '承担方']" :rows="[
  { k: '永久工程、已运现场材料的损坏及修复费用', v: ['发包人承担'] },

  { k: '承包人施工机具损坏、停工损失及措施项目损坏清理修复', v: ['承包人承担'] },
  { k: '双方各自人员伤亡及其他财产损失', v: ['各自承担'] },
  { k: '停工期间照管清理修复费用、留驻人员工资、赶工费用', v: ['发包人承担'] }
]" />

<Reveal label="例 8-10：逐项分析应批准补偿多少？">

- 永久工程损失 **26 万元** → 补偿（发包人承担）；
- 承包人受伤人员医药费、补偿金 **4.5 万元** → 不补偿（各自承担人员伤亡）；
- 施工机具损坏 **12 万元** → 不补偿（承包人承担）；
- 清理修复费用 **3.5 万元** → 补偿（发包人要求下照管清理，发包人承担）；
- **批准补偿金额 = 26 + 3.5 = 29.5 万元**。

</Reveal>

<template #notes>

不可抗力的损失承担按「谁的东西谁担」加几条特殊规则记：永久工程和已运现场材料归发包人、承包人机具归承包人、人员伤亡各自担、停工照管清理和赶工费归发包人。例 8-10 只批准 26+3.5=29.5 万元，人员医药费和机具损失都不批。

</template>

</Slide>

## 提前竣工与发包人索赔

### 提前竣工（加速施工）
- **发包人要求**提前竣工：承包人制定加快措施并修订计划，经发包人同意后实施，增加的赶工补偿由**发包人承担**；
- **承包人自行**提前竣工：应征得发包人同意，由此增加的费用由**承包人承担**。

## 一页总结：8.5 费用索赔管理必背要点

1. **三项条件**：约定期限内提出、非承包人原因且符合合同、造成**直接**经济损失。
2. **五类索赔**：不利自然条件与人为障碍、工期延误、发包人责任、不可抗力、提前竣工。
3. **两个界限**：发包人违约类**可索赔利润**，复检/试验/试运行类**不赔利润**；不可抗力**各自承担**（例 8-10 批 29.5 万元）。
4. **三种算法**：实际费用法**最常用**、总费用法对发包人不利、修正的总费用法接近实际费用法；自有设备窝工按**台班折旧费**。
