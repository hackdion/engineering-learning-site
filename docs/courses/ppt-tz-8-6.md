## 期中支付的四块拼图：每月到底怎么付钱

<p class="dk-lead">施工阶段的投资控制，最终都要落到「这一期该付多少钱」这一张支付证书上。</p>

- **一般规定**：谁申请、什么时候申请、怎么核对、怎么签发、怎么付款。
- **预付款**：开工前先给的一笔备料钱，后面再按约定扣回。
- **安全生产措施费**：单列、预付、专款专用，且**计算进度款时不扣回**。
- **进度款**：按计量周期确认已完工程，用公式（8-13）算出当期应付金额。

## 当期应付进度款：公式（8-13）的四步拆解

<Steps title="套公式算钱，顺序不能乱" :steps="[
  { t: '1. 算基数', d: '累计已完成工程总值（包括已确认的合同价格调整价款）× 支付比例。支付比例合同未约定时，不宜低于累计完成工程总值的 80%。' },
  { t: '2. 减扣回', d: '减去累计预付款扣回（包括当期扣回价款）——预付款是提前给的，这里要往回收。' },
  { t: '3. 减已付', d: '减去前期累计已支付进度款。按上一期支付证书列明的累计应付进度款计算，不看发包人实际付了多少。' },
  { t: '4. 减扣除', d: '减去发包人累计扣除的款项（不含预付款扣回），如质量保证金等，得到当期应付进度款。' }
]" />

<Reveal label="三个最容易被扣分的细节，点开核对">

- **80% 是底线**：合同未约定工程总值支付比例的，支付比例不宜低于累计完成工程总值的 80%。
- **看证书不看流水**：前期累计已支付进度款按上一期支付证书列明的累计应付金额计算，不考虑实际支付与应付金额的差异。
- **工资单列**：各期应付价款中应包括建筑工人工资，按合同约定比例（未约定可按商定比例或已完分部分项工程价款占比）单独列出，**不得挪作他用**。

</Reveal>

### 施工合同中的人工费用约定

《工程建设领域农民工工资专用账户管理暂行办法》人社部发〔2021〕53 号第五条规定，建设单位与总包单位订立书面工程施工合同时，应当约定：工程款计量周期和工程款进度结算办法；建设单位拨付人工费用的周期和拨付日期；人工费用的数额或者占工程款的比例等。人工费用应当满足农民工工资按时足额支付的要求。

<template #notes>

公式（8-13）看起来长，其实就是四步：先算基数，再减预付款扣回，再减前期已付，最后减其他扣除。考试最爱在三个细节上设坑：80% 的支付比例底线、前期已付要按支付证书而不是按银行流水、建筑工人工资必须单列且不得挪用。

</template>

]" />

<template #notes>

预付款有三个高频判断点。第一，它不是借款，发包人不得收取利息。第二，计算基数不是合同总价，必须扣掉暂列金额、计日工价款和专业工程暂估价这三项，因为它们还没真正发生。第三，发包人拖着不付，承包人可以催告，催告后仍不付就有权暂停施工并索赔。

</template>

</Slide>

安全生产措施费记住三个数字和一个“不”：28 天、50%、不扣回。它和预付款最大的区别就在这里——预付款要扣回，安全生产措施费在计算进度款时不扣回。另外它是专款专用，财务账目要单独列项备查，挪用了发包人有权责令改正甚至暂停施工，损失由承包人自己承担。

<template #notes>

计量规则一定要先分清合同类型。单价合同是“重新计量再乘单价”，总价合同是“算比例再乘合价”，措施项目清单则走支付分解。这三套算法经常被出成一道多选题，让同学们判断某个清单项目该用哪种口径。计量周期还要和支付周期一致，约定不明的可以按月计量支付。

</template>

## 一页总结：8.6 期中支付必背五个点

1. **四块内容**：一般规定、预付款、安全生产措施费、进度款。
2. **一个公式**：当期应付 =（累计完成工程总值 × 支付比例）− 预付款扣回 − 前期已付 − 其他扣除；支付比例不宜低于 **80%**。
3. **两个“不”**：预付款**不收利息**；安全生产措施费计算进度款时**不扣回**。
4. **一个时限一个比例**：安全生产措施费开工后 **28d** 内预付不低于 **50%**。
5. **一条红线**：建筑工人工资单独列示，**不得挪作他用**。
