## 结算不是一次动作，而是四个层级

<p class="dk-lead">从施工过程到缺陷责任期结束，工程价款要经过四次“结账”。</p>

- **施工过程结算**：在约定的结算节点上，对当期已完工程进行合同价格的计算、调整、确认。
- **竣工结算**：工程完工后，汇总全部过程结算文件，形成最终结算总价。
- **合同解除后的结算**：合同中途终止时，按解除原因分别处理。
- **工程保修与最终结清**：缺陷责任期届满，把预留的质量保证金结清。

<template #notes>

同学们先建立层级感：过程结算是“分期结”，竣工结算是“总结”，解除结算是“中途结”，最终结清是“收尾结”。这四层对应四个不同的时间节点和四套不同的规则，考试时先判断题目问的是哪一层，再去找对应条文，就不会张冠李戴。

</template>

## 三条硬规则：80%、组成部分、不重新计量

<Reveal label="过程结算最容易被考的三个判断，点开核对">

- **支付比例 80%**：施工过程结算价款的支付比例应在合同中约定，**不应低于当期施工过程结算价款总额的 80%**。
- **成为竣工结算的组成部分**：经双方签署确认的施工过程结算文件，应作为工程竣工结算文件的组成部分；除竣工结算条款规定的调整外，**竣工结算不应对其重新计量、计价**。
- **不替代竣工验收**：施工过程验收不代替竣工验收，不能免除或减轻竣工验收时质量不合格的整改义务，也不影响缺陷责任期及质量保修期。

</Reveal>

<template #notes>

这三条是过程结算的制度价值所在。第一，80% 保证了承包人干完一段就能拿到大部分钱，缓解垫资压力。第二，已经签认的过程结算文件直接进竣工结算，不再重新计量计价，避免反复扯皮。第三，但要注意过程验收不等于竣工验收，质量责任一点都没减轻，质保期也照算。

</template>

</Slide>

  { k: '效力边界', v: ['不作为竣工结算依据', '两项计算结果仅用于计算和支付过程结算价款，不作为竣工结算价款确定的依据'] },

这两项费用的处理非常特殊：过程结算时按比例、按工期先折算出个数付钱，但这个数只是“临时数”。到了竣工结算，措施项目费和总承包服务费必须重新计算，过程结算里列支的金额不能作为竣工结算的依据。这个“先付后算”的逻辑，是本节最容易出判断题的地方。

## 一页总结：8.7 工程结算必背五个点

1. **四层结算**：施工过程结算 → 竣工结算 → 合同解除结算 → 保修与最终结清。
2. **两个 80%**：过程结算支付比例不低于 **80%**；期中进度款支付比例同样不宜低于 **80%**。
3. **一个例外**：过程结算文件不重新计量计价，但**措施项目费和总承包服务费**竣工时必须重算。
4. **一个 3%**：累计扣留质量保证金不超过结算总额 **3%**，已提供履约担保不得同时预留。
5. **一条公式**：最终结清款 = 预留质保金 − 缺陷责任期修复费用，返还不计利息。
