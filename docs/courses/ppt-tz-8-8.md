## 为什么要用挣值法？

<p class="dk-lead">传统的投资控制把<strong>投资</strong>和<strong>进度</strong>分开看，往往出现误判——</p>

- 发现实际花钱比计划多，很难立刻分清：是**单价涨了（投资超支）**，还是**干活干得快（进度提前）**？
- 发现实际花钱比计划少，也很难立刻分清：是**省钱了（投资节支）**，还是**工程拖延没干活（进度拖后）**？
- <strong>挣值法（赢得值法）</strong>通过引入第三个参数「已完工作预算投资」，将投资与进度综合在一起定量分析。

<template #notes>

这一节讲投资偏差分析，核心工具是挣值法，也叫赢得值法。它解决了一个实际工程里的老难题：光看实际花钱比计划花钱多或少，没法判断是超支了还是活干快了。把进度和费用放进同一个坐标系里比较，答案就一目了然。

</template>

</Slide>

## 挣值法的三个基本参数

<CompareCard title="三个基本参数对照（可点击「遮住自测」）" :cols="['缩写与名称', '计算公式与核心含义']" :rows="[
  { k: '计划工作预算投资', v: ['BCWS', '计划工作量 × 预算单价（按计划应当花多少钱；除非合同变更，实施中保持不变）'] },
  { k: '已完工作预算投资（赢得值）', v: ['BCWP', '已完成工作量 × 预算单价（发包人按预算标准认可支付给承包人的金额）'] },
  { k: '已完工作实际投资', v: ['ACWP', '已完成工作量 × 实际单价（到某一时刻实际花费的总金额）'] }
]" />

<Reveal label="速记技巧：怎么一眼分清 BCWS、BCWP、ACWP 最后一个字母？">

- **B** = Budgeted（预算单价），**A** = Actual（实际单价）；
- **S** = Scheduled（计划工作量），**P** = Performed（已完成工作量）。
- 记忆法：**W（Work）不变**，前看 **B/A**（预算还是实际单价），后看 **S/P**（计划还是已完工作量）。

</Reveal>

<template #notes>

三个基本参数的英文缩写是每年必考的基础。大家用前后字母拆分法来记：前面 B 代表预算，A 代表实际；后面 S 代表计划工作量，P 代表已完工作量。记住 BCWP 叫做赢得值，是连接计划和实际的桥梁，后面四个评价指标全都要用到它。

</template>

</Slide>

## 挣值法的四个评价指标（绝对偏差 vs 相对偏差）

<div class="dk-cols">

<div>

### 两个绝对偏差（以金额计）
- **投资偏差**：$\mathrm{CV} = \mathrm{BCWP} - \mathrm{ACWP}$
  - $\mathrm{CV} > 0$ 节支；$\mathrm{CV} < 0$ **超出预算（超支）**
- **进度偏差**：$\mathrm{SV} = \mathrm{BCWP} - \mathrm{BCWS}$
  - $\mathrm{SV} > 0$ 进度提前；$\mathrm{SV} < 0$ **进度延误（拖后）**

</div>

<div>

### 两个相对指数（无量纲）
- **投资绩效指数**：$\mathrm{CPI} = \mathrm{BCWP} / \mathrm{ACWP}$
  - $\mathrm{CPI} > 1$ 节支；$\mathrm{CPI} < 1$ **超支**
- **进度绩效指数**：$\mathrm{SPI} = \mathrm{BCWP} / \mathrm{BCWS}$
  - $\mathrm{SPI} > 1$ 提前；$\mathrm{SPI} < 1$ **拖后**

</div>

</div>

> **局限性辨析**：$\mathrm{CV}$、$\mathrm{SV}$ 反映绝对偏差，仅适合对**同一项目**作偏差分析（10 万元偏差对 1000 万项目和 1 亿项目严重性完全不同）；$\mathrm{CPI}$、$\mathrm{SPI}$ 反映相对偏差，不受项目层次与时间限制，**同一项目和不同项目比较中均可采用**。

<template #notes>

四个评价指标必须牢记两条规律：第一，永远是 BCWP 赢得值在前面做被减数或者分子；第二，算出来的差值大于零、比值大于一，都代表好现象（节支或提前），小于零、小于一都代表坏现象（超支或拖后）。另外常考一道概念题：绝对偏差只适合同一项目比较，相对偏差在不同项目之间也能比。

</template>

</Slide>

## 完工预测指标：BAC、EAC 与 VAC

在挣值法评价曲线中，常用于预测项目最终投资结局的三个符号：

- **BAC（完工预算）**：编计划时预计的项目完工总投资。
- **EAC（预测完工估算）**：根据当前进度与投资偏差预测的项目完工总投资。
- **VAC（预测完工投资偏差）**：$\mathrm{VAC} = \mathrm{BAC} - \mathrm{EAC}$

<Reveal label="教材例 8-20：已知 BAC = 80000 元，CPI = 0.79，如何估算 EAC 与 VAC？">

- 若当前变化可以反映未来（按当前绩效延续）：$\mathrm{EAC} = \mathrm{BAC} / \mathrm{CPI} = 80000 / 0.79 = 101265$ 元；
- $\mathrm{VAC} = \mathrm{BAC} - \mathrm{EAC} = 80000 - 101265 = -21265$ 元，即预测项目最终将超计划预算 21265 元。
- 另有三种典型场景：延续当前绩效（按 $\mathrm{CPI}$ 修正剩余预算）、原假设完全失效（实际支出 + 对剩余工作的全新估计）、当前只是特殊一次性偏差（实际支出 + 剩余原预算）。

</Reveal>

<template #notes>

曲线法还能往后做预测，记住三个英文缩写：BAC 是原定的完工预算，EAC 是现在预测最终要花的总钱，VAC 是两者的差。如果项目接下来还按现在 0.79 的绩效干下去，直接用 BAC 除以 CPI，就能算出最终会超支两万多元。

</template>

</Slide>

## 投资偏差原因五大类（图 8-12 梳理）

<div class="dk-cols">

<div>

### 1. 物价上涨
人工涨价、材料涨价、设备涨价、利率和汇率变化。

### 2. 设计原因
设计错误、设计漏项、设计标准变化、设计保守、图纸提供不及时等。

增加内容、投资规划不当、组织不落实、建设手续不全、协调不佳、未及时提供场地等。

施工方案不当、材料代用、施工质量有问题、赶进度、工期拖延等。

### 5. 客观原因
自然因素、基础处理、社会原因、法规变化等。

</div>

</div>

## 纠偏措施四维度与 EAC 三种估算场景

<div class="dk-cols">

<div>

### 纠偏的四类措施
1. **组织措施**（明确职责与分工）
2. **经济措施**（审核付款与资金计划）
3. **技术措施**（寻找更好更省的设计方案）
4. **合同措施**（变更工程范围、处理索赔等）

</div>

<div>

### 完工总投资 EAC 的三种估算
1. **当前变化可反映未来**：$\text{实际支出} + \text{按实施情况修正的剩余预算}$（如 $\mathrm{BAC}/\mathrm{CPI}$）
2. **原假设基本失效**：$\text{实际支出} + \text{对全部剩余工作的新估计}$
3. **当前变化仅属特殊情况**：$\text{实际支出} + \text{原剩余预算}$

</div>

</div>

<template #notes>

纠偏还是经典的老四样：组织、经济、技术、合同措施。最后提醒一下 EAC 完工估算的三种条件判断，题目如果说以前的估计假设已经完全失效，那就得选实际支出加上对剩余工作的重新估计。

</template>

</Slide>

## 小结：挣值法核心公式一张表

- **三参数**：$\mathrm{BCWS}$（计划）、$\mathrm{BCWP}$（赢得值）、$\mathrm{ACWP}$（实际）。
- **四指标**：$\mathrm{CV} = \mathrm{BCWP} - \mathrm{ACWP}$、$\mathrm{SV} = \mathrm{BCWP} - \mathrm{BCWS}$、$\mathrm{CPI} = \mathrm{BCWP}/\mathrm{ACWP}$、$\mathrm{SPI} = \mathrm{BCWP}/\mathrm{BCWS}$。
- **正大优、负小劣**：$\mathrm{CV}>0, \mathrm{CPI}>1$ 为节支；$\mathrm{SV}>0, \mathrm{SPI}>1$ 为提前；**$\mathrm{BCWP}$ 永远在前面**。
- **表达与纠偏**：最常用**表格法**；纠偏主攻**发包人原因与设计原因**。
