## 六项制度，本节展开五项

<p class="dk-lead">依据《建筑法》《建设工程质量管理条例》《建设工程勘察设计管理条例》等法律法规，我国工程建设领域建立了系列质量管理制度。</p>

- **教材概述列出的六项**：施工图审查制度、建筑工程施工许可制度、工程监理制度、工程质量监督制度、质量事故报告与处理制度、竣工验收与备案制度。
- **本节正文展开五项**：施工图审查、施工许可、工程监理、工程质量监督、竣工验收及备案。
- **一条逻辑**：前两项管「开工前」，监理和质量监督管「施工中」，竣工验收备案管「收尾」。
- **一个共同点**：五项制度都围绕**政府监督 + 建设单位责任**展开，政府管程序和底线，建设单位组织落实。

## 施工图审查：先勘察、后设计

<p class="dk-lead">施工图审查，是指施工图审查机构按照有关法律、法规，对施工图涉及<strong>公共利益、公众安全和工程建设强制性标准</strong>的内容进行的审查。施工图审查应当坚持<strong>先勘察、后设计</strong>的原则。</p>

- **审查对象**：施工图设计文件，含勘察文件。
- **审查依据**：《房屋建筑和市政基础设施工程施工图设计文件审查管理办法》（住房和城乡建设部令第 13 号）。
- **机构性质**：审查机构是专门从事施工图审查业务、**不以营利为目的的独立法人**。
- **两类机构**：一类机构承接房屋建筑、市政基础设施工程施工图审查业务范围**不受限制**；二类机构可以承接**中型及以下**房屋建筑、市政基础设施工程的施工图审查。
- **机构条件**：有健全的技术管理和质量保证体系；审查人员满足专业勘察、设计工作经历要求并具备相应注册资格或高级工程师职称；专职审查人员数量符合规定；**60 岁以上审查人员不超过该专业审查人员规定数的 1/2**。
- **名录管理**：省级住房城乡建设主管部门确定审查机构数量，名录报国务院住房城乡建设主管部门备案并向社会公布。

<Reveal label="审查机构不得与哪些单位有隶属关系或其他利害关系？">

审查机构不得与所审查项目的**建设单位、勘察设计企业**有隶属关系或者其他利害关系。审查机构对施工图审查工作负责并承担审查责任；施工图经审查合格后，仍有违反法律、法规和工程建设强制性标准的问题，给建设单位造成损失的，审查机构依法承担相应的赔偿责任。

</Reveal>

<template #notes>

这一段是责任条款，常出判断题。「审查合格」不等于审查机构免责，只要还有违反强制性标准的问题并造成损失，就要赔。另外记住审查机构是「不以营利为目的的独立法人」，这决定了它不能与被审查单位有利害关系。

施工图审查抓五个点：审什么（涉及公共利益、公众安全和强制性标准）、什么原则（先勘察后设计）、谁来审（两类机构）、机构性质（非营利独立法人）、责任（对审查工作负责）。一类二类的区别只有一句：一类不受限制，二类只能做中型及以下。

</template>

## 工程监理：三项签字，三条安全职责

<p class="dk-lead">依据《建筑法》，国家推行工程监理制度。实行监理的建筑工程，由建设单位委托具有相应资质条件的工程监理单位监理，并订立<strong>书面</strong>委托监理合同。</p>

- **监理依据**：法律、行政法规、有关技术标准、设计文件和建筑工程承包合同。
- **监理内容**：代表建设单位对承包单位的**施工质量、建设工期和建设资金使用**实施监督。
- **材料与工序**：未经**监理工程师**签字，建筑材料、建筑构配件和设备不得在工程上使用或者安装，施工单位不得进行下一道工序的施工。
- **拨款与验收**：未经**总监理工程师**签字，建设单位不拨付工程款，不进行竣工验收。
- **监理形式**：按照工程监理规范的要求，采取**旁站、巡视和平行检验**等形式实施监理。
- **禁止性规定**：监理单位不得转让工程监理业务，与被监理工程的承包单位及材料设备供应单位不得有隶属关系或其他利害关系。

<Reveal label="发现安全事故隐患，监理单位按什么顺序处理？">

1）在实施监理过程中发现存在安全事故隐患的，应当要求施工单位**整改**；2）情况严重的，应当要求施工单位**暂时停止施工**，并及时报告建设单位；3）施工单位**拒不整改或者不停止施工**的，应当及时向有关主管部门**报告**。

</Reveal>

<template #notes>

这三步是递进的，不能跳步：先整改，严重才停工，拒不执行才向主管部门报告。注意「报告建设单位」和「报告主管部门」是两回事，前者在停工环节，后者在拒不执行环节。

监理这一页抓两组签字：监理工程师管材料、构配件、设备和工序；总监理工程师管工程款和竣工验收。这两组不要混。监理形式三种：旁站、巡视、平行检验。安全职责记「整改—停工报告—主管部门报告」三级递进。

</template>

</Slide>

## 工程质量监督：职责与三项措施

<p class="dk-lead">县级以上地方人民政府建设行政主管部门对本行政区域内的建设工程质量实施监督管理；交通、水利等有关部门在各自职责范围内负责专业建设工程质量的监督管理。</p>

<Steps title="履行监督检查职责时有权采取的三项措施" :steps="[
  { t: '查文件资料', d: '要求被检查的单位提供有关工程质量的文件和资料' },
  { t: '进现场检查', d: '进入被检查单位的施工现场进行检查' },
  { t: '责令改正', d: '发现有影响工程质量的问题时，责令改正' }
]" />

> 质量监督的两个对象：**工程实体质量**与**工程质量行为**。实体质量监督盯涉及主体结构安全、主要使用功能的部分；行为监督盯各责任主体履行法定质量责任和义务的情况。

<template #notes>

三项措施很好记：要资料、进现场、责令改。质量监督的定义要抓两个监督对象——实体质量和质量行为。实体质量不是全面检查，而是抽查涉及主体结构安全和主要使用功能的部分，这一点决定了监督是抽查制而不是验收制。

</template>

</Slide>

> **建设工程经验收合格方可交付使用。** 竣工验收由**建设单位**负责组织实施，组织勘察、设计、施工、监理等有关单位进行。

五项条件记「干完—资料—试验—四方签字—保修书」。第 4 项是四家分别签署，不是建设单位一家出证明。还要记住组织者：竣工验收由建设单位组织，不是监理单位组织，也不是政府组织；政府是监督竣工验收。

## 小结：五道关口，一条时间轴

<p class="dk-lead">审图管能不能用，许可管能不能开工，监理管过程签不签字，监督管抽查，备案管收尾。</p>

- **施工图审查**：审强制性标准、地基基础和主体结构安全、消防、人防、节能与绿建、签章等七项；先勘察后设计；一类机构不受限制，二类做中型及以下。
- **施工许可**：七项条件；7 日发证、5 日一次告知补正；3 个月开工、两次延期、1 个月内报告中止、满 1 年核验；未办证罚款 1%～2%，施工单位 3 万元以下。
- **工程监理**：监理工程师签材料与工序，总监理工程师签拨款与竣工验收；安全隐患者按「整改—停工报告—主管部门报告」递进处理。
- **质量监督**：三项措施、八项内容；实体质量与质量行为并重，抽查为主。
- **竣工验收与备案**：五项条件由建设单位组织验收；15 日内备案六项文件，未备案或虚假备案罚 20～50 万元。
