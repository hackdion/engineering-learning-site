## 七项安全生产制度，先搭骨架

<p class="dk-lead">依据《安全生产法》《建设工程安全生产管理条例》《安全生产许可证条例》《特种设备安全监察条例》《生产安全事故报告和调查处理条例》等法律法规，我国工程建设领域建立了系列的安全生产管理制度。</p>

- **准入**：安全生产许可证制度——没有证，不得从事建筑施工活动。
- **监管**：安全生产监督管理制度——主管部门对责任主体履职情况抽查并处理违法违规行为。
- **能力**：安全教育培训制度——未经教育培训的人员不得上岗作业。
- **高风险作业**：危大工程管理制度、特种设备（作业）管理制度。
- **兜底**：应急管理制度、生产安全事故报告制度。
- **一条主线**：从「能不能干」到「怎么干」，再到「出事怎么办」，制度覆盖全过程。

## 安全生产许可证：十一项条件

<p class="dk-lead">国家对建筑施工企业实行安全生产许可制度。建筑施工企业<strong>未取得安全生产许可证的，不得从事建筑施工活动</strong>。</p>

<Reveal label="「安管人员」指哪三类人？">

**主要负责人、项目负责人、专职安全生产管理人员**，合称「安管人员」。他们应当通过受聘企业，向企业工商注册地的省、自治区、直辖市人民政府住房城乡建设主管部门申请安全生产考核，取得安全生产考核合格证书。

</Reveal>

<template #notes>

这一组概念后面在监理审核职责里还会出现：监理要审核「安管人员」安全生产考核合格证书和特种作业人员操作资格证书。注意两类证书不是一回事：安管人员是考核合格证书，特种作业人员是操作资格证书。

十一项条件不用逐条背，按四组记：制度与投入、机构与人员、教育培训与保险、现场条件与应急。其中三个「每年/必须」要记：管理人员和作业人员每年至少一次教育培训并考核合格；必须设置安全生产管理机构并配专职人员；必须依法参加工伤保险并为危险作业人员办意外伤害保险。

## 安全生产监督：六项内容、五项措施

<p class="dk-lead">施工安全监督，是住房城乡建设主管部门依据有关法律法规，对建设、勘察、设计、施工、监理等单位及人员履行安全生产职责、执行法律法规和强制性标准等情况实施<strong>抽查</strong>并对违法违规行为进行处理的<strong>行政执法活动</strong>。</p>

<Steps title="施工安全监督的主要内容" :steps="[
  { t: '抽查履职情况', d: '抽查工程建设责任主体履行安全生产职责情况' },
  { t: '抽查执法守法情况', d: '抽查责任主体执行法律、法规、规章、制度及工程建设强制性标准情况' },
  { t: '抽查标准化', d: '抽查建筑施工安全生产标准化开展情况' },
  { t: '事故调查处理', d: '组织或参与工程项目施工安全事故的调查处理' },
  { t: '行政处罚', d: '依法对工程建设责任主体违法违规行为实施行政处罚' },
  { t: '处理投诉举报', d: '依法处理与工程项目施工安全相关的投诉、举报' }
]" />

<Reveal label="监督机构有权采取哪五项措施？">

1）要求工程建设责任主体提供有关工程项目安全管理的文件和资料；2）进入工程项目施工现场进行安全监督抽查；3）发现安全隐患，责令整改或暂时停止施工；4）发现违法违规行为，按权限实施行政处罚或移交有关部门处理；5）向社会公布工程建设责任主体安全生产不良信息。

</Reveal>

<template #notes>

五项措施比质量监督多了两项：责令停工和公布不良信息。注意「向社会公布」是安全监督特有的手段，质量监督的三项措施里没有。

内容和措施要分开记：内容是「查什么」（履职、守法、标准化、事故、处罚、投诉），措施是「凭什么查」（要资料、进现场、责令整改或停工、处罚移交、公布不良信息）。监督对象是已办理施工安全监督手续并取得施工许可证的工程项目。

</template>

</Slide>

## 安全教育培训：类型、对象与内容

<p class="dk-lead">建筑施工企业应当建立健全劳动安全生产教育培训制度；<strong>未经安全生产教育培训的人员，不得上岗作业</strong>。</p>

<Steps title="安全教育培训的四个要点" :steps="[
  { t: '计划编制', d: '依据类型、对象、内容、时间安排、形式等需求编制安全生产教育培训计划' },
  { t: '培训类型', d: '各类上岗证书的初审、复审培训，三级教育（企业、项目、班组）、岗前教育、日常教育、年度继续教育' },
  { t: '培训对象', d: '企业各管理层的负责人、管理人员、特殊工种以及新上岗、待岗复工、转岗、换岗的作业人员' },
  { t: '岗前教育五项内容', d: '安全生产法律法规和规章制度；安全操作规程；针对性的安全防范措施；违章指挥、违章作业、违反劳动纪律产生的后果；预防减少安全风险以及紧急情况下应急救援的基本知识、方法和措施' }
]" />

<Reveal label="年度继续教育要学哪三方面内容？">

1）新颁布的安全生产法律法规、安全技术标准规范和规范性文件；2）先进的安全生产技术和管理经验；3）典型事故案例分析。施工企业每年应按规定对所有从业人员进行安全生产继续教育。

</Reveal>

<template #notes>

三类内容正好对应「新规—新技术—新案例」。三级教育是企业、项目、班组三级，不是三个工种。培训对象里「待岗复工、转岗、换岗」这三类容易被忽略，只要岗位发生变化就要重新教育。

这一页抓三层：类型（证书培训、三级教育、岗前、日常、继续教育）、对象（负责人、管理人员、特殊工种、新上岗及待岗复工转岗换岗人员）、内容（岗前五项、继续教育三项）。一条红线是「未经教育培训不得上岗」，这是条例原文。

</template>

</Slide>

## 危大工程：方案、签字与专家论证

<p class="dk-lead">施工单位应当在施工组织设计中编制安全技术措施和施工现场临时用电方案，对达到一定规模的<strong>危险性较大的分部分项工程</strong>编制专项施工方案，并附具安全验算结果。</p>

<Steps title="危大工程管理的五个动作" :steps="[
  { t: '编制专项施工方案', d: '针对达到一定规模的危大工程编制专项施工方案，不能只用施工组织设计里的一般安全技术措施代替' },
  { t: '附具安全验算结果', d: '专项施工方案应附具安全验算结果，用计算支撑方案的安全性' },
  { t: '两级签字后实施', d: '经施工单位技术负责人、总监理工程师签字后实施，缺一不可' },
  { t: '专职人员现场监督', d: '由专职安全生产管理人员进行现场监督，并做好记录' },
  { t: '超过一定规模的组织论证', d: '对于超过一定规模的危大工程，施工单位还应当组织专家进行论证、审查' }
]" />

<Reveal label="未编制安全技术措施或专项方案，怎么处罚？">

施工单位在施工组织设计中未编制安全技术措施、施工现场临时用电方案或者专项施工方案的，责令限期改正；逾期未改正的，责令停业整顿，并处 **10 万元以上 30 万元以下**的罚款；情节严重的，降低资质等级，直至吊销资质证书；造成重大安全事故构成犯罪的，对直接责任人员依照刑法追究刑事责任；造成损失的，依法承担赔偿责任。工程监理单位未对安全技术措施或专项施工方案进行审查的，按同一标准处罚。

</Reveal>

<template #notes>

注意罚则对监理同样适用：监理未审查专项方案，也是责令改正、逾期停业整顿并处 10～30 万元罚款。这一条把监理的安全审查义务落到了责任上。签字环节记「施工技术负责人 + 总监」两个人，不是项目经理签字。

五个动作按「编—算—签—督—论证」记。两个「一定规模」要区分：达到一定规模编专项方案；超过一定规模的还要专家论证。前者是编制义务，后者是论证义务，不能混为一谈。

</template>

</Slide>

## 特种设备与电梯安装

<p class="dk-lead">特种设备是指涉及生命安全、危险性较大的<strong>锅炉、压力容器、压力管道、电梯、起重机械、客运索道、大型游乐设施和场（厂）内专用机动车辆</strong>。</p>

- **告知义务**：特种设备安装、改造、维修的施工单位应当在施工前将拟进行的情况**书面告知**直辖市或者设区的市特种设备安全监督管理部门，告知后方可施工。
- **监管分工**：房屋建筑工地和市政工程工地用起重机械、场（厂）内专用机动车辆的安装、使用的监督管理，由建设行政主管部门依照有关法律法规制定相应规定。

<Steps title="电梯安装管理的四条要求" :steps="[
  { t: '谁可以安装', d: '电梯的安装、改造、维修，必须由电梯制造单位或者其通过合同委托、同意并按照《特种设备安全监察条例》取得许可的单位进行；制造单位对电梯质量以及安全运行涉及的质量问题负责' },
  { t: '井道与现场', d: '电梯井道的土建工程必须符合建筑工程质量要求；安装单位应遵守施工现场安全生产要求，落实现场安全防护措施' },
  { t: '服从总包管理', d: '电梯安装施工过程中，电梯安装单位应当服从建筑施工单位管理，并订立合同，明确各自的安全责任' },
  { t: '校验与调试', d: '制造单位委托或同意其他单位安装、改造、维修的，应对其活动进行安全指导和监控；活动结束后，制造单位应按安全技术规范校验和调试，并对结果负责' }
]" />

<template #notes>

电梯这一页的责任落点很特别：不管谁安装，制造单位都要对质量和安全运行涉及的质量问题负责，还要在结束后校验调试。这和一般分包「谁干谁负责」不同，考试常在这里设问。

## 建筑起重机械：五种情形不得出租、使用

<p class="dk-lead">出租单位出租的、使用单位购置租赁使用的建筑起重机械，应当具有<strong>特种设备制造许可证、产品合格证、制造监督检验证明</strong>；首次出租前或首次安装前，应到本单位工商注册所在地县级以上地方人民政府建设主管部门办理备案。</p>

## 小结：从准入到报告的一条安全链

<p class="dk-lead">先有证，再有监督；人受培训，险有方案；设备验收，事故必报。</p>

- **许可证**：11 项条件；45 日审查、3 年有效期、期满前 3 个月延期、未发生死亡事故延期 3 年不再审查、变更 10 日内办理。
- **监督**：六项内容、五项措施；监督对象是已办安全监督手续并取得施工许可证的工程。
- **培训**：三级教育（企业、项目、班组）+ 岗前、日常、继续教育；未经培训不得上岗。
- **危大工程**：专项方案 + 安全验算 + 施工单位技术负责人与总监签字 + 专职人员监督；超规模还要专家论证。
- **特种设备**：安装改造维修前书面告知；起重机械五种不得出租、安装后自检—监督检验—验收—30 日内使用登记；总包与监理各负审核监督职责。
