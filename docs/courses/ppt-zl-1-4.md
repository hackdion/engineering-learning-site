## 五方主体，五张行为清单

<p class="dk-lead">根据《工程质量安全手册（试行）》，工程质量责任主体单位应依法履行工程质量行为责任。</p>

- **建设单位**：依法发包、委托和办理手续，落实施工图审查、组织图纸会审与设计交底，履行合同职责，组织竣工验收。
- **勘察设计单位**：施工前详细说明设计文件，及时解决施工中的勘察设计问题，参与施工验槽和质量事故分析。
- **监理单位**：组建项目监理机构，审查方案与材料，旁站、巡查、平行检验，组织隐蔽工程和检验批验收。
- **施工单位**：不得违法分包转包，建立质量责任制，编制施工组织设计和方案，技术交底，样板引路，依法履行施工质量行为。
- **检测单位**：独立、真实、准确地检测，不得与被检测工程相关单位有利害关系，不合格结果及时报告。
- **一条主线**：谁的行为造成质量问题，谁承担相应责任；行为准则是责任的「操作版」。

## 建设单位（一）：不得肢解发包、不得压缩工期

<p class="dk-lead">根据《建筑法》，发包单位可以将建筑工程的勘察、设计、施工、设备采购一并发包给一个工程总承包单位，也可以将其中一项或者多项发包给一个工程总承包单位；但<strong>不得将应当由一个承包单位完成的建筑工程肢解发包</strong>。</p>

- **肢解发包的定义**：建设单位将应当由一个承包单位完成的建设工程分解成若干部分发包给不同的承包单位。
- **不得低于成本竞标**：不得迫使承包方以低于成本的价格竞标。
- **不得任意压缩合理工期**：建设单位任意压缩合理工期的，责令改正，处 **20 万元以上 50 万元以下**的罚款。
- **安全条例的叠加约束**：不得对勘察、设计、施工、工程监理等单位提出不符合建设工程安全生产法律、法规和强制性标准规定的要求，**不得压缩合同约定的工期**。

<Reveal label="「合理工期」与「合同约定工期」是一回事吗？">

不是同一表述。《建设工程质量管理条例》禁止「任意压缩**合理工期**」，《建设工程安全生产管理条例》禁止「压缩**合同约定的工期**」。前者强调工期本身的合理性，后者强调已约定工期的稳定性；两条都指向同一个结论：建设单位不能以工期为由压掉应有的质量安全投入。

</Reveal>

<template #notes>

这一页有两个高频点：肢解发包的定义、压缩工期的罚款 20～50 万元。还要注意两部条例的措辞不同，考试若原样引用「压缩合同约定的工期」，对应的是安全生产管理条例；引用「任意压缩合理工期」，对应的是质量管理条例。

肢解发包判断的关键是「应当由一个承包单位完成」。如果工程本身可以合理划分标段，分别发包不违法；把本应整体完成的工程切成几块分给不同单位，才是肢解。罚款数字 20～50 万元要和后面竣工验收备案的罚款区分开，两者数字相同但事由不同。

</template>

</Slide>

## 勘察设计单位：三条准则

<Steps title="勘察设计单位的质量行为准则" :steps="[
  { t: '施工前详细说明', d: '在工程施工前，就审查合格的施工图设计文件向施工单位和监理单位作出详细说明，即设计交底' },
  { t: '及时解决与参与分析', d: '及时解决施工中发现的勘察、设计问题；参与工程质量事故调查分析；对因勘察、设计原因造成的质量事故提出相应的技术处理方案' },
  { t: '参与施工验槽', d: '依据《工程勘察通用规范》GB 55017，勘察单位应参与施工验槽，检验开挖揭露的地质条件与工程勘察报告的一致性；如有异常，应提出处理措施或修改设计的建议' }
]" />

<Reveal label="施工图设计文件，谁有权修改？">

建设单位、施工单位、监理单位**不得修改**建设工程勘察设计文件；确需修改的，应当由**原勘察设计单位**修改。经原勘察设计单位**书面同意**，建设单位也可以委托其他具有相应资质的勘察设计单位修改，修改单位对修改的勘察设计文件承担相应责任。内容需要作**重大修改**的，建设单位应当报经原审批机关批准后方可修改。

</Reveal>

<template #notes>

修改权限分三层：原则上原单位改；例外是原单位书面同意后可委托其他有资质单位改，谁改谁负责；重大修改还要原审批机关批准。这三层要按顺序说，不能只说「原单位修改」就完。

三条准则对应三个阶段：施工前交底、施工中解决问题、验槽时核对地质条件。勘察单位参与验槽是 GB 55017 的明确要求，检验的是「开挖揭露的地质条件与勘察报告是否一致」，不是重新勘察。

</template>

</Slide>

<Reveal label="四种交底形式分别适用什么场合？">

**会议交底**适用于单位工程技术交底和分项工程技术交底；**书面交底**适用于对施工班组长和工人的技术交底；**施工样板交底**适用于施工工艺的交底；**岗位技术交底**适用于岗位工艺操作的交底。

</Reveal>

<template #notes>

四种形式按「对象—内容」匹配：会议对群体、书面对班组长和工人、样板对工艺、岗位对具体操作。考试常把「施工样板交底」说成适用于所有交底，这是错的。

两类交底的时机不同：单位工程在开工时，分项工程在施工前并留准备时间。内容上单位工程偏「部署与计划」，分项工程偏「工艺与标准」。这一页和上一节的样板引路可以连起来看：样板本身就是一种交底载体。

材料样板、加工样板、工序样板、装修样板间等。样板引路的作用是规范施工工艺，保证重要工序、关键环节的质量控制，消除工程质量通病，提高工程质量整体水平——把质量管理从事后验收提前到施工前的预控和施工过程的控制。

## 小结：五方各守一条底线

<p class="dk-lead">建设不肢解、设计不乱改、监理不缺位、施工不违法分包、检测不作假。</p>

- **建设单位**：不得肢解发包、不得压缩合理工期（罚 20～50 万元）、不得指定材料供应商；办监督手续、报审图、组织会审交底、组织竣工验收。
- **勘察设计单位**：施工前设计交底、及时解决施工中的问题、参与验槽；设计文件只能由原单位修改，重大修改报原审批机关批准。
- **监理单位**：机构人员到位，审查方案与材料、审核分包资质，旁站巡查平行检验，验收隐蔽工程和检验批并复查整改。
- **施工单位**：不得转包和违法分包（主体结构不得分包）；建责任制、编施工组织设计与专项方案、技术交底、样板引路、按图施工、隐蔽报验。
- **检测单位**：不转包、不转借资质、不推荐监制、不搞利益关联；按强制性标准检测，数据报告真实准确，不合格台账单独立账。
