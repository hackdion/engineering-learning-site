## 六方主体，一张安全责任网

<p class="dk-lead">根据《工程质量安全手册（试行）》，安全生产管理责任主体单位应依法履行以下安全生产行为责任。</p>

- **建设单位**：办安全监督手续、提交危大工程清单、保障安全费用、提供现场及毗邻区域资料、拆除工程备案。
- **勘察单位**：勘察文件真实准确，并在文件中说明地质条件可能造成的工程风险。
- **设计单位**：保证工程安全性能，注明施工安全重点部位和环节，对危大工程提出安全意见，必要时专项设计。
- **监理单位**：编规划细则、审查安全技术措施和专项方案、审核资质证书、核查机械设施、实施现场安全监理。
- **施工单位**：十二条行为，从机构人员、教育培训到隐患排查、应急演练、事故报告。
- **监测单位**：编监测方案、按方案监测、及时报送、异常即报。
- **一条主线**：安全责任按「谁委托、谁审查、谁实施、谁监测」划分，越靠前越要提供条件和资料。

这一节和上一节结构相同，都是按主体列行为，但视角从质量换成安全。学习时抓两类动作：一类是「提供条件」，如建设单位给资料、给费用；一类是「审查把关」，如监理审资质、审方案。监测单位是安全这一节特有的主体，质量那一节没有。

施工现场及毗邻区域内**供水、排水、供电、供气、供热、通信、广播电视等地下管线资料**，**气象和水文观测资料**，**相邻建筑物和构筑物、地下工程的有关资料**等。

这一页四个义务都指向「给条件」：给钱（安全费用单列）、给合格产品（不得暗示用不合格防护用品）、给资料、给合格的施工队伍（拆除工程要有资质）。建设单位的安全责任不是管现场，而是保证现场具备安全条件。

## 勘察单位：真实准确 + 说明风险

<Steps title="勘察单位的安全生产行为准则" :steps="[
  { t: '勘察文件真实准确', d: '根据《建设工程勘察设计管理条例》，勘察单位应按规定进行勘察，提供的勘察文件应当真实、准确，满足建设工程规划、选址、设计、岩土治理和施工的需要' },
  { t: '说明地质风险', d: '根据《危险性较大的分部分项工程安全管理规定》，勘察单位应当根据工程实际及工程周边环境资料，在勘察文件中说明地质条件可能造成的工程风险' }
]" />

<Reveal label="未在勘察文件中说明地质风险，怎么处理？">

责令限期改正，依照《建设工程安全生产管理条例》对其进行处罚。这一条把「说明风险」从技术要求变成了法定义务：不写就是违法，而不是「写得不够详细」的技术瑕疵。

</Reveal>

<template #notes>

勘察单位的安全责任很集中：文件要真实准确，还要主动说明地质条件可能造成的工程风险。注意「可能造成的工程风险」不是泛泛提示，而是要结合工程实际和周边环境作出判断。

两条准则一句话：勘察数据要真，风险要说。这一条在案例题里常和基坑坍塌、边坡失稳结合，问勘察单位有没有责任，就看勘察文件是否说明了相应地质风险。

</template>

</Slide>

## 设计单位：三条准则

<Steps title="设计单位的安全生产行为准则" :steps="[
  { t: '保证工程安全性能', d: '建筑工程设计应当符合按照国家规定制定的建筑安全规程和技术规范；按照法律法规和工程建设强制性标准进行设计，防止因设计不合理导致生产安全事故' },
  { t: '注明安全重点部位与环节', d: '应当考虑施工安全操作和防护的需要，在设计文件中注明施工安全的重点部位和环节，并对防范生产安全事故提出指导意见' },
  { t: '危大工程专项要求', d: '应当在设计文件中注明涉及危大工程的重点部位和环节，提出保障工程周边环境安全和工程施工安全的意见，必要时进行专项设计' }
]" />

<Reveal label="采用新技术、新材料又没有国家技术标准，怎么用？">

应当由**国家认可的检测机构**进行试验、论证，出具检测报告，并经**国务院有关部门或者省、自治区、直辖市人民政府有关部门组织的建设工程技术专家委员会审定**后，方可使用。

</Reveal>

<template #notes>

这条路径要按顺序说：先检测机构试验论证出报告，再经专家委员会审定，最后才能使用。缺任何一步都不行。另外，采用新结构、新材料、新工艺的建设工程和特殊结构的建设工程，设计单位还应当在设计文件中提出保障施工作业人员安全和预防事故的措施建议。

设计单位三条准则对应三个层次：整体安全性能、施工安全的重点部位环节、危大工程的专项要求。第三条是《危险性较大的分部分项工程安全管理规定》加的，比前两条更具体：要注明、要提意见、必要时专项设计。

</template>

</Slide>

五项按「编—审—核—查—报」记。第 5 项要特别注意报告对象是「政府主管部门」，而上一节质量隐患的处理里，监理是先要求整改、严重时要求暂停施工并报告建设单位，拒不整改才报主管部门。两条链要对照记。

</template>

</Slide>

## 监测单位：方案、报送与罚则

<p class="dk-lead">监测单位应严格履行工程监测安全行为，按规定编制监测方案并按照监测方案开展监测。对于按照规定需要进行第三方监测的危大工程，<strong>建设单位应当委托具有相应勘察资质的单位</strong>进行监测。</p>

<Steps title="监测单位的三项核心义务" :steps="[
  { t: '编制监测方案', d: '方案内容包括工程概况、监测依据、监测内容、监测方法、人员及设备、测点布置与保护、监测频次、预警标准及监测成果报送等' },
  { t: '审批与认可', d: '监测方案由监测单位技术负责人审核签字并加盖单位公章，报送监理单位认可后方可实施' },
  { t: '按方案监测并报告', d: '按监测方案开展监测，及时向建设单位报送监测成果并对成果负责；发现异常时，及时向建设、设计、施工、监理单位报告，建设单位应当立即组织相关单位采取处置措施' }
]" />

<Reveal label="监测单位哪四种行为会被罚 1 万～3 万元？">

1）未取得相应勘察资质从事第三方监测的；2）未按照规定编制监测方案的；3）未按照监测方案开展监测的；4）发现异常未及时报告的。有上述行为之一的，责令限期改正，并处 **1 万元以上 3 万元以下**的罚款。

</Reveal>

<template #notes>

四种情形都围绕「资质—方案—执行—报告」这条链，正好对应监测单位的全部核心义务。注意罚款额度是 1 万～3 万元，比施工单位的 10 万～30 万元低，但性质同样是行政处罚。

## 小结：六方各就各位

<p class="dk-lead">建设单位给条件，勘察设计说风险，监理审与报，施工守十二条，监测盯数据。</p>

- **建设单位**：办安全监督手续并提交危大清单；安全费用单列并及时支付；提供现场及毗邻区域资料；拆除工程 15 日前备案。
- **勘察单位**：勘察文件真实准确，说明地质条件可能造成的工程风险。
- **设计单位**：保证安全性能，注明施工安全重点部位和环节，危大工程提意见、必要时专项设计；新技术新材料经检测论证和专家委员会审定。
- **监理单位**：编规划细则、审安全技术措施与专项方案、审核资质与两类证书、核查机械设施、现场安全监理并在拒不整改时报告政府主管部门。
- **施工单位**：十二条行为，重点是机构人员一致、总包与分包签安全生产协议书、隐患排查、带班制度、应急演练与如实报告。
- **监测单位**：有勘察资质、编方案并经技术负责人签章和监理认可、按方案监测报送、异常即报；违规罚 1～3 万元。
