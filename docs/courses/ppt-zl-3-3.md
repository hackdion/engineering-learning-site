## 现浇混凝土：一条从材料到验收的链

<p class="dk-lead">现浇混凝土结构施工应确保实现<strong>设计要求</strong>，应编制<strong>施工方案</strong>并按方案实施。</p>

- **用材**：水泥、砂、粗骨料、拌合用水、钢筋及连接接头，各有控制指标和限值。
- **施工**：模板工程、钢筋与预应力工程、混凝土工程，三道工序依次交接。
- **验收**：过程检验（隐蔽验收、拆模强度）+ 强度检验评定 + 现浇结构质量验收。
- **一条底线**：材料不合格不得使用，隐蔽未验收不得浇筑，强度未达要求不得拆模。

## 水泥与砂：四个指标和三组百分数

<Steps title="结构混凝土用材的第一组控制点" :steps="[

  { t: '砂的坚固性', d: '坚固性指标不应大于 10%；有抗渗、抗冻、抗腐蚀、耐磨等特殊要求时，坚固性不应大于 8%' },
  { t: '砂的含泥量', d: '特殊要求混凝土含泥量和泥块含量分别不应大于 3.0% 和 1.0%；高强混凝土分别不应大于 2.0% 和 0.5%' },
  { t: '砂的氯离子', d: '钢筋混凝土用砂氯离子含量不应大于 0.03%，预应力混凝土用砂不应大于 0.01%；海砂必须经过净化处理' }
]" />

> 记忆抓手：砂的坚固性 **10% → 8%**，含泥量 **3.0%/1.0% → 2.0%/0.5%**，氯离子 **0.03% → 0.01%**，越严的场合数字越小。

<template #notes>

这一页四组数字容易混。记法：普通砂坚固性 10%，一有特殊要求就降到 8%；含泥量普通是 3.0 和 1.0，高强降到 2.0 和 0.5；氯离子钢筋混凝土 0.03%、预应力 0.01%，因为预应力钢丝更怕腐蚀。机制砂还要看石粉的亚甲蓝值和流动比。

## 钢筋与接头：延伸率和三个接头等级

<CompareCard title="钢筋机械连接接头的实测极限抗拉强度" :cols="['I 级', 'II 级', 'III 级']" :rows="[

  { k: '控制对象', v: ['最高的接头等级，强调断在钢筋而不是连接件', '不低于钢筋极限抗拉强度标准值', '按钢筋屈服强度标准值的 1.25 倍控制'] }

- **最大力总延伸率**（表 3-2）：HPB300 为 **10.0%**；HRB400、HRB500 为 **7.5%**；HRB400E、HRB500E 为 **9.0%**；RRB400 为 **5.0%**；CRB550 为 **2.5%**；CRB600H 为 **5.0%**。

## 钢筋进场：三个试件、一个公式、三档偏差

<p class="dk-lead">钢筋、成型钢筋进场时，应抽取试件作<strong>屈服强度、抗拉强度、伸长率和重量偏差</strong>检验；盘卷钢筋调直后还要做力学性能和重量偏差检验。</p>

<Steps title="重量偏差检验怎么做" :steps="[
  { t: '取样数量', d: '对 3 个试件先进行重量偏差检验，再取其中 2 个试件进行力学性能检验' },
  { t: '计算公式', d: 'Δ =（W − W₀）/ W₀ × 100%；W 为 3 个调直钢筋试件实际重量之和，W₀ 为每米理论重量与 3 个试件长度之和的乘积' },
  { t: '试件要求', d: '切口应平滑并与长度方向垂直，长度不应小于 500mm；长度和重量量测精度分别不应低于 1mm 和 1g' },
  { t: '允许偏差', d: '公称直径 6～12mm 为 ±5.5%；14～20mm 为 ±4.5%；22～50mm 为 ±3.5%' }
]" />

<template #notes>

顺序要记牢：先 3 个试件全做重量偏差，再从里面取 2 个做力学性能，不是各取各的。公式里分母是理论重量 W₀，不是实际重量。三档偏差随着直径变粗而收紧，6～12 是 5.5，14～20 是 4.5，22～50 是 3.5。

## 钢筋加工与安装：弯弧、弯钩、保护层

<CompareCard title="钢筋弯折与弯钩的关键尺寸（d 为钢筋直径）" :cols="['弯弧内直径', '箍筋弯钩', '保护层']" :rows="[
  { k: '一般要求', v: ['光圆钢筋 ≥2.5d；335MPa、400MPa 级带肋钢筋 ≥4d；箍筋弯折处尚不应小于纵向受力钢筋直径', '一般结构构件弯折角度 ≥90°，平直段 ≥5d；有抗震设防要求或设计专门要求时 ≥135°，平直段 ≥10d', '受力钢筋保护层厚度合格点率应达到 90% 及以上'] },
  { k: '特殊规定', v: ['500MPa 级带肋钢筋：直径小于 28mm 时 ≥6d，直径 28mm 及以上时 ≥7d', '圆形箍筋搭接长度 ≥受拉锚固长度，末端弯钩 ≥135°；梁、柱复合箍筋中的单肢箍两端弯钩均 ≥135°', '不得有超过验收规范表 5.5.3 中数值 1.5 倍的尺寸偏差'] }
]" />

- 光圆钢筋末端做 **180° 弯钩** 时，弯钩平直段长度不应小于钢筋直径的 **3 倍**。
- 钢筋加工采用**尺量**检验：同一设备加工的同一类型钢筋，每工作班抽查不应少于 **3 件**。

<template #notes>

弯弧内直径按强度等级递进：光圆 2.5d，335/400 带肋 4d，500 带肋 6d 或 7d（以 28mm 为界）。箍筋弯钩看两个数：一般 90° 配 5d，抗震 135° 配 10d。保护层是 90% 合格点率加「不得超过 1.5 倍偏差」双控，这两条要一起答。

</template>

## 混凝土工程：五条现场纪律

<p class="dk-lead">混凝土工程的质量，一半在配合比，一半在现场有没有人乱来。</p>

- **预拌混凝土**：进场全数检查质量证明文件，质量应符合《预拌混凝土》GB/T 14902 的规定。
- **氯离子与碱含量**：应符合《混凝土结构设计标准》GB/T 50010 和设计要求，检查原材料试验报告与计算书，同一配合比检查不少于一次。
- **严禁加水**：运输、输送、浇筑过程中严禁加水；散落的混凝土严禁用于结构浇筑。
- **观察拌合物**：全数观察拌合状态，混凝土拌合物不应有离析现象。
- **后浇带与施工缝**：留设位置符合设计要求，留设及处理方法符合施工方案，全数观察检查。

<template #notes>

这五条都是「现场看得见」的纪律，考试常出「严禁」类判断题。特别注意两句「严禁」：过程中严禁加水，散落的混凝土严禁用于结构浇筑。后浇带的位置是设计定的，处理方法是方案定的，监理两头都要对。

</template>

</Slide>

## 拆模强度与强度评定：两张表一条分界线

<CompareCard title="底模拆除时的混凝土强度要求（设计无具体要求时）" :cols="['构件与跨度', '达到设计强度等级值的百分率']" :rows="[
  { k: '板（跨度 ≤2m）', v: ['≥50%'] },
  { k: '板（跨度 >2m，≤8m）', v: ['≥75%'] },
  { k: '板（跨度 >8m）', v: ['≥100%'] },
  { k: '梁、拱、壳（跨度 ≤8m）', v: ['≥75%'] },
  { k: '梁、拱、壳（跨度 >8m）', v: ['≥100%'] },
  { k: '悬臂结构（不限跨度）', v: ['≥100%'] }
]" />

- **分界线**：样本容量 **10 组**。小于 10 组用非统计方法；不少于 10 组用统计方法。
- **统计方法**：连续 3 组试件时，平均值 ≥ f<sub>cu,k</sub> + 0.7σ₀，最小值 ≥ f<sub>cu,k</sub> − 0.7σ₀；C20 及以下最小值还应 ≥0.85f<sub>cu,k</sub>，高于 C20 应 ≥0.90f<sub>cu,k</sub>。
- **非统计方法**：平均值 ≥ λ₃f<sub>cu,k</sub>，最小值 ≥ λ₄f<sub>cu,k</sub>；低于 C60 时 λ₃ 取 1.15，C60 及以上取 1.10，λ₄ 均取 0.95。

<template #notes>

拆模表抓三个 100%：板跨度大于 8m、梁拱壳跨度大于 8m、悬臂结构。强度评定先看组数：10 组是分界。统计方法里 σ₀ 计算值小于 2.5N/mm² 时取 2.5；检验期不少于 60d、不大于 90d，前一检验期样本容量不少于 45。这些细节容易出选择题。

</template>

## 小结：现浇混凝土的三句话

<p class="dk-lead">材料看限值，工序看卡口，验收看判据。</p>

- **用材**：水泥四项指标；砂坚固性 10%/8%、氯离子 0.03%/0.01%；粗骨料坚固性 12%/8%；水溶性氯离子按环境 0.30%～0.10%，预应力 0.06%。
- **施工**：模板起拱 1/1000～3/1000、后浇带支架独立；钢筋先 3 个试件做重量偏差再取 2 个做力学；预应力张拉设备标定不超过半年；混凝土严禁加水。
- **验收**：底模拆除按跨度取 50%/75%/100%；强度评定以 10 组为界分统计与非统计；现浇结构不应有严重缺陷和影响使用的尺寸偏差。
