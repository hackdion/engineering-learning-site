## 装配式：把工地搬进工厂，再把节点搬回工地

<p class="dk-lead">装配式建筑主要表现为<strong>钢结构部品部件</strong>和<strong>预制混凝土构件</strong>工厂化生产，施工现场连接组装和安装。</p>

- **监理重点**：钢结构部品部件和预制混凝土构件的**连接、组装和安装**施工。
- **钢结构线**：吊装方案审查 → 原材料及成品验收 → 制作与安装 → 预拼装 → 安装精度。
- **混凝土线**：施工准备 → 构件安装与临时支撑 → 构件连接与后浇混凝土 → 隐蔽工程验收。
- **一条共性**：工厂做得好不等于现场装得好，质量风险集中在**节点**。

<template #notes>

这一节两条线要分清：钢结构是「工厂做构件、现场用焊缝和高强螺栓连」，装配式混凝土是「工厂做构件、现场用灌浆和后浇混凝土连」。两条线的风险点都在节点，不在构件本身。先建立这个判断，再记具体数字。

</template>

</Slide>

## 构件安装：竖向看垂直度，水平看平整度

<CompareCard title="预制构件就位后的校核与调整" :cols="['构件类型', '校核与调整内容']" :rows="[
  { k: '竖向构件', v: ['预制墙板、预制柱安装后，对安装位置、安装标高、垂直度进行校核与调整'] },
  { k: '水平构件', v: ['叠合构件、预制梁安装后，对安装位置、安装标高进行校核与调整；相邻预制构件的平整度、高低差、拼缝尺寸也要校核'] },
  { k: '装饰类构件', v: ['对装饰面的完整性进行校核与调整'] },
  { k: '临时支撑', v: ['临时固定措施、临时支撑系统应具有足够的强度、刚度和整体稳固性，应进行验算'] }
]" />

- **竖向临时支撑**：不宜少于 **2 道**；上部斜支撑的支撑点距板底不宜小于构件高度的 **2/3**，且不应小于 **1/2**；斜支撑与构件可靠连接。
- **水平临时支撑**：首层架体地基平整坚实、宜硬化；竖向连续支撑层数不宜少于 **2 层**且上下层宜对准；叠合板预制底板下部支架宜选用定型独立钢支柱。

<template #notes>

安装校核按「竖向、水平、装饰」三类记：竖向管位置、标高、垂直度；水平管位置、标高，外加相邻构件的平整度、高低差、拼缝；装饰类只管装饰面完整性。临时支撑竖向上部斜支撑的 2/3 和 1/2 是一组常考数字，注意「不宜小于 2/3、不应小于 1/2」的措辞差别。

</template>

## 小结：装配式的两句话

<p class="dk-lead">钢结构的质量在焊缝和螺栓，装配式的质量在灌浆和后浇。</p>

- **钢结构**：吊装方案看顺序、起重和复杂结构计算；焊接先评定工艺；高强螺栓终拧后 1h～48h 检查，扭剪型漏拧不超过 5%；预拼装试孔器 85% 与 100% 双控。
- **装配式混凝土**：先试安装再定方案；竖向支撑不少于 2 道、斜支撑 2/3 与 1/2；连接钢筋偏位不超过 3mm，严禁切割；后浇混凝土和灌浆料达强度才拆支撑。
- **共同点**：连接节点是隐蔽工程，浇筑或封闭前必须验收。
