## 安装工程：三条线，一套验收逻辑

<p class="dk-lead">建筑安装工程一般包括给水排水与采暖工程、通风与空调工程、建筑电气与智能化工程。</p>

- **给排水与采暖**：管道标识、阀门试验、套管与支架、系统试压与冲洗。
- **通风与空调**：风管制作与安装、设备安装、空调水系统、防腐绝热。
- **电气与智能化**：电压区段、配电箱柜与用电设备、智能建筑 120h 试运行、检验检测。
- **共同逻辑**：先材料设备进场验收，再工序交接检查，最后系统试验与检测。

## 通风空调：风管制作的两条禁令

<p class="dk-lead">风管质量按材料、加工工艺、系统类别分别验收，内容包括材质、规格、强度、严密性能和成品观感质量。</p>

- **连接方式**：镀锌钢板及含有各类复合保护层的钢板应采用**咬口连接或铆接，不得采用焊接连接**。
- **材料证明**：板材、型材及其他主要材料进场验收，提供出厂检验合格证明；成品风管提供产品合格证书或进行强度、严密性现场复验。
- **净化空调风管**：设计无要求时宜采用镀锌钢板，镀锌层厚度不应小于 **100g/m²**；采用非金属风管时应采用**不燃或难燃材料**。
- **安装时机**：净化空调系统风管及部件安装，应在该区域建筑地面工程施工完成且室内具有防尘措施的条件下进行。

<template #notes>

风管制作最常考的是「镀锌钢板不得焊接」，只能咬口或铆接，因为焊接会破坏镀锌层。净化空调的两个数：镀锌层 100g/m²，非金属风管必须不燃或难燃。安装时机强调「地面完成＋防尘措施」，防止土建灰尘进入净化系统。

</template>

</Slide>

## 电气：三个电压区段与持证上岗

<CompareCard title="电气设备、器具和材料的额定电压区段" :cols="['区段', '交流', '直流']" :rows="[
  { k: '特低压', v: ['50V 及以下', '120V 及以下'] },
  { k: '低压', v: ['50V～1.0kV（含 1.0kV）', '120V～1.5kV（含 1.5kV）'] },
  { k: '高压', v: ['1.0kV 以上', '1.5kV 以上'] }

- **人员**：安装电工、焊工、起重吊装工和电力系统调试等人员应**持证上岗**。
- **计量器具**：安装和调试用各类计量器具应**检定合格**，使用时应在检定有效期内。
- **间接接触防护**：采用Ⅱ类设备、电气隔离、特低电压供电、将设备安装在非导电场所内、设置不接地的等电位联结。

<template #notes>

电压区段记三个分界：交流 50V、1.0kV，直流 120V、1.5kV。注意低压是「含 1.0kV」「含 1.5kV」，边界值归低压。人员持证和计量器具检定是电气施工质量管理的两条前置条件，缺一条后面的数据都不可信。

## 小结：安装工程的三条线

<p class="dk-lead">水看坡度与试压，风看连接与严密，电看接地与检测。</p>

- **给排水采暖**：四色标识；阀门强度 1.5 倍、严密性 1.1 倍；套管 20mm/50mm；热水试压顶点不小于 0.3MPa；交付前冲洗消毒。
- **通风空调**：镀锌钢板不得焊接；净化风管镀锌层不小于 100g/m²；先严密性检验再绝热；防腐不低于 5℃。
- **电气智能化**：交流 50V/1.0kV、直流 120V/1.5kV 分区段；配电箱高出地坪 200mm；智能建筑连续试运行 120h；10kg 以上灯具 5 倍荷载 15min。
