## 防水与节能：一个防渗，一个防漏能

<p class="dk-lead">建筑防水包括地下、地面、墙面、屋面及其构造防水；建筑节能覆盖墙体、幕墙、门窗、屋面、地面、供暖、通风空调、冷热源、配电照明和监测控制。</p>

- **防水线**：防水材料质量控制 → 施工质量控制（基本要求、地下、屋面、外墙、室内、道桥、蓄水）→ 验收核验资料。
- **节能线**：见证取样 → 隐蔽工程验收 → 监测与控制节能工程检查验收。
- **一个共同前提**：材料性能先达标，施工工艺才有意义。
- **一个共同方法**：看不见的部位，靠**复验报告**和**隐蔽验收记录**说话。

这一节两条线：防水和节能。它们的结构很像，都是「材料—施工—验收」，而且都高度依赖复验和隐蔽记录。先记框架，再往里填数字。防水关注「水能不能渗进去」，节能关注「能效指标和保温构造对不对」。

## 施工基本要求：专项方案与搭接宽度

<CompareCard title="防水卷材最小搭接宽度（表 3-11）" :cols="['卷材类型', '搭接方式与宽度']" :rows="[
  { k: '聚合物改性沥青类', v: ['热熔法、热沥青 ≥100mm；自粘搭接（含湿铺）≥80mm'] },
  { k: '合成高分子类', v: ['胶粘剂、粘结料 ≥100mm；胶粘带、自粘胶 ≥80mm'] },
  { k: '合成高分子类焊接', v: ['单缝焊 ≥60mm，有效焊接宽度不应小于 25mm；双缝焊 ≥80mm，有效焊接宽度 10×2＋空腔宽'] },
  { k: '塑料防水板', v: ['双缝焊 ≥100mm，有效焊接宽度 10×2＋空腔宽'] }
]" />

- 施工前应编制**防水专项施工方案**；雨天、雪天或**五级及以上大风**不应进行露天防水施工。
- 材料进场提供合格证、质量检验报告、使用说明书、进场复验报告；卷材复验报告应包含**无处理时接缝剥离强度和搭接缝不透水性**。
- 基层验收合格后方可施工；阴阳角部位做成**圆弧状或倒角**；防水层验收合格后才能进行下一道工序。

<template #notes>

搭接宽度按「热熔 100、自粘 80、单缝焊 60、双缝焊 80、塑料板双缝焊 100」记。焊接还要看有效焊接宽度：单缝不小于 25mm，双缝是 10×2 加空腔宽。天气条件是雨雪和五级及以上大风不得露天施工。卷材复验报告必须含接缝剥离强度和搭接缝不透水性。

## 防水验收：八类资料一件不能少

<p class="dk-lead">防水工程施工完成后应按规定程序和组织方式进行质量验收，验收时应核验下列文件和记录。</p>

- **设计文件**：设计施工图、图纸会审记录、设计变更文件。
- **材料证明**：产品合格证、质量检验报告、进场材料复验报告。
- **施工依据**：施工方案。
- **过程记录**：隐蔽工程验收记录；工程质量检验记录、渗漏水处理记录。
- **试验记录**：淋水、蓄水或水池满水试验记录。
- **收尾**：施工记录；质量验收记录。

<Reveal label="为什么「渗漏水处理记录」也算验收资料？">

因为防水工程允许出现个别渗漏点并处理后验收，但**处理过程必须留痕**：哪里渗、怎么处理、处理后是否复查合格。没有这份记录，就无法判断渗漏是已闭合还是被掩盖。

</Reveal>

<template #notes>

八类资料按「设计、材料、方案、过程、试验、收尾」记。最容易被忽略的是「渗漏水处理记录」——防水不是绝对不能渗，而是渗了必须处理并记录。验收看的是闭合证据，不是一句「已处理」。

</template>

</Slide>

## 小结：防水看闭合，节能看报告

<p class="dk-lead">防水的成败在节点和成品保护，节能的成败在复验报告和隐蔽记录。</p>

- **防水材料**：耐久性匹配设计年限；防水混凝土 C25、抗渗提高 0.2MPa、养护 14d；涂料厚度 1.5mm/2.0mm；卷材搭接 100/80/60/80/100。
- **防水施工**：雨雪五级风不露天；短边错缝 500mm、双层错开 1/3、同层不超 3 层；明挖桩头 300mm、暗挖缓冲层 50mm；屋面 30% 防滑、道桥 80% 强度。
- **节能**：五件套性能复验；三项指标同一报告；门窗按气候区分档；隐蔽验收看基层、厚度、固定、热桥、隔气；监测控制连续运行 120h。
