## 一条主线：先会抽，再会看

<p class="dk-lead">抽样检验和质量数据统计分析，可以反映产品的<strong>质量特征、质量状态和质量趋势</strong>，为生产状态判断、质量趋势预测和质量控制提供依据。</p>

- **前半：抽样**。总体与样本、特征值、波动原因、检验批、四种随机抽样、抽样方案与两类风险。
- **后半：七种工具**。调查表、分层法、排列图、因果分析图、直方图、控制图、相关图。
- **两条底线**：抽样必须随机，判断必须看分布而不是看单个数据。
- **一句提醒**：这节的公式都能查，真正要记的是**每个指标说明什么问题**。

## 总体、个体、样本与检验批

<p class="dk-lead">总体也称母体，是所研究对象的全体；个体是组成总体的基本元素；样本是从总体中随机抽取、用于推断总体的那部分个体。</p>

- **有限总体与无限总体**：一批产品中的个体数 N 有限，是有限总体；把整个生产过程过去、现在和将来的产品视为总体，N 无限，是无限总体。
- **样本容量**：被抽中的个体称样品，样品的数目称样本容量，用 n 表示。
- **检验批**：提供检验的一批产品称检验批，其中包含的单位产品数量称批量。
- **构成检验批的条件**：在基本相同条件下、大约相同时期内制造的**同形式、同等级、同种类、同尺寸、同成分**的单位产品。

<template #notes>

这里要分清三组词：总体和样本是统计概念，检验批和批量是检验概念。检验批的六个「同」是判断能不能放在一批的依据，本质是排除系统性差异。批量大小没有硬性规定：质量不稳定的宜小批量，质量稳定的可以大一些，但过大一旦误判损失也大。

</template>

</Slide>

## 正常波动与异常波动

<CompareCard title="两类波动原因的分工" :cols="['对比项', '偶然性原因', '系统性原因']" :rows="[
  { k: '变化幅度', v: ['人机料法环的微小变化，随机发生', '因素发生较大变化，如违反操作规程、设备故障或过度磨损、原材料规格显著差异'] },
  { k: '能否消除', v: ['不可避免、难以测量和控制，经济上不值得消除', '特征明显、容易识别，应及时排除'] },
  { k: '波动性质', v: ['正常波动，属于允许偏差、允许位移范畴', '异常波动，数据离散过大或与标准较大偏离'] },
  { k: '后果', v: ['一般不会造成废品，生产过程正常稳定', '次品、废品产生，生产过程不正常'] }
]" />

<p class="dk-lead">质量数据的规律是<strong>中间高、两端低、左右对称</strong>，一般服从正态分布：计量值服从正态分布，计件值服从二项分布，计点值服从泊松分布。</p>

<template #notes>

判断正常还是异常，尺子是「是否在质量标准允许范围内」，不是「有没有波动」。任何生产都有波动，偶然原因造成的波动不用管；系统性原因造成的波动必须停线排查。三种分布对应三类数据：计量值、计件值、计点值，考试常把二项和泊松对调来设错。

</template>

## 为什么全数检验做不到

<Steps title="必须采用抽样检验的五条理由" :steps="[

  { t: '成本不经济', d: '检验费用很高、产品本身价值又不大时，全数检验在经济上不合算' },
  { t: '时间不允许', d: '有些情况下来不及对一件件产品进行全数检验' },

  { t: '抽样本身更可靠', d: '抽样不受检验人员主观意愿支配，每个个体被抽中概率相同，样本分布均匀、有代表性，还节省人力物力财力时间' }
]" />

<template #notes>

五条理由按「不能检、检不起、来不及、检不准、抽更准」记。第四条最反直觉，也最常考：全数检验不等于 100% 合格。第五条是抽样检验的正面价值，注意它的前提是随机——不随机的抽样，代表性无从谈起。

## 一次抽样与二次抽样

<CompareCard title="计数型抽样检验方案" :cols="['方案', '参数', '判定规则']" :rows="[
  { k: '一次抽样', v: ['(N, n, C)，三个参数', '抽 n 件，不合格数 d ≤ C 判合格；d > C 判不合格'] },
  { k: '二次抽样', v: ['(N, n₁, n₂, C₁, C₂)，五个参数', 'd₁ ≤ C₁ 判合格；d₁ > C₂ 判不合格；C₁ < d₁ ≤ C₂ 时再抽 n₂，用 d₁ + d₂ 与 C₂ 比较'] },
  { k: '多次抽样', v: ['允许三次以上抽样才作判断', '同样规定最多抽样次数'] }
]" />

<p class="dk-lead">例：N = 1000、n₁ = 36、n₂ = 59、C₁ = 0、C₂ = 3 时，第一次发现 0 件不合格即判合格；超过 3 件判不合格；1～3 件则继续抽 59 件，累计不超过 3 件判合格。</p>

<template #notes>

二次抽样的五个参数要能对上号：两个样本量、两个判定数。判定规则容易记反：第一次的不合格数落在 C₁ 和 C₂ 之间才是「说不清」，需要继续抽；小于等于 C₁ 直接合格，大于 C₂ 直接不合格。中间区域是二次抽样的价值所在，也是考试最爱设问的地方。

</template>

</Slide>

## 小结：抽样靠随机，判断靠分布

<p class="dk-lead">样本要随机，指标看用途，图形看形状，控制看界限。</p>

- **抽样基础**：总体与样本、有限与无限总体、检验批六个「同」；均值与中位数看中心，极差、标准差、变异系数看离散。
- **抽样方法**：简单、系统、分层、多阶段；系统抽样以 [N/n] 为间隔，分层按比例分配样本量。
- **方案与风险**：一次 (N, n, C)，二次五个参数；α 弃真 1%～5%，β 存伪 5%～10%；GB 50300 主控项目两个 5%，一般项目 5% 与 10%。
- **七种工具**：调查表与分层打底，排列图分 ABC，因果图找人机料法环，直方图看形状，控制图判稳定，相关图看关系。
