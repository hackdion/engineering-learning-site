## 材料进场：两条腿走路

<p class="dk-lead">工程采用的主要材料、半成品、成品、构配件等进场应有<strong>性能检验报告</strong>；涉及安全、节能、环境保护和主要使用功能的重要材料、产品应按各专业规定进行<strong>复验</strong>，并应经项目监理机构检查认可。</p>

- **第一条腿：查文件**。出厂合格证、质量证明书、型式检验报告、第三方检测报告。
- **第二条腿：抽样复验**。按批取样、按标准试验、按判据下结论。
- **四条主线**：钢筋及钢材、混凝土及砌体材料、防水与防火材料、装饰装修块材。
- **一句提醒**：这一节考的是「批量 + 试样 + 判据」三件套，不是试验操作细节。

<template #notes>

开场先立规矩：进场检验不是监理替施工单位做试验，而是查文件、见证取样、审核报告。这一节的数字特别多，复习时按四条主线走，每条主线只记三样——多少吨一批、取几个试样、合格判据是什么。试验步骤了解即可，考试很少考操作细节。

- **检查数量**：按进场批次和产品的抽样检验方案确定。

## 拉伸试验：标距、加荷与三个公式

<Steps title="钢筋拉伸试验的关键控制" :steps="[
  { t: '试样制备', d: '从钢筋母材截取，避开热影响区或弯曲部位；按 GB/T 228.1 加工，砂纸去毛刺、酒精清洁表面' },
  { t: '试样尺寸', d: '直径 6～10mm 标距 50mm；12～20mm 标距 100mm；22～40mm 标距 200mm；平行段宽度公差分别为 ±0.1、±0.2、±0.5mm' },
  { t: '试验机要求', d: '按 GB/T 16825.1 校准，准确度 1 级或优于 1 级；试验荷载范围应在最大荷载的 20%～80%' },
  { t: '加载与读数', d: '上夹头升起 10mm 后固定试件，预加载约 1% 预期最大力消除间隙；指针停转时的恒定荷载或不计初始瞬时效应的最小荷载为屈服荷载 Nvk；拉断时最大荷载为 Nmst' },
  { t: '结果计算与异常处理', d: '屈服强度 fvk = Nvk/S0，抗拉强度 fmst = Nmst/S0，断后伸长率 δ = [(Lu − L0)/L0] × 100%；断在标距端点或标距处结果无效应重做' }
]" />

<template #notes>

标距这组数字按「50—100—200」随直径递增记，公差也随直径放宽。试验机看两个数：准确度 1 级、荷载在最大荷载的 20%～80%。三个公式的分母都是原始截面积 S0，不是断后截面积。断在标距端点或标距处必须重做，断在标距之外而伸长率合格可判合格。

</template>

## 弯曲与接头：弯心、支辊与压痕

<Steps title="钢筋弯曲试验与接头检验" :steps="[
  { t: '确定参数', d: '确定试件长度与弯心直径；支辊间距 = 弯心直径 + 两个钢筋直径 + 间隙 + 支辊半径；确定加荷速度' },
  { t: '冷弯试验', d: '在规定直径的弯心上弯到 90° 或 180°，检查有无裂缝、鳞落、断裂；既可检原材料，也可检焊接接头' },
  { t: '试验温度', d: '一般在 10～35℃ 进行；对温度要求严格的试验，在（23 ± 5）℃ 下进行' },
  { t: '机械连接', d: '螺纹接头检验拧紧扭矩值，挤压接头量测压痕直径，结果应符合《钢筋机械连接技术规程》JGJ 107' },
  { t: '接头试件来源', d: '机械连接接头、焊接接头的力学性能和弯曲性能应符合标准，接头试件应从工程实体中截取' }
]" />

<template #notes>

弯曲试验考三个词：弯心直径、支辊间距、弯到 90° 或 180°。支辊间距的公式看着长，其实是「弯心 + 两倍钢筋直径 + 间隙 + 支辊半径」，理解成给钢筋留出弯曲空间就不会记混。接头试件必须从工程实体截取，不能用同批材料另做，这是保证代表性的关键。

</template>

## 水泥：四项指标与 5.0mm 的判据

<Steps title="水泥进场检验与主要性能试验" :steps="[
  { t: '进场检验', d: '结构混凝土用水泥主要控制凝结时间、安定性、胶砂强度和氯离子含量；进场时对强度、安定性和凝结时间进行检验' },
  { t: '凝结时间', d: '按标准稠度用水量制备净浆，养护 30min 后第一次测量；临近初凝每 3～5min 测一次，试针沉入至距底板 3～5mm 判初凝；临近终凝每 10～15min 测一次，试针沉入 0.5mm 判终凝' },
  { t: '安定性', d: '有试饼法和雷氏夹法，以雷氏夹法为准；养护 22～26h 后测针尖间距，沸煮 175～185min，冷却后再测' },
  { t: '合格判定', d: '两次针尖间距平均值小于或等于 5.0mm 判合格；大于 5.0mm 应复检，复检仍大于 5.0mm 判不合格' },
  { t: '强度', d: '按 GB/T 17671 制备胶砂试体，养护至规定龄期后做抗折和抗压强度试验' }
]" />

<template #notes>

水泥这一页记「四项指标、两个沉入值、一个 5.0mm」。初凝看试针沉到距底板 3～5mm，终凝看沉入 0.5mm，这两个数容易混。安定性以雷氏夹法为准，5.0mm 是合格线，超过要复检而不是直接判废。不同品种水泥不得混合使用，这是砌体结构用水泥的硬规定。

</template>

</Slide>

## 混凝土：拌合物看稠度，硬化后看抗压

<Steps title="普通混凝土性能试验" :steps="[
  { t: '拌合物稠度', d: '稠度用坍落度、维勃稠度或扩展度表示；坍落度试验宜用于骨料最大公称粒径不大于 40mm、坍落度不小于 10mm 的拌合物；维勃稠度宜用于 5～30s，按 V0～V4 分级' },

  { t: '成型与养护', d: '成型后覆盖表面，在（20 ± 5）℃ 静置 1～2 昼夜；编号拆模后立即放入标准养护室' },

## 小结：批量、试样、判据

<p class="dk-lead">材料进场先查报告，再按批次取样，最后按判据下结论。</p>

- **钢筋与钢材**：进场查屈服、抗拉、伸长率、弯曲、重量偏差；抗震强屈比 ≥1.25、超强比 ≤1.30、总伸长率 ≥9%；钢丝 60t、钢绞线 100t、热轧钢筋 60t 加 40t 增量。
- **水泥与骨料**：水泥控制凝结时间、安定性、胶砂强度、氯离子，安定性 5.0mm；细骨料筛分析 500g、含泥量 400g、泥块 200g；粗骨料按粒径定试样量。
- **混凝土与砂浆**：立方体 150mm、三件一组，加荷 0.3～0.5、0.5～0.8、0.8～1.0MPa/s；砂浆 70.7mm、K 取 1.35，验收平均 1.10 倍、最低 85%。
- **防水与防火**：涂料成膜 >2mm、低温柔度 −25℃；卷材不透水 0.2MPa/30min；防火分 A、B1、B2、B3 四级。
