## 验收四层：单位、分部、分项、检验批

<p class="dk-lead">工程施工质量验收按<strong>结构分解</strong>的原则划分层次，从大到小依次是<strong>单位工程 → 分部工程 → 分项工程 → 检验批</strong>。</p>

- **划分方案由谁定**：施工前由施工单位制定单位、分部、分项和检验批的划分方案，监理单位审核通过后实施；现场与规定不同时，由建设单位组织监理、施工单位共同确定。
- **检验批最小**：检验批是施工质量验收的最小单位，是分项、分部、单位工程质量验收的基础。
- **过程与竣工**：涉及施工过程质量验收和竣工质量验收两个层面。
- **一句主线**：先划层次，再逐层验收，下道工序建立在上一批验收合格的基础上。

<template #notes>

这一节先立骨架：验收是一个自下而上的递进过程。划分方案施工前由施工单位制定、监理审核，这一点常考「谁制定、谁审核」。记住最小单位是检验批，它是一切验收的基础，后面每一层都是对下一层的汇总。考试先判断问的是哪一层，再想「谁组织、谁参加」。

</template>

<template #notes>

主控项目和一般项目是检验批验收的核心概念。主控项目全部合格，没有商量余地；一般项目按标准判定，允许存在一定数量不合格点，但不能有严重缺陷。两个概率容易混：错判 α 主控和一般都不超 5%；漏判 β 主控 5%、一般放宽到 10%。先分清「错判」和「漏判」的语义再记数字。

  { t: '验收时机', d: '隐蔽工程完成后、被覆盖或掩盖前必须进行质量验收，合格后方可继续施工' },
  { t: '组织者', d: '隐蔽工程可能是检验批、分项或子分部工程，按相应层级要求验收；为检验批时由专业监理工程师组织' },
  { t: '留存影像', d: '验收时宜留存检查、验收过程的照片、影像等资料' },

]" />

<template #notes>

隐蔽工程的核心是「时机」：必须在下道工序覆盖之前验收，合格才准继续。它可能是一个检验批，也可能是分项或子分部，所以组织者要按它属于哪一层来定。分项工程验收的实质是汇总统计，不是重新检验，合格条件就是所含检验批都合格且资料齐全。

</template>

</Slide>

## 检验批不合格：三种处理出路

<Steps title="检验批施工质量不符合验收标准时的处理" :steps="[

  { t: '检测达到设计要求', d: '经有资质的检测机构检测能够达到设计要求的检验批，应予以验收' },
  { t: '原设计核算认可', d: '检测达不到设计要求，但经原设计单位核算认可能够满足安全和使用功能的检验批，应予以验收' },

## 小结：层层递进，各层有人

<p class="dk-lead">层次划得清，组织者对得上，不合格有出路。</p>

- **层次**：单位工程 → 分部工程 → 分项工程 → 检验批；检验批最小，是验收基础；建筑工程十大分部。
- **组织者**：检验批、分项由专业监理工程师组织；分部由总监理工程师组织；单位工程由建设单位项目负责人组织。
- **验收要求**：主控项目全部合格；一般项目按标准判定；错判 α 不超 5%，漏判 β 主控 5%、一般 10%。
- **不合格出路**：返工返修重验、有资质检测合格、原设计核算认可；返修加固仍不满足安全或重要使用要求的，严禁验收。
