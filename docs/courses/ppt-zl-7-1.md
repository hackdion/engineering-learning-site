## 质量缺陷：定义与三种分类

<p class="dk-lead">工程质量缺陷是指工程不符合国家或行业的有关技术标准、设计文件及合同中对质量或使用的要求。</p>

- **按严重程度**：严重缺陷、一般缺陷——看是否对受力性能或使用性能有决定性影响。
- **按缺陷性质**：结构安全性、功能适用性、感官性、耐久性、环境安全性五类。
- **按出现阶段**：施工中的质量缺陷、完工后的质量缺陷。
- **监理动作**：巡视检查已完工程、签发质量问题通知单，调查原因、审查处理方案，跟踪处理过程、验收处理结果。

<template #notes>

先立定义和三条分类线索。定义的关键词是「不符合技术标准、设计文件、合同要求」三选一都算缺陷。三种分类方式都要记：严重/一般看「决定性影响」，性质看「安全、适用、感官、耐久、环境」，阶段看「施工中/完工后」。监理的动作是一个闭环：发现→通知→调查→审方案→跟踪→验收。

</template>

</Slide>

## 严重缺陷与一般缺陷：一条分界线

<CompareCard title="按严重程度划分的质量缺陷" :cols="['严重缺陷', '一般缺陷']" :rows="[
  { k: '判断标准', v: ['对结构构件的受力性能或安装使用性能有决定性影响', '对受力性能或安装使用性能无决定性影响'] },
  { k: '典型例子', v: ['地基基础不均匀沉降导致建筑物倾斜、主体结构混凝土强度严重不足', '混凝土表面轻微蜂窝麻面、墙面局部裂缝'] },
  { k: '验收态度', v: ['现浇结构外观质量不应有严重缺陷，已出现的应出技术处理方案并重新验收', '已出现的一般缺陷按技术处理方案处理并重新验收'] }
]" />

> 判别的尺子不是面积大小，而是「对受力性能和使用性能的影响是否决定性」。

<template #notes>

严重缺陷和一般缺陷的分界就一句话：有没有「决定性影响」。地基基础不均匀沉降、主体结构强度严重不足是严重缺陷；轻微蜂窝麻面、局部裂缝是一般缺陷。处理要求也不同：严重缺陷要由施工单位提技术处理方案，涉及裂缝、连接部位或影响结构安全的还要设计单位认可；一般缺陷按技术处理方案处理即可，两者处理后都要重新验收。

</template>

</Slide>

## 按性质分类：五类缺陷

<Steps title="按缺陷性质划分的五类质量缺陷" :steps="[
  { t: '结构安全性缺陷', d: '可能直接导致人身财产损害、引发安全事故，如地基、基础、主体结构的质量缺陷' },
  { t: '功能适用性缺陷', d: '导致工程丧失或影响正常使用功能，如给水排水系统漏水、电气系统故障' },
  { t: '感官性缺陷', d: '不影响安全性及使用功能的外观缺陷，如混凝土表面的蜂窝、麻面、裂缝、平整度' },
  { t: '耐久性缺陷', d: '影响结构或构件抵抗自然和人为因素作用的能力，如钢筋锈蚀、混凝土碳化' },
  { t: '环境安全性缺陷', d: '室内空气质量问题或对周边环境的影响，如噪声、振动、辐射等' }
]" />

<template #notes>

五类按性质划分：结构安全、功能适用、感官、耐久、环境安全。判断时看「后果落在哪个维度」——威胁人身财产安全的是结构安全，影响正常使用的是功能适用，只看外观的是感官，影响寿命的是耐久，影响周边环境的是环境安全。钢筋锈蚀、混凝土碳化属于耐久性，这是易错点。

</template>

</Slide>

## 地基基础不均匀沉降：四类成因

<Steps title="建筑地基基础不均匀沉降的主要原因" :steps="[
  { t: '地质因素', d: '土层分布不均（软弱下卧层、透镜体、孤石、填土区、古河道、暗浜、溶洞）；基岩起伏变化；地下水变化（水位升降、潜蚀、管涌）' },
  { t: '荷载因素', d: '上部荷载分布不均（大跨度、大悬挑、重型设备集中）；相邻建筑影响；施工荷载不当（材料设备堆放集中或超载）' },
  { t: '时间效应与外部干扰', d: '饱和软黏土的固结与蠕变；地震、振动、温度剧烈变化等环境变化' },
  { t: '勘察设计施工缺陷', d: '地质勘察不准确（布孔不准、孔深不到位）；基础选型或设计不当（桩长不足、筏板刚度不够）；施工质量差（回填不密实、桩身缺陷）' }
]" />

<template #notes>

不均匀沉降的成因按「地质—荷载—时间—人为」四类记。地质是先天条件（软弱层、溶洞、地下水），荷载是后天施加（分布不均、相邻影响），时间是长期演变（固结蠕变），人为是勘察设计施工的失误。考试常给一个现象让选成因，先判断属于这四类里的哪一类。

</template>

</Slide>

## 混凝土裂缝：深度、方向、原因

<Steps title="混凝土结构施工裂缝的分类" :steps="[
  { t: '按深度分', d: '表面裂缝（较浅，影响耐久和美观）、深层裂缝（贯穿内部但未穿透）、贯穿裂缝（贯穿至另一侧，破坏整体性和防水性）' },
  { t: '按方向分', d: '水平裂缝（梁板等水平构件）、垂直裂缝（柱墙等竖向构件）、斜向裂缝（荷载偏心、温度应力、不均匀沉降）、放射状裂缝（应力集中或材料缺陷）' },
  { t: '按原因分（塑性与收缩）', d: '塑性收缩（水分蒸发大于泌水）、干燥收缩（游离水蒸发）、塑性沉降（骨料下沉受钢筋阻隔）' },
  { t: '按原因分（温度与沉降）', d: '温度裂缝（水化热、内外温差过大）、不均匀沉陷裂缝（地基未夯实、支撑不牢、过早拆模）' },
  { t: '按原因分（撞击与冻胀）', d: '撞击裂缝（拆模外力撞击、拆模过早）、冻胀裂缝（冬期早期受冻、解冻后变形无法恢复）' }
]" />

<template #notes>

混凝土裂缝要从三个维度看：深度（表面/深层/贯穿）、方向（水平/垂直/斜向/放射状）、原因（七种）。原因里记规律：塑性收缩是浇筑初期表面失水，干燥收缩是硬化后失水，塑性沉降是骨料下沉被钢筋挡住，温度是水化热和内外温差，不均匀沉陷是地基和支撑问题，撞击是拆模，冻胀是冬期受冻。特征对应原因，判断才准。

</template>

</Slide>

<Steps title="混凝土强度不合格的主要原因" :steps="[

  { t: '配合比不当', d: '随意套用配合比；用水量过大（水灰比增大）；水泥用量不足；外加剂用错或掺量不准' },
  { t: '施工工艺', d: '拌制不佳（加料颠倒、搅拌时间短）；运输离析漏浆；浇筑方法不当（初凝后浇筑、离析）；养护不足（温湿度不足、受冻）' },

<template #notes>

强度不合格归到「材料—配比—工艺—试块」四个环节。注意最后一个是「试块管理」，它不代表混凝土真的不行，而是试块本身代表性失真——这也是很多「强度不合格」误判的来源。考试常问「哪一项属于试块管理问题」，答案指向非标准养护、试模变形、制作不规范。

</template>

## 缺陷成因分析：五步与原点

<Steps title="工程质量缺陷成因分析的基本步骤" :steps="[
  { t: '现场调查', d: '进行细致的现场调查研究，观察记录全部实况，掌握引发缺陷的现象和特征' },

> 分析要领：先确定缺陷的**初始点（原点）**，围绕原点分析现象特征，最后综合判断确定诱发缺陷的**真正原因**。

<template #notes>

成因分析五步：现场调查 → 收集资料 → 找全因素 → 分析判断 → 论证确认。要领是「原点」——它是独立原因集合起来的爆发点，反映直接原因。分析不是简单描述，而是逻辑推理，其结论可用于事前控制。这一页偏方法论，案例题里体现为「先调查、再分析、后确认」的思维顺序。

## 处理三方法：修补、返工、不做处理

<CompareCard title="施工质量缺陷处理的三种基本方法" :cols="['修补处理', '返工处理', '不做处理']" :rows="[
  { k: '适用情形', v: ['质量未达标准但修补后可达要求，不影响使用和外观', '严重缺陷、影响安全和构成重大影响、无法修补时', '影响不大、经分析论证和鉴定认可，可不专门处理'] },
  { k: '具体做法', v: ['封闭保护、复位纠偏、结构补强、表面处理', '挖除重做、整体拆除全面返工', '后续工序弥补、法定检测合格、原设计核算认可'] },
  { k: '注意要点', v: ['加固补强可能造成永久性缺陷（改变外形、影响次要功能）', '修补费用比返工还高的，应整体拆除全面返工', '不论哪种情况都要备好书面文件、组织签认'] }
]" />

> 不做处理不等于放任：要经分析论证、法定检测单位鉴定和设计等有关单位认可，并备好书面文件。

<template #notes>

三种方法的选择逻辑：能补就补（修补）、补不了就重做（返工）、影响不大可不管（不做处理）。「不做处理」最容易考——它不是偷懒，而是有严格前提：不影响安全使用、后续工序能弥补、法定检测合格、原设计核算仍满足。任何一种处理都要留书面文件、组织签认，责任方承担经济责任。

</template>

## 小结：分类要清，处理要闭环

<p class="dk-lead">缺陷分得清，成因找得准，处理走闭环。</p>

- **分类**：严重/一般看决定性影响；性质分五类；阶段分施工中和完工后；表 7-1 九个外观缺陷。
- **成因**：不均匀沉降（地质、荷载、时间、人为）、混凝土裂缝（深度/方向/原因）、强度不合格（材料、配比、工艺、试块）。
- **分析**：五步 + 原点要领。
- **处理**：六步程序（签发通知单→调查提方案→审方案→实施验收→核签费用→归档）；三方法（修补、返工、不做处理）。
