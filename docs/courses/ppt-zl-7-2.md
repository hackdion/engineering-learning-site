## 质量事故：定义与四个等级

<p class="dk-lead">工程质量事故是指违反工程质量有关法律法规和工程建设标准，使工程产生结构安全、重要使用功能等方面的质量缺陷，造成<strong>人身伤亡或者重大经济损失</strong>的事故。</p>

- **与缺陷的区别**：缺陷是「不符合标准」，事故是缺陷升级到「造成人身伤亡或重大经济损失」。
- **四个等级**：特别重大事故、重大事故、较大事故、一般事故，按人员伤亡或直接经济损失划分。
- **划分依据**：《生产安全事故报告和调查处理条例》（国务院令第 493 号）。
- **来源**：主要源于建造的不合格或使用不当，总体属于生产性范围。

<template #notes>

先分清「缺陷」和「事故」的边界：缺陷是不符合标准，事故是缺陷造成了人身伤亡或重大经济损失，严重程度更高、处理程序更严。四个等级按伤亡或直接经济损失划分，具体数字在第八章第三节展开，这里先记住「四级」和「国务院令第 493 号」这个依据。

</template>

## 处理程序：暂停令到复工令

<Steps title="工程质量事故的处理程序" :steps="[
  { t: '签发暂停令', d: '总监理工程师签发《工程暂停令》，暂停事故部位及关联部位施工，要求防止事故扩大、保护现场，并上报' },
  { t: '调查提交报告', d: '施工单位进行事故调查、分析原因，提交质量事故调查报告；由事故调查组处理的，监理应积极配合' },
  { t: '技术处理方案', d: '一般由施工单位提出，经原设计单位同意签认，报建设单位批准；涉及结构安全和加固处理的重大方案一般由原设计单位提出' },
  { t: '实施与验收', d: '制定详细施工方案，对处理过程跟踪检查、对处理结果验收，必要时组织鉴定' },
  { t: '复工', d: '处理完毕具备复工条件时，施工单位申请复工，总监签署审核意见，报建设单位批准后签发工程复工令' },
  { t: '书面报告归档', d: '及时向建设单位提交质量事故书面报告，并将完整的处理记录整理归档' }
]" />

<template #notes>

这是本节最重要的程序链：暂停令 → 调查 → 方案 → 实施 → 复工令 → 报告。几个关键点：暂停令和复工令都由总监签发，但复工令要报建设单位批准；技术处理方案一般由施工单位提、原设计单位同意、建设单位批准，重大方案由原设计单位提出。质量事故书面报告有六项内容（单位名称、时间地点部位、经过损失、原因判断、措施方案、过程结果）。

</template>

</Slide>

## 小结：报告有时限，处理有程序

<p class="dk-lead">报告看时限，处理看程序，加固看数字。</p>

- **报告**：24 小时（有关单位）、1 小时（建设单位负责人）、2 小时（每级上报）；四级事故，一般到省、较大以上到中央。
- **调查与处罚**：调查七项职责；对单位/人员各四档处罚，转送 15 个工作日。
- **处理程序**：暂停令 → 调查 → 方案 → 实施 → 复工令 → 书面报告归档。
- **加固**：混凝土强度推定值 13.0MPa、正拉粘结强度 1.5MPa、配筋率 0.2%、材料保证率 95%。
