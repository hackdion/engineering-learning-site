## 安全风险管理：理论、方法、危险源三条线

<p class="dk-lead">安全风险管理先用<strong>理论</strong>解释事故为什么发生，再用<strong>方法</strong>辨识和追溯风险，最后落到<strong>危险源管理</strong>。</p>

- **六大理论**：海因里希法则、瑞士奶酪模型理论、能量释放理论、脆弱性理论、系统安全理论、韧性安全理论。
- **三种方法**：预先危险性分析法（PHA）、事件树分析法（ETA）、事故树分析法（FTA）。
- **管理落点**：两类危险源、重大事故隐患判定、六类重大危险源的现场控制。
- **一条主线**：理论给判断，方法给工具，危险源管理给动作。

  { t: '事故因果连锁论', d: '伤亡事故涉及遗传及社会环境、人的缺点、人的不安全行为或物的不安全状态、事故、伤害五个环节，任何一环被中断，事故即可避免' },

## 系统安全、韧性安全与其他四则

<CompareCard title="两种系统观（可点击「遮住自测」）" :cols="['系统安全理论', '韧性安全理论']" :rows="[

  { k: '核心主张', v: ['安全性在构思阶段纳入并贯穿全生命周期；改善物的可靠性；承认绝对安全不存在，把危险降到可接受程度', '不追求绝对安全或零风险，聚焦受攻击、故障或突发事件后的快速识别、隔离与恢复'] },
  { k: '关键概念', v: ['轨迹交叉理论、能量意外转移理论；整体性、相关性、动态性', '冗余性、适应性、恢复性、可感知性'] },
  { k: '管理策略', v: ['设计阶段引入安全冗余、风险评估分级管控、全员参与多方协同', '分层防护、层层发现、主动防御、跨行跨业联动、极限生存'] }

<span class="dk-tag">破窗理论：对细微违规零容忍</span><span class="dk-tag">风险矩阵：可能性 P × 后果 C</span><span class="dk-tag">Bowtie：左预防、右缓解</span><span class="dk-tag">LOPA：评估保护层失效概率</span>

<Reveal label="其他四个理论各记一句话">

- **破窗理论**：环境中的不良现象被放任，会诱使人们效仿，最终引发事故；管理上要对任何细微的安全违规或隐患「零容忍」。
- **风险矩阵理论**：通过可能性（P）和后果严重性（C）构建矩阵，把风险划分为高、中、低等级，确定管控优先级。
- **Bowtie 模型（蝴蝶结模型）**：以危险源为中心，左侧为预防措施，右侧为缓解措施，中间为事故场景。
- **LOPA（保护层分析）**：通过评估各保护层的失效概率，确定风险是否可接受，常用于化工、石油等高危行业。

</Reveal>

<template #notes>

系统安全理论的三条基本原则要记：全生命周期、改善物的可靠性、承认绝对安全不存在。韧性安全的关键转变是从「零风险」转向「快速恢复」，四个特性是冗余、适应、恢复、可感知。其他四个理论只需知道一句话和适用场景，不要在课堂上展开。

## 预先危险性分析：活动开始前先想一遍

<Steps title="预先危险性分析（PHA）的五个步骤" :steps="[
  { t: '调查了解', d: '对系统的生产目的、工艺过程以及操作条件和周围环境进行充分的调查了解' },
  { t: '收集经验', d: '收集以往经验和同类生产中发生过的事故情况，分析危险、有害因素和触发事件' },
  { t: '推测后果', d: '推测可能导致的事故类型和危险或危害程度' },
  { t: '确定等级', d: '确定危险、有害因素后果的危险等级' },
  { t: '制定措施', d: '针对潜在事故制定相应安全措施，尽可能消除不可接受的危险性等级风险' }
]" />

<Reveal label="转化条件和触发条件有什么区别？">

风险源的存在并不一定会引发事故。风险源在一定内部因素或外部因素单独作用或者共同作用下，使系统处于危险状态，这些因素称为**转化条件**；处于危险状态的系统也并不一定都会发生事故，只有在某些条件下才会发生事故，这种条件称为**触发条件**。

</Reveal>

<template #notes>

PHA 的关键是「活动开始前」，这是它与 ETA、FTA 最大的区别，也是考试常设的辨析点。转化条件让系统进入危险状态，触发条件让危险状态变成事故，两个概念不要混。五步里第一步的调查了解是基础，审查专项方案时也常看这一项是否做实。

</template>

</Slide>

## 两张分级表：风险分级与危险性等级

<CompareCard title="表 8-1 危险事件风险分级表（可点击「遮住自测」）" :cols="['轻微伤害', '一般伤害', '严重伤害']" :rows="[
  { k: '极不可能', v: ['可忽略风险', '可容许风险', '中度风险'] },
  { k: '不可能', v: ['可容许风险', '中度风险', '重大风险'] },
  { k: '可能', v: ['中度风险', '重大风险', '不可容许风险'] }
]" />

- **可忽略风险**：不采取措施，风险管理文件可不做记录。
- **可容许风险**：不增加额外控制设施，需要监视；或考虑改进但不增加额外成本。
- **中度风险**：规定期限内实施降低风险的措施；与严重伤害相关时须进一步评价。
- **重大风险**：风险降低后才可开始工作；涉及正在进行的工作应采取应急措施，保证大量资源投入。
- **不可容许风险**：风险降低后才可工作；大量资源也不能降低风险时，必须禁止工作。

表 8-2 危险性等级：**I 级安全**（可忽略）、**II 级临界**（处于事故边缘，应予排除或控制）、**III 级危险**（造成人员伤亡和系统损坏，立即采取措施）、**IV 级破坏性**（灾难性事故，必须立即排除）。

<template #notes>

表 8-1 是「可能性 × 严重程度」的九宫格，从可忽略一路到不可容许，横着看严重程度、竖着看可能性。表 8-2 是 PHA 专用的四级划分，III 级和 IV 级属于不可接受的危险等级，应尽可能消除。两张表不要混：一张用于风险分级管控，一张用于 PHA 的后果定级。

</template>

## 事件树与事故树：两棵方向相反的树

<CompareCard title="ETA 与 FTA 的对照（可点击「遮住自测」）" :cols="['事件树分析 ETA', '事故树分析 FTA']" :rows="[

<template #notes>

> 施工安全管理的缺陷属于**第二类危险源**；重大事故隐患是指危害程度较大、可能导致群死群伤或造成重大经济损失的生产安全事故隐患。

<template #notes>

两类危险源的分工要背准：第一类决定后果严重程度，第二类决定发生可能性。管理上先控第一类的能量，再消除第二类的失效因素。教材明确施工安全管理缺陷属于第二类危险源，这个例子常考。重大事故隐患的定义要抓住「危害程度较大、可能导致群死群伤或重大经济损失」三个限定。

  { t: '情况严重', d: '签发工程暂停令，并及时报告建设单位' },

<Reveal label="施工安全管理中哪些情形直接判定为重大事故隐患？">

- 未取得安全生产许可证擅自从事建筑施工活动，或超（无）资质承揽工程。
- 未按规定足额配备安全生产管理人员，或主要负责人、项目负责人、专职安全生产管理人员未取得有效安全生产考核合格证书。
- 建筑施工特种作业人员未取得有效特种作业操作资格证书上岗作业。
- 危险性较大的分部分项工程未编、未审核专项施工方案，或方案存在严重缺陷，或未按规定组织专家论证。
- 按规定需要验收的危大工程，未经验收合格即进入下一道工序或投入使用。

</Reveal>

## 小结：理论给判断，方法给工具，现场给动作

<p class="dk-lead">理论解释事故为什么发生，方法用来事前辨识和事后追溯，危险源管理才是落脚点。</p>

- **六大理论**：海因里希 1:29:300 与五环节；瑞士奶酪四层防御；能量释放两类伤害；脆弱性三要素；系统安全全寿命周期；韧性安全冗余、适应、恢复、可感知。
- **三种方法**：PHA 在活动开始前辨识并定级；ETA 从初始事件推结果；FTA 从顶上事件找原因，两棵树方向相反。
- **危险源管理**：第一类管后果、第二类管可能性；重大事故隐患按判定标准认定；六类现场危险源抓好数字和禁令。
