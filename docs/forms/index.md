# 监理用表

《建设工程监理规范》GB/T 50319—2013 附录规定了 25 张工程监理基本表式：A 类工程监理单位用表 8 张，B 类施工单位报审、报验用表 14 张，C 类通用表 3 张。本页按规范附录原表格式整理，可在线查看，也可点「复制表格」粘贴到 Word 或 WPS 中填写。

各表的用途和签章要求，见教材《建设工程监理概论》[第八章第一节 工程监理基本表式及主要文件资料](/textbook/chapter-08/section-01)。

## 表 A.0.6 旁站记录

- **用途**：项目监理机构对工程关键部位或关键工序的施工质量进行现场跟踪监督时填写。
- **填写与签字**：旁站监理人员填写并签字。
- **份数**：本表一式一份，项目监理机构留存。
