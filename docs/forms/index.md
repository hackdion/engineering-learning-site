# 监理用表

《建设工程监理规范》GB/T 50319—2013 附录规定了 25 张工程监理基本表式：A 类工程监理单位用表 8 张，B 类施工单位报审、报验用表 14 张，C 类通用表 3 张。本页按规范附录原表的栏目、文字和签章位置逐张整理，可在线查看，也可点每张表上方的「复制表格」，粘贴到 Word 或 WPS 中填写。空白填写区的高度按网页阅读适当缩短，使用时可自行拉高。

各表的用途和签章要求，见教材《建设工程监理概论》[第八章第一节 工程监理基本表式及主要文件资料](/textbook/chapter-08/section-01)。

## A 类表　工程监理单位用表 {#a}

由工程监理单位或项目监理机构签发，共 8 张。


### 表 A.0.1 总监理工程师任命书 {#a-0-1}


- **用途**：工程监理合同签订后，工程监理单位法定代表人通过任命书委派有类似工程监理经验的注册监理工程师担任总监理工程师，并在任命书中明确其授权范围。
- **表内签章**：工程监理单位（盖章）、法定代表人（签字）。
- **份数**：本表一式三份，项目监理机构、建设单位、施工单位各一份。

## B 类表　施工单位报审、报验用表 {#b}

### 表 B.0.1 施工组织设计/（专项）施工方案报审表 {#b-0-1}


- **用途**：施工单位编制的施工组织设计、施工方案、专项施工方案经其技术负责人审批同意并加盖施工单位公章后，连同本表报送项目监理机构，先由专业监理工程师审查，再由总监理工程师审核；超过一定规模的危险性较大的分部分项工程专项施工方案，还需报送建设单位审批。
