# 隐蔽工程没报验就施工，监理该怎么处理

## 问题场景

某工程，施工单位完成一层顶板钢筋绑扎后，没有向项目监理机构报送隐蔽工程报验申请表，也没有通知监理到场检查，就直接安排混凝土浇筑。专业监理工程师巡视时，混凝土已经浇了一半。

题目通常问：监理应如何处理，费用和工期由谁承担。

这类题看似考“怎么办”，实际考三件事：监理有没有制止权，隐蔽工程验收走什么程序，未报验就覆盖的后果由谁承担。

## 判断步骤

第一步，立即制止。总监理工程师应签发《工程暂停令》，要求停止该部位及后续工序施工。情况紧急时，可先以监理通知单或书面指令要求立即停止浇筑，再按程序补发暂停令。口头制止不留痕迹，事后很难证明监理履职。

第二步，要求补报验。施工单位应提交隐蔽工程报验申请表、自检记录、钢筋质量证明文件、复试报告以及相关的检验批资料。监理不能因为已经浇了一部分就跳过报验。

第三步，现场检查验收。专业监理工程师按验收标准检查，必要时进行平行检验或旁站。检查合格的，签认隐蔽工程报验申请表和隐蔽验收记录，同意进入下一道工序；检查不合格的，禁止继续浇筑，要求返修或返工，处理后重新报验。

第四步，处理已经覆盖的部分。监理有权指示施工单位钻孔探测或揭开检查。施工单位未通知监理到场检查、私自覆盖的，由此增加的费用和延误的工期由施工单位承担。这条不看检查结果是否合格，程序违规本身就要承担后果。

第五步，区分“未通知私自覆盖”和“监理未按时检查”。施工单位已按约定提前书面通知，监理未按时检查也未提出延期要求的，视为隐蔽工程质量合格，施工单位可以覆盖。这种情况下监理事后要求揭开，检查合格的，费用和工期由建设单位承担；检查不合格的，由施工单位承担。

第六步，记录和报告。把巡视情况、暂停指令、报验资料、检查记录、处理结果写入监理日志和监理月报，必要时报告建设单位。已经浇筑且涉及结构安全的，按质量缺陷或质量事故程序处理，不能直接签认。

## 依据

- 《建筑法》第三十七条：未经监理工程师签字，建筑材料、建筑构配件和设备不得在工程上使用或者安装，施工单位不得进行下一道工序的施工。
- 《建设工程质量管理条例》第三十条：施工单位必须建立、健全施工质量的检验制度，严格工序管理，做好隐蔽工程的质量检查和记录；隐蔽工程在隐蔽前，施工单位应当通知建设单位和建设工程质量监督机构。
- 《民法典》第七百九十七条：隐蔽工程隐蔽以前，承包人应当通知发包人检查；发包人没有及时检查的，承包人可以顺延工程日期，并有权请求赔偿停工、窝工等损失。
- 《建设工程施工合同（示范文本）》GF-2017-0201 通用合同条款第 5.3 款：承包人应在隐蔽工程隐蔽前 48 小时书面通知监理人检查；未通知私自覆盖的，监理人有权指示钻孔探测或揭开检查，增加的费用和延误的工期由承包人承担。
- 2026 版《建设工程监理案例分析》第二章第二节“施工合同示范文本”、第三章第九节“工程施工质量控制与验收”，以及第四章第二节案例 2-5。

## 易错点

1. **只口头要求停工，不签发书面指令**：停工程序要有书面文件留痕，否则后续责任说不清。
2. **把费用承担写反**：未通知私自覆盖的，**无论检查结果合格与否**，费用和工期都由施工单位承担；已通知而监理未及时检查的，检查合格时费用和工期由建设单位承担。
3. **把“监理未按时检查”当成“施工单位擅自施工”**：前者按示范文本可顺延工期并索赔窝工损失，后者属于程序违规。
4. **已经浇筑就默认合格**：未经监理工程师签字，施工单位不得进行下一道工序施工。
5. **把隐蔽工程验收和检验批验收混为一谈**：两者资料和程序不能互相替代。

## 自测题

某工程顶板钢筋绑扎完成后，施工单位未通知监理即安排混凝土浇筑。监理发现时已浇筑一半。

**问**：项目监理机构应如何处理？已浇筑部分的检查费用和延误的工期由谁承担？

**解析**：

- **处理程序**：总监理工程师应立即签发《工程暂停令》，要求停止浇筑；责成施工单位补报隐蔽工程报验申请表、自检记录和钢筋质量证明文件；对已浇筑部分，监理有权指示钻孔探测或揭开检查。检查合格的，补办隐蔽验收签认；检查不合格的，要求返工处理并重新报验。过程记入监理日志并报告建设单位。
- **费用与工期归属**：由施工单位承担。因施工单位未通知监理到场检查即私自覆盖，属于程序违规，由此增加的检查费用和延误的工期均由承包人承担。
