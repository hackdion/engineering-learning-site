# 工程合同管理法律基础：法律关系、代理与违约责任

三个工地场景，像连环扣把这一章的知识全扣在一起。

第一个场景：项目经理有一张盖着公司真章的空白合同纸，授权书写的是“现场施工管理”。他拿这张纸签下一笔远超授权限额的钢材单。材料进场后，公司说“他没这个权限，我们不认”。供应商把合同纸往桌上一放——这签字到底算不算数？

第二个场景：为赶工期，发包人指定承包人采购某品牌保温板。板材不符合强制性标准，承包人检验时发现异常并书面提请更换，发包人仍坚持使用。外墙完工后开裂脱落。这笔质量账，该记在谁头上？

第三个场景：工程还没到约定竣工期，施工方突然停工撤场。既不是发包人拖欠，也没有行政指令。发包人主张，你用行为表明不想干了，我要你提前担责。停工，真的等于要赔钱吗？

这三笔账，就是这一章要回答的全部问题。

读完这一章，合同从招标到结算怎么管、谁有资格签字、违约了怎么赔，你会一次看透。

## 一、工程合同怎么管：从招标到结算别漏哪几步？

你可能会想，合同管理不就是签个字、盖个章吗？其实不然。

合同从招标就开始，一直管到结算付款。少留一次书面记录，追责就少一分依据，这一步步走的是闭环。

工程交易以招标为主流，另有询价比选、谈判采购、竞价和直接采购。依法必须招标的项目，施工单项 400 万元以上、重要设备材料 200 万元以上、服务 100 万元以上，就必须招标。公开招标面向不特定对象，邀请招标向三个以上特定对象发出邀请，电子招标与纸质招标效力相同。

招标阶段做总体策划。明确采购的是工程、服务还是物资，用工作分解结构排出计划，以开工日、竣工日为节点，用横道图、网络图衔接任务。用标准示范文本防漏项，把工作范围、风险、组织、费用、进度五类界面写清（注意是“费用界面”，不要误写作“委用界面”）。

合同文本拿来就用？其实不然。订立前做文本分析和风险识别，完成合法合规、合理可行、严密完整、与产品或过程有关要求、风险评估这五项评审。发现问题的书面澄清或调整，都会成为合同的组成部分。

计价方式要在签约前定好，本质是把量价风险在业主和承包商之间重新分一次。

<div style="overflow-x:auto">

| 计价方式 | 风险怎么分 | 适合什么场景 |
| --- | --- | --- |
| 单价合同 | 量价分离、单价优先，工程量风险与价格风险各归各 | 设计未完成、工程量清单未确定；固定单价适合工期短且工作量变化小，可变单价可按约定调价 |
| 固定总价 | 承包商承担工作量与价格变动的主要风险，业主投资好控制 | 范围与图纸明确、现场条件清楚、工期较短（约一年）且价格波动不大；变更超过约定幅度可调价 |
| 可调总价 | 市场价格波动风险主要由业主承担，可能突破既定价格 | 不适用固定总价条件、建设周期一年半以上的项目 |
| 成本加酬金 | 价格与工程量风险基本由业主承担，承包商缺乏降本动力 | 技术、结构方案难以预先确定，时间紧迫的抢险救灾工程 |

</div>

抓住一句话就不会混：谁承担价格波动，谁就承担相应风险；写死单价还是写死总价，决定后面变更怎么调价。

履行阶段照样不能撒手。要建立制度、做实施计划，书面交底并签署确认书。过程按 PDCA 循环跟踪纠偏，也就是计划、执行、检查、处置，把补充协议和会议纪要留存。变更经授权人员签认，同步调整价款和工期。

索赔是双向的。反驳对方索赔叫反索赔，不能按甲方乙方身份划分。报告要写明理由、金额和工期，证据留足。

::: tip

记一个闭环口诀：策划定范围，文本防漏项，评审挡风险，交底留书面，PDCA 纠偏，结算索赔收口。六步连起来，就是一条完整的合同管理链。

:::

### 随堂小练

某项目图纸已明确、现场条件清楚、工期约一年且价格波动不大，业主希望投资易控制。最适合采用的计价方式是哪一种？

A. 单价合同　B. 固定总价合同　C. 可调总价合同　D. 成本加酬金合同

<details><summary>查看答案与解析</summary>

答案：B。固定总价把工作量与价格变动的主要风险交给承包商，业主投资易控制，正适合范围明确、工期较短、价格波动不大的项目。

错选 C 是把“建设周期一年半以上、不适用固定总价”的可调总价条件，误当成了本题的短工期场景；错选 A 是把“设计未完成、清单未确定”的单价合同前提，误套到了图纸已明确的项目上。

</details>

## 二、签合同前先看清：谁能签、签什么、什么会让合同变化？

合同跟谁签、签的是什么、什么东西一变合同就跟着变，这三个问题不先想清楚，后面签字容易出岔子。

合同关系是当事人之间的权利义务关系，具有相对性，由主体、客体、内容组成，缺一不成立。改动其中任何一个，原来的关系就变了。

先看主体，也就是谁能签。自然人的民事权利能力从出生到死亡，一律平等；民事行为能力按年龄和精神状况判断。

<div style="overflow-x:auto">

| 年龄与状态 | 行为能力 | 怎么实施民事法律行为 |
| --- | --- | --- |
| 不满八周岁 | 无民事行为能力 | 由法定代理人代理实施 |
| 八周岁以上的未成年人 | 限制民事行为能力 | 由法定代理人代理或经其同意、追认；可独立实施纯获利益或与其年龄、智力相适应的行为 |
| 十六周岁以上，以自己劳动收入为主要生活来源 | 视为完全民事行为能力 | 可独立实施 |
| 十八周岁以上的成年人 | 完全民事行为能力 | 可独立实施；不能辨认自己行为的成年人仍为无民事行为能力人 |

</div>

抓住八周岁、十六周岁、十八周岁这三个节点就不会混。不能辨认自己行为的成年人是无民事行为能力人，这一点常被漏掉。

::: warning

最容易错的是“十六周岁以上”。以为没满十八就一定是限制民事行为能力人，其实不然。只要以自己的劳动收入为主要生活来源，就视为完全民事行为能力人，可以独立签合同。错把“视为”当成“不是”，效力判断就会反。

:::

法人依法独立享有权利、承担义务，能力自成立产生、至终止消灭，法定代表人以法人名义活动的后果由法人承受。法人分三类：营利法人如有限责任公司、股份有限公司；非营利法人如事业单位、社会团体、基金会、社会服务机构；特别法人如机关法人、农村集体经济组织法人、城镇农村合作经济组织法人、基层群众性自治组织法人。分支机构的民事责任由法人承担，也可先以其管理的财产承担，不足部分由法人补。

还有一类非法人组织，包括个人独资企业、合伙企业和不具法人资格的专业服务机构。财产不足清偿债务时，由出资人或设立人承担无限责任。

再看客体。客体是权利义务指向的对象，分物、行为和智力成果。物要能人为控制且有经济价值，材料、设备、建筑物、货币资金、有价证券都算，月球矿产虽有价值却不能控制，就不是物。行为指完成工作或提供劳务，如勘察设计、施工安装、运输、保管。智力成果如专利、专有技术、工程设计、计算机软件。

这里有个好类比：同一本书，拿在手里那叠纸是物，书里的内容却是智力成果。二者长在一起，性质却不同，分清它们，客体就不会答错。

最后是内容，即约定和法定的权利义务。权利主体可按自己意志行为，并要求对方为或不为一定行为，义务人不履行就要担责。

让合同关系产生、变更、消灭的是法律事实，分行为和事件。行为有作为与不作为、合法与违法之分，订立有效合同、依法行政管理是合法行为，违约是违法行为，生效判决、裁定和仲裁裁决也属于行为。事件不以当事人意志为转移，包括地震、台风等自然事件和战争、罢工、禁运等社会事件。

不可抗力指不能预见、不能避免且不能克服的客观情况，因不可抗力不能履行民事义务的，不承担民事责任，法律另有规定的除外。认定要三个要件同时满足，且与不能履行有因果关系。受影响方应及时通知并提供证明。疫情或防控措施是否构成不可抗力，要结合合同、时间和影响程度判断。

::: info

这一节的依据，可查 [2026 版《建设工程合同管理》第一章第三节](/textbook/contract-management/chapter-01/section-03)，以及《民法典》第十八条至第二十一条、第五十七条至第七十四条、第七十六条、第八十七条、第九十六条、第一百零二条和第一百八十条。

:::

### 随堂小练

关于合同关系三要素和法律事实，下列说法正确的是哪一项？

A. 合同关系具有相对性，主体、客体、内容缺一不可
B. 货币资金不属于客体中的物
C. 生效的仲裁裁决属于法律事实中的事件
D. 地震属于社会事件，战争属于自然事件

<details><summary>查看答案与解析</summary>

答案：A。合同关系具有相对性，三要素缺一不可。

错选 B 是把“货币资金归入物”的教材口径误当成了一般直觉；错选 C 是把生效判决、裁定和仲裁裁决误当成了事件，它们其实属于行为；错选 D 是把自然事件与社会事件对调了，地震是自然事件，战争才是社会事件。

</details>

## 三、一张授权书为何让公司买单？委托代理、无权代理与表见代理

回到第一笔账：盖真章的空白纸越权签下钢材单，公司为什么可能要为它买单？这就要看懂代理。

代理是代理人以被代理人名义实施、后果由被代理人承受的行为，分委托代理和法定代理。项目经理、总监理工程师、招标代理机构都是委托代理。书面授权委托书要载明代理人姓名或名称、事项、权限和期间并签章。授权是单方法律行为，可随时撤销；代理人也可随时辞去委托，但不能给被代理人或善意第三人造成损失。法定代理依法律规定产生，为无民事行为能力人、限制民事行为能力人设立。

看到这里你可能会想，只要没有授权，签字就一律无效吧？其实不然。法律把“没有代理权”分成无权代理和表见代理，两者效力完全不同。

无权代理有三种：没有代理权、超越代理权限、代理权终止后仍然代理。未经追认的，对被代理人不发生效力。被代理人可按后果是否有利选择追认或拒绝，追认后转为有权代理。相对人可以催告被代理人在收到通知之日起三十日内予以追认，未作表示的视为拒绝追认。追认前，善意相对人有权撤销，撤销以通知方式作出。代理人与相对人恶意串通损害被代理人权益的，两者承担连带责任。

::: warning

这里有个必须核准的条号：无权代理催告追认期，按《民法典》第一百七十一条现行原文是“三十日内”。2026 版《合同管理》教材第一章第三节正文仍沿用了旧表述“一个月内”。考试时请结合题干语境辨别，实务一律以《民法典》第一百七十一条的三十日为准，不要被教材旧措辞带偏。

:::

表见代理则不同。行为人无代理权、超越代理权或代理权终止后仍实施代理，相对人有理由相信其有代理权的，代理行为有效。条件有四：行为人实际无代理权；存在可信赖的权利外观，比如盖真章的授权文件、长期交易习惯、企业明知越权不纠正；相对人善意且无过失；行为本身具备有效要件。

关键差别在于表见代理无需追认，直接由被代理人担责。这就是一张盖真章的空白纸能把公司拖进付款责任的原因。

<div style="overflow-x:auto">

| 比较项 | 无权代理 | 表见代理 |
| --- | --- | --- |
| 代理权状态 | 没有、超越或终止后的代理权 | 同样无代理权，但存在可信赖的权利外观 |
| 相对人状态 | 未要求善意无过失 | 须善意且无过失，有理由相信代理权存在 |
| 效力 | 原则对被代理人不发生效力，追认后转为有权代理 | 代理行为有效，无需追认 |
| 后果承担 | 未追认由行为人承担，恶意串通者与相对人连带 | 被代理人向相对人承担，之后可向有过错行为人追偿 |

</div>

表前想分清的是：同样“没授权”，为什么一个效力待定、一个直接有效。表后记住一条就不会混：有没有让善意相对人信赖的权利外观，是分水岭。

工地签字分四步。第一步，查授权书有无法定代表人签章，事项、权限、期间是否写全。第二步，比对签字是否超出授权。第三步，看相对人是否持有盖真章文件、有无既往同类交易、企业是否知情未反对。第四步定效力：构成表见代理由企业担责，不构成且企业拒绝追认的由签字人自担。

印章管理失范是把越权推向表见代理的主要推手。作废旧章、及时公告、多人会签，都是把风险堵在门口的实招。

::: info

代理这部分的依据，可查 [2026 版《建设工程合同管理》第一章第三节](/textbook/contract-management/chapter-01/section-03) 与《民法典》第一百六十四条至第一百七十二条。

:::

### 随堂小练

承接第一案：项目经理授权书写明负责现场施工管理，却与材料商签下钢材采购合同，数量价格与以往三次相近，合同纸盖着真实合同章。企业以未授权拒付。下列判断正确的是？

A. 无权代理，企业拒绝追认后一概不担责
B. 表见代理，代理行为有效，企业应向材料商承担责任
C. 法定代理，企业必须承担责任
D. 项目经理个人担责，企业不承担任何后果

<details><summary>查看答案与解析</summary>

答案：B。授权事项与签字内容基本对应，又有盖真章的空白合同纸和既往同类交易，材料商有理由相信代理权存在且无过失，构成表见代理，后果先由企业承受，之后可向有过错的项目经理追偿。

错选 A 是把“无权代理经拒绝追认不生效”的规则误套到了有权利外观的场景；错选 C 是把委托代理误当成了依法律规定产生的法定代理；错选 D 忽略了善意相对人的合理信赖应受保护。

</details>

## 四、违约了怎么赔，发包人有过错怎么办？

再看第二、第三笔账。保温板开裂和停工撤场，最后都落到“怎么赔、谁赔”。

法律责任分行政、刑事和民事三类，前两类不能约定，民事责任可在不违反强制性规定的前提下约定。民事责任里，合同责任和侵权责任并列，合同责任又分违约责任与缔约过失责任。承担方式有停止侵害、排除妨碍、返还财产、恢复原状、修理重作更换、继续履行、赔偿损失、支付违约金、赔礼道歉，可单独或合并适用。

违约责任的基本形态是继续履行、采取补救措施和赔偿损失。一方明确表示或以行为表明不履行合同义务的，对方可以在履行期限届满前请求其承担违约责任，这就是预期违约。开篇第三案里，施工方未到竣工期就停工撤场，能否按预期违约主张，要看行为是否足以表明不履行，并给出合理催告期，而不是看到停工就断定合同已解除。

::: warning

停工不等于解除合同，更不等于自动担责。很多人把“人撤了”直接等同于“明确表示不履行”，其实不然。只有行为足以表明不履行，或者在合理催告期后仍不恢复，才可能构成期前违约。少了催告这一步，主张就容易落空。

:::

赔偿额相当于因违约造成的损失，包括合同履行后可以获得的利益，但不得超过违约方订立合同时预见到或应当预见到的损失。非金钱债务存在法律上或事实上不能履行、不适于强制履行或费用过高、债权人未在合理期限内请求等情形的，不能请求继续履行，但不影响违约责任。

违约金和定金是两项最容易算错的账。违约金可以约定，低于损失的可请求增加，过分高于损失的可请求适当减少。支付迟延履行违约金后，债务仍要继续履行。定金不得超过主合同标的额的百分之二十，超过部分不产生定金效力，且自实际交付时成立。给付方违约无权请求返还，收受方违约双倍返还。既约定违约金又约定定金的，一方违约时对方只能择一适用。

讲个小例子：一万元的电脑，定金最多两千。你交了两千，对方却卖给别人，双倍返还的四千元里有两千是本金，实际赔偿只有两千。若约定违约金三千，选违约金再要回本金，合计五千。错就错在把“双倍返还四千”当成了净收益。

::: tip

定金口诀记四句：两成封顶、交付成立、给付方不退、收受方双倍。再来一句择一：违约金与定金只能二选一，双倍返还里要先把本金剔掉再比较。

:::

现在说发包人过错。开篇第二案里，保温板是发包人指定的，承包人又做过检验并书面提请更换，责任就不是一边倒。

<div style="overflow-x:auto">

| 发包人过错 | 典型表现 | 责任怎么落 |
| --- | --- | --- |
| 提供的设计有缺陷 | 图纸节点构造不满足要求，承包人按图施工后出现质量缺陷 | 发包人承担相应过错责任；承包人发现图纸差错未提出意见的，也承担相应责任 |
| 提供或指定购买的建材、构配件、设备不符合强制性标准 | 指定品牌保温材料不合格，进场后仍被要求使用 | 发包人承担过错责任；承包人未按规定检验的，不能免除自身责任 |
| 直接指定分包人分包专业工程 | 发包人绕过总承包人确定专业分包单位 | 因指定造成质量缺陷的，发包人承担过错责任 |

</div>

表前想分清的是：发包人指定的材料和承包人自己的检验义务，责任如何各自归位。表后抓住一条就不会混：发包人指定有过错要担责，承包人该检验不检验也跑不掉，两者并行不悖。

发包人未按约提供原材料、设备、场地、资金、技术资料的，承包人可顺延工期并索赔停工窝工损失。主要建材不符合强制性标准致无法施工，经催告合理期限仍未履行的，承包人可解除合同。发包人逾期不付价款，除工程性质不宜折价、拍卖外，承包人可协议折价或请求法院拍卖，价款就折价或拍卖价款优先受偿。

担保这块点到为止。保证合同是主债权债务合同的从合同，主债权债务合同无效的，保证合同无效，但是法律另有规定的除外，比如独立保函。保证方式约定不明按一般保证承担，保证期间无约定时为主债务履行期限届满之日起六个月。展开内容见 [保证合同的方式与保证期间](/knowledge/surety-contract-mode-and-period)，这里不重复。

::: danger

这是刑事红线，不能靠合同约掉。工程监理单位与建设单位或建筑施工企业串通、弄虚作假、降低工程质量的，造成损失要承担连带赔偿责任，这对应《建筑法》第六十九条。建设单位、设计单位、施工单位、工程监理单位违反国家规定降低工程质量标准，造成重大安全事故构成犯罪的，对直接责任人员依法追究刑事责任。串通投标、非国家工作人员受贿等达到入罪标准的，同样会被追责。一般质量瑕疵和工期延误属民事违约，真触红线也不能用合同约定免责。

:::

::: info

本节依据可查：[《建筑法》](/law/jianzhufa) 第二十五条、第二十九条、第三十五条、第六十九条，[《建设工程质量管理条例》](/law/zhiliang-tiaoli) 第十四条、第十六条、第七十四条，以及《民法典》第一百八十条、第五百七十七条至第五百八十八条、第六百八十二条、第六百八十六条、第六百九十二条。

:::

### 随堂小练

关于违约责任，下列说法正确的是哪一项？

A. 迟延履行违约金支付后，就不需要再履行债务
B. 定金约定为标的额百分之三十的，全部有效
C. 违约金过分高于损失的，可以请求人民法院或仲裁机构适当减少
D. 预期违约只能在履行期限届满后才能主张

<details><summary>查看答案与解析</summary>

答案：C。违约金过分高于损失时，可请求适当减少。

错选 A 是把“迟延履行违约金”误当成了债务终结，付了违约金仍要履行；错选 B 是把定金上限误记成了百分之三十，实际是百分之二十，超出部分不产生定金效力；错选 D 是把预期违约误当成了届期后的责任，实际上明确表示或以行为表明不履行的，可以在期限届满前主张。

</details>

## 五、回到开篇工地案：把整章知识串起来用

三笔账一起算，看知识怎么落到一件事上。

第一笔，项目经理的签字。钢材采购是否超出“现场施工管理”授权？再看权利外观：合同纸盖着真章、有过三次同类交易、企业未纠正。材料商善意且无过失，有理由相信代理权存在，构成表见代理。企业先付款，再向有过错的项目经理追偿。若及时作废旧章、公告并多人会签，空白纸根本流不到市场上。

第二笔，保温板开裂。发包人指定采购不符合强制性标准的板材，有过错要担责。承包人检验发现异常并书面提请更换，已尽提示义务，不因按指定使用而当然担责。但没按规定检验或明知不合格仍使用的，就在自身过错范围内分担责任。设计图纸有缺陷、承包人发现未提意见的，同样担责。

第三笔，停工撤场。未到竣工期就停工，不当然等于解除，也不当然等于违约成立。要看行为是否足以表明不履行、是否给了合理催告期。构成预期违约的，发包人可在期限届满前主张责任；没催告就断定的，主张可能落空。承包人因发包人未按约供料而停工的，反而可顺延工期并索赔窝工损失。

<div style="overflow-x:auto">

| 开篇场景 | 用到本章哪一讲 | 结论一句话 |
| --- | --- | --- |
| 盖真章的空白合同越权签钢材单 | 代理与表见代理 | 有权利外观且相对人善意无过失，企业先担责再追偿 |
| 发包人指定不合格保温板致外墙开裂 | 发包人过错与承包人检验义务 | 指定方有过错担责，承包人未尽检验也在自身范围内担责 |
| 未到竣工期停工撤场 | 违约责任与预期违约 | 看行为是否表明不履行、是否给催告期，停工不等于解除 |

</div>

表前想看清的是：三个场景分别调用本章哪一块知识。表后抓住一条就不会混：先定关系与权限，再看过错与外观，最后落到责任和赔偿。

### 随堂小练 · 综合判断

结合开篇三案，判断下列说法正确的是哪一项？

A. 只要项目经理越权，企业一律不用担责
B. 发包人指定建材，质量责任就全部由发包人承担，承包人无论是否检验都无责
C. 施工方未到竣工期停工撤场，必然构成解除合同，发包人可立即主张全部损失
D. 相对人持有盖真章文件、有既往同类交易且善意无过失的，可能构成表见代理，企业承担责任后可向有过错行为人追偿

<details><summary>查看答案与解析</summary>

答案：D。

错选 A 是把“无权代理未经追认不生效”误当成了绝对规则，忽略了表见代理的权利外观；错选 B 是把发包人指定过错误当成了承包人检验义务的免除，两者并行不悖；错选 C 是把停工撤场误当成了必然解除和必然担责，忽略了行为是否表明不履行以及合理催告期。选 D 的要点在于，善意相对人的合理信赖受保护，企业担责后仍可向有过错的内部人员追偿。

</details>
