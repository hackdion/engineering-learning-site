## 如何新增文章

1. 外部素材先放入 `待审核素材/`，人工验收通过后方可导入。
2. 在 `docs/knowledge/` 目录下新建 Markdown 文件，文件顶部添加 frontmatter（至少包含 `title`）。
3. 在本页「文章列表」中添加对应条目与链接。
4. 在 `docs/.vitepress/config.mts` 的 `/knowledge/` 侧边栏中登记新页面，确保导航可达。
