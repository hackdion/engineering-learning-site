## 如何新增文章

1. 在 `docs/knowledge/` 目录下新建 Markdown 文件，文件顶部添加 frontmatter（至少包含 `title`）。
2. 在本页「文章列表」中添加对应条目与链接。
3. 在 `docs/.vitepress/config.mts` 的 `/knowledge/` 侧边栏中登记新页面，确保导航可达。
