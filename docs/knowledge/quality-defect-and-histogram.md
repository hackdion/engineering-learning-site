# 质量缺陷的处理程序和直方图判断

## 问题场景

某监理单位同时负责两个施工标段的监理工作。其中甲施工单位承建的标段，基础工程通过验收后出现局部开裂。总监当即要求暂停施工，后查明开裂源于设计考虑不周。

B 标段提供了 5、6、7 三个月混凝土试块抗压强度的直方图。题目要求写出处理基础工程问题的程序，并指出三个月的直方图分别属于哪种类型、形成原因是什么。

这道题有两个考点：一是质量问题的处理程序，二是直方图的形状判断。两件事要分开答，不能混在一起。

## 判断步骤

第一步，先给问题定性。工程质量缺陷一般指不满足规定要求、但不影响结构安全和使用功能的问题；质量事故则已经影响结构安全或重要使用功能。如果基础开裂已涉及基础结构安全并定性为质量事故，则按事故程序处理；若定性为一般质量缺陷，则按缺陷程序处理。

第二步，**质量缺陷按六步处理**：

1. 项目监理机构安排监理人员检查和记录，签发监理通知单，责成施工单位修复；
2. 施工单位调查缺陷原因，提出处理方案，方案应经设计等相关单位认可；
3. 项目监理机构审查处理方案并签署意见；
4. 施工单位按审查认可的方案处理，监理跟踪检查，并对处理结果验收；
5. 非施工单位原因造成的缺陷，监理核实施工单位申报的修复费用，签认工程款支付证书，报建设单位；
6. 处理记录整理归档。

第三步，**质量事故按五步处理**。总监理工程师已经下达《工程暂停令》的，后续按五步走：向建设单位报告 → 审查事故处理的技术方案 → 处理期间监督全过程 → 完成后组织验收 → 经建设单位同意签发复工令。

第四步，直方图先看整体形状。中间高、两侧低、左右接近对称的，属于正常型。形状异常的，再看峰的数量、位置和边缘。

第五步，按形状对号入座：

| 异常类型 | 图形特征 | 常见原因 |
| --- | --- | --- |
| 孤岛型 | 主分布旁边出现一个孤立小峰 | 原材料发生变化，或临时由他人顶班作业 |
| 双峰型 | 出现两个高度相近的峰 | 两种不同方法、两台设备或两组工人数据相混 |
| 折齿型 | 形状像折断的锯齿 | 分组组数不当或组距确定不当 |
| 绝壁型（陡壁型） | 一侧正常，另一侧突然截断 | 数据收集不正常，人为剔除一侧数据或检测人为干预 |
| 偏态型（缓坡型） | 峰偏向一侧，另一侧缓坡 | 对上限或下限控制太严 |
| 平顶型 | 顶部较平 | 生产过程中某种缓慢变化的因素在起作用 |

第六步，答题时把类型和原因成对写。只写“孤岛型”不写原因，通常只能拿到一半的分。

## 依据

- 2026 版《建设工程监理案例分析》第三章第十一节“工程质量缺陷和事故处理”：质量缺陷处理的六步程序。
- 同书第三章第十节“工程质量统计分析和检验检测方法”：直方图法的观察与分析。
- 同书第四章第二节案例 2-1：质量事故处理程序和直方图类型判断。
- 《建设工程监理规范》GB/T 50319—2013 关于总监理工程师处理质量缺陷、质量事故的规定。

## 易错点

1. **把质量缺陷和质量事故混为一谈**：一般缺陷走六步程序；已经影响结构安全的事故，要先暂停施工，再按五步事故程序处理。
2. **漏掉“处理方案经设计等相关单位认可”**：缺陷处理方案涉及设计的，不能由施工单位自行决定或由监理直接批准。
3. **事故处理结束后直接复工**：复工令必须经建设单位同意后由总监签发。
4. **非施工单位原因造成的缺陷，修复费用让施工单位承担**：监理应核实修复费用并签认工程款支付证书报建设单位。
5. **直方图类型和原因错配**：孤岛型对应原材料变化/顶班，双峰型对应两组数据相混，折齿型对应分组/组距不当，绝壁型对应数据收集不正常。
6. **看到直方图正常就认为质量合格**：直方图正常只反映数据分布形状，还需看分布中心与质量标准界限的位置关系。

## 自测题

某工程混凝土试块强度直方图的一侧正常，另一侧突然截断。问：这属于哪种类型，形成原因是什么？如果该部位随后发现基础局部开裂并已下达《工程暂停令》，后续处理程序是什么？

**解析**：

- **直方图类型及原因**：属于绝壁型（陡壁型），原因是数据收集不正常，可能有意识地剔除了某一侧的数据，或检测过程中存在人为因素影响。
- **基础开裂后续程序**：报告建设单位；审查事故处理技术方案；监督管理处理过程；验收处理结果；经建设单位同意后签发复工令。（若经调查属于一般质量缺陷，则改按六步缺陷处理程序执行。）
