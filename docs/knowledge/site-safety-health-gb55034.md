# 施工现场安全卫生与职业健康核心强制要点（GB 55034—2022）

《建筑与市政施工现场安全卫生与职业健康通用规范》（**GB 55034—2022**）经住房和城乡建设部公告 **2022 年第 164 号**于 `2022-10-31` 批准发布，自 **`2023-06-01`** 起正式实施。本规范属于**全文强制性国家标准**（并非部门规章），全部条文必须严格执行；原相关国家、行业标准中的对应强制性条文同时废止，现有地方标准及推荐性标准不得低于本规范规定。点击可直达[GB 55034—2022 全文条文页](/law/gb55034-2022-anquan-weisheng)。

## 一、基本规定与封闭式管理底线

1. **方案预案与重大危险源清单（[2.0.1～2.0.2](/law/gb55034-2022-anquan-weisheng#c2)）**：结合工程类型与环境地质条件编制专项施工方案、应急预案，开展危险源辨识和风险评价，建立重大危险源清单与管控台账。
2. **生活区封闭与围挡高度（[2.0.4](/law/gb55034-2022-anquan-weisheng#c2)）**：
   - 围挡采用可循环、可拆卸、标准化定型材料，**高度不得低于 `1.8m`**；
   - 出入大门设**专职门卫并实行封闭式管理**（实务司法免责核心三要素：① 无追逐行为、② 无恐吓行为、③ 落实有效封闭管理与安全警示）；
   - 宿舍标准衔接口径：依据现行《建设工程施工现场环境与卫生标准》（**JGJ 146—2013** 第 5.1.1 条），每间宿舍居住人员**不得超过 `16` 人**、床铺不超过 `2` 层、严禁通铺、人均面积 `≥2.5m²`（部分文明工地按更严企业标准控至 `6～12` 人，但国/行标底线为 `16` 人）。
3. **材料与停缓建管理（[2.0.6～2.0.8](/law/gb55034-2022-anquan-weisheng#c2)）**：进场材料具备质量证明文件，设施设备具备制造许可证或其他质量证明文件；停缓建项目须做好停工期间安全保障，复工前全面排查隐患。

## 二、安全管理 13 类高危作业核心控制参数（[第 3 章](/law/gb55034-2022-anquan-weisheng#c3)）

| 事故类型与节号 | 核心强制规定与关键限值 | 现场监理巡视核查要点 |
| --- | --- | --- |
| **一般规定 & 外电线路**（[3.1](/law/gb55034-2022-anquan-weisheng#s31)） | 安全隐患实行**「定人、定时间、定措施」三定整改**；**严禁在外电架空线路正下方**施工、吊装、搭设作业棚、建生活设施或堆放物料杂物 | 核查警示标志配置；复核外电架空线保护距离与正下方严禁堆载 |
| **高处坠落**（[3.2](/law/gb55034-2022-anquan-weisheng#s32)） | 基准面 `≥2m` 设防护+防滑措施+戴帽系带；围护设施低于 **`1.2m`** 的楼层、楼梯、阳台、沟坑边沿应防护严禁随意拆；遇雷雨、大雪、浓雾或 **5 级及以上大风**停止高处作业 | 垂直交叉作业**并非绝对禁止**，但存在风险时必须在上下层之间设置可靠安全防护设施，严禁无防护垂直交叉作业 |
| **物体打击 & 起重伤害**（[3.3](/law/gb55034-2022-anquan-weisheng#s33)、[3.4](/law/gb55034-2022-anquan-weisheng#s34)） | 严禁高处向下抛掷材料机具；安全通道上方设**抗高处坠物穿透防护棚**；预应力张拉/拆除时**轴线方向严禁有人**，**无粘结预应力结构拆除前须先解除预应力**；物料提升机严禁使用摩擦式卷扬机；**行程限位开关严禁作停止控制开关** | 大型起重机械严禁低能见度安拆；**起重机最高处风速超过 `9.0m/s`**（区别于普通高处作业 5 级大风）停止安拆作业；吊装严禁超载、斜拉、起吊不明重量物 |
| **坍塌（基坑/模板/拆除）**（[3.5](/law/gb55034-2022-anquan-weisheng#s35)） | 严禁超挖；基坑出现变形超限、大量漏水/流土/管涌、**桩间土流失孔洞深度超过桩径**须立即处理；回填严禁混入淤泥、沼泽土、冻土或生活垃圾；临时支撑严禁与起重设备/脚手架连接 | 拆模强度控制包含**底模和侧模**各自设计/规范要求（见 `GB 55008—2021`）；拆除遵循**自上而下、先非承重后承重**，严禁底部掏掘或推倒墙体 |
| **机械与车辆伤害**（[3.6](/law/gb55034-2022-anquan-weisheng#s36)、[3.8](/law/gb55034-2022-anquan-weisheng#s38)） | 机械清洁维修先切断电源、停稳并设警示牌；塔吊安全监控须具备**数据存储**并在危险趋势时自动切断控制电源；特种车辆运输危险品挂警示牌，特殊路段设**反光柱、爆闪灯、转角灯**，**夜间施工车辆须降低行驶速度** | 现场高频伤人机械以**角磨机/手持切割机**最突出（I 类金属外壳 vs II 类双绝缘外壳 vs III 类安全电池驱动）：监理须紧盯防护罩完整、切割片完好与穿绝缘鞋 |
| **中毒窒息与有限空间**（[3.9](/law/gb55034-2022-anquan-weisheng#s39)） | 有毒物品领用实行**双人双重责任制**；受限/密闭空间作业前按**「氧气 → 可燃性气体 → 有毒有害气体」顺序检测**；室内装修严禁使用**苯、工业苯、石油苯、重质苯、混苯**及有机溶剂清洗用具；外墙清洗不得用强酸强碱 | 贯彻 **「先通风、再检测、后作业」** 与全程监护。依 2026-06-01 起施行的**新版《特种作业目录》（`应急〔2026〕45号`）**，**建筑有限空间作业监护工**正式纳入特种作业持证上岗目录 |
| **临时用电与爆炸**（[3.10](/law/gb55034-2022-anquan-weisheng#s310)、[3.11](/law/gb55034-2022-anquan-weisheng#s311)） | 发电机组与其他电源**互相闭锁、严禁并列运行**；绝缘导线色标：**PE/PEN 为黄绿双色，N 线为淡蓝色，严禁混用**；检修**严禁带电作业**，断电上锁挂「禁止合闸、有人工作」牌，**严禁预约停送电**；**安全隔离变压器严禁带入金属容器或金属管道内** | 特殊照明电压分级：`≤36V` 安全特低电压（SELV）一般手持灯具，`≤24V` 潮湿导电环境，`≤12V` 金属容器内；管道试压严禁使用可燃气体和氧气，**严禁利用可燃介质输送管道作电气保护接地或电弧引弧**；容器外储存易燃易爆气瓶**严禁存放在住人用房** |

</div>

> [!IMPORTANT]
> **氧气瓶与乙炔气瓶现场间距规范口径核校**：依据现行 **GB 50720—2011**《建设工程施工现场消防安全技术规范》第 6.3.3 条，施工现场气瓶**使用时，氧气瓶与乙炔气瓶间距不应小于 `5m`**，气瓶与**明火（动火点）间距不应小于 `10m`**，乙炔瓶严禁横躺卧放并须配回火防止器；**储存阶段**严禁存放在住人用房（[3.11.1](/law/gb55034-2022-anquan-weisheng#s311)），且助燃气体与可燃气体严禁同库室混储（确因临时中转分置同一专用暂存区时应保持安全间隔及物理隔离，不得简单等同于普通材料堆放）。

## 三、环境、卫生与职业健康劳动防护用品强制速查（[第 4～6 章](/law/gb55034-2022-anquan-weisheng#c6)）

1. **环境与卫生核心区分（[第 4～5 章](/law/gb55034-2022-anquan-weisheng#c4)）**：
   - 出入口设**冲洗池和沉淀池**，建筑垃圾分类存放、封闭/防护运输，**严禁熔融沥青和焚烧废弃物**；
   - **临时休息点 vs 吸烟区**：[4.0.9](/law/gb55034-2022-anquan-weisheng#c4) 规定「施工现场应在**安全位置**设置临时休息点；**施工区域禁止吸烟**」——即便是结构楼层内的避难层/临时休息点**仍属施工区域，不可吸烟**，吸烟区必须设置在施工区域外（如项目部大门外专区）；
   - **饮用水系统与非饮用水系统不得存在直接或间接连接**（[5.0.2](/law/gb55034-2022-anquan-weisheng#c5)）；食堂配独立制作间、储藏间与排风冷藏设施，**严格执行食品留样制度**并持有餐饮/卫生许可证与健康证；生活区制定法定传染病、食物中毒、急性职业中毒应急预案。

2. **重点工种劳动防护用品配备对照表（高频易混淆考点，[6.0.1～6.0.13](/law/gb55034-2022-anquan-weisheng#c6)）**：

<div style="overflow-x:auto">

| 工种 / 作业环境 | 规范强制配备的劳动防护用品（对应条款） | 考场/现场高频混淆对比点 |
| --- | --- | --- |
| **安装电工** | **手套和防护眼镜**（[6.0.3-2](/law/gb55034-2022-anquan-weisheng#c6)） | 极易误选“绝缘鞋和绝缘手套”（那是**维修电工**标准配备！） |
| **维修电工** | **绝缘鞋、绝缘手套和灵便紧口的工作服**（[6.0.3-1](/law/gb55034-2022-anquan-weisheng#c6)） | 区别于安装电工与高压电工 |
| **高压电气作业电工** | **相应等级的绝缘鞋、绝缘手套和有色防护眼镜**（[6.0.3-3](/law/gb55034-2022-anquan-weisheng#c6)） | 强调“**相应等级**”与**有色**防电弧强光眼镜 |
| **手持电动工具（电钻、砂轮）** | **绝缘鞋、绝缘手套和防护眼镜**（[6.0.12](/law/gb55034-2022-anquan-weisheng#c6)） | 可能飞溅渣屑的机械设备作业需配备防护眼镜 |
| **油漆工（涂刷、喷漆）** | 防静电工作服、防静电鞋、防静电手套、**防毒口罩**和防护眼镜（[6.0.6](/law/gb55034-2022-anquan-weisheng#c6)） | 涉及有机溶剂挥发与静电引燃，配**防静电+防毒口罩** |
| **油漆工（砂纸打磨）** | **防尘口罩和密闭式防护眼镜**（[6.0.6](/law/gb55034-2022-anquan-weisheng#c6)） | 打磨粉尘大而无挥发漆雾，配**防尘口罩+密闭式眼镜** |
| **信号指挥工（强光环境）** | 专用标识服装；强光条件配备**有色防护眼镜**（[6.0.2-2](/law/gb55034-2022-anquan-weisheng#c6)） | 允许佩戴合规有色眼镜防刺眼强光误判信号 |
| **石棉、玻璃棉含尘毒材料** | **防异物工作服、防尘口罩、风帽、风镜和薄膜手套**（[6.0.10-3](/law/gb55034-2022-anquan-weisheng#c6)） | 强调全套防纤维刺入与密闭（领口/袖口/裤口紧口） |
| **电焊/气割（高处/腐蚀性/密闭）** | 基本：阻燃服、绝缘鞋、鞋盖、电焊手套、面罩；高处：帽连式面罩+**阻燃安全带**；腐蚀性：**耐酸碱**防护服/胶鞋/手套；密闭：**送风式防护面罩**（[6.0.4](/law/gb55034-2022-anquan-weisheng#c6)） | 清焊渣需戴防护眼镜；高处作业建议采用**五点式安全带**；噪声区耳塞须加防脱系绳 |
| **职业卫生健康监护档案** | 从事**放射性、高毒、高危粉尘**等职业病危害作业人员应建立档案（[6.0.1](/law/gb55034-2022-anquan-weisheng#c6)） | 普通砌筑工等无上述特种危害作业不属于强制建档范围 |

</div>

## 自测题

**题 1（单选）**：依据 `GB 55034—2022` 第 `6.0.3` 条，**安装电工**作业时应配备的劳动防护用品是（　）；使用电钻、砂轮等手持电动工具作业时应配备的是（　）。  
A. 绝缘鞋和绝缘手套 ／ 防尘口罩和防护眼镜  
B. 手套和防护眼镜 ／ 绝缘鞋、绝缘手套和防护眼镜  
C. 防静电服和防毒口罩 ／ 绝缘鞋和绝缘手套  
D. 阻燃防护服和安全带 ／ 保护足趾安全鞋和手套  

**答案与解析**：**B**。`GB 55034—2022` 第 `6.0.3` 条第 2 款明确规定“安装电工应配备手套和防护眼镜”（维修电工才配绝缘鞋、绝缘手套和紧口工作服）；第 `6.0.12` 条规定电钻、砂轮等手持电动工具作业应配备绝缘鞋、绝缘手套和防护眼镜。

**题 2（单选）**：关于施工现场特殊场所照明及临时用电规定，下列说法符合 `GB 55034—2022` 的是（　）。  
A. 为保障不断电，现场发电机组电源可与市政电网电源长期并列运行  
B. 在金属管道或金属容器内检修时，安全隔离变压器应随身带入管道内以便操作  
C. 电气设备维修期间严禁预约停送电，切断电源并上锁后在醒目位置悬挂停电标识牌  
D. 保护接地导体（PE）与中性导体（N）均可使用黄绿双色绝缘线  

**答案与解析**：**C**。依据 `GB 55034—2022` 第 `3.10.2～3.10.5` 条：发电机组电源应与其他电源互相闭锁、严禁并列运行（A 错）；安全隔离变压器严禁带入金属容器或金属管道内使用（B 错）；PE/PEN 应为黄绿双色、N 线应为淡蓝色，不得混用（D 错）。
