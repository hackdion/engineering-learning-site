# 监理机构职责划分、地方规程差异与现场防踩坑实务

## 底层工程关系与保修期限速记

### 1. 五方责任主体“漏斗沟通”规则

在工程实施阶段，建设单位分别与勘察、设计、监理、施工单位订立合同，监理单位作为受建设单位委托的独立第三方技术服务机构，在合同授权范围内履行监督管理职责：

- 监理与勘察、设计单位属于**平级单位**，监理主要负责阅图并向建设单位提出书面意见或建议，不监理勘察与设计行为本身；
- 在建设工程监理工作范围内，建设单位向施工单位下达指令，以及施工单位向建设单位提交报告和文件，**均必须通过项目监理机构传导**，建设单位不应越过监理直接指令施工单位。

### 2. 法定最低质量保修期限常见易错点

对照《建设工程质量管理条例》第四十条，现场交工与考试中最常混用的两类年限是：

- **5 年**：屋面防水工程、有防水要求的卫生间、房间和**外墙面的防渗漏**（含外墙保温防渗漏体系）；
- **2 年**：电气管线、给排水管道、设备安装和装修工程（注意：**消防工程按管线与设备安装类执行，法定最低保修期同样为 2 年**，不要误背成 5 年）。

## 监理机构组成与人员职责边界

项目监理机构应当按**总监理工程师（必要时可设总监理工程师代表）、专业监理工程师、监理员**三个层次组建，并在监理合同签订后 `7 天内` 将组织形式、总监任命书（`A.0.1`）、人员名单及进退场计划书面通知建设单位；因合理理由更换总监理工程师时，须**提前 `7 天` 书面通知并取得建设单位书面同意**。

### 1. 各岗位核心条件与地方配置细则

- **总监理工程师**：由工程监理单位**法定代表人**书面任命；一名注册监理工程师原则上最多同时担任 **3 项**建设工程监理合同的总监。部分省区地方标准对非强制监理二级及以下项目另有衔接办法（如[新疆 `XJJ 088—2018` 第 3.0.6 条](/law/xjj088-2018-jianli-guicheng#c3)规定满足大专及以上学历+中级职称/工程类注册资格+8 年工作经历+一定项目专监业绩的人员经认定可任 1 项二级以下项目总监）；
- **总监理工程师代表**：须具备工程类注册执业资格，或**中级及以上专业技术职称 + 3 年及以上**工程实践经验；常驻现场，可兼任专业监理工程师；
- **专业监理工程师**：须具备工程类注册执业资格，或**中级及以上专业技术职称 + 2 年及以上**工程实践经验；
- **监理员**：须具备**中专或高中及以上学历**，在专业监理工程师指导下具体实施旁站、见证取样、检查原始记录等工作；
- **最低常驻人数红线**：参考[新疆 `XJJ 088—2018` 表 4.2.3](/law/xjj088-2018-jianli-guicheng#c4-2)“项目监理机构人员数量最低配置标准”，表中带括号人员为非常驻人员，但实际常驻现场人数**不得少于最低配置标准**。

### 2. 总监「不得委托」vs「可以委托」镜像对照表

此表直接对应现场履职边界及监理取证高频镜像考题（如总监授权代表审核分包与审查施组的区别）：

<div style="overflow-x:auto">

| 职责事项 | 能否委托给总监代表 | 履职要点与原因说明 |
| --- | :---: | --- |
| 组织编写**监理规划**、审批**监理实施细则** | **不得委托** | 属项目监理机构纲领性与核心技术把关职责 |
| 根据工程进展及工作情况**调配监理人员** | **不得委托** | 涉及履约团队稳定与专业配备 |
| **组织审查施工组织设计、（专项）施工方案** | **不得委托** | 直接关系重大施工技术与安全方案合法合规性 |
| 签发**工程开工令、暂停令和复工令** | **不得委托** | 涉及工程状态变更与停复工责任边界（表 A.0.2/A.0.5/A.0.7） |
| 签发**工程款支付证书**、组织审核**竣工结算** | **不得委托** | 涉及重大经济支付与造价审核（表 A.0.8） |
| 调解建设单位与施工单位的**合同争议**，处理**工程索赔** | **不得委托** | 涉及双方法律权益与索赔判定 |
| 审查施工单位**竣工申请**，组织**工程竣工预验收**，编写**工程质量评估报告**，参与工程竣工验收 | **不得委托** | 竣工质量评估报告须经总监和监理单位技术负责人签字审核 |
| 参与或配合**工程质量安全事故的调查和处理** | **不得委托** | 事故追责与原因调查须由第一负责人牵头配合 |
| **组织审核分包单位资格**（表 B.0.4） | **可以委托** | 经总监书面授权（并通知建设和施工单位）后，可由总监代表组织审核 |
| **组织召开监理例会** | **可以委托** | 属于日常协调运行组织工作，可书面授权总监代表主持 |
| **组织审查和处理工程变更** | **可以委托** | 可在总监书面授权范围内协助处理工程变更审查 |
| **组织检查施工单位现场质量、安全生产管理体系的建立及运行情况** | **可以委托** | 日常体系运行核查工作可委托总监代表组织 |
| **定期审阅监理日志**、组织编写监理月报及整理监理文件资料 | **可以委托** | 日常文书与信息管理统筹可书面授权 |

</div>

## 监理规划 vs 监理实施细则，以及关键报审时限

<div style="overflow-x:auto">

| 比较维度 | 监理规划 | 监理实施细则 |
| --- | --- | --- |
| **编审与签字主体** | **总监**主持编写（专监参与）→ 总监签字 → 报**监理单位技术负责人**审批 | **专业监理工程师**编制 → 报**总监理工程师**审批 |
| **报送时间要求** | 国标《GB/T 50319》规定在**召开第一次工地会议前**报送建设单位；地方细则如[新疆 `XJJ 088—2018` 5.1.1](/law/xjj088-2018-jianli-guicheng#c5-1)进一步明确须在**第一次工地会议 `3 天前`**报送（注意与开工日期 `7 天前` 发出工程开工令相区分） | 对专业性较强、危险性较大的分部分项工程及采用四新工程，在**相应工程施工前**编制完成并经总监审批 |
| **可不编制情形** | 所有依法实施监理的工程项目**均应编制** | 对规模小、技术简单的工程，可不编制监理实施细则 |
| **核心内容差异** | 包含项目概况、监理范围/内容/目标、监理机构组织形式及人员分工、**监理工作制度**、质量/造价/进度/安全控制措施等全面纲领 | 只围绕专业特点展开：**专业工程特点、编制依据、监理工作流程、监理工作要点、监理工作方法及措施**（**不包含“监理工作制度”**） |
| **动态调整特性** | 实际内容或合同发生重大变化时，由**总监理工程师组织专业监理工程师修改**，重新报监理单位技术负责人审批 | 应随着工程建设实际情况变化补充、修改和完善，体现监理实施细则的**灵活性** |

</div>

## 开工前审图、施组审核与分包/特种工核验

1. **红章施工图核验**：进场开工前应核验施工单位是否取得**盖有审图机构及设计单位有效签章的正式施工蓝图**（严禁仅凭无章白草图组织施工），阅图后向建设单位提出书面审查意见。
2. **施工组织设计报审程序（B.0.1）**：施工单位由项目经理组织编制施工组织设计，须经**施工单位技术负责人**审核签字、加盖单位公章后，再报送项目监理机构审查（**注意不要与“监理单位技术负责人”混淆**）；危大工程专项施工方案还须遵循住建部令第 37 号与[专项方案专题](/knowledge/special-construction-plan-approval)程序。
3. **分包单位资格审核（B.0.4）**：由总包单位填写 `分包单位资格报审表`，经专监审查、**总监理工程师审核签认**。审查内容包括：① 营业执照、企业资质等级证书；② 安全生产许可证；③ 类似工程业绩；④ 专职管理人员和特种作业人员的资格；⑤ 施工单位对分包单位的管理制度。**注意：分包单位资格审查基本内容不包括分包单位的“财务状况”。**
4. **省级发证与外省核验（地方实务重点）**：施工/监理企业资质、安全生产许可证以及特种作业人员操作证均由省级住房城乡建设主管部门或兵团建设主管部门核发（区县级机关无企业施工资质与特种工发证权限）；外省进场特种作业人员证件须按当地规定查验联网有效性或办理备案，无证严禁上岗。
5. **现场 8 类特种作业人员核验清单**：
   1. **建筑电工**；
   2. **电焊工**；
   3. **气焊/气割工**；
   4. **建筑架子工**（含普通脚手架、附着式升降脚手架、吊篮等搭拆）；
   5. **建筑起重机械司机**（塔式起重机、施工升降机、物料提升机等）；
   6. **建筑起重信号司索工**（信号与司索合并发证，塔吊等每台班配备不少于 2 人协调作业）；
   7. **建筑起重机械安装拆卸工**；
   8. **高处作业吊篮或特殊电气设备安拆维护作业人员**（动火监护按属地规定配齐专用警示背心或袖标）。

## 现场检验检测、材料管控、隐蔽验收与文书留痕

1. **第三方检测费用与委托主体（住建部令第 57 号 + `XJJ 088` 6.4.5）**：建设工程质量检测业务必须由**建设单位委托**具有相应资质的检测机构实施，所需第三方检测费用应在工程概算中单列；非建设单位委托的检测机构出具的检测报告不得作为工程质量验收依据。检测方案应报项目监理机构审查确认。
2. **混凝土试块留置用途区分**：标准边长 `150mm` 立方体混凝土试块（每组 `3 块`）应严格区分——**标准养护**（`20±2℃`、相对湿度 `≥95%` 养护 `28 天`）检验混凝土原材料与配合比自身强度质量；**同条件养护**（与工程结构同环境养护）反映现场实际施工成型条件与拆模/结构实体强度。
3. **进场不合格材料的合规处置（`XJJ 088` 6.5.4）**：当进场材料、构配件或设备检验不合格或未经批准时，监理不能仅作口头拒绝，而应书面要求施工单位**做好明显标识或隔离措施，限期撤出施工现场**；同时，施工单位与项目监理机构双方均应健全材料进场报审与见证取样台账。
4. **隐蔽工程私自覆盖处理（`XJJ 088` 6.5.2）**：施工单位未通知监理到场验收擅自覆盖隐蔽工程、或监理对工程质量有怀疑时，项目监理机构有权指示其采取**钻孔探测、剥离揭开或 X/γ 射线/声波无损检测**进行复验，具体程序与费用工期归属详见[隐蔽工程未报验处理专题](/knowledge/concealed-work-uninspected-handling)。
5. **返工与返修用语不可混用**：在《监理通知单》中，**返工**指推倒拆除不合格结构或部位重做；**返修**指经鉴定在不影响结构安全及使用功能前提下采取修补加固。两者性质不同，发文措辞须严谨区分。
6. **监理日志与文书份数及职业边界**：
   - 监理日志严禁笼统填写“今日一切正常、无异常”，而应具体记载当日巡视的楼层部位、脚手架与三级配电箱抽查状况、天气及人员履职；专项旁站/巡视已单独成册的，日志中可载明“详见专项旁站/巡视记录”；
   - 所有文件资料审查签字一律在**会议室或例会场所**办理，不在施工方宿舍等非正式区域单独签署；
   - **常用 A 类表份数速记**：`A.0.6 旁站记录` 为一式一份（留存监理档案）；**`A.0.4 监理报告` 为一式四份**（主管部门、建设单位、监理单位、项目监理机构各一份）；`A.0.1`、`A.0.2`、`A.0.3`、`A.0.5`、`A.0.7`、`A.0.8` 均按一式三份流转。
7. **安全隐患「免责留痕」四步闭环**：发生安全生产隐患或违规作业时，监理“什么都不签”属于履职失职；真正合法合规的风险隔离闭环是：  
   **现场口头制止并同步影像/纸面留痕** → **下达[《监理通知单》（A.0.3）](/forms/#a-0-3)** → **拒不整改或情节严重时总监签发[《工程暂停令》（A.0.5）](/forms/#a-0-5)并用[工作联系单（C.0.1）](/forms/#c-0-1)报告建设单位** → **施工单位仍拒不整改或拒不停工时，立即书面向工程所在地住建主管部门与建设单位提交[《监理报告》（A.0.4）](/forms/#a-0-4)**（同时留存完整送达/邮寄回执）。

## 自测题

**题 1（单选，镜像对照）**：总监理工程师可以书面委托给总监理工程师代表的工作是（　）；**不得**委托给总监理工程师代表的工作是（　）。  
A. 组织审核分包单位资格 / 组织审查施工组织设计  
B. 组织审查施工组织设计 / 组织召开监理例会  
C. 签发工程开工令 / 组织验收分部工程  
D. 审批监理实施细则 / 调解合同争议  

**答案与解析**：**A**。总监代**可以**受委托承担“组织审核分包单位资格”“组织召开监理例会”“检查现场质安体系”等工作；但“组织审查施工组织设计/专项方案”“签发开/停/复工令”“批细则”等 9 项关键职责总监**不得委托**。

**题 2（单选）**：下列哪项**不属于**监理实施细则应包括的主要内容（　）。  
A. 专业工程特点　　B. 监理工作流程　　C. 监理工作要点　　D. 监理工作制度  

**答案与解析**：**D**。「监理工作制度」属于**监理规划**的组成部分；监理实施细则主要包括专业工程特点、编制依据、监理工作流程、监理工作要点、监理工作方法及措施。
