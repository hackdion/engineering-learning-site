## 使用说明 {#sm}

### 一、适用范围与危大属性判定

1. 本方案范例适用于房屋建筑和市政基础设施工程中采用矿山法、盾构法、顶管法施工的隧道、洞室工程。
2. 按《危险性较大的分部分项工程安全管理规定》（住房和城乡建设部令第37号，2019年修正）及《住房城乡建设部办公厅关于实施〈危险性较大的分部分项工程安全管理规定〉有关问题的通知》（建办质〔2018〕31号）附件1第三条，采用矿山法、盾构法、顶管法施工的隧道、洞室工程，属于危险性较大的分部分项工程，应编制专项施工方案。
3. 按建办质〔2018〕31号附件2第三条，采用矿山法、盾构法、顶管法施工的隧道、洞室工程，属于超过一定规模的危险性较大的分部分项工程，按37号令第十二条应当组织专家论证。暗挖工程没有另外的深度或长度门槛，凡属上述工法的隧道、洞室工程均应按超过一定规模管理。
4. 本项目为【填写：工程名称】暗挖区间（洞室），采用【填写：矿山法／盾构法／顶管法】施工，隧道长【填写：长度】m，开挖断面【填写：断面尺寸与面积】m²，最大埋深【填写：埋深】m，按上述标准判定为超过一定规模的危险性较大的分部分项工程，须组织专家论证。

### 二、编制与审批流程

1. 实行施工总承包的，专项施工方案由施工总承包单位组织编制；实行分包的，可由专业分包单位组织编制，但须由总承包单位技术负责人及分包单位技术负责人共同审核签字并加盖单位公章。
2. 方案经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的暗挖工程，由施工总承包单位组织专家论证会；专家论证结论应为专家组一致意见。结论为「修改后通过」的，施工单位修改完善后重新履行审核、审查程序，并将修改情况及时告知专家；结论为「不通过」的，修改后重新组织论证。论证专家应从工程所在地住房城乡建设主管部门专家库中选取，专业应满足本工程需要，人数不少于5名；与本工程有利害关系的人员不得以专家身份参加论证（依据37号令第十二条、第十三条和建办质〔2018〕31号第三条，具体条件以当地规定为准）。
4. 方案实施前，编制人员或项目技术负责人向施工现场管理人员进行方案交底；施工现场管理人员向作业人员进行安全技术交底，并由双方和项目专职安全生产管理人员共同签字确认。
5. 施工过程中不得擅自修改方案。因规划调整、设计变更、地质条件与勘察报告不符等确需调整的，修改后的方案应重新履行审核、审查程序；涉及资金或工期调整的，按37号令第十一条办理；属于超过一定规模的，须重新组织专家论证。

### 三、填写要求

1. 文中【填写：…】处应按项目勘察报告、设计文件、施工组织设计和现场调查资料填写，不得留空，不得照抄本范例的示例数值。
2. 未加标记的条文为示范性通用表述，应结合工法、地层、周边环境和合同要求修改；与本项目无关的条目应删除，不得以「通用」为由保留不适用内容。
3. 本范例同时覆盖矿山法、盾构法、顶管法三种工法的主要工序。项目方案只保留与本项目工法相符的工序，其余删除；采用盾构法或顶管法的，尚应按工法特点补充盾构机（顶管机）选型、始发与接收、管片拼装或顶进纠偏等内容。
4. 文中的题目、单位名称、人名、地名、数值均为虚构，仅用于说明写法；表格中的验收标准数值应替换为设计文件和现行标准的规定值。

### （三）施工方法及操作要求

#### 1. 竖井施工

1. 竖井采用【填写：倒挂井壁法／钻孔灌注桩＋内支撑】施工，锁口圈梁高出地面 0.3m，防止地表水流入。
2. 每开挖【填写：进尺】m 施作一环支护，支护紧跟开挖面；井壁渗水集中引排，不得敞口放置。
3. 竖井设置安全梯（间距不大于 10m 设休息平台）、防坠网和临边防护，井口设置限位装置和警示标志。
4. 提升设备安装后经验收合格方可使用，钢丝绳、吊钩、限位器和防坠器每日班前检查并记录。

#### 2. 超前地质预报与超前支护

1. 每循环开挖前进行超前地质预报，采用【填写：地质雷达／超前钻探／掌子面素描】；钻探发现与勘察报告不符时，立即停止开挖并通知设计、监理。
2. 小导管按设计位置钻孔，孔位偏差不大于 50mm，外插角偏差不大于 2°；导管插入后用锚固剂封孔，注浆压力达到设计值并稳压 5min 后停止。
3. 注浆顺序由下而上、间隔跳孔；邻孔串浆时停止注浆并封堵；注浆量异常增大时查明原因，防止浆液流失至管线或地表。
4. 注浆完成后检查注浆效果，采用【填写：检查孔／开挖面观察】验证，未达到设计要求时补注。

#### 3. 开挖

1. 采用台阶法开挖，上台阶超前下台阶 3～5m；上台阶高度【填写：高度】m，下台阶开挖后及时施作仰拱，封闭成环距开挖面不大于【填写：距离】m。
2. 砂层段采用人工开挖配合小型机械，严禁超挖；欠挖不大于【填写：值】mm，超挖部分用喷射混凝土回填。
3. 开挖面出现渗水、掉块、裂缝扩展、支护变形增大等异常时，立即停止作业、撤出人员并报告。
4. 洞内运输限速 10km/h，人车分流，转弯和交叉口设置警示标志与照明。

#### 4. 初期支护

1. 开挖后先初喷 50mm 混凝土封闭围岩，再架设钢架、挂网；钢架间距偏差不大于 ±50mm，垂直度偏差不大于 2°。
2. 钢架之间用纵向连接筋连接，拱脚设置锁脚锚管并与钢架焊接；钢架背后间隙用喷射混凝土或楔形块顶紧，不得留有空洞。
3. 喷射混凝土分段、分片、由下而上进行，喷头与受喷面垂直，距离 0.8～1.2m；回弹料不得重复使用。
4. 喷射混凝土 24h 强度应达到【填写：值】MPa，方可进行下一循环开挖；强度不足时延长养护时间。

#### 5. 防水层

1. 初期支护表面应平整，凸出物应割除并用砂浆抹平，凹凸差不大于【填写：值】mm；渗水点先注浆止水。
2. 土工布与防水板采用无钉铺设，搭接宽度不小于 100mm，热熔焊接双缝，焊缝充气检验压力【填写：值】MPa，保持 5min 不下降为合格。
3. 防水板铺设后应保护，绑扎钢筋时设置临时保护层，发现破损立即修补并记录。

#### 6. 二次衬砌

1. 仰拱先行，仰拱与填充分开浇筑；二次衬砌采用模板台车，每循环浇筑长度【填写：长度】m。
2. 混凝土入模温度 5～30℃，分层浇筑、分层振捣，振捣棒不得触碰防水板；拱顶设置排气孔和观察孔，确保拱顶混凝土密实。
3. 拆模时同条件养护试件强度应达到设计强度的【填写：百分比】；拆模后及时养护，养护时间不少于【填写：天数】d。
4. 二次衬砌完成且达到设计强度后，进行拱顶回填注浆，注浆孔间距【填写：距离】m，注浆压力 0.2～0.3MPa。

#### 7. 施工排水与降水

1. 洞内设排水沟和集水坑，工作面配备【填写：台数】台潜水泵，备用泵不少于 2 台，并配备发电机作为备用电源。
2. 砂层段地下水丰富时采用洞内降水或超前注浆止水，不得在开挖面大量抽水造成地层流失。
3. 洞内废水经沉淀处理达标后排入市政管网，不得直接排入河道或农田。

### （四）材料进场与工序检查

1. 材料进场查验合格证、出厂检验报告，并按批次取样复试；不合格材料立即清退出场并记录。
2. 每循环检查开挖断面尺寸、钢架间距与垂直度、钢筋网搭接、喷射混凝土厚度与外观、锁脚锚管数量与角度。
3. 每【填写：循环数】循环检查一次注浆记录、超前地质预报结论与设计符合性。
4. 防水板铺设、二次衬砌钢筋、预埋件与止水带安装经监理验收合格后方可浇筑。
5. 工序检查记录采用【填写：表号】，检查人和监理工程师签字确认后归档。

5. 项目负责人应在施工现场履职；专职安全生产管理人员应对专项施工方案实施情况进行现场监督，发现未按方案施工的，应要求立即整改（37号令第十四条、第十七条）。

### （二）安全技术措施

1. 洞内作业人员必须佩戴安全帽、反光背心和防尘口罩；有害气体可能超限的作业面配备便携式检测仪和自救器。
2. 每班作业前检测洞内氧含量和有毒有害气体，氧含量低于 19.5% 或有害气体超限时，立即撤离人员、加强通风，合格后方可进入。
3. 洞内动火作业实行审批制度，配备灭火器和消防水源；防水板施工区域严禁明火，焊接作业设置接火斗。
4. 临时用电采用 TN-S 系统、三级配电两级保护，洞内照明电压不大于 36V，潮湿部位不大于 24V。
5. 竖井口、竖井内作业平台、洞内临边和深坑设置防护栏杆和盖板，夜间设置警示灯。
6. 机械设备定期检查维护，提升设备、压力容器和起重设备按规定检验，检验合格证在有效期内。

### （三）质量技术措施

1. 实行技术交底、首件验收和样板引路制度；首环初期支护、首段防水层、首段二次衬砌经验收合格后方可大面积施工。
2. 测量实行双人复核，隧道中线、高程每【填写：距离】m 复测一次，贯通前进行贯通测量。
3. 喷射混凝土厚度采用埋设标钉或钻孔检查，每【填写：m】检查一个断面；厚度不足处补喷。
4. 二次衬砌背后回填注浆饱满度采用【填写：敲击／钻孔／地质雷达】检查，发现脱空补充注浆。
5. 建立质量缺陷台账，对渗漏水、裂缝、蜂窝麻面等缺陷逐项处理并复查。

### （四）文明施工与环境保护措施

1. 施工围挡连续封闭，出入口设置洗车槽和沉淀池，车辆不带泥上路。
2. 土方和渣土集中堆放并覆盖，运输车辆密闭；水泥、砂石料仓封闭，拌合站设置除尘设备。
3. 施工噪声控制在【填写：昼间/夜间限值】dB 以内，夜间施工办理许可并公告。
4. 弃渣按指定地点堆放，不得随意倾倒；施工废水沉淀处理后排放。

### （五）季节性施工技术措施

1. 雨季：检查竖井口挡水墙、排水沟和集水坑，备足排水泵；雨前检查边坡和地表裂缝，防止地表水倒灌。
2. 冬季：混凝土采用保温措施，入模温度不低于 5℃；供水管路和注浆管路防冻，提升设备制动系统防滑。
3. 高温：调整作业时间，洞内加强通风，配备防暑降温用品。

### （六）监测监控措施

2. 监测数据当日整理，异常数据及时复测并报告；达到预警值时按第八章应急响应处置。
3. 监测点埋设后测定初始值，初始值取开挖前连续 3 次稳定读数的平均值。

## 九、计算书及相关施工图纸 {#c9}

### （一）计算书应包含的内容

1. 计算依据、计算假定和计算简图。
2. 超前小导管注浆量、开挖循环与工期、喷射混凝土用量、二衬混凝土用量、通风风量等施工参数计算。
3. 支护结构安全性验算：由设计单位提供或按设计文件复核，施工单位不得自行降低支护参数。
4. 竖井提升设备、临时用电负荷、排水设备能力验算。
5. 监测控制值确定依据。

### （二）示例计算

#### 1. 超前小导管单孔注浆量

按浆液充填围岩孔隙估算：

$$Q=\pi R^{2} L n \alpha (1+\beta)$$

式中：$Q$ 为单孔注浆量（m³）；$R$ 为浆液扩散半径（m），取 0.30m；$L$ 为导管注浆段长度（m），取 3.0m；$n$ 为围岩孔隙率，取 0.35；$\alpha$ 为浆液充填系数，取 0.6；$\beta$ 为浆液损失系数，取 0.1。

代入得：

$$Q=3.1416\times0.30^{2}\times3.0\times0.35\times0.6\times1.1=0.196\ \text{m}^3$$

拱部 120° 范围环向间距 0.3m，单循环布置 21 根，单循环注浆量：

$$21\times0.196=4.11\ \text{m}^3$$

> 该式按孔隙充填估算，未考虑浆液在砂层中的劈裂与流失，实际注浆量以现场注浆压力和结束标准控制；公式与参数取值出处未核实，使用前应核对设计文件。

#### 2. 单循环开挖与出渣量

开挖断面积 32.1m²，循环进尺 1.0m，实体开挖量：

$$V=32.1\times1.0=32.1\ \text{m}^3$$

按松散系数 1.25 计，弃渣量：

$$V_s=32.1\times1.25=40.1\ \text{m}^3$$

每循环按 2 个台班组织，日进尺 2.0m，单工作面月进尺（按 25 个工作日）：

$$2.0\times25=50\ \text{m/月}$$

#### 3. 初期支护喷射混凝土用量

初支周长 20.4m，厚度 0.25m，每延米设计量：

$$V=20.4\times0.25\times1.0=5.10\ \text{m}^3/\text{m}$$

按回弹率 15% 计，每延米备料量：

$$5.10\times1.15=5.87\ \text{m}^3/\text{m}$$

480m 隧道喷射混凝土备料量约：

$$5.87\times480=2818\ \text{m}^3$$

#### 4. 二次衬砌混凝土用量

二次衬砌内轮廓周长 19.6m，厚度 0.40m，每延米混凝土量：

$$V=19.6\times0.40\times1.0=7.84\ \text{m}^3/\text{m}$$

480m 隧道二次衬砌混凝土量：

$$7.84\times480=3763\ \text{m}^3$$

#### 5. 洞内通风风量

按两个工作面同时作业、洞内最多 24 人、每人需风量 4m³/min 计：

$$Q_1=24\times4=96\ \text{m}^3/\text{min}=1.60\ \text{m}^3/\text{s}$$

按最小风速 0.15m/s 计：

$$Q_2=0.15\times32.1=4.82\ \text{m}^3/\text{s}$$

取二者较大值并计入漏风系数 1.1：

$$Q=1.1\times4.82=5.30\ \text{m}^3/\text{s}$$

选用风量不小于 5.3m³/s 的轴流风机，风机全压按风筒长度和漏风计算确定。

> 通风风量计算中的每人需风量、最小风速和漏风系数取值出处未核实，实际应按施工组织设计和通风专项计算确定。

#### 6. 排水设备能力

按洞内最大涌水量【填写：m³/h】、单台泵流量 20m³/h 计，工作泵数量：

$$n=\frac{Q}{20}\times1.2$$

示例涌水量 60m³/h 时，$n=3.6$，取 4 台工作泵，另备 2 台备用泵和 1 台发电机。

7. 计算书依据是否可靠，计算假定与结果是否偏于安全。
