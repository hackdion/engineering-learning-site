# 拆除工程专项施工方案编写范例（本站整理）

<LawBanner />

> **本站依据官方指南整理，不是官方文本；不得直接用于报审，须结合项目实际、现行标准和专业人员复核。**

> 本方案范例依据《危险性较大的分部分项工程专项施工方案编制指南》（建办质〔2021〕48号）第五章「拆除工程」的编制内容与顺序编写，供施工单位编制具体项目方案时参照，不替代设计文件、结构检测报告和项目实际论证。

## 使用说明 {#sm}

### 一、适用范围与危大属性判定

1. 本方案范例适用于房屋建筑、构筑物及附属设施的机械拆除、人工拆除、静态破碎及局部保留改造拆除工程；采用爆破拆除的，还应按《爆破安全规程》GB 6722-2014 和公安部门规定另行编制爆破专项方案。
2. 按《危险性较大的分部分项工程安全管理规定》（住房和城乡建设部令第37号，2019年修正）及《住房城乡建设部办公厅关于实施〈危险性较大的分部分项工程安全管理规定〉有关问题的通知》（建办质〔2018〕31号）附件1，可能影响行人、交通、电力设施、通讯设施或其他建（构）筑物安全的拆除工程，属于危险性较大的分部分项工程，应编制专项施工方案。
3. 按建办质〔2018〕31号附件2，码头、桥梁、高架、烟囱、水塔或拆除中容易引起有毒有害气（液）体或粉尘扩散、易燃易爆事故发生的特殊建、构筑物的拆除工程，文物保护建筑、优秀历史建筑或历史文化风貌区影响范围内的拆除工程，属于超过一定规模的危险性较大的分部分项工程，按37号令第十二条应当组织专家论证。文物保护建筑、优秀历史建筑或历史文化风貌区影响范围内的拆除工程列于附件2，属于超过一定规模的危大工程。
4. 本项目拆除对象为【填写：建筑类型、层数、高度、结构形式】，周边【填写：邻近建筑、道路、管线情况】，按上述标准判定为【填写：危大工程／超过一定规模的危大工程】。
5. 拆除作业前应取得房屋权属证明、拆除许可或相关批准文件，完成管线迁改或切断，签订拆除施工合同和安全生产管理协议。

### 二、编制与审批流程

1. 实行施工总承包的，专项施工方案由施工总承包单位组织编制；实行分包的，可由专业分包单位组织编制，但须由总承包单位技术负责人及分包单位技术负责人共同审核签字并加盖单位公章。
2. 方案经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的，方案在通过施工单位审核和总监理工程师审查后，由施工总承包单位组织专家论证；论证结论应为专家组的「一致意见」，结论为「修改后通过」的，修改完善后重新履行审核审查程序，并将修改情况及时告知专家；论证不通过的，修改后重新组织论证。
4. 方案实施前，编制人员或项目技术负责人向施工现场管理人员进行方案交底，施工现场管理人员向作业人员进行安全技术交底，并由双方和项目专职安全生产管理人员共同签字确认。
5. 施工单位应当严格按照专项施工方案组织施工，不得擅自修改专项施工方案（依据37号令第十六条）。本方案进一步要求不得擅自改变拆除顺序、方法和范围；确需调整的，应重新审核、论证。

### 三、填写要求

1. 所有项目特定信息统一使用【填写：…】标记，不得留空、不得以「同上」「略」代替。
2. 本章节顺序不得删减；本项目确不涉及的条、款，写「本项目不涉及」并说明理由，不得直接删除。
3. 拆除对象的层数、层高、结构形式、构件尺寸、配筋、混凝土强度应以结构检测报告和原设计图纸为依据，不得凭经验填写。
4. 周边建（构）筑物、道路、管线的距离应注明是净距还是中心距，并附平面图。
5. 拆除顺序、机械选型、防护措施、监测控制值应相互对应，不得前后矛盾。
6. 文中标注「本站整理表式，非官方表式」的表格，仅为便于项目使用而整理，不是住房和城乡建设部或地方主管部门发布的官方附件，不得以官方名义引用。

### （二）工艺流程

1. 机械拆除工艺流程：

施工准备 → 围挡及警戒 → 管线迁改、切断 → 防护棚、防震沟施工 → 内部清空 → 屋面及附属物拆除 → 逐层拆除非承重结构 → 逐层拆除楼板、次梁、主梁、柱 → 基础拆除 → 垃圾清运 → 场地平整 → 验收移交。

2. 单层拆除工艺流程：

定位放线 → 切断该层水电气 → 拆除门窗、隔墙 → 拆除外挑构件 → 破碎楼板 → 切断次梁 → 切断主梁 → 放倒或吊运柱 → 清理渣土 → 进入下一层。

3. 局部静力切割工艺流程：

放线定位 → 钻孔穿绳 → 安装绳锯／墙锯 → 切割 → 临时支撑 → 吊运 → 清理。

### （三）施工方法及操作要求

#### 1. 施工准备

1. 收集原设计图纸、竣工图、结构检测报告，查明结构体系、构件尺寸、配筋、混凝土强度和后加改造情况。
2. 调查周边建（构）筑物、道路、管线、架空线路，取得管线产权单位交底记录。
3. 办理拆除许可、占道、临时用水用电、垃圾外运等手续。
4. 切断或迁改水、电、气、通信、供热管线，挂设警示标志，办理确认手续。
5. 设置围挡、警戒区、安全通道、防护棚、防震沟和监测点。
6. 对作业人员进行方案交底、安全技术交底和应急培训。

#### 2. 围挡与警戒

1. 拆除现场四周设置连续封闭围挡，高度不低于2.5m，围挡基础稳固、抗风。
2. 拆除建筑四周设置警戒区。JGJ 147-2016第4.0.3条只要求设置硬质封闭围挡及安全警示标志，未规定按拆除高度取定警戒范围，也不存在「不小于建筑高度1/2」的统一通行做法。本示例为虚构算例，警戒范围按不小于建筑高度的1/2且不小于【填写】m设定，仅为算例取值，实际应按项目所在地管理规定确定（地方依据待核）。本示例北侧道路净距8m、南侧管线净距5m，均小于算例取值（23.1/2＝11.6m），应采取设置硬质围挡、临时占道审批、交通导改、管线迁改或加固、专人值守等措施，并在方案中说明协调结果，不得仅以警戒线代替防护。
3. 出入口设置门卫、车辆冲洗设施和警示标志，无关人员不得进入。
4. 夜间设置警示灯，临街部位加设防护通道。

#### 3. 管线保护

1. 拆除前采用管线探测仪、人工探挖确认管线位置、埋深、走向，绘制管线图。
2. 给水、燃气、通信、电力管线应迁改或切断，燃气管道应放散、置换、检测合格。
3. 不能迁改的管线，采取悬吊、包封、隔离、防震沟等保护措施，并设置监测点。
4. 拆除过程中发现不明管线、容器，立即停止作业，报告产权单位和主管部门。

#### 4. 防护棚与防震沟

1. 邻近住宅、道路侧搭设双层防护棚，立杆基础坚实，立杆间距不大于1.5m，步距不大于1.8m。
2. 防护棚顶部铺设双层50mm厚木板，上下层间距不小于0.6m，外侧满挂密目网。
3. 防护棚应能承受落物冲击，经验算合格后方可使用；使用期间不得堆载。
4. 邻近管线侧开挖防震沟，沟宽0.6m、深1.0m，沟内不得积水，必要时设置支撑。

#### 5. 机械拆除

1. 机械拆除应自上而下、逐层、逐跨进行，先拆非承重结构，后拆承重结构。
2. 长臂液压剪站在建筑外侧作业，作业半径内不得站人；机械回转半径与邻近建筑、线路保持安全距离。
3. 机械拆除框架结构应按楼板、次梁、主梁、柱的顺序进行，严禁先拆柱、主梁。
4. 机械不得带故障运转，不得超载作业，不得任意扩大使用范围。
5. 拆除的较大构件应采用起重机具吊下，严禁向下抛掷。
6. 机械作业时设专人指挥、专人监护，发现结构异常立即停止作业。

#### 6. 楼面小型机械作业

1. 小型破碎锤上楼前，应验算楼板承载力；不满足时设置回顶支撑、铺设钢板、沿梁行走。
2. 回顶支撑采用Φ48.3×3.6钢管，立杆间距不大于1.2m，步距不大于1.5m，顶托顶紧楼板。
3. 机械行走路线应避开悬挑板、后浇带、洞口和切割后的楼板，沿主梁方向行驶。
4. 楼面作业时，下方楼层不得同时作业，设置水平兜网和警戒。

#### 7. 人工配合与局部切割

1. 人工拆除应从上而下、逐层进行，不得上下同时作业，不得掏掘、推倒。
2. 人工拆除时使用手动工具，不得使用大锤猛击承重构件；作业人员站在稳定结构上，系挂安全带。
3. 局部保留结构采用静力切割，切割前设置临时支撑，切割后及时吊运，不得使保留结构失去稳定。
4. 切割用水、泥浆应收集沉淀，不得直接排入市政管网。
5. 采用静态破碎（破碎剂）时，应写明破碎剂型号、适用温度、孔径、孔距、孔深、装药量和养护时间；钻孔不得损伤保留钢筋和相邻结构，装药后人员撤离至安全距离，破碎剂反应期间不得浇水、不得扰动。
6. 静态破碎适用于混凝土构件、基础或不宜产生振动、飞石的部位；作业时应佩戴防护眼镜、手套，防止喷孔灼伤。
7. 本项目采用静态破碎的部位为【填写：部位／不涉及】，其参数以产品说明书和试破碎结果确定。

#### 8. 基础拆除

1. 上部结构拆除完成、渣土清运后，方可进行基础拆除。
2. 基础拆除前查明地下管线、化粪池、电缆沟、人防设施，切断相关管线。
3. 条形基础采用破碎锤分段破碎，保留邻近建筑基础安全距离，必要时设置支护。
4. 基础拆除后及时回填、分层夯实，场地平整至设计标高。

#### 9. 降尘、降噪与垃圾清运

1. 拆除作业全程洒水降尘，配备雾炮机，破碎点、装卸点重点喷洒。
2. 建筑垃圾及时清运，不得在场地内长期堆存；堆场设置围挡、覆盖、洒水。
3. 运输车辆封闭覆盖，出场冲洗轮胎，按规定路线、时段行驶，不得遗撒。
4. 控制施工噪声，夜间不得进行破碎、切割等强噪声作业；确需夜间施工的，办理审批并公告周边。
5. 建筑垃圾按可回收物、惰性物、有害物分类，交有资质单位运输、消纳。

## 五、施工保证措施 {#c5}

### （一）组织保障措施

1. 成立以项目经理为组长的拆除安全领导小组，明确技术、安全、施工、机械、监测职责。
2. 拆除作业由专业班组实施，机械司机、起重工、架子工持证上岗，专人指挥、专人监护。
3. 建立方案交底、班前讲话、检查整改、阶段验收、应急演练制度。
4. 与周边单位、管线产权单位建立联系机制，明确应急联系人。
5. 在施工现场显著位置公告本项目拆除工程的名称、施工时间和具体责任人员，并在危险区域设置安全警示标志（依据37号令第十四条）。
6. 项目负责人应在拆除作业期间现场履职，项目专职安全生产管理人员应实施现场监督（依据37号令第十七条）。

### （二）技术措施

#### 1. 安全保证措施

1. 严格执行拆除工程「十不准」：无方案不准拆、未断管线不准拆、未设围挡不准拆、未设防护不准拆、结构不清不准拆、顺序不对不准拆、机械带病不准拆、人员未交底不准拆、大风大雨不准拆、警戒未设不准拆（本表述为行业通行管理要求，非法规原文，具体条文出处待核）。
2. 拆除作业区设置警戒线和警示标志，无关人员不得进入；临街部位设置防护通道。
3. 高处作业人员系挂安全带，设置操作平台、临边防护和水平生命线。
4. 严禁向下抛掷材料、工具和垃圾；较大构件采用起重机具吊下。
5. 临时用电按《建筑与市政工程施工现场临时用电安全技术标准》JGJ/T 46-2024 执行（住建部公告2024年第152号：2025-01-01施行，原 JGJ 46-2005 同日废止）。该标准第3.1.1条适用于施工现场临时用电工程专用的电源中性点直接接地的220/380V三相四线制低压电力系统，按该条应采用三级配电系统、TN-S系统和二级剩余电流动作保护系统（第3.1.2条：总配电箱、分配电箱、开关箱三级配电装置）；拆除前切断原有电源。
6. 动火作业办理审批，清除周边可燃物，配备灭火器材，设专人监护。
7. 与架空线路保持规定安全距离，不能满足时采取停电、迁改或绝缘隔离措施。

#### 2. 质量技术保证措施

1. 拆除前进行结构检测，查明结构体系、构件尺寸、配筋和损伤，作为拆除顺序和机械选型依据。
2. 保留部位设置明显标识和隔离，采取支撑、包封、覆盖等保护措施。
3. 拆除到位，不得留下悬挑、孤立构件；基础拆除至设计标高，回填密实。
4. 场地平整、无积水、无残留垃圾，满足移交条件。

#### 3. 文明施工保证措施

1. 围挡连续封闭，出入口设置门卫、冲洗设施和警示标志。
2. 材料、机械定点存放，场地整洁，道路畅通。
3. 建筑垃圾及时清运，堆场覆盖、洒水。
4. 夜间施工控制噪声和照明，减少对周边影响。

#### 4. 环境保护措施

1. 拆除作业全程洒水降尘，配备雾炮机，破碎、装卸重点喷洒。
2. 运输车辆封闭覆盖，出场冲洗，防止遗撒。
3. 建筑垃圾按类分流，交有资质单位运输、消纳，不得随意倾倒。
4. 废机油、废电池等有害物分类收集，交有资质单位处理。
5. 保护周边树木、绿地，不得随意砍伐、占用。

#### 5. 季节性施工保证措施

1. 雨季施工做好排水、防滑、防坍塌，基坑、沟槽设置支护和排水。
2. 高温季节调整作业时间，供应防暑降温用品，防止中暑。
3. 冬季施工清除冰雪，采取防滑措施，风力6级及以上停止作业。
4. 台风季节提前加固围挡、防护棚，收起机械臂，台风过后全面检查。

## 九、计算书及相关施工图纸 {#c9}

### （一）计算书应包含的内容

1. 计算依据、计算参数、计算简图、荷载组合、控制指标和计算结果。
2. 拆除工程量、建筑垃圾量、运输车辆和工期匹配计算。
3. 机械拆除能力、机械站位处地基承载力、机械上楼楼面承载力、回顶支撑及下层楼板验算。
4. 构件吊运验算：最大构件重量、吊车工况、吊索具。
5. 防护棚抗冲击、抗风验算；围挡抗风验算。
6. 防震沟减振、邻近建筑和管线振动控制验算。
7. 局部保留结构的临时支撑验算。
8. 采用爆破时，按GB 6722-2014进行爆破参数、安全距离、振动、飞石验算。

### （二）示例算式

> 以下算例对应本方案范例开头的示例工程，仅演示计算步骤和数值关系，不得替代项目实际计算。实际计算应按结构检测报告、实际构件尺寸和现行规范进行。

#### 1. 建筑垃圾量及运输计算（示例）

建筑面积A＝6800m²，框架结构拆除垃圾产生量按0.85t/m²估算（该指标为经验值，示例取值，实际应按结构形式、装修情况和当地统计资料确定）：

W＝6800×0.85＝5780t，取5800t

松散体积（松散体积密度取1.6t/m³，示例取值，应按实测松散密度确定；5800t÷1.6t/m³＝3625m³）：

V＝5800/1.6＝3625m³，取3600m³

按工期60d、有效运输45d，日运输量：

V日＝3600/45＝80m³/d

选用载重15t自卸汽车，按每车装运8m³、每日4车计，需车辆：

N＝80/(8×4)＝2.5，取3辆

3辆车每日可运96m³，大于日需80m³，运输能力满足。

#### 2. 楼面小型机械承载力验算（示例）

5t小型破碎锤，机重G＝50kN，冲击系数K＝1.5，履带接地面积A＝2×0.35×2.8＝1.96m²：

q＝K×G/A＝1.5×50/1.96＝38.3kN/m²

原楼板设计活荷载2.0kN/m²，远小于38.3kN/m²，不能直接上楼作业。

采取回顶措施：回顶范围3.0m×3.0m，立杆间距1.2m×1.2m，共9根立杆。回顶范围总荷载设计值取机重乘冲击系数：

P＝1.5×50＝75kN

单根立杆承担：

N＝75/9＝8.3kN

Φ48.3×3.6钢管立杆稳定承载力远大于8.3kN，满足要求；同时铺设20mm厚钢板扩散荷载，机械沿主梁方向行走。回顶传至下层楼板（及再下层）的荷载应逐层验算，必要时连续两层回顶；本示例假定下层为同强度楼板且已设连续回顶，未再列出逐层验算过程。

#### 3. 构件吊运验算（示例）

最大吊运构件为主梁，截面300×700mm，长6.0m（尺寸取结构检测报告和图纸，混凝土容重取25kN/m³）：

V＝0.3×0.7×6.0＝1.26m³

G＝1.26×25＝31.5kN＝3.15t

考虑动载系数1.1、吊具0.3t、吊钩0.2t：

Q计＝3.15×1.1＋0.3＋0.2＝3.97t

25t汽车吊，幅度8m、臂长27.6m时额定起重量9.5t（以该机型起重性能表为准）：

3.97t＜9.5t，满足要求。

#### 4. 防护棚木板抗冲击验算（示例）

防护棚顶层铺50mm厚木板，木板支承于楞木上，楞木间距0.5m，故板跨L＝0.5m；取1m宽板带，按均布荷载q＝1.0kN/m（含落物冲击）验算：

M＝qL²/8＝1.0×0.5²/8＝0.031kN·m

W＝bh²/6＝1000×50²/6＝416667mm³

σ＝M/W＝0.031×10⁶/416667＝0.07N/mm²

0.07N/mm²＜13N/mm²（木材抗弯强度设计值，示例取值，具体取值应按所采用木结构标准确定），满足要求。

挠度：

I＝bh³/12＝1000×50³/12＝1.04×10⁷mm⁴

δ＝5qL⁴/(384EI)＝5×1.0×500⁴/(384×10000×1.04×10⁷)＝0.008mm

0.008mm＜L/250＝2mm，满足要求。

楞木及横杆另按2.0m跨承受板传来的荷载验算，本示例未列出计算过程。

#### 5. 围挡抗风验算（示例）

围挡高2.5m，立柱间距3.0m，基本风压ω0＝0.45kN/m²，风压高度变化系数μz＝1.0，体型系数μs＝1.3：

ωk＝0.7×0.45×1.0×1.3＝0.41kN/m²

单根立柱承受风力：

F＝ωk×3.0×2.5＝3.08kN

作用点距基础1.25m，倾覆弯矩：

M＝3.08×1.25＝3.85kN·m

立柱采用100×100×3mm方钢管，W≈36.6cm³：

σ＝3.85×10⁶/(36.6×10³)＝105.2N/mm²

105.2N/mm²＜215N/mm²，满足要求；基础采用C20混凝土墩，预埋螺栓固定。

> 基本风压应按GB 50009-2012取用：临时围挡可按施工期（如10年一遇）取值，永久或跨年使用按50年一遇取值，并在方案中写明取值口径；0.7为风荷载组合值系数，版本出处待核。

#### 6. 防震沟减振说明（示例）

南侧管线距拆除建筑5m，设置宽0.6m、深1.0m防震沟，沟长沿管线布置。破碎锤作业时对管线处振动速度控制值取0.5cm/s，超过时降低机械冲击频率、增加防震沟深度或改用静力切割。振动监测点布置在管线正上方地表，每2h观测一次。

#### 7. 其他验算项目及判别式

| 验算项目 | 计算式（示意） | 控制指标 |
| --- | --- | --- |
| 回顶立杆稳定 | N/(φA) | ≤205N/mm² |
| 回顶立杆地基 | p＝N/A | ≤fak |
| 吊索受力 | T＝Q/(n·sinα) | ≤破断拉力/安全系数 |
| 防护棚立杆稳定 | N/(φA) | ≤205N/mm² |
| 防护棚基础 | p＝N/A | ≤fak |
| 局部支撑 | 按受弯、受压构件验算 | 强度、稳定满足 |
| 邻近建筑振动 | 振动速度 | ≤【填写】cm/s |
| 爆破安全距离 | 按GB 6722-2014 | 满足 |

> 本表判别式为通行示意，其中立杆稳定应力限值 205N/mm²、振动速度控制值等具体条文出处待核，应按所采用标准原文确定；表中数值为示例。
