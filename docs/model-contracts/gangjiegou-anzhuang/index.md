# 钢结构安装工程专项施工方案编写范例（本站整理）

<LawBanner />

> **本站依据官方指南整理，不是官方文本；不得直接用于报审，须结合项目实际、现行标准和专业人员复核。**

本页梳理文本组成、危大判定与九章结构，不替代项目实际方案、设计文件或吊装工况分析。[读全文与条款原文 →](./full.md)

## 文本组成

本方案范例由三部分组成：

1. **使用说明**：适用范围与危大属性判定、编制与审批流程、填写要求，并给出一个虚构的示例工程设定，供对照写法。
2. **九章正文**：按建办质〔2021〕48号第九章规定的九章顺序展开——工程概况、编制依据、施工计划、施工工艺技术、施工保证措施、施工管理及作业人员配备和分工、验收要求、应急处置措施、计算书及相关施工图纸。
3. **附录 A～D**：专项施工方案审批表、专家论证会签到表、专家论证报告要点、编制依据（文号、标准号）核对表。

文中【填写：…】为项目填写处；示例工程与示例数据均为虚构，仅用于说明写法和数值关系。正文与附录中的表式均标注「本站整理表式，非官方表式」。

## 危大属性与审批

按建办质〔2018〕31号附件 1，钢结构、网架和索膜结构安装工程属于危险性较大的分部分项工程，应编制专项施工方案。

按附件 2，跨度 36m 及以上的钢结构安装工程，或跨度 60m 及以上的网架和索膜结构安装工程，属于超过一定规模的危险性较大的分部分项工程，按 37 号令第十二条应当组织专家论证。

审批流程：

1. 实行施工总承包的，由施工总承包单位组织编制；实行分包的，可由专业分包单位编制，但须由总承包单位与分包单位技术负责人共同审核签字并加盖单位公章。
2. 经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的，由施工总承包单位组织专家论证；论证结论应为专家组一致意见，结论为「修改后通过」的，修改完善后重新履行审核审查程序，并将修改情况及时告知专家；不通过的，修改后重新组织论证。
4. 实施前逐级进行方案交底和安全技术交底，由双方及项目专职安全生产管理人员共同签字确认。
5. 不得擅自修改方案；因设计变更、吊装分段调整、起重设备或临时支撑体系改变等确需调整的，重新审核、论证。

## 教材里怎么讲

- **质量与安全 8.2**「危险性较大的分部分项工程施工安全管理」：危大工程范围、专项施工方案编制与审查、专家论证、现场安全管理、验收与应急处置，是本方案范例九章结构的主要依据。
- **质量与安全 8.1**「安全风险管理」：危险源分类与风险分级，对应第一章的风险辨识与分级、第五章的监测监控。
- **质量与安全 1.3**「安全生产管理主要制度」第四部分「危大工程管理」：专项方案的编制、签字、论证要求及未编制、未审查的法律责任。
- **案例分析 3.12**「安全生产管理的监理工作」：专项施工方案的编制与审查、危大工程现场安全管理，对应监理审查本方案的考点。
- **案例分析 1.4**「建设工程安全生产管理条例」：监理单位未审查专项施工方案的法律责任。

7. **监测与验收**：第五章与表 5-1 列出临时支撑沉降、桁架挠度、柱顶位移、基础沉降和风速的监测要求；第七章及表 7-1 写明验收合格须经施工单位项目技术负责人及总监理工程师签字确认后方可进入下一道工序，验收人员按 31 号文第七条列明。

9. **算例说明**：第九章先按整体吊装验算，荷载率 101.9% 不满足，示例据此改为分两段吊装并重新验算至 51.6%，用于说明「先验算、不满足则调整工况」的写法；吊耳只验算净截面拉应力，未验算孔壁承压和焊缝；临时支撑只验算单根立杆稳定，未验算整体稳定和基础；各项限值与系数出处未核实。
