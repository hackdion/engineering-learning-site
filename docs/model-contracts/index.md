# 合同示范文本

按合同类型归档施工、监理、总承包、咨询、勘察设计、分包与标准招标文件。每份文本分「导读」与「条文」两部分：导读说明适用范围、文本结构和填写要点，条文保留原编号与附件顺序。

<LawIndex mode="contracts" />

## 接入说明 {#pending}

已接入两份文本：建设工程施工合同（示范文本）GF-2017-0201、建设工程监理合同（示范文本）GF-2012-0202。卡片点击进入导读页，导读页可再进全文；其余类型仍为占位卡，标记「待接入」时不可点击。

每份文本在 `docs/model-contracts/` 下占一个目录：`index.md` 为导读与条款索引，`full.md` 为按原件顺序排列的全文。补齐版本卡字段（文本名称、编号、类型、发文与执行日期、版本状态、官方出处）即可进入本页与左侧分组，不需要改组件。
