# 合同示范文本

按合同类型归档施工、监理、总承包、咨询、勘察设计、分包与标准招标文件。每份文本分「导读」与「条文」两部分：导读说明适用范围、文本结构和填写要点，条文保留原编号与附件顺序。

<LawIndex mode="contracts" />

## 接入说明 {#pending}

当前为骨架版：卡片按合同类型分组并显示筛选，文本名称与编号来自规划清单，正文、版本日期和附件仍在整理。卡片标记「待接入」时不可点击，接入后自动改为导读入口。

正式接入时，每份文本在 `docs/model-contracts/` 下建立独立页面，补齐版本卡字段（文本名称、编号、颁布/发布单位、施行日期、版本状态、官方出处），即可进入本页与左侧分组，不需要改组件。
