# 合同示范文本

按类型归档施工、监理、总承包、咨询、勘察设计、分包与标准招标文件，并收录按分部分项工程分类的专项施工方案示范文本。每份文本分「导读」与「全文」两部分：导读说明适用范围、文本结构和填写要点，全文保留原顺序与编号。

<LawIndex mode="contracts" />

## 接入说明 {#pending}

已接入两份合同示范文本：建设工程施工合同（示范文本）GF-2017-0201、建设工程监理合同（示范文本）GF-2012-0202；另接入五份专项施工方案示范文本：基坑工程、模板工程及支撑体系、起重吊装及安装拆卸、脚手架、拆除工程。卡片点击进入导读页，导读页可再进全文；其余类型仍为占位卡，标记「待接入」时不可点击。

专项施工方案示范文本依据住房和城乡建设部令第 37 号、建办质〔2018〕31 号、建办质〔2021〕48 号整理，属**本站整理文本，非官方示范文本**，版本卡中标明「整理依据」与「文本性质」，文中的表式均标注「本站整理表式，非官方表式」。

每份文本在 `docs/model-contracts/` 下占一个目录：`index.md` 为导读与条款索引，`full.md` 为按原件顺序排列的全文。合同文本补齐版本卡字段（文本名称、编号、类型、发文与执行日期、版本状态、官方出处），专项方案写清整理依据与文本性质，即可进入本页与左侧分组，不需要改组件。
