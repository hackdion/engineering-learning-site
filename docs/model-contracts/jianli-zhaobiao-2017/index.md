# 标准监理招标文件（2017年版）中标通知书与投标文件格式

<LawBanner />

本页只摘录与监理合同文件构成直接相关的三份格式：中标通知书、投标函、投标函附录。文字按原件转录，原件中的空白填写处以下划线表示，格式未作改写。

来源为《标准监理招标文件》（2017年版），国家发展改革委等九部门以发改法规〔2017〕1606号于2017年9月4日印发，自2018年1月1日起实施。实际招标、投标时，以招标文件及其组成部分为准。

## 适用范围 {#fw}

《标准监理招标文件》使用说明第一条：

一、《标准监理招标文件》适用于工程监理招标。

因此，该标准文件只规定招标工程使用的格式。非招标工程由委托人直接委托监理，合同文件中的委托书、监理与相关服务建议书不属于本文件的组成部分，全国层面也没有统一格式，由委托文件约定。

## 中标通知书 {#zbtzs}

（第二章 附件四，原件第 30 页）

________（中标人名称）：

你方于________（投标日期）所递交的________（项目名称）监理招标的投标文件已被我方接受，被确定为中标人。

中标价：________元。

监理服务期限：________日历天。

总监理工程师：________（姓名）。

请你方在接到本通知书后的________日内到________（指定地点）与我方签订监理合同，并按招标文件第二章“投标人须知”第7.6款规定向我方提交履约保证金。

特此通知。

招标人：________（盖单位章）

法定代表人：________（签字）

________年________月________日

## 投标文件格式 {#tbwj}

第六章投标文件格式由下列部分组成（原件第 69 页目录）：一、投标函及投标函附录；二、法定代表人身份证明（适用于无委托代理人的情况）；二、授权委托书（适用于有委托代理人的情况）；三、联合体协议书；四、投标保证金；五、监理报酬清单；六、资格审查资料；七、监理大纲；八、其他资料。其中与本合同文件构成直接相关的是投标函及投标函附录，转录如下。

### 投标函 {#tbh}

（原件第 70～71 页）

________（招标人名称）：

1．我方已仔细研究了________（项目名称）监理招标项目招标文件的全部内容，愿意以人民币（大写）________（¥________）的投标总报价（其中，增值税税率为________），监理服务期限：________日历天，按合同约定完成监理工作。

2. 我方的投标文件包括下列内容：

（1）投标函及投标函附录；

（2）法定代表人身份证明或授权委托书；

（3）联合体协议书（如有）；

（4）投标保证金（如有）；

（5）监理报酬清单；

（6）资格审查资料；

（7）监理大纲；

……

投标文件的上述组成部分如存在内容不一致的，以投标函为准。

3．我方承诺在招标文件规定的投标有效期内不撤销投标文件。

4．如我方中标，我方承诺：

（1）在收到中标通知书后，在中标通知书规定的期限内与你方签订合同；

（2）在签订合同时不向你方提出附加条件；

（3）按照招标文件要求提交履约保证金；

（4）在合同约定的期限内完成合同规定的全部义务。

5．我方在此声明，所递交的投标文件及有关资料内容完整、真实和准确，且不存在第二章“投标人须知”第1.4.3项规定的任何一种情形。

6．________（其他补充说明）。

投标人：________（盖单位章）

法定代表人或其委托代理人：________（签字）

地址：________

网址：________

电话：________

传真：________

邮政编码：________

________年________月________日
