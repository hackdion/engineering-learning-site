# 脚手架工程专项施工方案（示范文本）

> 本示范文本依据《危险性较大的分部分项工程专项施工方案编制指南》（建办质〔2021〕48号）第四章「脚手架工程」的编制内容与顺序编写，供施工单位编制具体项目方案时参照，不替代设计文件、计算书和项目实际论证。
>
> 文中【填写：…】为项目填写处；未加标记的条文为示范性通用表述，应结合项目实际修改。文中示例工程、示例数据均为虚构，仅用于说明写法和数值关系，不得直接用于实际工程。

## 使用说明 {#sm}

### 一、适用范围与危大属性判定

1. 本示范文本适用于房屋建筑和市政基础设施工程中的落地式钢管脚手架、悬挑式脚手架、附着式升降脚手架、高处作业吊篮、卸料平台及操作平台等。
2. 按《危险性较大的分部分项工程安全管理规定》（住房和城乡建设部令第37号，2019年修正）及《住房城乡建设部办公厅关于实施〈危险性较大的分部分项工程安全管理规定〉有关问题的通知》（建办质〔2018〕31号）附件1，搭设高度24m及以上的落地式钢管脚手架工程（包括采光井、电梯井脚手架），附着式升降脚手架工程，悬挑式脚手架工程，高处作业吊篮，卸料平台、操作平台工程，异型脚手架工程，属于危险性较大的分部分项工程，应编制专项施工方案。
3. 按建办质〔2018〕31号附件2，搭设高度50m及以上的落地式钢管脚手架工程，提升高度在150m及以上的附着式升降脚手架工程或附着式升降操作平台工程，架体高度20m及以上的悬挑式脚手架工程，属于超过一定规模的危险性较大的分部分项工程，施工单位应当组织召开专家论证会。
4. 本项目脚手架搭设总高度为【填写：高度】m，其中落地段【填写：高度】m、悬挑段【填写：高度】m，按上述标准判定为【填写：危大工程／超过一定规模的危大工程】。
5. 附着式升降脚手架、高处作业吊篮等工具式脚手架，除本方案外，还应按产品说明书、专业分包合同和相应标准编制专项方案，并履行安装、检测、验收程序。

### 二、编制与审批流程

1. 专项施工方案由施工总承包单位组织编制；实行分包的，可由专业分包单位组织编制，但须由总承包单位技术负责人及分包单位技术负责人共同审核签字并加盖单位公章。
2. 方案经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的，方案在通过施工单位审核和总监理工程师审查后，由施工总承包单位组织专家论证；论证结论为「修改后通过」的，修改完善后重新履行审核审查程序；论证不通过的，修改后重新组织论证。
4. 方案实施前，编制人员或项目技术负责人向施工现场管理人员进行方案交底，施工现场管理人员向作业人员进行安全技术交底，并由双方和项目专职安全生产管理人员共同签字确认。
5. 脚手架搭设完成后，应按本方案组织验收，验收合格并挂设验收合格牌后方可使用；未经验收或验收不合格的，不得使用。

### 三、填写要求

1. 所有项目特定信息统一使用【填写：…】标记，不得留空、不得以「同上」「略」代替。
2. 本章节顺序不得删减；本项目确不涉及的条、款，写「本项目不涉及」并说明理由，不得直接删除。
3. 架体参数、构配件规格、连墙件间距、悬挑梁型号必须与计算书一致；同一参数在全文中只采用一个数值。
4. 脚手架搭设高度应自搭设基础面算至架体顶端，注明是否包含女儿墙、防护栏杆高度。
5. 图表应连续编号，图名在图下、表名在表上；引用图纸时写明图号。
6. 文中标注「本站整理表式，非官方表式」的表格，仅为便于项目使用而整理，不是住房和城乡建设部或地方主管部门发布的官方附件，不得以官方名义引用。

### （二）工艺流程

1. 搭设工艺流程：

施工准备 → 基础处理与验收 → 放置垫板、底座 → 立杆定位 → 安装扫地杆 → 逐层安装立杆、水平杆 → 安装连墙件 → 安装剪刀撑 → 铺设脚手板 → 挂设密目网、兜网 → 安装防护栏杆、挡脚板 → 验收挂牌。

2. 悬挑架安装工艺流程：

悬挑层结构施工预埋U型螺栓 → 混凝土达到设计强度 → 安装悬挑工字钢 → 安装压板、拧紧螺母 → 安装钢丝绳、花篮螺栓 → 搭设上部架体 → 安装连墙件 → 验收。

3. 拆除工艺流程：

设置警戒 → 清理架体材料 → 拆除密目网、脚手板 → 拆除剪刀撑 → 拆除连墙件（随架体逐层拆除） → 拆除水平杆 → 拆除立杆 → 拆除悬挑梁、钢丝绳 → 材料分类堆放、退场。

### （三）施工方法及操作要求

#### 1. 施工准备

1. 编制并审批专项方案，完成方案交底和安全技术交底。
2. 架子工持证上岗，进行体检，禁止高血压、心脏病、恐高症人员从事高处作业。
3. 钢管、扣件、脚手板、安全网进场验收，不合格不得使用。
4. 基础处理：回填土分层夯实，压实系数不小于【填写】，铺设C15混凝土硬化层，厚度不小于【填写】mm，设置排水沟。
5. 弹出架体立杆位置线，复核建筑边线、悬挑梁位置和标高。

#### 2. 基础与底座

1. 落地架基础应平整、坚实、排水畅通，垫板长度不小于2跨，垫板下不得悬空。
2. 底座放置在垫板中心，立杆与底座插接牢固，不得用砖块、石块垫高。
3. 架体基础为结构楼板时，应验算楼板承载力，必要时设置回顶支撑。
4. 基础周边设排水沟和集水井，防止积水浸泡。

#### 3. 立杆与水平杆

1. 立杆接头采用对接扣件，接头交错布置，相邻立杆接头不得在同步同跨内，错开距离不小于500mm。
2. 立杆垂直度偏差不大于架体高度的1/500，且不大于100mm。
3. 纵向水平杆设置在立杆内侧，长度不小于3跨，采用对接扣件连接，接头交错布置。
4. 横向水平杆在主节点处必须设置，偏离主节点距离不大于150mm，外伸长度符合方案要求。
5. 扫地杆：纵向扫地杆距底座上皮不大于200mm，横向扫地杆紧靠纵向扫地杆下方。

#### 4. 剪刀撑与横向斜撑

1. 架体外侧沿全高、全长连续设置剪刀撑，每道剪刀撑宽度不大于8m，斜杆与地面夹角45°～60°。
2. 剪刀撑斜杆采用旋转扣件固定在立杆或横向水平杆伸出端，扣件中心距主节点不大于150mm。
3. 剪刀撑搭接长度不小于1.0m，采用不少于2个旋转扣件固定。
4. 24m以上架体全立面连续设置；转角、端部、开口处应设置横向斜撑，中间每隔6跨设置一道。

#### 5. 连墙件

1. 连墙件按两步三跨设置，菱形布置，从底层第一步纵向水平杆处开始设置。
2. 连墙件采用刚性连接，优先采用预埋件＋短钢管＋双扣件，不得采用仅靠钢丝绳、钢筋拉结的柔性连接。
3. 连墙件应靠近主节点设置，偏离主节点距离不大于300mm，呈水平、垂直于墙面。
4. 连墙件不得随意拆除；因施工需要临时拆除时，应经项目技术负责人同意，采取加固措施并在作业完成后立即恢复。
5. 架体两端、转角、顶部及特殊部位应加密连墙件。

#### 6. 脚手板与安全防护

1. 脚手板应铺满、铺稳、铺实，不得有探头板、空隙板和活动板。
2. 钢笆片应与横向水平杆绑扎固定，木脚手板两端用镀锌钢丝固定。
3. 作业层设1.2m高防护栏杆和180mm高挡脚板，外侧满挂密目网。
4. 首层、每隔10m及作业层下方设置水平兜网，兜网应绷紧、固定牢靠。
5. 架体内立杆与结构之间空隙大于150mm时，应铺设脚手板或设置水平防护。

#### 7. 悬挑架安装

1. 悬挑层结构施工时按设计位置预埋U型螺栓，预埋位置偏差不大于10mm，混凝土强度达到设计值后方可安装悬挑梁。
2. 悬挑工字钢安装前检查型号、长度、焊缝和防腐，安装时紧贴结构面，压板与U型螺栓拧紧，螺母下设垫板。
3. 悬挑梁外端设置Φ16钢丝绳斜拉卸荷，钢丝绳与水平夹角约60°，采用花篮螺栓张紧，绳卡不少于3个，间距不小于6d。
4. 悬挑梁上立杆位置应焊接短钢筋固定，防止立杆滑移；立杆底部设底座和垫板。
5. 悬挑梁安装完成后，经项目技术负责人、安全员、监理验收合格，方可搭设上部架体。
6. 悬挑梁锚固端不得设置在悬挑板、空调板等非承重构件上；锚固长度和螺栓数量不得减少。

#### 8. 架体使用要求

1. 架体验收合格并挂设「验收合格牌」后方可使用，牌上注明搭设高度、允许荷载、验收日期、责任人。
2. 施工荷载不得超过3.0kN/m²，同时作业层数不得超过2层，不得集中堆料。
3. 不得在架体上拉缆风绳、固定泵管、搭设起重设备，不得利用架体支撑模板。
4. 不得随意拆除杆件、连墙件、安全网；确需拆除时按审批程序办理。
5. 每日班前检查架体、连墙件、脚手板、安全网，发现隐患立即整改。
6. 遇大风、暴雨、大雪后，应全面检查架体，确认安全后方可使用。

#### 9. 架体拆除

1. 拆除前编制拆除交底，设置警戒区，清除架体上材料和杂物。
2. 拆除应自上而下逐层进行，先搭后拆、后搭先拆，严禁上下同时作业。
3. 连墙件应随架体逐层拆除，严禁先将连墙件全部拆除后再拆架体。
4. 拆除的杆件、扣件、脚手板应采用传递或吊运方式下放，严禁抛掷。
5. 悬挑梁拆除应在上一段架体拆除完成后进行，先拆钢丝绳、再拆压板、最后抽出工字钢。
6. 拆除至地面2m时，应设置临时支撑，防止架体整体倾倒。

## 五、施工保证措施 {#c5}

### （一）组织保障措施

1. 成立以项目经理为组长的脚手架安全领导小组，明确技术、安全、施工、材料、监测职责。
2. 脚手架搭设、拆除由专业班组实施，架子工持证上岗，专人指挥、专人监护。
3. 建立方案交底、班前讲话、检查整改、验收挂牌和应急演练制度。

### （二）技术措施

#### 1. 安全保证措施

1. 严格执行脚手架「十不搭」：无方案不搭、基础不合格不搭、材料不合格不搭、无交底不搭、无防护不搭、连墙件不到位不搭、剪刀撑不连续不搭、大风大雨不搭、夜间照明不足不搭、验收不合格不使用。
2. 高处作业人员系挂安全带，安全带高挂低用，挂点牢固。
3. 架体与架空线路保持安全距离，不能满足时采取停电、迁改或绝缘隔离。
4. 架体设置防雷接地，接地电阻不大于10Ω。
5. 架体上动火作业办理动火审批，配备灭火器材，设专人监护。

#### 2. 质量技术保证措施

1. 钢管、扣件、脚手板、安全网进场验收，按批抽检，不合格退场。
2. 立杆接头错开，水平杆交圈，剪刀撑连续，连墙件刚性连接。
3. 扣件螺栓扭矩控制在40～65N·m，不得过紧或过松。
4. 架体搭设偏差按JGJ 130-2011和GB 51210-2016控制，超差立即纠正。
5. 悬挑梁焊缝由持证焊工施焊，按设计要求检测。

#### 3. 文明施工保证措施

1. 材料分类堆放、挂牌标识，场地整洁，道路畅通。
2. 架体杆件、扣件不得随意堆放，拆除材料及时清运。
3. 安全网、密目网保持整洁，破损及时更换。
4. 夜间施工控制噪声和照明，减少扰民。

#### 4. 环境保护措施

1. 钢管除锈、刷漆在指定区域进行，废漆、废油分类收集。
2. 拆除时洒水降尘，建筑垃圾及时清运。
3. 控制施工噪声，避免夜间进行切割、敲击作业。
4. 安全网、脚手板等周转材料分类回收，减少浪费。

#### 5. 季节性施工保证措施

1. 雨季施工做好排水、防滑、防雷，架体基础不得积水。
2. 高温季节调整作业时间，供应防暑降温用品。
3. 冬季施工清除架体冰雪，采取防滑措施，五级以上大风停止作业。
4. 台风季节提前加固架体、拆除密目网或卸载，台风过后全面检查。

### （二）示例算式

> 以下算例对应本模板开头示例工程，仅演示计算步骤和数值关系，不得替代项目实际计算。实际计算应按项目架体参数、荷载和现行规范进行。

#### 1. 立杆轴力计算（悬挑段，示例）

架体高21.6m，步距1.8m，共12步；立杆纵距1.5m，横距0.9m。

每米立杆承受结构自重标准值gk＝0.125kN/m：

NG1k＝0.125×21.6＝2.70kN

构配件自重：

脚手板2层：0.35×1.5×0.9×2＝0.945kN

栏杆、挡脚板：0.14×1.5×12＝2.52kN

密目网：0.005×1.5×21.6＝0.162kN

NG2k＝0.945＋2.52＋0.162＝3.63kN

施工荷载（3.0kN/m²，2层同时作业，按最不利1层计算）：

NQk＝3.0×1.5×0.9＝4.05kN

立杆轴力设计值：

N＝1.2×(NG1k＋NG2k)＋1.4×NQk
＝1.2×(2.70＋3.63)＋1.4×4.05
＝7.60＋5.67＝13.27kN

#### 2. 立杆稳定性验算（示例）

Φ48.3×3.6钢管，A＝506mm²，i＝15.9mm，W＝5260mm³，f＝205N/mm²。

长细比：

λ＝l0/i＝1800/15.9＝113.2

按Q235、b类截面查表，稳定系数φ≈0.50。

风荷载标准值（ω0＝0.45kN/m²，μz＝1.31，μs＝1.0）：

ωk＝0.7×0.45×1.31×1.0＝0.413kN/m²

风荷载产生的弯矩：

Mw＝0.9×1.4×ωk×la×h²/10
＝0.9×1.4×0.413×1.5×1.8²/10
＝0.253kN·m

稳定性验算：

σ＝N/(φA)＋Mw/W
＝13270/(0.50×506)＋253000/5260
＝52.5＋48.1＝100.6N/mm²

100.6N/mm²＜205N/mm²，立杆稳定性满足要求。

#### 3. 连墙件验算（示例）

连墙件两步三跨，覆盖面积：

Aw＝3.6×4.5＝16.2m²

风荷载产生的连墙件轴向力：

Nlw＝1.4×ωk×Aw＝1.4×0.413×16.2＝9.37kN

连墙件轴向力设计值：

Nl＝Nlw＋N0＝9.37＋3.0＝12.37kN

单扣件抗滑承载力设计值8.0kN，双扣件12.0kN，均小于12.37kN，故不采用纯扣件连接，改用预埋件＋短钢管＋双扣件刚性连墙件，预埋件抗拉承载力不小于15kN。

#### 4. 悬挑梁强度、刚度验算（示例）

悬挑梁采用16#工字钢，Wx＝141cm³，Ix＝1130cm⁴，自重0.205kN/m。悬挑梁间距1.5m，外挑1.5m，锚固2.0m；内立杆距结构0.30m，外立杆距结构1.20m。

每根悬挑梁承受两根立杆轴力，N＝13.27kN。

未设钢丝绳时，支座处最大弯矩：

M＝13.27×1.20＋13.27×0.30＋0.205×1.5×0.75
＝15.92＋3.98＋0.23＝20.13kN·m

σ＝M/Wx＝20.13×10⁶/(141×10³)＝142.8N/mm²

142.8N/mm²＜215N/mm²，强度满足要求，但悬挑端挠度较大，故设置Φ16钢丝绳斜拉卸荷。

设钢丝绳承担外立杆荷载的60%，则挑梁支座弯矩：

M＝(13.27×0.40)×1.20＋13.27×0.30＋0.23
＝6.37＋3.98＋0.23＝10.58kN·m

σ＝10.58×10⁶/(141×10³)＝75.0N/mm²

外立杆剩余荷载P＝13.27×0.40＝5.31kN，悬挑端挠度：

δ＝PL³/(3EI)
＝5310×1200³/(3×206000×1130×10⁴)
＝1.3mm

1.3mm＜L/250＝4.8mm，刚度满足要求。

#### 5. 钢丝绳及锚固验算（示例）

钢丝绳拉力（与水平夹角60°）：

T＝5.31/sin60°＝5.31/0.866＝6.13kN

考虑花篮螺栓预紧和舞动，取1.5倍：

T设计＝1.5×6.13＝9.20kN

Φ16mm、6×19+FC、1670MPa钢丝绳最小破断拉力约143kN：

K＝143/9.20＝15.5＞6，满足要求。

悬挑梁锚固端拉力：

R＝M/2.0＝20.13/2.0＝10.07kN

采用2道Φ20 U型螺栓（As＝314mm²/根），锚固钢筋抗拉承载力：

2×314×210＝131.9kN＞10.07kN，满足要求；同时应验算锚固处混凝土局部承压和抗冲切。

#### 6. 立杆地基承载力验算（示例）

落地段立杆轴力N＝13.27kN，垫板尺寸0.2m×1.5m：

p＝N/A＝13.27/(0.2×1.5)＝44.2kPa

基础经硬化处理，地基承载力特征值fak＝120kPa：

44.2kPa＜120kPa，满足要求。

### （四）计算书及图纸编制注意事项

1. 计算书应由具备相应能力的技术人员编制，项目技术负责人审核，施工单位技术负责人审批。
2. 架体参数、构配件规格、连墙件间距必须与计算书、图纸一致。
3. 风荷载应按施工期实际可能出现的风力取值，台风地区应单独校核。
4. 悬挑梁锚固应验算锚固螺栓抗拔、混凝土局部承压和抗冲切，不得只验算钢梁强度。
5. 图纸应标注尺寸、标高、型号、节点做法，图签完整，签字齐全。
6. 计算书、图纸应随方案一同报审、论证，架体参数变化时重新验算。
