## 使用说明 {#sm}

### 一、适用范围与危大属性判定

1. 本方案范例适用于房屋建筑和市政基础设施工程中的基坑（槽）土方开挖、支护、降水工程。
2. 按《危险性较大的分部分项工程安全管理规定》（住房和城乡建设部令第37号，2019年修正）及《住房城乡建设部办公厅关于实施〈危险性较大的分部分项工程安全管理规定〉有关问题的通知》（建办质〔2018〕31号）附件1，开挖深度超过3m（含3m），或开挖深度虽未超过3m但地质条件、周围环境和地下管线复杂，或影响毗邻建（构）筑物安全的基坑（槽）土方开挖、支护、降水工程，属于危险性较大的分部分项工程，应编制专项施工方案。
3. 按建办质〔2018〕31号附件2，开挖深度超过5m（含5m）的基坑（槽）土方开挖、支护、降水工程，属于超过一定规模的危险性较大的分部分项工程，按37号令第十二条应当组织专家论证。
4. 本项目基坑开挖深度为【填写：开挖深度】m，最大开挖深度为【填写：局部最大深度】m，按上述标准判定为【填写：危大工程／超过一定规模的危大工程】。

### 二、编制与审批流程

1. 实行施工总承包的，专项施工方案由施工总承包单位组织编制；实行分包的，可由专业分包单位组织编制，但须由总承包单位技术负责人及分包单位技术负责人共同审核签字并加盖单位公章。
2. 方案经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的，方案在通过施工单位审核和总监理工程师审查后，由施工总承包单位组织专家论证；论证结论应为专家组的「一致意见」，结论为「修改后通过」的，修改完善后重新履行审核审查程序，并将修改情况及时告知专家；论证不通过的，修改后重新组织论证。
4. 方案实施前，编制人员或项目技术负责人向施工现场管理人员进行方案交底，施工现场管理人员向作业人员进行安全技术交底，并由双方和项目专职安全生产管理人员共同签字确认。
5. 施工单位不得擅自修改专项施工方案；因规划调整、设计变更等确需调整的，修改后的方案应重新审核、论证。

### 三、填写要求

1. 所有项目特定信息统一使用【填写：…】标记，不得留空、不得以「同上」「略」代替。
2. 本章节顺序不得删减；本项目确不涉及的条、款，写「本项目不涉及」并说明理由，不得直接删除。
3. 数值应注明单位；同一参数在全文中只采用一个数值，前后不一致时以设计文件和专家论证后的方案为准，并同步修改所有引用处。
4. 图表应连续编号，图名在图下、表名在表上；引用图纸时写明图号。
5. 文中标注「本站整理表式，非官方表式」的表格，仅为便于项目使用而整理，不是住房和城乡建设部或地方主管部门发布的官方附件，不得以官方名义引用。

### （二）工艺流程

#### 1. 总体施工工艺流程

施工准备及测量放线 → 支护桩施工 → 桩身质量检测 → 止水帷幕施工 → 冠梁及第一道支撑施工 → 降水井施工及预降水 → 第一层土方开挖 → 第二道支撑施工及养护 → 第二层土方开挖至坑底 → 验槽、垫层及底板施工 → 主体结构施工 → 支撑拆除及土方回填 → 基坑监测贯穿全过程。

#### 2. 分项工程工艺流程

1. 支护桩：场地平整 → 桩位放样 → 护筒埋设 → 成孔 → 清孔 → 钢筋笼制作与吊装 → 导管安装 → 水下混凝土灌注 → 桩顶混凝土凿除 → 桩身检测。
2. 三轴水泥土搅拌桩：场地处理 → 桩位放样 → 桩机就位 → 切土下沉 → 水泥浆制备 → 提升搅拌 → 重复搅拌 → 桩机移位 → 成桩检测。
3. 冠梁及支撑：土方开挖至冠梁底 → 凿除桩顶浮浆 → 钢筋绑扎 → 模板安装 → 混凝土浇筑 → 养护 → 拆模 → 支撑轴力监测点安装。
4. 降水：井位放样 → 钻孔 → 井管安装 → 滤料回填 → 洗井 → 试抽 → 正式降水 → 水位观测。
5. 土方开挖：分层分段放线 → 机械开挖 → 人工清底 → 支撑施工或垫层浇筑 → 排水 → 监测 → 下一层开挖。

### （三）施工方法及操作要求

#### 1. 施工准备

1. 完成图纸会审、设计交底和方案交底；核对支护结构、降水井、支撑与主体结构的位置关系，避免冲突。
2. 完成场地平整、临时道路、临时用水用电、排水系统、泥浆池及沉淀池布置；场地承载力应满足桩机、吊车行走和作业要求。
3. 复核测量控制点，建立基坑平面控制网和高程控制网，控制点应设在基坑影响范围以外并定期复测。
4. 查明地下管线、障碍物位置，必要时人工探挖；对需要保护的管线设置明显标识和监测点。
5. 材料、构配件、设备进场并完成验收；计量器具、监测仪器在检定有效期内。

7. 桩身完整性检测按【填写：低应变／声波透射】进行，检测数量和结果应符合设计要求。

1. 桩机就位后应调平，桩位偏差不应大于【填写】mm，垂直度偏差不应大于【填写】。
2. 水泥浆应按规定配合比制备，水灰比【填写】，水泥掺量【填写】%，浆液应随拌随用，停放时间超过【填写】h 不得使用。
3. 下沉和提升速度应均匀，下沉速度不宜大于【填写】m/min，提升速度不宜大于【填写】m/min；应重复搅拌【填写】次，保证桩体均匀。
4. 相邻桩搭接长度不应小于【填写】mm，搭接时间间隔不应大于【填写】h；因故停浆时应在恢复施工前将桩机下沉至停浆点以下【填写】m 再提升。
5. 桩顶应凿除浮浆至设计标高，桩身 28d 无侧限抗压强度不应小于【填写】MPa，渗透系数不应大于【填写】cm/s。
6. 帷幕应闭合，转角、丁字接头、与支护桩交接部位应加强；发现渗漏应及时封堵并分析原因，不得盲目注浆。

#### 4. 冠梁与内支撑施工

1. 冠梁沟槽开挖后应凿除桩顶浮浆和松散混凝土，桩顶主筋锚入冠梁长度应符合设计要求。
2. 冠梁、支撑钢筋绑扎应保证位置准确，支撑与围檩、立柱节点应按设计详图施工，焊缝质量应符合设计要求。
3. 模板应具有足够强度、刚度和稳定性，接缝严密，不得漏浆；支撑底模应考虑拆除顺序和沉降。
4. 混凝土应连续浇筑、振捣密实，施工缝应按规范处理；养护时间不应少于【填写】d。
5. 支撑达到设计强度【填写】%后方可进行下一层土方开挖；支撑立柱应防止侧向失稳，立柱与支撑节点应可靠连接。
6. 支撑上不得堆放材料、行走重型机械；确需穿越支撑的，应设置专用通道并经验算。

#### 5. 降水与回灌

1. 降水井施工应在基坑开挖前完成，预降水时间不应少于【填写】d，水位降至坑底以下【填写】m 后方可开挖。
2. 降水应连续进行，配备备用泵和备用电源；泵的排水能力应大于设计涌水量的【填写】倍。
3. 抽水含砂量应控制，发现井水浑浊、含砂应及时停抽检查，防止带走地层细颗粒。
4. 坑外应设置水位观测井和回灌井；当周边水位下降超过【填写】mm/d 或建筑物沉降接近预警值时，应启动回灌。
5. 回灌水应清洁，回灌压力不宜过大，防止顶托地层；回灌量与抽水量应平衡，避免造成新的沉降或隆起。
6. 降水期间应做好水位、水量、含砂量记录，每日汇总分析。

#### 6. 土方开挖

1. 土方开挖必须在支护结构、降水、监测均满足要求后进行；开挖前应确认支撑已达到设计强度。
2. 遵循「分层、分段、对称、限时」原则，每层开挖厚度不应大于【填写】m，分段长度不应大于【填写】m，严禁超挖、掏底开挖。
3. 机械开挖至坑底以上【填写】mm 时改为人工清底，防止扰动基底；坑底应及时浇筑垫层，无支撑暴露时间不应超过【填写】h。
4. 挖掘机、自卸汽车不得在支撑上行走或作业；机械回转半径内严禁站人；坑边【填写】m 范围内严禁堆载。
5. 开挖过程中应随时观察土层、支护结构、支撑和周边环境变化，发现异常立即停止开挖并报告。
6. 坑内应设置排水沟和集水井，及时排除积水；雨季施工应备足排水设备并保持坑顶截排水畅通。

#### 7. 支撑拆除与土方回填

1. 支撑拆除应在主体结构达到设计强度、且换撑（或结构代换）措施完成后进行，拆除顺序应符合设计要求，严禁提前拆除。
2. 拆除前应释放支撑轴力，采用机械或静力切割，严禁爆破；拆除作业应设置警戒区，防止坠物伤人。
3. 支撑拆除后应及时回填或施工换撑结构，减少基坑无支撑暴露时间。
4. 土方回填应在主体结构外墙防水、保护层验收合格后进行；回填土料、含水率、分层厚度应符合设计及规范要求，每层厚度不宜大于【填写】mm，压实系数不应小于【填写】。
5. 回填应对称、均匀进行，防止主体结构受偏压；回填过程中应继续监测支护结构和周边环境。

## 五、施工保证措施 {#c5}

### （一）组织保障措施

1. 成立以项目负责人为组长的基坑工程安全生产领导小组，成员包括项目技术负责人、专职安全生产管理人员、施工员、质量员、监测负责人及各班组负责人。
2. 建立安全生产责任制，明确各岗位安全职责；项目负责人对基坑工程安全生产全面负责，项目技术负责人对方案实施和技术措施负责，专职安全生产管理人员对现场监督检查负责。
3. 建立方案交底、安全技术交底、班前教育、安全检查、隐患整改、应急演练等制度，并保留记录。
4. 施工单位应在施工现场显著位置公告危大工程名称、施工时间和具体责任人员，在危险区域设置安全警示标志。
5. 项目负责人应在施工现场履职，专职安全生产管理人员应对专项施工方案实施情况进行现场监督，发现未按方案施工的，应要求立即整改。

### （二）技术措施

#### 1. 安全保证措施

1. 严格执行「先撑后挖、分层分段、限时完成」的开挖原则，严禁超挖、掏底开挖和擅自改变开挖顺序。
2. 基坑周边设置连续、牢固的防护栏杆，高度不应低于1.2m，设置挡脚板和安全网；夜间设置警示灯。
3. 基坑内设置专用上下通道，宽度不应小于【填写】m，设置扶手、防滑条和照明；严禁攀爬支撑、立柱上下。
4. 坑边【填写】m 范围内严禁堆载，施工道路、材料堆场与坑边距离应经验算确定；重型机械行走路线应避开支撑和基坑影响范围。
5. 支撑上不得堆放材料、不得行走；确需在支撑附近作业时，应设置操作平台和防护设施。
6. 临时用电采用TN-S系统，做到三级配电、两级保护；电缆不得拖地、泡水，配电箱应防雨防潮。
7. 起重吊装应编制吊装作业方案，设置警戒区，由专职信号司索工指挥；大风、暴雨、大雾等恶劣天气停止吊装和开挖作业。
8. 基坑内作业人员应佩戴安全帽，高处作业系安全带；有限空间作业应先通风、检测，合格后方可进入。

#### 2. 质量技术保证措施

1. 建立测量复核制度，控制点、轴线、标高由测量员放样、技术负责人复核、监理工程师验线。
2. 支护桩、帷幕、支撑施工应逐桩逐段进行工序检查，上道工序不合格不得进入下道工序。
3. 混凝土浇筑应控制配合比、坍落度、振捣和养护，试块按规定留置；冬期、雨期施工应采取相应措施。
4. 钢筋、水泥等材料应见证取样送检，检测不合格的材料不得使用并应清退出场。
5. 做好施工记录、隐蔽工程验收记录、监测记录和影像资料，资料应与施工进度同步。

#### 3. 文明施工保证措施

1. 施工现场围挡连续、封闭，出入口设置大门、洗车槽和沉淀池，车辆冲洗后出场。
2. 土方运输车辆应覆盖，防止遗撒；施工道路应硬化并定期洒水降尘。
3. 材料分类堆放、标识清晰，钢筋加工场、木工加工场应封闭或半封闭。
4. 生活区、办公区与作业区分离，设置临时厕所、垃圾收集点，保持场地整洁。

#### 4. 环境保护措施

1. 控制施工噪声，夜间施工应办理许可并公告周边居民；高噪声设备应设置隔声屏障。
2. 泥浆、废水应经沉淀处理后排放，不得直接排入市政管网或水体；泥浆外运应采用密闭车辆。
3. 扬尘控制采用洒水、覆盖、喷淋等措施；水泥、砂石等易扬尘材料应封闭存放。
4. 保护周边树木、绿地及市政设施；施工结束后及时恢复场地。

#### 5. 季节性施工保证措施

1. 雨季施工：提前疏通排水系统，备足水泵、发电机、砂袋、彩条布；暴雨前覆盖边坡、检查支护和支撑，暴雨后先检查再作业。
2. 汛期施工：与气象、水文部门建立联系，掌握雨情、水情；临近河道、湖泊的基坑应设置防汛围堰和撤离通道。
3. 高温施工：合理安排作业时间，避开高温时段，供应防暑降温饮品和药品。
4. 冬期施工：混凝土采取保温、防冻措施，不得在冻结的地基上搭设支撑；雪后及时清除坑边积雪和结冰。

### （三）监测监控措施

#### 1. 监测组织与职责

1. 建设单位委托具有相应勘察资质的第三方监测单位进行监测；施工单位开展施工监测，监理单位对监测实施进行监督检查。
2. 监测方案由监测单位编制，明确监测项目、测点布置、监测方法、频率、预警值和控制值，经监测单位技术负责人审核签字并加盖单位公章，报送监理单位后方可实施；作为附加管理要求，监测方案还应送设计、建设单位确认。
3. 监测人员应固定，仪器应在检定有效期内；监测数据应真实、及时，不得涂改、补记。

#### 2. 监测项目、频率及控制值

监测范围应覆盖基坑本体、支护结构、周边建（构）筑物、道路、地下管线及地下水；各项目的监测方法（如水准测量、极坐标法、测斜、轴力计、水位观测等）应在监测方案中逐项明确。

#### 3. 巡视检查

1. 监测单位每日进行现场巡视，检查基坑侧壁、支护结构、支撑、坑底、周边道路、建筑物、管线及排水系统；施工单位应同时开展安全巡视，发现险情立即撤离人员并报告。
2. 巡视内容包括：有无渗水、漏砂、裂缝、变形、沉降、隆起、支撑松动、异响、积水等。
3. 巡视发现异常应立即拍照、记录并报告；必要时加密监测并启动预警程序。

#### 4. 信息反馈与预警处置

1. 监测数据应当日整理、当日反馈；达到预警值时，监测单位应立即口头报告建设、施工、监理、设计单位，并在【填写】h 内提交书面预警报告。
2. 达到报警值时，施工单位应立即停止开挖，撤离危险区域人员，组织分析原因并采取措施；监理单位应下达停工令并报告建设单位。
3. 达到控制值时，施工单位应立即启动应急预案，组织抢险，并按规定报告主管部门。
4. 监测成果应定期汇总分析，绘制时间-位移曲线，判断变形趋势；施工工况变化时应进行专项分析。

## 七、验收要求 {#c7}

### （一）验收标准

1. 支护结构、止水帷幕、冠梁、支撑、降水、土方开挖的验收应符合设计文件、《建筑地基基础工程施工质量验收标准》GB 50202-2018、《混凝土结构工程施工质量验收规范》GB 50204-2015 及地方标准的规定。
2. 验收应具备下列条件：施工记录、材料合格证及复试报告、隐蔽工程验收记录、检测报告、监测数据齐全；上道工序验收合格。
3. 基坑开挖至基底且变形相对稳定后，应组织基坑验收；验收合格后方可进行垫层和底板施工。

### （二）验收程序及人员

1. 验收程序：施工单位自检 → 项目技术负责人组织预验收 → 监理单位组织验收 → 形成验收记录 → 设置验收标识牌，并公示验收时间及责任人员。
2. 验收人员应包括：总承包单位和分包单位技术负责人或授权委派的专业技术人员、项目负责人、项目技术负责人、专项施工方案编制人员、专职安全生产管理人员及相关人员；监理单位项目总监理工程师及专业监理工程师；建设单位项目负责人；有关勘察、设计和监测单位项目技术负责人。
3. 验收合格须经施工单位项目技术负责人及总监理工程师签字确认后，方可进入下一道工序；验收不合格的，应限期整改并重新验收；未经验收或验收不合格的，不得进入下道工序。

### （五）应急响应流程

发现险情 → 现场人员立即报告项目负责人并撤离危险区域 → 项目负责人启动应急预案、组织抢险 → 设置警戒、疏散人员 → 报告建设、监理、监测单位及主管部门 → 勘察、设计单位配合分析险情、提出处理方案 → 组织专家分析、制定抢险方案 → 实施抢险并加密监测 → 险情稳定后，由建设单位组织评估、制定恢复方案并开展后评估 → 修复、复工 → 总结并完善预案。

## 九、计算书及相关施工图纸 {#c9}

### （一）计算书应包含的内容

1. 计算依据、计算参数、计算简图（模型）、荷载工况组合、控制指标和计算结果。
2. 支护结构内力与变形计算：桩身弯矩、剪力、位移，支撑轴力，冠梁内力。
3. 稳定性验算：整体稳定、抗倾覆、抗隆起、抗突涌、抗渗流（管涌）稳定。
4. 支撑体系计算：支撑截面承载力、立柱承载力及稳定、节点连接强度。
5. 降水计算：涌水量估算、井数量及井深、降水影响范围、回灌量。
6. 支护桩配筋计算及裂缝宽度验算。
7. 当基坑为具有相应资质的单位进行正式施工图设计时，本章可附设计计算书摘要，并说明设计单位、图号及审查情况；施工单位仍应对施工工况、超挖、坑边荷载等进行复核。

### （二）示例算式

> 以下算例对应本模板开头示例工程，仅演示计算步骤和数值关系，不得替代项目实际计算。实际计算应按勘察报告分层参数、设计工况和现行规范进行。

#### 1. 主动土压力计算（简化单层示例）

取②粉质黏土，重度 γ＝18.5 kN/m³，黏聚力 c＝15 kPa，内摩擦角 φ＝18°，开挖深度 H＝8.6m。

主动土压力系数：

Ka＝tan²(45°－φ/2)＝tan²(36°)＝0.528

深度 z 处主动土压力强度：

ea(z)＝Ka·γ·z－2c·√Ka

坑底处：

ea(8.6)＝0.528×18.5×8.6－2×15×√0.528
＝84.0－21.8＝62.2 kPa

临界深度：

z0＝2c/(γ·√Ka)＝30/(18.5×0.727)＝2.23 m

即 0～2.23m 范围内主动土压力为零，2.23m 以下按上式线性增加。

#### 2. 单根支撑轴力估算（简化示例）

取支撑间距 s＝9.0m，按单位长度主动土压力合力估算：

Ea＝1/2×62.2×(8.6－2.23)＝198.1 kN/m

单根支撑轴力标准值：

Nk＝Ea×s＝198.1×9.0＝1783 kN

考虑温度、施工荷载及不均匀性，设计值取：

N＝1.35×Nk＝2407 kN

（1.35 为示例取值，分项系数应按设计文件及现行规程确定。上述估算将全部主动土压力合力计入单根支撑，偏于保守，仅作初估；正式计算应按弹性支点法分工况计算，并计入坑边超载、地下水及温度作用。）

据此进行支撑截面承载力、配筋及立柱稳定验算；示例截面 800×900、C35 应经验算满足要求后方可采用。
