# 基坑工程专项施工方案（示范文本）

<LawBanner />

本页梳理文本组成、危大判定与九章结构，不替代项目实际方案、设计文件或勘察报告。[读全文与条款原文 →](./full.md)

## 文本组成

本示范文本由三部分组成：

1. **使用说明**：适用范围与危大属性判定、编制与审批流程、填写要求，并给出一个虚构的示例工程设定，供对照写法。
2. **九章正文**：按建办质〔2021〕48号第一章规定的九章顺序展开——工程概况、编制依据、施工计划、施工工艺技术、施工保证措施、施工管理及作业人员配备和分工、验收要求、应急处置措施、计算书及相关施工图纸。
3. **附录 A～D**：专项施工方案审批表、专家论证会签到表、专家论证报告要点、编制依据（文号、标准号）核对表。

文中【填写：…】为项目填写处；示例工程与示例数据均为虚构，仅用于说明写法和数值关系。正文与附录中的表式均标注「本站整理表式，非官方表式」。

## 危大属性与审批

按建办质〔2018〕31号附件 1，开挖深度 3m 及以上，或开挖深度虽未超过 3m 但地质条件、周围环境和地下管线复杂，或影响毗邻建（构）筑物安全的基坑（槽）土方开挖、支护、降水工程，属于危险性较大的分部分项工程，应编制专项施工方案。

按附件 2，开挖深度 5m 及以上的同类工程，属于超过一定规模的危险性较大的分部分项工程，施工单位应当组织召开专家论证会。

审批流程：

1. 施工总承包单位组织编制；实行分包的，可由专业分包单位编制，但须由总承包单位与分包单位技术负责人共同审核签字并加盖单位公章。
2. 经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的，由施工总承包单位组织专家论证；结论为「修改后通过」的，修改完善后重新履行审核审查程序；不通过的，修改后重新组织论证。
4. 实施前逐级进行方案交底和安全技术交底，由双方及项目专职安全生产管理人员共同签字确认。
5. 不得擅自修改方案；因规划调整、设计变更等确需调整的，重新审核、论证。

## 教材里怎么讲

- **质量与安全 8.2**「危险性较大的分部分项工程施工安全管理」：危大工程范围、专项施工方案编制与审查、专家论证、现场安全管理、验收与应急处置，是本示范文本九章结构的主要依据。
- **质量与安全 8.1**「安全风险管理」：危险源分类与风险分级，对应第一章的风险辨识与分级、第五章的监测监控。
- **质量与安全 1.3**「安全生产管理主要制度」第四部分「危大工程管理」：专项方案的编制、签字、论证要求及未编制、未审查的法律责任。
- **案例分析 3.12**「安全生产管理的监理工作」：专项施工方案的编制与审查、危大工程现场安全管理，对应监理审查本方案的考点。
- **案例分析 1.4**「建设工程安全生产管理条例」：监理单位未审查专项施工方案的法律责任。
