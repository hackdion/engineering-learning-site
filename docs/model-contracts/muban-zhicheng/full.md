## 使用说明 {#sm}

### 一、适用范围与危大属性判定

1. 本示范文本适用于混凝土模板支撑工程，包括搭设高度5m及以上的现浇混凝土模板支撑工程，或搭设跨度10m及以上，或施工总荷载（荷载效应基本组合的设计值）10kN/m²及以上，或集中线荷载（设计值）15kN/m及以上，或高度大于支撑水平投影宽度且相对独立无联系构件的混凝土模板支撑工程。
2. 按建办质〔2018〕31号附件1，上述范围属于危险性较大的分部分项工程，应编制专项施工方案。
3. 按建办质〔2018〕31号附件2，搭设高度8m及以上，或搭设跨度18m及以上，或施工总荷载（设计值）15kN/m²及以上，或集中线荷载（设计值）20kN/m及以上的混凝土模板支撑工程，属于超过一定规模的危险性较大的分部分项工程，施工单位应当组织召开专家论证会。
4. 本项目高支模区域为【填写：部位】，搭设高度【填写】m，最大跨度【填写】m，最大梁截面【填写】mm×【填写】mm，板厚【填写】mm，按上述标准判定为【填写：危大工程／超过一定规模的危大工程】。

### 二、编制与审批流程

1. 专项施工方案由施工总承包单位组织编制；实行分包的，可由专业分包单位组织编制，但须由总承包单位技术负责人及分包单位技术负责人共同审核签字并加盖单位公章。
2. 方案经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的，方案在通过施工单位审核和总监理工程师审查后，由施工总承包单位组织专家论证；论证结论为「修改后通过」的，修改完善后重新履行审核审查程序；论证不通过的，修改后重新组织论证。
4. 方案实施前，编制人员或项目技术负责人向施工现场管理人员进行方案交底，施工现场管理人员向作业人员进行安全技术交底，并由双方和项目专职安全生产管理人员共同签字确认。
5. 施工单位不得擅自修改专项施工方案；因设计变更、材料替代、支撑体系变更等确需调整的，修改后的方案应重新审核、论证。

### 三、填写要求

1. 所有项目特定信息统一使用【填写：…】标记，不得留空、不得以「同上」「略」代替。
2. 本章节顺序不得删减；本项目确不涉及的条、款，写「本项目不涉及」并说明理由，不得直接删除。
3. 支撑体系参数、荷载取值、计算书和附图必须一致；修改任一参数时，应同步修改计算书、平面图、剖面图和验收表。
4. 图表应连续编号，图名在图下、表名在表上；引用图纸时写明图号。
5. 文中标注「本站整理表式，非官方表式」的表格，仅为便于项目使用而整理，不是住房和城乡建设部或地方主管部门发布的官方附件，不得以官方名义引用。

#### 3. 构造措施

1. 竖向剪刀撑：架体四周及中部每隔【填写】跨设置一道，宽度【填写】m，由底至顶连续设置；梁高超过600mm时，沿梁方向设置竖向剪刀撑。

### （二）工艺流程

施工准备及放线 → 支撑基础处理及验收 → 放置可调底座、安放扫地杆 → 逐层搭设立杆、水平杆、竖向斜杆 → 安装可调托撑 → 铺设主梁、小梁 → 铺设模板 → 模板起拱、校正 → 支架及模板验收 → 钢筋绑扎、预埋 → 浇筑前复验 → 混凝土浇筑及监测 → 养护 → 拆除。

### （三）施工方法及操作要求

#### 1. 施工准备

1. 完成图纸会审、方案交底和安全技术交底；核对梁板截面、标高、跨度与支架布置图一致。
2. 支撑基础应平整、坚实；支撑在结构板上时，应核对结构板承载力并经设计单位确认；支撑在回填土上时，应分层夯实并设置垫板、排水措施。
3. 按方案放出台架边线、立杆定位线、梁底线和剪刀撑位置线，并复核标高。
4. 材料进场后应逐批检查规格、壁厚、焊缝、锈蚀、变形和插头、销片完好情况；不合格材料不得使用。
5. 作业人员应经安全教育和技术交底，架子工持证上岗；作业面应设置临边防护和上下通道。

#### 2. 支架搭设

1. 按定位线安放可调底座，底座下设置垫板；底座丝杆伸出长度不应大于【填写】mm。
2. 立杆应逐根安装，底部设置扫地杆，扫地杆距支撑面不应大于【填写】mm；立杆接头应错开布置，不得在同一水平面集中对接。
3. 水平杆应随立杆逐层安装，插头插入连接盘后应敲紧销片，销片应自上而下插紧，不得遗漏。
4. 竖向斜杆应按方案布置，与立杆连接盘可靠连接；搭设高度超过8m时竖向斜杆满布，不得随意减少。
5. 架体应保持横平竖直，立杆垂直度偏差不应大于【填写】，水平杆水平度偏差不应大于【填写】。
6. 每搭设【填写】层应进行一次检查，校正立杆间距、步距、垂直度和剪刀撑位置；发现偏差及时调整，不得在架体上集中堆放材料。
7. 架体顶部安装可调托撑，托撑丝杆插入立杆长度不应小于【填写】mm，伸出长度不应大于【填写】mm；托撑托板应与主梁居中受力。
8. 架体与已浇筑柱、墙按方案抱结；抱柱件应独立设置，不得随意连接在临边防护、脚手架或机电管道上。

#### 3. 模板安装

1. 主梁应铺设在可调托撑托板上，主梁接头应错开，悬挑长度不应大于【填写】mm；小梁应垂直于主梁铺设，间距均匀。
2. 模板面板应拼缝严密、表面平整，接缝处贴胶带或填缝，不得漏浆；模板与混凝土接触面应清理干净并涂刷脱模剂。
3. 梁、板跨度大于4m时，模板应按设计要求起拱；设计无要求时，起拱高度宜为跨度的【填写】/1000～【填写】/1000，起拱不得削减梁截面高度。
4. 梁侧模应设置对拉螺栓，螺栓间距、直径应符合方案；梁高超过【填写】mm时，应设置双螺母或加设垫板。
5. 模板安装后应复核轴线、标高、截面尺寸、平整度和垂直度；预留洞、预埋件位置应准确，不得事后剔凿。
6. 模板安装完成后应清理架体上多余材料和垃圾，保持作业面整洁。

#### 4. 支撑架使用要求

1. 浇筑前应完成支架、模板验收，确认立杆间距、步距、剪刀撑、顶托、抱柱、模板支撑符合方案；浇筑前24小时内应进行再次验收。
2. 混凝土浇筑应编制浇筑顺序图，由中间向两侧对称、均匀进行，严禁从一端向另一端单向推进或集中堆载。
3. 分层浇筑厚度不应大于【填写】mm，浇筑速度不应大于【填写】m/h；梁、板交接部位应先浇梁、后浇板，避免梁侧模受集中侧压力。
4. 振捣器不得直接触碰模板、钢筋、预埋件和支撑体系；振捣应密实，防止漏振、过振。
5. 浇筑过程中应安排专人观察支架、模板、支撑基础，发现立杆沉降、水平位移、模板鼓胀、支撑异响等异常，立即停止浇筑、撤离人员并报告。
6. 浇筑期间项目经理、项目技术负责人、专职安全员、监理工程师应在场；浇筑完成后应按方案继续监测至混凝土初凝后【填写】h。
7. 混凝土养护时间不应少于【填写】d；冬期、雨期、高温施工应按专项措施执行。

#### 5. 模板及支架拆除

1. 拆模时间应根据同条件养护试块强度确定：板跨度≤2m 时混凝土强度达到设计值的50%以上，2m＜跨度≤8m 时达到75%以上，跨度＞8m 时达到100%；梁跨度≤8m 时达到75%以上，跨度＞8m 时达到100%；悬臂构件达到100%。
2. 拆模前应办理拆模申请，经项目技术负责人和监理工程师批准；拆模顺序应按方案进行，先支后拆、后支先拆，先拆非承重模板、后拆承重模板。
3. 拆除支架应自上而下逐层进行，严禁上下同时作业、整体推倒或拉倒；拆除的构配件应及时传运至地面，不得抛掷。
4. 拆除区域应设置警戒线和警示标志，设专人监护；拆除作业人员应佩戴安全帽、系安全带，站在稳固位置。
5. 后浇带处支架不得随主体支架同时拆除；后浇带封闭并达到设计强度后方可拆除。
6. 拆下的模板、支架应及时清理、维修、分类堆放，变形、损坏的构配件不得再次使用。

#### 6. 常见问题及预防、处理措施

| 常见问题 | 主要原因 | 预防措施 | 处理措施 |

## 五、施工保证措施 {#c5}

### （一）组织保障措施

1. 成立以项目负责人为组长的高支模安全生产领导小组，成员包括项目技术负责人、专职安全生产管理人员、施工员、质量员、架子工班组长和混凝土班组长。
2. 建立安全生产责任制，明确各岗位职责；项目负责人对高支模施工安全全面负责，项目技术负责人对方案实施和技术措施负责，专职安全生产管理人员对现场监督检查负责。
3. 建立方案交底、安全技术交底、班前教育、材料验收、搭设过程检查、浇筑前验收、浇筑过程值守、拆模审批等制度。
4. 施工单位应在施工现场显著位置公告危大工程名称、施工时间和具体责任人员，在危险区域设置安全警示标志。
5. 项目负责人应在施工现场履职；专职安全生产管理人员应对专项施工方案实施情况进行现场监督，发现未按方案施工的，应要求立即整改。

### （二）技术措施

#### 1. 安全保证措施

1. 支架搭设、拆除人员必须持架子工特种作业操作证上岗，作业前进行安全技术交底和班前教育。
2. 作业层应满铺脚手板，设置防护栏杆、挡脚板和安全网；临边、洞口应设置防护设施和警示标志。
3. 支架上不得集中堆放模板、钢筋等材料；施工荷载不得超过方案规定值，不得在支架上行走重型机械。
4. 支架搭设、拆除区域应设置警戒线和专人监护，禁止上下同时作业，禁止抛掷构配件。
5. 高处作业人员应系挂安全带，安全带应高挂低用，挂在牢固的结构或生命绳上，不得挂在支架水平杆上。
6. 临时用电采用TN-S系统，做到三级配电、两级保护；电缆不得拖地、泡水，配电箱应防雨防潮。
7. 混凝土浇筑期间应保证照明充足，设置备用电源；泵管应独立固定，不得直接固定在支架上。
8. 大风、暴雨、大雾、雪天应停止支架搭设、拆除和高处作业；雨后、雪后应检查基础、支架和防护设施，确认安全后方可作业。

#### 2. 质量技术保证措施

1. 支架材料应进行进场验收和抽样检测，壁厚、焊缝、插头、托撑不符合要求的不得使用。
2. 严格执行放线、搭设、校正、验收程序，每搭设一层检查一次，搭设完成后进行整体验收。
3. 模板安装应控制轴线、标高、截面尺寸、平整度和拼缝，起拱高度应符合设计及方案要求。
4. 混凝土浇筑应控制配合比、坍落度、分层厚度、振捣和养护，试块按规定留置。
5. 拆模应以同条件养护试块强度为依据，办理拆模审批，不得凭经验或工期压力提前拆模。
6. 做好施工记录、验收记录、监测记录和影像资料，资料应与施工进度同步。

#### 3. 文明施工保证措施

1. 施工现场围挡连续、封闭，材料分类堆放、标识清晰，支架构配件按规格码放整齐。
2. 施工道路硬化、定期洒水降尘；模板、木方加工区应设置防尘、降噪措施。
3. 作业面做到工完料尽场地清，拆下的模板、支架及时清理、维修、堆放。
4. 生活区、办公区与作业区分离，设置临时厕所、垃圾收集点，保持场地整洁。

#### 4. 环境保护措施

1. 控制施工噪声，夜间施工应办理许可并公告周边居民；高噪声设备应设置隔声屏障。
2. 模板脱模剂、废机油等应集中收集处理，不得随意倾倒。
3. 木方、模板边角料应分类回收，不得在现场焚烧。
4. 混凝土泵车、运输车辆应冲洗，废水经沉淀后排入市政管网。

#### 5. 季节性施工保证措施

1. 雨期施工：支架基础应排水畅通，设置排水沟和集水井；雨后检查基础沉降、立杆垂直度和支架整体稳定。
2. 高温施工：合理安排作业时间，避开高温时段，供应防暑降温饮品和药品；混凝土浇筑后及时养护。
3. 冬期施工：支架基础不得受冻，混凝土采取保温、防冻措施；雪后清除支架、模板和作业面积雪、结冰。
4. 大风天气：停止高处作业和吊装，检查架体拉结、剪刀撑和临边防护，必要时加固。

### （三）监测监控措施

#### 1. 监测组织与职责

1. 施工单位负责支架变形监测，必要时委托第三方监测；监理单位对监测实施进行监督检查。
2. 监测方案应明确监测项目、测点布置、监测方法、频率、预警值和控制值，经项目技术负责人和总监理工程师确认。
3. 监测人员应固定，仪器应在检定有效期内；监测数据应真实、及时，不得涂改、补记。

#### 2. 监测项目、频率及控制值

#### 3. 巡视检查

1. 支架搭设期间，每搭设一层由施工员、安全员、架子工班组长检查一次；搭设完成后由项目技术负责人组织验收。
2. 混凝土浇筑前24小时内，由项目技术负责人组织方案编制人、专职安全员、分包单位项目负责人及监理单位，对地基、支架搭设质量、混凝土浇筑设施进行再验收。
3. 浇筑期间应安排专人对支架、模板、支撑基础连续巡视，重点检查立杆沉降、水平杆变形、剪刀撑松动、顶托滑移、模板鼓胀和支撑基础渗水。
4. 巡视发现异常应立即报告，必要时停止浇筑、撤离人员。

#### 4. 信息反馈与预警处置

1. 监测数据应实时记录、及时反馈；达到预警值时，监测人员应立即报告项目技术负责人和总监理工程师，加密监测并分析原因。
2. 达到报警值时，应立即停止浇筑，撤离作业人员，组织加固；未经重新验收合格不得恢复浇筑。
3. 达到控制值或发现架体明显变形、异响、杆件弯曲时，应立即启动应急预案，设置警戒，组织抢险，并按规定报告主管部门。
4. 监测成果应整理成表，绘制沉降、位移时间曲线，作为拆模和后续施工的依据。

## 七、验收要求 {#c7}

### （一）验收标准

1. 模板及支架的验收应符合设计文件、《混凝土结构工程施工质量验收规范》GB 50204-2015、《建筑施工模板安全技术规范》JGJ 162-2008、《建筑施工承插型盘扣式钢管支架安全技术规程》JGJ 231-2010 及地方标准的规定。
2. 验收应具备下列条件：材料合格证及检测报告、支架搭设记录、模板安装记录、隐蔽工程验收记录、监测点布置及初始值记录齐全；上道工序验收合格。
3. 高支模支架应实行三次验收：搭设前对支撑基础验收；搭设完成后对支架、模板验收；混凝土浇筑前24小时内再验收。验收合格并履行签字手续后方可浇筑。

### （二）验收程序及人员

1. 验收程序：班组自检 → 施工员、质量员复检 → 项目技术负责人组织预验收 → 监理单位组织验收 → 形成验收记录 → 设置验收标识牌。
2. 验收人员应包括：总承包单位和分包单位技术负责人或授权委派的专业技术人员、项目负责人、项目技术负责人、专项施工方案编制人员、专职安全生产管理人员及相关人员；监理单位项目总监理工程师及专业监理工程师；有关设计单位项目技术负责人。
3. 验收不合格的，应限期整改并重新验收；未经验收或验收不合格的，不得进行混凝土浇筑。

## 八、应急处置措施 {#c8}

### （一）应急组织与职责

1. 成立高支模应急处置领导小组，由项目负责人任组长，项目技术负责人、安全负责人任副组长，成员包括施工、技术、质量、安全、物资、后勤等部门负责人。
2. 领导小组下设抢险组、安保组、后勤组、医救组、善后组，明确各组负责人、成员及联系方式。
3. 应急职责：

| 小组 | 负责人 | 主要职责 |

## 九、计算书及相关图纸 {#c9}

### （一）计算书应包含的内容

1. 计算依据、计算参数、计算简图、荷载工况组合、控制指标和计算结果。
2. 荷载计算：模板及支架自重、新浇混凝土自重、钢筋自重、施工人员及设备荷载、振捣混凝土荷载、倾倒混凝土荷载、风荷载。
3. 模板面板、小梁、主梁的抗弯强度、抗剪强度和挠度验算。
4. 支架立杆的轴力、稳定性验算；水平杆、剪刀撑、连墙（抱柱）件验算。
5. 可调底座、可调托撑、连接盘、插头的承载力验算。
6. 支撑基础（结构板、地基）承载力验算，必要时应取得设计单位复核意见。
7. 架体高宽比、抗倾覆验算。
8. 采用软件计算时，应说明软件名称、版本、计算模型、边界条件和输出结果，并由技术人员复核。

### （二）示例算式

> 以下算例对应本模板开头示例工程，仅演示计算步骤和数值关系，不得替代项目实际计算。实际计算应按结构图纸、材料实测参数和现行规范进行。

#### 1. 板底立杆轴力（示例）

板厚 120mm，立杆纵横向间距 1.2m×1.2m，单根立杆承担面积 A＝1.44m²。

永久荷载标准值：

- 新浇混凝土自重：24×0.12＝2.88 kN/m²
- 钢筋自重：1.1×0.12＝0.132 kN/m²
- 模板及支架自重：0.50 kN/m²
- 合计 Gk＝3.512 kN/m²

可变荷载标准值（计算支架立杆）：

- 施工人员及设备荷载：1.0 kN/m²
- 振捣混凝土荷载：2.0 kN/m²
- 合计 Qk＝3.0 kN/m²

按现行通用规范，永久荷载分项系数取1.3，可变荷载分项系数取1.5：

N＝1.3×Gk×A＋1.5×Qk×A
＝1.3×3.512×1.44＋1.5×3.0×1.44
＝6.57＋6.48＝13.05 kN

#### 2. 梁底立杆轴力（示例）

最大梁截面 500mm×1200mm，梁下立杆纵距 0.9m，梁底设 2 根立杆。

永久荷载标准值（沿梁长每米）：

- 新浇混凝土自重：0.5×1.2×24＝14.40 kN/m
- 钢筋自重：1.5×0.5×1.2＝0.90 kN/m
- 模板及支架自重：0.5×(0.5＋2×1.2)＝1.45 kN/m
- 合计 Gk＝16.75 kN/m

可变荷载标准值（沿梁长每米）：

- 施工人员及设备荷载：1.0×0.5＝0.50 kN/m
- 振捣混凝土荷载：2.0×0.5＝1.00 kN/m
- 合计 Qk＝1.50 kN/m

单根梁底立杆轴力：

N＝[1.3×16.75×0.9＋1.5×1.50×0.9]÷2
＝[19.60＋2.03]÷2＝10.82 kN

#### 3. 立杆稳定性验算（示例）

采用 Φ48.3×3.2 盘扣立杆，Q355 钢，截面面积 A＝453mm²，回转半径 i＝16.0mm，步距 h＝1500mm。

长细比：

λ＝h/i＝1500/16.0＝93.8

按 b 类截面查稳定系数 φ≈0.634；钢材强度设计值 f＝300 N/mm²。

稳定承载力：

φAf＝0.634×453×300＝86.2 kN

板底立杆轴力 13.05 kN、梁底立杆轴力 10.82 kN，均小于 86.2 kN，稳定性满足要求（示例）。

#### 4. 支撑基础承载力复核（示例）

板底立杆轴力 13.05 kN，承担面积 1.44m²，支撑面等效均布荷载：

q＝13.05/1.44＝9.06 kN/m²

计入支架自重约 0.3 kN/m²，支撑面等效荷载标准值约 9.4 kN/m²。应小于首层结构板允许施工荷载【填写：由设计单位复核确认】kN/m²；当不满足时，应增设回顶、扩大垫板或调整立杆间距。

#### 5. 其他验算项目及判别式

| 验算项目 | 计算式（示意） | 控制指标 |
| --- | --- | --- |
| 面板抗弯 | σ＝M/W≤f | f 按模板材料取值 |
| 面板挠度 | v≤L/400 | 按 JGJ 162-2008 表4.4.1 |
| 小梁抗弯、抗剪 | σ＝M/W≤f，τ＝VS/(Ib)≤fv | 按木方材料取值 |
| 主梁抗弯、挠度 | σ＝M/W≤f，v≤L/400 | 按钢管或型钢取值 |
| 立杆稳定 | N/(φA)≤f | 按 JGJ 231-2010 |
| 架体高宽比 | H/B≤3 | 超过时应采取抗倾覆措施 |
| 抗倾覆 | K＝抗倾覆力矩/倾覆力矩 | K≥【填写】 |

上述控制指标应按设计要求及现行规范取值，计算书应列出完整参数、公式和结果，不得只写结论。
