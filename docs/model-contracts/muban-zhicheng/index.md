# 模板工程及支撑体系专项施工方案编写范例（本站整理）

<LawBanner />

> **本站依据官方指南整理，不是官方文本；不得直接用于报审，须结合项目实际、现行标准和专业人员复核。**

本页梳理文本组成、危大判定与九章结构，不替代项目实际方案、结构计算或设计文件。[读全文与条款原文 →](./full.md)

## 文本组成

本方案范例由三部分组成：

1. **使用说明**：适用范围与危大属性判定、编制与审批流程、填写要求，并给出一个虚构的高支模示例工程设定。
2. **九章正文**：按建办质〔2021〕48号第二章规定的九章顺序展开——工程概况、编制依据、施工计划、施工工艺技术、施工保证措施、施工管理及作业人员配备和分工、验收要求、应急处置措施、计算书及相关图纸。
3. **附录 A～D**：专项施工方案审批表、专家论证会签到表、专家论证报告要点、编制依据（文号、标准号）核对表。

文中【填写：…】为项目填写处；示例工程与示例数据均为虚构，仅用于说明写法和数值关系。正文与附录中的表式均标注「本站整理表式，非官方表式」。

## 危大属性与审批

按建办质〔2018〕31号附件 1，搭设高度 5m 及以上，或搭设跨度 10m 及以上，或施工总荷载（荷载效应基本组合的设计值）10kN/m² 及以上，或集中线荷载（设计值）15kN/m 及以上，或高度大于支撑水平投影宽度且相对独立无联系构件的混凝土模板支撑工程，属于危险性较大的分部分项工程，应编制专项施工方案。

按附件 2，搭设高度 8m 及以上，或搭设跨度 18m 及以上，或施工总荷载（设计值）15kN/m² 及以上，或集中线荷载（设计值）20kN/m 及以上的混凝土模板支撑工程，属于超过一定规模的危险性较大的分部分项工程，应组织专家论证。

审批流程：

1. 实行施工总承包的，由施工总承包单位组织编制；实行分包的，可由专业分包单位编制，但须由总承包单位与分包单位技术负责人共同审核签字并加盖单位公章。
2. 经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的，由施工总承包单位组织专家论证；论证结论应为专家组一致意见，结论为「修改后通过」的，修改完善后重新履行审核审查程序，并将修改情况及时告知专家；不通过的，修改后重新组织论证。
4. 实施前逐级进行方案交底和安全技术交底，由双方及项目专职安全生产管理人员共同签字确认。
5. 不得擅自修改方案；因规划调整、设计变更、材料替代、支撑体系变更等确需调整的，重新审核、论证。

## 教材里怎么讲

- **质量与安全 8.2**「危险性较大的分部分项工程施工安全管理」：危大工程范围、专项施工方案编制与审查、专家论证、现场安全管理、验收与应急处置，对应本方案从支架参数到验收的全过程。
- **质量与安全 8.1**「安全风险管理」：危险源分类与风险分级，对应第一章的风险辨识与分级。
- **质量与安全 1.3**「安全生产管理主要制度」第四部分「危大工程管理」：专项方案的编制、签字、论证要求及未编制、未审查的法律责任。
- **案例分析 3.12**「安全生产管理的监理工作」：专项施工方案的编制与审查，是监理审查高支模方案的主要考点。
- **案例分析 1.4**「建设工程安全生产管理条例」：监理单位未审查专项施工方案的法律责任。

1. **依据**：本页依据《危险性较大的分部分项工程安全管理规定》（住房和城乡建设部令第37号，2019年修正）、建办质〔2018〕31号、建办质〔2021〕48号第二章整理，章节顺序按 48 号指南。

3. **表式**：正文与附录中的验收表、审批表、签到表、论证报告要点，均为「本站整理表式，非官方表式」，不是主管部门发布的官方附件。
4. **示例数据**：示例工程与全部数值均为虚构，仅用于说明写法与数值关系，不得直接用于实际工程；示例算例仅演示计算步骤，不得替代项目计算。
5. **正文**：全文页按整理稿逐字保留，仅在章标题上增加锚点（#sm、#c1～#c9、#ap），不改写措辞。
6. **验收签字**：第七章及表 7-1 写明验收合格须经施工单位项目技术负责人及总监理工程师签字确认后方可进入下一道工序，验收人员按 31 号文第七条列明；「三次验收」为本站整理的管理要求，不是法规原文。
7. **算例修正**：第九章板底立杆轴力按模板自重 0.50 与支架自重 0.45 kN/m² 分列重算（Gk＝3.962、N＝13.90 kN）；立杆稳定按 l0＝βH·η·h 计算（λ＝103、φ≈0.54），并按Ⅰ级安全等级计入 γ0＝1.1；支撑基础改用标准组合复核。βH、η、φ 为示例取值，应以 JGJ/T 231-2021 原文附表为准。梁底立杆口径统一为「每排共 2 根（梁两侧各 1 根，边立杆计入总数，板下网格立杆不重复计入）」，示例设定、参数表与算例同步。
8. **标准版本**：JGJ/T 46-2024 已按住建部公告2024年第152号核实，自 2025-01-01 施行，原《施工现场临时用电安全技术规范》JGJ 46-2005 同日废止；JGJ 231-2010 据公开信息已被 JGJ/T 231-2021 替代（2021-10-01 施行），尚未在住建部公告页终核；附录 D 分「已经官方页面核实」与「版本未核实」两档，未核实项不标「现行」。
9. **待核事项**：预压荷载与持荷时间、监测频率与预警比例、立杆计算长度系数 βH、η 及稳定系数 φ 的具体取值，未取得标准正式文本，保持示例或原整理稿表述，使用时须以标准原文、设计文件和当地规定为准。
