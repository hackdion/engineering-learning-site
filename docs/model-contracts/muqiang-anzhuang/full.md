## 使用说明 {#sm}

### 一、适用范围与危大属性判定

1. 本方案范例适用于房屋建筑工程中建筑幕墙的安装施工，包括玻璃幕墙、金属幕墙、石材幕墙、人造板材幕墙及其组合幕墙。
2. 按《危险性较大的分部分项工程安全管理规定》（住房和城乡建设部令第37号，2019年修正）及《住房城乡建设部办公厅关于实施〈危险性较大的分部分项工程安全管理规定〉有关问题的通知》（建办质〔2018〕31号）附件1，建筑幕墙安装工程属于危险性较大的分部分项工程，应编制专项施工方案。
3. 按建办质〔2018〕31号附件2，施工高度 50m 及以上的建筑幕墙安装工程，属于超过一定规模的危险性较大的分部分项工程，按37号令第十二条应当组织专家论证。
4. 本项目幕墙施工高度为【填写：高度】m，幕墙面积【填写：面积】m²，最高安装标高【填写：标高】m，按上述标准判定为【填写：危大工程／超过一定规模的危大工程】。

### 二、编制与审批流程

1. 实行施工总承包的，专项施工方案由施工总承包单位组织编制；实行分包的，可由专业分包单位组织编制，但须由总承包单位技术负责人及分包单位技术负责人共同审核签字并加盖单位公章。
2. 方案经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的幕墙安装工程，由施工总承包单位组织专家论证会；论证结论应为专家组一致意见。结论为「修改后通过」的，修改完善后重新履行审核、审查程序，并将修改情况及时告知专家；结论为「不通过」的，修改后重新组织论证。论证专家应从工程所在地住房城乡建设主管部门专家库中选取，专业应满足本工程需要，人数不少于5名；与本工程有利害关系的人员不得以专家身份参加论证（依据37号令第十二条、第十三条和建办质〔2018〕31号第三条，具体条件以当地规定为准）。
4. 方案实施前，编制人员或项目技术负责人向施工现场管理人员进行方案交底；施工现场管理人员向作业人员进行安全技术交底，并由双方和项目专职安全生产管理人员共同签字确认。
5. 不得擅自修改方案；因设计变更、幕墙分格调整、安装操作设施形式改变等确需调整的，重新履行审核、审查程序；属于超过一定规模的，须重新组织专家论证。

### 三、填写要求

1. 文中【填写：…】处应按幕墙设计文件、结构计算书、施工组织设计和现场调查资料填写，不得留空，不得照抄本范例的示例数值。
2. 未加标记的条文为示范性通用表述，应结合幕墙类型、安装高度、支承结构和安装操作设施形式修改；与本项目无关的条目应删除。
3. 本范例以单元式玻璃幕墙、高处作业吊篮安装为主线，同时列出构件式幕墙、环形轨道和落地脚手架安装应补充的内容。项目方案只保留与本项目实际相符的内容。
4. 文中的题目、单位名称、人名、地名、数值均为虚构，仅用于说明写法；表中的验收标准数值应替换为设计文件和现行标准的规定值。

### （三）施工方法及操作要求

#### 1. 高处作业吊篮安装与使用

1. 吊篮安装前编制安装方案，悬挂机构设置在【填写：屋面位置】，前梁外伸长度、配重数量按本方案第九章验算结果设置，不得随意加长前梁或减少配重。
2. 配重块应固定牢固并设置防盗、防移动措施，配重块不得使用破损、缺角或重量不明的替代物。
3. 吊篮安装完成后由安装单位、使用单位、监理单位共同验收，进行额定载荷和超载试验，验收合格挂牌后方可使用。
4. 每日使用前检查钢丝绳、安全锁、提升机、电气控制和配重，空载运行一次；安全锁应在标定有效期内。
5. 作业人员不超过 2 人，载荷均匀分布，严禁超载；严禁在吊篮内使用梯子、凳子，严禁将吊篮作为垂直运输设备。
6. 吊篮作业下方设置警戒区，严禁交叉作业；风力达到 5 级及以上、雨雪、雷电、大雾天气停止作业，并将吊篮降至地面固定。

#### 2. 环形轨道安装与使用

1. 环形轨道支撑点设置在主体结构梁上，支撑件经设计确认，安装后进行加载试验，试验荷载为额定荷载的 1.25 倍。
2. 电动葫芦应设置上限位、下限位和防坠装置，导轨接头平顺，运行范围内无障碍物。
3. 作业人员使用双钩安全带，一只挂钩挂在独立生命线上，不得挂在轨道或葫芦上。

#### 3. 测量放线

1. 以主体结构控制网为基准，测设幕墙分格控制线，每【填写：层数】层设置一道水平控制线，垂直控制线用经纬仪投测。
2. 测量成果经第二人复核并报监理验线；主体结构偏差超出幕墙调整能力时，报设计处理，不得强行安装。

#### 4. 预埋件与后置锚栓

1. 预埋件位置偏差超过允许值时，采用后置锚栓补强，补强方案经设计确认；后置锚栓不得打在混凝土保护层、裂缝或钢筋密集区。
2. 钻孔前用钢筋探测仪扫描钢筋位置，钻孔深度按锚栓规格控制，孔内粉尘用毛刷和吹风机清理干净。
3. 锚栓安装后按比例做拉拔试验，试验合格后方可安装转接件。

#### 5. 龙骨与面板安装

1. 转接件与预埋件（锚栓）连接螺栓按设计扭矩紧固，扭矩抽检比例不小于【填写：比例】。
2. 立柱安装先临时固定，拉通线调整垂直度后终拧；横梁按标高安装，同一层标高偏差不大于 3mm。
3. 面板安装前检查龙骨、防火封堵和保温层，隐蔽验收合格后方可安装面板。
4. 单元板块吊装采用专用吊具，起吊和就位设专人指挥，板块挂接后调整高低差和缝宽，挂接件螺栓全部拧紧。

#### 6. 注胶与清洁

1. 注胶前用清洁剂清洁缝壁，粘贴美纹纸，保证缝宽均匀；注胶连续饱满，不得断胶、裹胶。
2. 注胶后及时修缝，胶缝表面平整、无气泡；美纹纸在胶未固化前揭除。
3. 清洁剂不得污染面板和型材，清洁作业自上而下进行，废水集中收集。

#### 7. 防火、防雷与保温

1. 层间防火封堵采用 1.5mm 镀锌钢板承托，岩棉填塞密实，不得留有缝隙；防火封堵与主体结构、幕墙结构可靠连接。
2. 幕墙防雷连接按设计设置，立柱之间、立柱与主体防雷系统之间采用不小于【填写：截面】的导体连接，连接电阻不大于 0.2Ω。
3. 保温材料铺设连续、无空腔，接缝错开，防止形成冷桥。

### （四）材料进场与工序检查

1. 幕墙构件、面板、结构胶、锚栓进场查验合格证、型式检验报告和复试报告，不合格材料清退出场。
2. 结构胶检查牌号、批号、有效期，过期胶不得使用；每批胶做剥离试验并记录。
3. 每道工序完成后由班组自检、项目部复检、监理验收，隐蔽工程留存影像资料。
4. 工序检查记录采用【填写：表号】，检查人和监理工程师签字确认后归档。

## 五、施工保证措施 {#c5}

### （一）组织保障

1. 成立以项目经理为组长的安全生产领导小组，配备专职安全生产管理人员【填写：人数】人。
2. 建立安全生产责任制、安全教育培训、班前讲话、隐患排查治理和应急管理制度。
3. 幕墙安装期间实行项目负责人带班制度，吊篮、环形轨道作业时安全员现场监护。
4. 施工单位应在施工现场显著位置公告危大工程名称、施工时间和具体责任人员，并在危险区域设置安全警示标志。
5. 项目负责人应在施工现场履职；专职安全生产管理人员应对专项施工方案实施情况进行现场监督，发现未按方案施工的，应要求立即整改（37号令第十四条、第十七条）。

### （二）安全技术措施

1. 高处作业人员必须系挂双钩安全带，做到「高挂低用」；作业层设置水平安全网和临边防护。
2. 吊篮、环形轨道安装和拆除由专业人员进行，作业区域设置警戒线和警示标志，严禁上下同时作业。
3. 工具使用工具袋或系安全绳，材料随用随运，不得集中堆放在吊篮内或临边。
4. 幕墙安装下方设置隔离区，出入口搭设双层防护棚，防护棚宽度大于出入口两侧各【填写：距离】m。
5. 临时用电采用 TN-S 系统、三级配电两级保护，吊篮电缆设置防磨损措施，潮湿天气加强绝缘检查。
6. 动火作业实行审批制度，配备灭火器和接火斗，作业后检查确认无火种。

### （三）质量技术措施

1. 实行样板引路，先做【填写：层数】层样板段，经建设、设计、监理验收合格后大面积施工。
2. 测量放线双人复核，每层安装前复测控制线，主体结构偏差及时反馈。
3. 结构胶、耐候胶按批次做相容性和粘结性试验，注胶环境温度、湿度符合产品要求。
4. 螺栓扭矩按比例抽检，抽检不合格时加倍抽检，仍不合格时全数复拧。
5. 淋水试验发现渗漏，查明原因后修补并重新试验。

### （四）文明施工与环境保护措施

1. 幕墙构件分类堆放、标识清晰，场地保持整洁；包装材料及时回收。
2. 切割、钻孔采取降尘措施，噪声控制在【填写：限值】dB 以内。
3. 废胶、废胶桶、废玻璃和废石材分类收集，交由有资质单位处理。
4. 注胶作业保持通风，作业人员佩戴防毒口罩和手套。

### （五）季节性施工技术措施

1. 雨季：关注天气预报，雨前将吊篮降至地面并固定，检查配电箱防雨措施；雨后检查吊篮钢丝绳和安全锁。
2. 冬季：注胶环境温度低于产品要求时停止注胶或采取加热保温措施；冰雪天气停止高处作业，清除积雪和结冰。
3. 高温：调整作业时间，避开中午高温时段，配备防暑降温用品。

### （六）监测监控措施

1. 幕墙安装期间对吊篮悬挂机构、配重、主体结构支承点进行日常检查，重要部位设置观察标记。
2. 大风、暴雨、地震后对幕墙面板、挂接件、密封胶进行全面检查，发现松动、开裂立即处理。
3. 检查记录每日填写，问题闭环管理。
4. 本工程按规定不需第三方监测；施工监测方案由施工单位项目技术负责人编制、施工单位技术负责人审批后实施。如建设单位按规定委托第三方监测，监测方案应经监测单位技术负责人审核签字并加盖单位公章、报送监理单位后方可实施（37号令第二十条）。

## 七、验收要求 {#c7}

### （一）验收标准

1. 幕墙工程验收执行《建筑装饰装修工程质量验收标准》GB 50210-2018、《玻璃幕墙工程技术规范》JGJ 102-2003、《金属与石材幕墙工程技术规范》JGJ 133-2001 及设计文件的规定。
2. 幕墙分项工程所含检验批全部合格，质量控制资料完整，观感质量符合要求，方可判定合格。
3. 吊篮、环形轨道等安装操作设施按《建筑施工工具式脚手架安全技术规范》JGJ 202-2010 验收，验收合格挂牌后方可使用。

### （二）验收程序及人员

1. 检验批由施工单位项目专业质量检查员组织验收，监理工程师参加。
2. 分项工程由施工单位项目技术负责人组织验收，总监理工程师参加。
3. 危大工程验收由施工单位项目技术负责人、总监理工程师及相关人员共同进行；验收合格经施工单位项目技术负责人及总监理工程师签字确认后，方可进入下一道工序。
4. 验收人员按建办质〔2018〕31号第七条列明，包括总承包单位和分包单位技术负责人或授权委派的专业技术人员、项目负责人、项目技术负责人、方案编制人员、专职安全生产管理人员，监理单位总监理工程师及专业监理工程师，以及有关勘察、设计和监测单位项目技术负责人等。

## 九、计算书及相关施工图纸 {#c9}

### （一）计算书应包含的内容

1. 计算依据、计算假定和计算简图。
2. 高处作业吊篮抗倾覆验算、钢丝绳安全系数验算、悬挂机构支承点楼面承载力验算。
3. 环形轨道支撑件与电动葫芦验算（采用环形轨道时）。
4. 后置锚栓承载力验算（由设计单位或专业厂家提供，施工单位复核）。
5. 幕墙结构本身的承载力、变形和连接验算由幕墙设计单位提供，施工单位不得自行变更。

### （二）示例计算

#### 1. 吊篮抗倾覆验算

计算简图：前梁外伸 $L_1=1.5$m，前后支点间距 $L_2=4.6$m，配重 $G_1=1000$kg，平台自重与额定载重合计 $G_2=1110$kg。

抗倾覆系数：

$$K=\frac{G_1 L_2}{G_2 L_1}=\frac{1000\times4.6}{1110\times1.5}=\frac{4600}{1665}=2.76$$

$K=2.76\ge2.0$，满足抗倾覆要求。

> 抗倾覆系数限值 2.0 为示例取值，出处未核实；实际应按 JGJ 202-2010 和吊篮产品说明书确定。

#### 2. 钢丝绳安全系数验算

总荷载：

$$G_2 g=1110\times9.8=10878\ \text{N}=10.88\ \text{kN}$$

两根工作钢丝绳均布，单根工作拉力：

$$F=\frac{10.88}{2}=5.44\ \text{kN}$$

选用 6×19S＋FC、Φ10 钢丝绳，最小破断拉力（示例产品值）$F_u=61.0$kN，安全系数：

$$n=\frac{F_u}{F}=\frac{61.0}{5.44}=11.2$$

$n=11.2\ge9$，满足要求。钢丝绳的最小破断拉力应以产品合格证和型式检验报告为准。

#### 3. 悬挂机构支承点楼面压力验算

以后支点为矩心，求前支点反力：

$$R_A\times4.6=1110\times9.8\times1.5$$

$$R_A=\frac{16317}{4.6}=3547\ \text{N}=3.55\ \text{kN}$$

后支点反力：

$$R_B=(1110+1000)\times9.8-3547=20678-3547=17131\ \text{N}=17.13\ \text{kN}$$

后支架设置两条 1.2m×0.3m 垫板，基底压力：

$$p=\frac{17.13}{1.2\times0.3\times2}=\frac{17.13}{0.72}=23.8\ \text{kN/m}^2$$

示例屋面承载力特征值为 30kN/m²，$p=23.8\ \text{kN/m}^2<30\ \text{kN/m}^2$，满足要求。实际工程应以结构设计文件或结构复核结论为准；承载力不足时应设置钢结构平台分散荷载，不得直接加大配重。

#### 4. 吊篮悬挂机构前梁强度验算（按悬臂受力近似）

前梁按悬臂受力，最不利弯矩：

$$M=G_2 g L_1=10.88\times1.5=16.32\ \text{kN}\cdot\text{m}$$

前梁采用【填写：型钢规格】，截面抵抗矩 $W_x$ 取【填写：值】cm³，弯曲应力：

$$\sigma=\frac{M}{W_x}$$

示例 $W_x=160$cm³ 时：

$$\sigma=\frac{16.32\times10^{6}}{160\times10^{3}}=102\ \text{N/mm}^2<205\ \text{N/mm}^2$$

满足要求。前梁规格、材质和截面特性应以产品说明书和实际构件为准，不得以本示例代替。

### （三）施工图纸

1. 幕墙立面图、剖面图、分格图与节点详图。
2. 预埋件（后置锚栓）布置图、转接件加工图。
3. 吊篮平面布置图、悬挂机构安装图、配重布置图。
4. 环形轨道支撑布置图（采用时）。
5. 防火封堵、防雷连接节点详图。
6. 施工平面布置图与警戒区布置图。
