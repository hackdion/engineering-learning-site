# 起重吊装及安装拆卸工程专项施工方案（示范文本）

<LawBanner />

[导读与九章索引](./index.md)　·　全文按整理稿顺序排列，仅增加章级锚点（#sm、#c1～#c9、#ap），正文未改动。

> 本示范文本依据《危险性较大的分部分项工程专项施工方案编制指南》（建办质〔2021〕48号）第三章「起重吊装及安装拆卸工程」的编制内容与顺序编写，供施工单位编制具体项目方案时参照，不替代设计文件、设备说明书和项目实际论证。
>
> 文中【填写：…】为项目填写处；未加标记的条文为示范性通用表述，应结合项目实际修改。文中示例工程、示例数据均为虚构，仅用于说明写法和数值关系，不得直接用于实际工程。

## 使用说明 {#sm}

### 一、适用范围与危大属性判定

1. 本示范文本适用于房屋建筑和市政基础设施工程中的起重吊装、起重机械安装与拆卸、钢结构安装、大型设备就位等作业。
2. 按《危险性较大的分部分项工程安全管理规定》（住房和城乡建设部令第37号，2019年修正）及《住房城乡建设部办公厅关于实施〈危险性较大的分部分项工程安全管理规定〉有关问题的通知》（建办质〔2018〕31号）附件1，采用非常规起重设备、方法且单件起吊重量在10kN及以上的起重吊装工程，采用起重机械进行安装的工程，以及起重机械安装和拆卸工程，属于危险性较大的分部分项工程，应编制专项施工方案。
3. 按建办质〔2018〕31号附件2，采用非常规起重设备、方法且单件起吊重量在100kN及以上的起重吊装工程，起重量300kN及以上或搭设总高度200m及以上或搭设基础标高在200m及以上的起重机械安装和拆卸工程，属于超过一定规模的危险性较大的分部分项工程，施工单位应当组织召开专家论证会。
4. 本项目最大单件起吊重量为【填写：重量】kN，起重设备为【填写：设备名称、型号】，按上述标准判定为【填写：危大工程／超过一定规模的危大工程】。
5. 汽车式起重机、轮胎式起重机等自行式起重机进场后无需现场安装，但其作业仍属于起重吊装工程；塔式起重机、施工升降机、门式起重机等需现场安装拆卸的，应按相应安装拆卸专项方案执行，不得以本方案替代。

### 二、编制与审批流程

1. 专项施工方案由施工总承包单位组织编制；实行分包的，可由专业分包单位组织编制，但须由总承包单位技术负责人及分包单位技术负责人共同审核签字并加盖单位公章。
2. 方案经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的，方案在通过施工单位审核和总监理工程师审查后，由施工总承包单位组织专家论证；论证结论为「修改后通过」的，修改完善后重新履行审核审查程序；论证不通过的，修改后重新组织论证。
4. 方案实施前，编制人员或项目技术负责人向施工现场管理人员进行方案交底，施工现场管理人员向作业人员进行安全技术交底，并由双方和项目专职安全生产管理人员共同签字确认。
5. 施工单位不得擅自修改专项施工方案；因设计变更、构件重量或吊装工况变化等确需调整的，修改后的方案应重新审核、论证。

### 三、填写要求

1. 所有项目特定信息统一使用【填写：…】标记，不得留空、不得以「同上」「略」代替。
2. 本章节顺序不得删减；本项目确不涉及的条、款，写「本项目不涉及」并说明理由，不得直接删除。
3. 起重设备性能参数应以设备出厂说明书、起重性能表和检验报告为准，不得凭经验填写；同一工况的幅度、臂长、额定起重量必须一一对应。
4. 构件重量应注明是计算重量还是实际称重；重要构件应逐件称重并挂牌标识。
5. 图表应连续编号，图名在图下、表名在表上；引用图纸时写明图号。
6. 文中标注「本站整理表式，非官方表式」的表格，仅为便于项目使用而整理，不是住房和城乡建设部或地方主管部门发布的官方附件，不得以官方名义引用。

### （二）工艺流程

1. 总体施工工艺流程：

施工准备 → 场地处理与道路硬化 → 起重设备进场检查 → 构件进场验收与堆放 → 基础复测 → 试吊 → 钢柱吊装与临时固定 → 柱间支撑安装 → 屋面梁吊装 → 檩条与支撑安装 → 校正与终拧 → 屋面板安装 → 起重设备退场。

2. 单件构件吊装工艺流程：

绑扎 → 挂钩 → 试吊（离地100～200mm停吊检查）→ 起升 → 回转 → 就位 → 临时固定 → 校正 → 最终固定 → 摘钩。

3. 二次运输路径、构件运输顺序及堆放排布应附平面图，标明运输车辆行驶路线、转弯半径、卸车位置和堆放区。

### （三）施工方法及操作要求

#### 1. 施工准备

1. 核对基础轴线、标高、预埋螺栓位置及外露长度，基础混凝土强度达到设计要求。
2. 检查构件编号、规格、数量、外观、涂层及变形情况，对超差构件退场处理。
3. 复核构件重量和重心，在构件上标注中心线、标高线、吊点位置和安装方向。
4. 检查起重设备证照、检验报告、安全装置、液压系统、轮胎及支腿。
5. 检查吊索具外观、断丝、变形、磨损和标识，不合格立即报废。
6. 场地处理：按地耐力要求换填、分层压实，铺设路基箱或枕木；支腿下垫板应平稳、不得悬空。
7. 设置警戒区、安全通道、临时用电和消防设施，向作业人员进行安全技术交底。

#### 2. 构件卸车与堆放

1. 卸车前核对构件编号和重量，按吊装顺序分类堆放。
2. 构件堆放场地应平整坚实，垫木位置设在构件支座或加劲板处，堆放层数不超过【填写】层。
3. 卸车采用两点绑扎，起吊离车后构件下方严禁站人，构件两端设溜绳控制方向。
4. 构件堆放高度应满足稳定性要求，超长构件应设置临时支垫，防止侧向失稳。

#### 3. 钢柱吊装

1. 钢柱采用旋转法或滑行法起吊，绑扎点设在柱上部1/4处或有牛腿处，柱脚设溜绳。
2. 试吊：将柱吊离地面100～200mm，停留检查吊索具、吊车稳定性和制动性能，确认无误后继续起升。
3. 就位：柱底板预留孔对准预埋螺栓，缓慢下落，利用撬棍和千斤顶微调，不得强行敲打。
4. 校正：用经纬仪校正垂直度，用全站仪复核标高和轴线；垂直度偏差控制在【填写：如H/1000且不大于10mm】以内。
5. 临时固定：每根柱不少于2根缆风绳或2道临时支撑，缆风绳与地面夹角45°～60°，地锚可靠。
6. 最终固定：拧紧地脚螺栓，进行二次灌浆；灌浆料达到设计强度前不得拆除缆风绳、不得承受吊装荷载。

#### 4. 柱间支撑安装

1. 钢柱校正固定后，立即安装柱间系杆和剪刀撑，形成稳定单元。
2. 支撑预拼装合格后整体起吊，先用安装螺栓固定，校正后焊接或终拧。
3. 支撑安装应与钢柱吊装同步推进，不得使已安装柱长时间处于悬臂状态。

#### 5. 屋面梁吊装

1. 屋面梁采用两点或三点吊装，吊点设在梁跨1/3处或节点处，必要时采用平衡梁。
2. 起吊前在梁两端设溜绳，控制梁体摆动和旋转；梁就位后先安装临时螺栓，校正后再终拧或焊接。
3. 第一榀梁应设置缆风绳临时固定，第二榀梁安装后立即安装檩条和支撑，形成稳定体系。
4. 梁的垂直度、侧向弯曲、标高和跨度偏差应符合GB 50205-2020的规定。

#### 6. 檩条、支撑及屋面板安装

1. 檩条按安装顺序成捆吊至屋面，分散堆放，不得集中堆载。
2. 檩条与梁连接螺栓应齐全、拧紧，拉条、撑杆按设计布置。
3. 屋面板安装应在檩条验收合格后进行，作业人员系挂安全带，设置水平生命线。
4. 屋面材料吊运应采用专用吊笼，不得用钢丝绳直接捆绑散料。

#### 7. 起重机械安装、拆卸

1. 汽车式、轮胎式起重机进场后无需现场安装，但应检查支腿、配重、安全装置并空载试运转。
2. 塔式起重机、施工升降机、门式起重机安装拆卸，应由具备相应资质的单位按专项方案实施，本方案不替代其安装拆卸专项方案。
3. 安装拆卸前应检查基础、预埋件、附着点、连接件和顶升系统；安装后按规定进行检测、验收和登记。
4. 安装拆卸作业区域应设置警戒，统一指挥，风速超过规定值时停止作业。

#### 8. 常见问题及预防、处理措施

| 常见问题 | 产生原因 | 预防措施 | 处理措施 |
| --- | --- | --- | --- |
| 支腿下沉 | 地基承载力不足、垫板面积小 | 地基处理、铺设路基箱、验算支腿压力 | 停止作业、卸载、重新处理地基 |
| 构件摆动碰撞 | 未设溜绳、起升过快 | 设溜绳、低速起升、统一指挥 | 停止起升、稳住构件后重新就位 |
| 构件翻转 | 重心偏移、吊点不对称 | 计算重心、对称设置吊点、试吊 | 重新绑扎、调整吊点 |
| 螺栓孔错位 | 构件制作偏差、安装顺序不当 | 深化设计、预拼装、先安装螺栓后终拧 | 铰刀修孔，不得气割扩孔 |
| 焊缝裂纹 | 焊接参数不当、母材潮湿 | 焊前预热、烘干焊条、按工艺焊接 | 清除重焊、检测合格 |
| 垂直度超差 | 校正不到位、缆风绳松动 | 经纬仪校正、缆风绳复紧 | 重新校正、复测 |

### （四）操作要求

1. 吊装作业必须设专职信号指挥，一人指挥、统一口令；多机作业时设总指挥。
2. 起吊前确认构件重量、重心、吊点、索具和吊车工况，严禁超载、斜拉、斜吊。
3. 起吊时先将构件吊离地面100～200mm试吊，确认制动、索具、吊车稳定后方可继续。
4. 构件吊运路线下方严禁站人，不得从人员上方越过；吊物不得长时间悬空。
5. 作业人员不得随吊物升降，不得在吊物上站立、行走。
6. 六级及以上大风、雷雨、大雾、能见度低时停止吊装；夜间作业应有足够照明。
7. 临时固定可靠后方可摘钩；未形成稳定体系前不得拆除临时支撑和缆风绳。

#### 2. 试吊方案及试吊前检查

1. 试吊应在首件、最大件或工况变化时进行，试吊重量不小于实际吊装重量的1.1倍。
2. 试吊前对照专项方案检查：构件重量、吊点、索具、吊车工况、地基处理、警戒范围、指挥信号。
3. 试吊时将构件吊离地面100～200mm，停留不少于10min，检查吊车支腿、地基、吊索具、制动和构件变形。
4. 试吊合格后形成记录，由项目技术负责人、专职安全员、信号指挥和起重机司机共同签字。

## 五、施工保证措施 {#c5}

### （一）组织保障措施

1. 成立以项目经理为组长的吊装安全领导小组，明确技术、安全、设备、施工、监测等岗位职责。
2. 建立安全生产责任制、方案交底制度、班前讲话制度、检查整改制度和事故报告制度。
3. 吊装作业实行「一吊一交底、一吊一检查」，关键工序由专职安全员旁站。

### （二）技术措施

#### 1. 安全保证措施

1. 严格执行起重吊装「十不吊」：超载不吊、斜拉斜吊不吊、吊物上站人不吊、无人指挥不吊、信号不清不吊、吊物边缘锋利无防护不吊、埋在地下物不吊、安全装置失灵不吊、光线不足不吊、六级以上大风不吊。
2. 起重设备必须取得检验合格证明，司机、信号司索工持证上岗。
3. 吊装作业区设置警戒线和警示标志，无关人员不得进入。
4. 高处作业人员系挂安全带，设置操作平台、临边防护和水平生命线。
5. 临时用电按JGJ 46-2005执行，实行三级配电、两级保护。
6. 与架空线路保持规定安全距离，不能满足时采取停电、迁改或绝缘隔离措施。

#### 2. 质量技术保证措施

1. 钢结构安装前进行深化设计和预拼装，减少现场修改。
2. 高强螺栓按初拧、终拧顺序施工，终拧扭矩符合设计要求，做好标记和记录。
3. 焊接按焊接工艺评定执行，焊工持证，焊缝按规定检测。
4. 安装偏差按GB 50205-2020控制，超差部位制定专项校正方案，不得强行组装。

#### 3. 文明施工保证措施

1. 构件分类堆放、挂牌标识，场地整洁，道路畅通。
2. 施工机具、索具定点存放，定期维护。
3. 夜间施工控制噪声和照明，减少对周边影响。
4. 建筑垃圾及时清运，不得高空抛掷。

#### 4. 环境保护措施

1. 构件运输车辆覆盖，防止遗撒；出场车辆冲洗。
2. 焊接烟尘、切割粉尘采取通风、洒水等措施。
3. 废机油、废焊条头分类收集，交有资质单位处理。
4. 控制施工噪声，避免夜间扰民。

#### 5. 季节性施工保证措施

1. 雨季施工做好排水、防滑、防雷接地，构件堆放垫高。
2. 高温季节调整作业时间，防止中暑。
3. 冬季焊接采取预热、保温措施，低温下不得进行关键焊接。
4. 台风季节提前加固构件、收起吊臂、锁定设备，台风过后检查后复工。

## 九、计算书及相关施工图纸 {#c9}

### （一）计算书应包含的内容

1. 计算依据、计算参数、计算简图、荷载组合、控制指标和计算结果。
2. 支承面承载能力验算：汽车式起重机支腿地基承载力、软弱地基变形、边坡稳定性。
3. 起重设备起重能力验算：起升高度、幅度、额定起重量、与既有建（构）筑物安全距离。
4. 吊索具验算：钢丝绳、卸扣、吊带、平衡梁的受力与安全系数。
5. 被吊物受力验算：吊点、吊耳、捆绑方式、翻身工况。
6. 临时固定验算：缆风绳、地锚、临时支撑，按向危险方向倾斜不少于5°并叠加风荷载。
7. 起重机械安装拆卸验算：基础、附着、附墙耳板、穿墙螺栓、附着杆、销轴等。
8. 多机抬吊时，按不同步影响对额定起重量折减，折减系数一般取0.75～0.80，并在计算书中说明。

### （二）示例算式

> 以下算例对应本模板开头示例工程，仅演示计算步骤和数值关系，不得替代项目实际计算。实际计算应按设备起重性能表、构件实际重量和现行规范进行。

#### 1. 起重能力校核（示例）

主吊选用100t汽车式起重机，作业半径R＝14m，主臂长L＝33m，查起重性能表该工况额定起重量G＝18.5t。

最大构件重Q＝6.2t，动载系数K1＝1.1，吊钩重q1＝0.45t，吊索具重q2＝0.25t：

Q计＝Q×K1＋q1＋q2＝6.2×1.1＋0.45＋0.25＝7.52t

7.52t＜18.5t，起重能力满足要求，利用率约41%。

#### 2. 起升高度校核（示例）

安装基面标高H1＝12.6m，吊钩高度H2＝1.0m，吊索高度H3＝6.0m，安全高度H4＝0.5m：

H需＝H1＋H2＋H3＋H4＝12.6＋1.0＋6.0＋0.5＝20.1m

主臂33m、幅度14m时，最大起升高度约：

Hmax＝√(33²－14²)＝√(1089－196)＝√893＝29.9m

29.9m＞20.1m，起升高度满足要求。

#### 3. 吊索受力验算（示例）

采用4点起吊，吊索与水平夹角60°，按最不利受力计算单根吊索拉力：

T＝Q计×g/(4×sin60°)＝7.52×9.8/(4×0.866)＝73.7/3.464＝21.3kN

选用6×37+FC、Φ24mm、1670MPa钢丝绳，最小破断拉力约336kN，安全系数：

K＝336/21.3＝15.8＞8，满足要求。

卸扣选用8t（额定荷载约78kN），78kN＞21.3kN，满足要求。

#### 4. 支腿地基承载力验算（示例）

100t汽车吊最大支腿反力R＝520kN，支腿下铺设2.0m×2.0m路基箱：

q＝R/A＝520/(2.0×2.0)＝130kPa

场地经换填处理后地基承载力特征值fak＝150kPa：

130kPa＜150kPa，满足要求。

若支腿位于回填土或边坡附近，应进行变形验算和边坡稳定性验算，并适当增大垫板面积。

#### 5. 钢柱临时固定验算（示例）

钢柱重G＝2.6t，高H＝12.6m，按向危险方向倾斜5°考虑，倾覆力矩：

M1＝G×g×H/2×sin5°＝2.6×9.8×6.3×0.0872＝14.0kN·m

风荷载按ωk＝0.315kN/m²，迎风面积A＝0.5×12.6＝6.3m²，风力作用点取柱高一半：

M2＝ωk×A×H/2＝0.315×6.3×6.3＝12.5kN·m

总倾覆力矩M＝M1＋M2＝26.5kN·m

设2根缆风绳，与地面夹角45°，缆风绳拉力：

T＝M/(H×sin45°×2)＝26.5/(12.6×0.707×2)＝1.49kN

选用Φ16mm钢丝绳（破断拉力约143kN），安全系数远大于要求，地锚按抗拔力不小于10kN设置。

#### 6. 其他验算项目及判别式

| 验算项目 | 计算式（示意） | 控制指标 |
| --- | --- | --- |
| 吊耳强度 | σ＝N/(t×b)，τ＝N/(t×l) | σ≤【填写】N/mm² |
| 吊耳焊缝 | σf＝N/(0.7hf×lw) | σf≤ffw |
| 平衡梁强度 | 按受弯构件计算σ＝M/W | σ≤f |

### （四）计算书及图纸编制注意事项

1. 计算书应由具备相应能力的技术人员编制，项目技术负责人审核，施工单位技术负责人审批。
2. 起重性能必须与设备说明书、性能表一致，注明设备型号、臂长、幅度、配重和支腿状态。
3. 构件重量应以深化设计计算书或实际称重为准，不得估算；计算书应附构件重量汇总表。
4. 图纸应标注尺寸、标高、机械位置、作业半径和安全距离，图签完整，签字齐全。
5. 计算书、图纸应随方案一同报审、论证，设备或工况变化时重新验算。
