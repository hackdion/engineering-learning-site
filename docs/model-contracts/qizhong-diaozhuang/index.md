# 起重吊装及安装拆卸工程专项施工方案编写范例（本站整理）

> **本站依据官方指南整理，不是官方文本；不得直接用于报审，须结合项目实际、现行标准和专业人员复核。**

本页梳理文本组成、危大判定与九章结构，不替代项目实际方案、设备说明书或设计文件。[读全文与条款原文 →](./full.md)

## 文本组成

本方案范例由三部分组成：

1. **使用说明**：适用范围与危大属性判定、编制与审批流程、填写要求，并给出一个虚构的门式刚架吊装示例工程设定。
2. **九章正文**：按建办质〔2021〕48号第三章规定的九章顺序展开——工程概况、编制依据、施工计划、施工工艺技术、施工保证措施、施工管理及作业人员配备和分工、验收要求、应急处置措施、计算书及相关施工图纸。
3. **附录 A～D**：专项施工方案审批表、专家论证会签到表、专家论证报告要点、编制依据（文号、标准号）核对表。

文中【填写：…】为项目填写处；示例工程与示例数据均为虚构，仅用于说明写法和数值关系。正文与附录中的表式均标注「本站整理表式，非官方表式」。

## 危大属性与审批

按建办质〔2018〕31号附件 1，采用非常规起重设备、方法且单件起吊重量在 10kN 及以上的起重吊装工程，采用起重机械进行安装的工程，以及起重机械安装和拆卸工程，属于危险性较大的分部分项工程，应编制专项施工方案。

按附件 2，采用非常规起重设备、方法且单件起吊重量在 100kN 及以上的起重吊装工程，起重量 300kN 及以上或搭设总高度 200m 及以上或搭设基础标高在 200m 及以上的起重机械安装和拆卸工程，属于超过一定规模的危险性较大的分部分项工程，按 37 号令第十二条应当组织专家论证。

自行式起重机进场后无需现场安装，但其作业仍属于起重吊装工程；塔式起重机、施工升降机、门式起重机等需现场安装拆卸的，应按相应安装拆卸专项方案执行，不得以本方案替代。

审批流程：

1. 实行施工总承包的，由施工总承包单位组织编制；实行分包的，可由专业分包单位编制，但须由总承包单位与分包单位技术负责人共同审核签字并加盖单位公章。
2. 经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 超过一定规模的，由施工总承包单位组织专家论证；论证结论应为专家组一致意见，结论为「修改后通过」的，修改完善后重新履行审核审查程序，并将修改情况及时告知专家；不通过的，修改后重新组织论证。
4. 实施前逐级进行方案交底和安全技术交底，由双方及项目专职安全生产管理人员共同签字确认。
5. 不得擅自修改方案；因设计变更、构件重量或吊装工况变化等确需调整的，重新审核、论证。

## 教材里怎么讲

- **质量与安全 8.2**「危险性较大的分部分项工程施工安全管理」：危大工程范围、专项施工方案编制与审查、专家论证、现场安全管理、验收与应急处置，对应本方案从吊装参数到试吊验收的全过程。
- **质量与安全 1.3**「安全生产管理主要制度」第五部分「特种设备（作业）管理」：建筑起重机械安装与拆卸、使用登记、检验检测及监理审核要求，对应第四章的起重机械安装拆卸与第五章的检查要求。
- **质量与安全 8.1**「安全风险管理」：危险源分类与风险分级，对应第一章的风险辨识与分级。
- **案例分析 3.12**「安全生产管理的监理工作」：专项施工方案的编制与审查，是监理审查吊装方案的主要考点。
- **案例分析 1.4**「建设工程安全生产管理条例」：监理单位未审查专项施工方案的法律责任。

1. **依据**：本页依据《危险性较大的分部分项工程安全管理规定》（住房和城乡建设部令第37号，2019年修正）、建办质〔2018〕31号、建办质〔2021〕48号第三章整理，章节顺序按 48 号指南。

3. **表式**：正文与附录中的验收表、审批表、签到表、论证报告要点，均为「本站整理表式，非官方表式」，不是主管部门发布的官方附件。
4. **示例数据**：示例工程与全部数值均为虚构，仅用于说明写法与数值关系，不得直接用于实际工程；示例算例仅演示计算步骤，不得替代项目计算。
5. **正文**：全文页按整理稿逐字保留，仅在章标题上增加锚点（#sm、#c1～#c9、#ap），不改写措辞。
6. **验收签字**：第七章及表 7-1 写明验收合格须经施工单位项目技术负责人及总监理工程师签字确认后方可进入下一道工序，验收人员按 31 号文第七条列明。
7. **算例修正**：第九章吊索受力按「最不利 2 支吊索受力」重算（主吊索由 Φ24 调整为 Φ26，示例估算破断拉力约 401kN，T＝42.6kN，K≈9.4）；原文按 4 支均分计算，其结果偏乐观，已不再采用。钢丝绳安全系数限值「＞8」为项目自行加严取值：JGJ 276-2012 第 4.3.1 条规定吊索安全系数不小于 6，直接捆绑且棱角有保护时取 6～8，起吊重、大或精密重物时取 10，规范未设「K＞8」这一分级。
8. **标准版本**：附核准引的 GB 3811-2008 已按编号规范写为 GB/T 3811-2008；JGJ 46-2005 据公开信息已被 JGJ/T 46-2024 替代（2025-01-01 施行），GB/T 5972-2016 据公开信息已被 GB/T 5972-2023 替代（2023-12-01 施行），均尚未在住建部公告页终核；附录 D 分「已经官方页面核实」与「版本未核实」两档，未核实项不标「现行」。
9. **待核事项**：钢丝绳破断拉力取值、试吊荷载倍数（JGJ 276-2012 第 7.1.7 条只要求试拼及试吊，未规定离地高度、停留时间等量化值）、支腿地基承载力验算方法与地基参数、风荷载计算中挡风系数与体型系数取值，未取得标准正式文本，保持示例或原整理稿表述，使用时须以设备说明书、标准原文和设计文件为准。地锚抗拔 K≥2 已核对到 JGJ 276-2012 附录 D 式(D.2.1-3)。
