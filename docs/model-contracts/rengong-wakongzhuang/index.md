# 人工挖孔桩工程专项施工方案编写范例（本站整理）

> **本站依据官方指南整理，不是官方文本；不得直接用于报审，须结合项目实际、现行标准和专业人员复核。**

本页梳理文本组成、危大判定、不得使用情形与九章结构，不替代项目实际方案、勘察报告或设计文件。[读全文与条款原文 →](./full.md)

## 文本组成

本方案范例由三部分组成：

1. **使用说明**：适用范围与危大属性判定、不得使用人工挖孔桩的情形、编制与审批流程、填写要求，并给出一个虚构的示例工程设定。
2. **九章正文**：按建办质〔2021〕48号第八章规定的九章顺序展开——工程概况、编制依据、施工计划、施工工艺技术、施工保证措施、施工管理及作业人员配备和分工、验收要求、应急处置措施、计算书及相关施工图纸。
3. **附录 A～D**：专项施工方案审批表、专家论证会签到表、专家论证报告要点、编制依据（文号、标准号）核对表。

文中【填写：…】为项目填写处；示例工程与示例数据均为虚构，仅用于说明写法和数值关系。正文与附录中的表式均标注「本站整理表式，非官方表式」。

## 危大属性与审批

按建办质〔2018〕31号附件 1，人工挖孔桩工程属于危险性较大的分部分项工程，应编制专项施工方案。

按附件 2，开挖深度 16m 及以上的人工挖孔桩工程，属于超过一定规模的危险性较大的分部分项工程，按 37 号令第十二条应当组织专家论证。

不得使用人工挖孔桩的情形（48 号指南第八章原文）：

1. 开挖深度范围内分布有厚度超过 2m 的流塑状泥或厚度超过 4m 的软塑状土。
2. 开挖深度范围内分布有层厚超过 2m 的砂层。
3. 有涌水的地质断裂带。
5. 地下水丰富，采取措施后仍无法避免边抽水边作业。
6. 高压缩性人工杂填土厚度超过 5m。
7. 开挖面 3m 以下土层中分布有腐植质有机物、煤层等可能存在有毒气体的土层。

> 原文序号为 1、2、3、5、6、7，缺第 4 项；本站照录，不自行补号或改写，作为待核事项登记。项目开工前应逐条对照勘察报告核对，存在上述情形之一的不得采用人工挖孔桩。

审批流程：

1. 实行施工总承包的，由施工总承包单位组织编制；实行分包的，可由专业分包单位编制，但须由总承包单位与分包单位技术负责人共同审核签字并加盖单位公章。
2. 经施工单位技术负责人审核签字、加盖单位公章，并由总监理工程师审查签字、加盖执业印章后方可实施。
3. 开挖深度 16m 及以上的，由施工总承包单位组织专家论证；论证结论应为专家组一致意见，结论为「修改后通过」的，修改完善后重新履行审核审查程序，并将修改情况及时告知专家；不通过的，修改后重新组织论证。
4. 实施前逐级进行方案交底和安全技术交底，由双方及项目专职安全生产管理人员共同签字确认。
5. 不得擅自修改方案；因设计变更、桩位调整、地质条件与勘察报告不符等确需调整的，重新审核、论证。

## 教材里怎么讲

- **质量与安全 8.2**「危险性较大的分部分项工程施工安全管理」：危大工程范围、专项施工方案编制与审查、专家论证、现场安全管理、验收与应急处置，是本方案范例九章结构的主要依据。
- **质量与安全 8.1**「安全风险管理」：危险源分类与风险分级，对应第一章的风险辨识与分级、第五章的监测监控。
- **质量与安全 1.3**「安全生产管理主要制度」第四部分「危大工程管理」：专项方案的编制、签字、论证要求及未编制、未审查的法律责任。
- **案例分析 3.12**「安全生产管理的监理工作」：专项施工方案的编制与审查、危大工程现场安全管理，对应监理审查本方案的考点。
- **案例分析 1.4**「建设工程安全生产管理条例」：监理单位未审查专项施工方案的法律责任。
