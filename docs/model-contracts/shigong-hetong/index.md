# 建设工程施工合同（示范文本）

<LawBanner />

本页梳理文本结构与教材对应关系，不做条款解读或评价。[读全文与条款原文 →](./full.md)

## 文本组成

《示范文本》由三部分组成：

1. **合同协议书**：共计 13 条，约定工程概况、合同工期、质量标准、签约合同价、项目经理、合同文件构成、承诺、词语含义、签订时间、签订地点、补充协议、合同生效等。
2. **通用合同条款**：共计 20 条，是合同当事人根据法律法规就工程施工事项作出的原则性约定。
3. **专用合同条款**：是对通用合同条款的细化、完善、补充、修改或另行约定，编号与通用条款对应。

另有 **附件** 11 份（承包人承揽工程项目一览表、发包人供应材料设备一览表、工程质量保修书、主要建设工程文件目录、承包人用于本工程施工的机械设备表、承包人主要施工管理人员表、分包人主要施工管理人员表、履约担保、预付款担保、支付担保、暂估价一览表）。

## 教材中明确提及的常见问题

以下问题在教材中有明确讨论，列示备查（不做展开解读）：

1. **监理人及总监理工程师的定义**：通用条款 1.1 对"监理人"和"总监理工程师"的含义作出约定（案例 2.2）。
2. **承包人的义务**：通用条款 3.1 约定承包人的一般义务，3.2、3.3 约定人员管理（案例 2.2）。
3. **监理人的职责与指示**：通用条款 4.1～4.4 约定监理人的一般规定、监理人员、监理人的指示、商定或确定（案例 2.2）。
4. **隐蔽工程检查**：通用条款 5.3 约定隐蔽工程检查程序及重新检查（案例 2.2）。
5. **施工组织设计与进度计划**：通用条款 7.1、7.2 约定施工组织设计和施工进度计划的提交与确认（案例 2.2）。
6. **不利物质条件与异常恶劣气候**：通用条款 7.6、7.7 分别约定不利物质条件和异常恶劣气候条件的处理（案例 2.2）。
7. **变更与变更估价**：通用条款 10.1、10.4 约定变更权与变更估价原则（案例 2.2）。
8. **竣工验收**：通用条款 13.2 约定竣工验收程序（案例 2.2）。
9. **争议解决**：通用条款 20.4 约定仲裁或诉讼（案例 2.2）。
10. **合同文件组成及优先解释顺序**：通用条款 1.5 约定合同文件的构成及优先解释顺序（合同管理 3.2）。
11. **缺陷责任期与质量保证金**：通用条款 15.2、15.3 约定缺陷责任期和质量保证金（合同管理 3.3）。
