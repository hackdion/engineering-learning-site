# 本站制作说明

这里说明工程学习手记如何整理教材、制作课程和维护页面。个人的其他作品会在个人总站中集中展示。

## 教材整理

教材正文按公开书目和版本信息整理，尽量保留原书的章、节、表格与公式，并为每册保留独立阅读入口。可以从[教材书架](/textbook/)查看当前可读内容。

## 课程制作

我选取已整理的章节制作视频或互动课件；课程中心只列出已经上线且可以打开的内容。互动课件由我撰写讲稿、设计练习并核对教材内容，使用 [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC) 项目呈现。现有示例是[《建设工程监理规范》互动课件](/courses/gl-2-2)。

## 页面维护

本网站由 hackdion 维护，记录教材和课程入口的更新。发现内容或页面问题，可通过[关于本站](/about)中的纠错邮箱联系我。

独立的 AI 工具实验和其他个人作品不属于本学习站的内容范围。
