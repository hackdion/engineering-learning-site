# 第一章 工程监理主要法律法规

工程监理的主要法律法规包括《中华人民共和国建筑法》《中华人民共和国招标投标法》《建设工程质量管理条例》《建设工程安全生产管理条例》等，这些法律法规对于保障工程质量、维护市场秩序、明确各方责任等具有重要作用。
