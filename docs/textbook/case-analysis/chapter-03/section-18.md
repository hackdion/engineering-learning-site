# 第十八节 费用与工期索赔管理

## （一）费用索赔管理

项目监理机构费用索赔管理的工作内容包括：

1. 及时收集、整理有关工程费用的原始资料，为处理费用索赔提供证据；

2. 审查索赔依据；

3. 受理和审查承包单位在承包合同约定的期限内提交的费用索赔意向通知书及索赔事件资料；

4. 受理和审查承包单位在承包合同约定的期限内提交的费用索赔报审表及证明文件资料；需要承包单位进一步提交详细资料的，应在承包合同约定的期限内发出通知；

5. 批准承包单位提出的费用索赔；

6. 协调建设单位、承包单位就索赔事项达成一致意见后，总监理工程师在费用索赔报审表中签署意见并报送建设单位；

7. 承包单位提出的费用索赔与工程延期申请相关联的，项目监理机构可对费用索赔和工程延期提出综合处理意见，并应与建设单位和承包单位协商达成一致意见；

8. 因承包单位原因造成建设单位损失，建设单位提出索赔的，项目监理机构应与建设单位和承包单位协商处理。

## （二）工期索赔管理

项目监理机构工期索赔管理的工作内容包括：

1. 受理承包单位提出的符合合同约定的工程延期要求；

2. 当影响工期事件具有持续性时，应对施工单位提交的阶段性工程临时延期报审表进行审查，并应签署工程临时延期审核意见后报建设单位；当影响工期事件结束后，应对施工单位提交的工程最终延期报审表进行审查，并应签署工程最终延期审核意见后报建设单位；

3. 在作出工程临时延期批准和工程最终延期批准前，均应与建设单位和施工单位协商；

4. 批准工程延期应同时满足下列条件：

（1）施工单位在施工合同约定的期限内提出工程延期；

（2）因非施工单位原因造成施工进度滞后；

（3）施工进度滞后影响到施工合同约定的工期。

5. 发生工期延误时，应按施工合同约定进行处理。
