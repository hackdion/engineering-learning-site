# 第一章 工程监理及其相关制度

工程监理制度自1988年开始实施以来，对于促进我国工程建设管理方式向社会化、专业化方向发展，保障工程质量和安全，提高工程建设管理水平和投资效益等发挥了重要作用。工程监理制与项目法人责任制、招标投标制、合同管理制统称为“四制”，共同构成我国工程建设领域的重要管理制度。
