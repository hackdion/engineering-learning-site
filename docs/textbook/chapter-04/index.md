# 第四章 工程监理招标投标与合同管理

工程监理任务可由建设单位直接委托，也可通过招标方式委托。但是，法律法规规定必须招标的，建设单位须通过招标方式委托。由此可见，工程监理招标投标是建设单位委托和工程监理单位承揽监理任务的主要方式。而且，工程监理合同管理是明确工程监理合同双方义务和责任、工程监理单位履行职责的重要保证。
