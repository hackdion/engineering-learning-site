# 第五章 工程承包模式及项目监理组织

由于不同工程的建设规模、建设性质、复杂程度等各不相同，会有不同的承包模式，即使是同一工程的不同标段，也会有不同的承包模式。基于不同的工程承包模式，建设单位会选用的工程监理委托方式也不相同。工程监理单位接受建设单位委托后，应在现场派驻项目监理机构，并明确实施监理的程序、原则及项目监理机构各层级监理人员的基本职责。
