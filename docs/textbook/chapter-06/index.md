# 第六章 工程监理规划及监理实施细则

监理规划是项目监理机构全面开展工程监理工作的指导性文件，监理实施细则是在监理规划的基础上，针对专业性较强、危险性较大的分部分项工程或某一专项目标监理工作编制的操作性文件。监理规划及监理实施细则的内容应全面具体，且需按程序报批后才能实施。
