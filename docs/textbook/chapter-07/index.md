# 第七章 工程监理工作内容和方式

工程监理的主要工作内容是通过合同管理、信息管理和组织协调等手段，控制工程质量、造价和进度目标，并履行建设工程安全生产管理的法定职责。审查核验、巡视、平行检验、旁站、见证等则是工程监理的主要工作方式。随着新一代信息技术的飞速发展，工程监理数智化也将成为必然趋势。
