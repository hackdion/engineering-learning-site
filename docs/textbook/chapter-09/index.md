# 第九章 全过程工程咨询及项目管理服务

全过程工程咨询是我国着力推行的一种咨询模式。工程监理单位可以拓展经营业务，扩大服务范围，为委托方提供全过程工程咨询或项目管理服务。值得指出的是，项目管理服务与全过程工程咨询密切相关，但与项目管理服务相比，全过程工程咨询的内涵更加丰富、服务范围更加广泛。此外，无论是工程监理还是全过程工程咨询或项目管理服务，风险管理及项目利益相关方管理均是值得重视的重要工作内容。
