# 第一章 工程合同管理法律制度

合同管理贯穿于工程项目全过程，是工程项目管理的核心，工程建设质量、投资、进度目标的设置及其管控，都是以合同为依据确立的，可以说，做好项目就是履行好合同。 尤其是在市场化、法制化不断完善的大背景下，合同管理越来越成为建设工程得以顺利实施的依托和保障，并对保护各方合法权益、维护社会经济秩序、推动建筑市场健康发展起着重要作用。知法守法、诚信履约、科学管控是工程交易有序进行和项目目标如期实现的关键。以下首先梳理工程交易方式及合同体系，进而提出从招标采购到合同签订与履行全过程的管理任务与方法；论述合同关系、委托代理关系、相关民事与刑事责任法律规定； 并介绍工程合同担保与工程保险两大基本制度，为开展建设工程项目合同管理提供法律基础。
