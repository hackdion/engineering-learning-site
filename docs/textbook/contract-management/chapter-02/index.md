# 第二章 工程勘察设计招标与合同管理

第二章工程勘察设计招标与合同管理

工程勘察设计是工程建设的龙头，也是工程材料设备采购、施工安装工作的依据，其成果质量对项目全局和全寿命周期有深远影响。以下分析勘察设计招标特点，梳理工程勘察设计招标和设计方案竞赛各环节主要工作；归纳勘察设计招标文件的文本组成和主要条款内容，提出勘察设计合同订立和履行的管理要点，为开展工程勘察设计招标和合同管理工作提供支持。
