# 第三章 工程施工招标与合同管理

工程施工阶段是将蓝图转化为实体的决定性阶段，也是施工单位、施工分包单位、监理单位履行义务和职责的重要阶段，其管理成效对工程项目目标的实现有直接影响。以下梳理工程施工招标方式、招标程序及主要工作；介绍施工招标文件的文本构成和主要条款内容；归纳施工合同、施工分包合同订立和履行的管理要点，为开展施工招标和施工合同管理工作提供重要支持。
