# 第四章 工程总承包招标与合同管理

工程总承包模式作为国际通行的工程项目发承包方式，以其整合设计、采购、施工的一体化、交钥匙承包优势，在我国工程建设领域得到推广。以下分析工程总承包的特点，梳理工程总承包招标方式、招标程序及各项主要工作；设计施工总承包招标文件的文本构成和主要条款内容；阐释工程总承包合同、分包合同订立和履行的管理要点。帮助合同当事人在工程总承包模式下做好管控工作，促进总承包项目顺利实施并成功交付。
