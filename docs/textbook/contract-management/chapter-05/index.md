# 第五章 工程材料设备采购招标与合同管理

工程材料与设备构成了工程实体和施工安装的物质基础，其质量、性能直接决定了工程的品质与安全，是项目建设过程中的重点管控对象。以下梳理工程材料设备采购报价方式、招标方式、招标程序及各项主要工作；详细阐述材料采购招标文件的文本构成、主要条款内容；阐释合同订立、履行的管理要点，为做好工程材料设备采购工作提供支持。
