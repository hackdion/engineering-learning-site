# 第六章 国际工程常用合同条件

随着经济全球化，国际工程合作日益频繁，从业者需要了解熟悉有广泛影响力的国际工程常用合同条件。以下阐述国际工程实践不同模式下的代表性标准合同条件，包括 FIDIC 施工合同条件、设计采购施工(EPC) 合同条件、设计施工和运营(DBO) 合同条件，NEC 工程施工合同，AIA 系列合同，以及合作伙伴管理理念。对比掌握不同合同体系的特点和要点，形成完整的建设工程合同规则框架，为做好国际、国内工程提供支持和借鉴。
