# 前言

为了更好地适应《监理工程师职业资格制度规定》及《监理工程师职业资格考试实施办法》要求，诠释《建设工程合同管理》科目考试大纲，中国建设监理协会组织专家编写本书。 由于《建设工程合同管理》科目属于基础科目，土木建筑工程、交通运输工程、水利工程三类专业人员都需要参加本科目测试。为此，本书力求兼顾土木建筑、交通运输、水利三个专业工程领域，依照通用标准招标及合同文件、国家相关法律法规编写相关内容。 本书共分六章，包括：工程合同管理法律制度；工程勘察设计招标与合同管理；工程施工招标与合同管理；工程总承包招标与合同管理；工程材料设备采购招标与合同管理； 国际工程常用合同条件。 本书由姜军(北京建筑大学教授)、赵振宇(华北电力大学教授)主编，刘伊生(北京交通大学教授)主审。第一章、第二章、第五章由赵振宇编写，第三章、第四章由姜军、任旭(北京交通大学教授)编写，第六章由赵振宇、花园园(北京建筑大学副教授) 编写。 本书是在原全国监理工程师学习丛书《建设工程合同管理》的基础上编写而成，在此，谨向原书编审者致以诚挚的谢意! 本书难免有不妥之处，请广大读者批评指正。
