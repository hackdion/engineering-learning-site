## 阅读方式

1. 从左侧目录进入章导读，再按节阅读正文。
2. 页面底部可使用「上一篇 / 下一篇」连续阅读；右侧「本节目录」可跳转到节内小标题（含四级标题）。
3. 搜索框支持中文全文搜索，标题、正文与表格内容均可检索。
4. 图表可点击「放大查看」，在手机上也便于阅读细节。
