# 第二章 资金时间价值与价值工程

建设工程投资控制活动中，考虑资金时间价值能够提高投资决策的科学性、资金使用的合理性、资金运作的经济性；在建设工程活动中应用价值工程，能够提升工程活动及其成果的价值，使工程活动在满足客户和社会对产品和服务需求的同时，促进企业持续创新，推动节约型社会建设。
