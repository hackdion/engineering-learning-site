# 第七章 工程招标阶段投资控制

工程量清单计价方式是随着我国建设领域市场化改革的不断深入发展而来。自2003年起在全国推广这种计价方式以来，历经2003版、2008版和2013版的不断改进。自2025年9月1日起实施的《建设工程工程量清单计价标准》GB/T50500—2024突出了由市场形成工程交易价格的本质，在招标人提供工程量清单的基础上，各投标人进行自主竞价，由招标人择优选择并形成最终的合同价格。在这种计价方式下，合同价格更能体现市场交易的真实水平，并且能更合理地对合同履行过程中可能出现的各种风险进行合理分配，提升发承包双方的履约效率。

《建设工程工程量清单计价标准》GB/T 50500—2024适用于建设工程施工发承包及实施阶段的计价活动，内容包括:总则、术语、基本规定、工程量清单编制、最高投标限价编制、投标报价编制、合同工程计量、合同价款调整、合同价款期中支付、工程结算与支付、工程价款争议的解决以及工程计价成果与档案管理。
