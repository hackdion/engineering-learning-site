# 第九章 工程投资控制数智化

建筑信息模型（BIM）、大数据、人工智能等现代信息技术和资源，为建设工程管理提供了数字化、智能化支持，确保投资控制的科学性与精准性。对工程监理单位而言，无论是提供单项咨询服务，还是开展全过程工程咨询，都需要转变思维方式，充分利用现代信息技术，使投资控制实现数字化的精确预算和智能化的动态调控，从而提升投资效益和项目管理质量。本章重点介绍 BIM、大数据和人工智能的基本特征及其在工程投资控制中的应用。
