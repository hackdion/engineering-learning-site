# 第二章 流水施工组织方式

流水施工是一种科学、有效的工程项目施工组织方法之一，它可以充分利用工作时间和操作空间，减少非生产性劳动消耗，提高劳动生产率，保证工程施工连续、均衡、有节奏地进行，从而对提高工程质量、降低工程造价、缩短工期发挥显著的作用。
