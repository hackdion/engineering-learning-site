# 第四章 工程进度计划实施监测与调整

确定工程进度目标，编制一个科学、合理的进度计划是监理工程师实现进度控制的首要前提。但是在工程项目的实施过程中，由于外部环境和条件的变化，进度计划的编制者很难事先对项目在实施过程中可能出现的问题进行全面的估计。气候的变化、不可预见事件的发生及其他条件的变化均会对工程进度计划的实施产生影响，从而造成实际进度偏离计划进度，如果实际进度与计划进度的偏差得不到及时纠正，势必影响进度总目标的实现。为此，在进度计划的执行过程中，必须采取有效的监测手段对进度计划的实施过程进行监控，以便及时发现问题，并运用行之有效的进度调整方法来解决问题。
