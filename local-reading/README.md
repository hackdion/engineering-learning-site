# 教材本地阅读（local-reading）

本目录是 2026 版《建设工程监理概论》的**本地阅读专用** VitePress 根，独立于公开站 `docs/`，不参与公开构建与部署。

## 启动与构建

```bash
npm run dev:reading      # 本地预览（开发服务器）
npm run build:reading    # 构建静态产物
npm run preview:reading  # 预览构建产物
```

产物目录为 `local-reading/.vitepress/dist/`，已在 `.gitignore` 中忽略，不进入公开仓库。

## 内容边界

- 教材正文只放在 `local-reading/chapter-*/`，该目录已被忽略，不入公开仓库。
- 骨架文件（`index.md`、`README.md`、`.vitepress/config.mts`、`.vitepress/theme/`）保持入库，便于维护。
- 公开站 `docs/` 不受本目录影响。

## 中文搜索

VitePress 默认按空白与标点切词，中文整句会变成一个超长词条，句中词（如「最低资本金比例」）无法命中。现已在 `.vitepress/config.mts` 配置 `cjkFriendlyTokenize`：汉字连续串切成「单字 + 相邻二字组合」，英文与数字按整段切分，标题、正文与表格文字都参与索引。建索引与浏览器查询使用同一函数（VitePress 会序列化该函数到客户端）。

## 推进方式

按「完成一章、核对一章、交付一章」推进：

1. **完成一章**：整理该章导读与各节正文，补全页码信息。
2. **核对一章**：以原 PDF 页图为依据逐段比对文字与页码，更新每节的 `reviewStatus`；MinerU 识别稿只作检索底稿。
3. **交付一章**：核对通过后，在侧边栏启用该章条目，并记录到素材来源清单。
4. **状态分开记录**：`reviewStatus` 记 AI 核对结果，`userAcceptance` 记用户验收，`publicationAuthorization` 记公开授权，三者不得互相替代。
